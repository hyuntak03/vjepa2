> **3줄 요약**
> - **질문** — 지금까지의 결과 (릴리즈 진단 · 원인 사슬 · 보조 감독 여러 판 · imagine-seg 공정 비교 · WROP 세 판 · 공동 연구자 계획) 를 한 논문으로 묶으면 무슨 이야기인가.
> - **답** — "latent world model 은 가려진 물체를 **읽히게 담지만** 미래에 **그리지 않는다**. 그리게 만드는 것은 감독 구조가 아니라 **학습 미래에서 가려진 것이 돌아오는 빈도**다." 진단 · 원인 · 개입 (음성 대조 + 데이터 양성) 은 이미 측정으로 선다. 빠진 것은 **실제 영상으로의 이식** 하나다.
> - **다음 할 일** — ① 캐시만으로 방향 평균 분해 · 학습 데이터 재등장률 (하루) → ② seed 2 개 + 가림 비율 용량-반응 (GPU 4 장 약 1.5 일) → ③ 추적 기반 실제 영상 가림 합성 + 실제 평가셋 200 쌍 이상.

근거 표시: [측정] 산출물 · 비교표에서 다시 읽은 값 · [이론] 정의 · 계산 · [추측] 아직 안 잰 것.

## 용어

| 용어 | 뜻 |
|---|---|
| 릴리즈 predictor | 공개 V-JEPA 2 ViT-H predictor. encoder 는 끝까지 고정 |
| post-train | 릴리즈 predictor 에서 시작해 같은 손실 (문맥 16 장 → 미래 16 장 latent L1) 로 이어 학습. 라벨 · 불가능 영상 없음 |
| 늦은 가림 | 가림이 문맥 끝에 걸려 미래 앞부분까지 이어지는 꼴. 다시 보임은 미래 안에서 |
| 읽힘 | 학습한 판독기 (probe · 보조 head) 가 은닉이나 예측 표현에서 가려진 물체 정보를 꺼낼 수 있음 |
| 그려짐 | 예측 미래 토큰의 물체 자리에 물체다운 토큰이 있어서, surprise 채점이 그것을 씀 |
| 학습 미래 | post-train 때 정답으로 쓰는 미래 구간 토큰들. 이것의 분포가 L1 의 최적 예측을 정한다 [이론] |
| 재등장률 | 학습 클립 가운데, 문맥 끝에 가려져 있던 내용이 미래 안에 다시 보이는 비율. 데이터 통계이고 모델과 무관 |
| 방향 A / B | 4 중항 쌍의 두 방향. A = 문맥에 물체가 있음 (사라지면 위반), B = 문맥에 물체가 없음 (생기면 위반) |
| 방향 평균 | 같은 4 중항 세트에서 A · B 정확도의 평균. "빈 미래가 싸다" 같은 결과 편향은 A 를 내리고 B 를 올려 상쇄되므로, 남는 것은 **문맥에 따라 예측을 바꾼 몫** 이다 [이론] |
| B · C · D 판 | WROP 실험의 세 post-train. B = SSv2 만 · C = SSv2 + WROP 가림 계열 · D = SSv2 + WROP 비영속 계열 (같은 엔진 대조군) |

## 1. 한 문장, 제목 후보

**한 문장** — 가려진 물체에 대한 latent predictor 의 예측은 학습 미래가 정한다. 은닉에 무엇을 더 읽히게 하든 출력은 그대로이고, 학습 미래에 "가려진 것이 돌아온다" 를 흔하게 만들면 출력이 바뀌고 다른 렌더 엔진으로 넘어간다.

제목 후보 (영문, 논문용):
1. *Decodable, Not Predicted: What Teaches a Latent World Model Object Permanence*
2. *Out of Sight, Out of Latent: Object Permanence in JEPA World Models Is Set by Their Training Futures*

**Framing** — 공동 연구자 계획의 "permanence = 시간축 amodal completion" 을 그대로 쓴다. 공간 amodal (지금 프레임에서 가려진 부분) 은 encoder 가 이미 하고, 시간 amodal (지금 가려진 물체를 미래에 그리기) 은 predictor 가 해야 하는데 안 한다.

**왜 corner case 가 아닌가** [이론] — 평가에서는 창을 밀어 (sliding) 물체가 보이는 경계를 고를 수 있다. 그래서 IntPhys 류에서 늦은 가림이 가려진다 (정지 · 가림 모양 위반이 고정 창 46.9 → 창 밀기 최고 90.6 [측정]). 그러나 planning 에서 **문맥 끝은 언제나 "지금"** 이다. 지금 가려진 물체 (주차된 차 뒤 보행자, 컵 안의 공) 는 정의상 늦은 가림이다. 늦은 가림은 벤치마크의 구석이지만 배치의 기본 상황이다.

## 2. 이야기 줄기 — 다섯 막

### 막 1. 진단 — 읽히지만 그려지지 않는다 (있음)

| 주장 | 근거 |
|---|---|
| 정보는 남아 있다 | 등가속 + 가림에서 예측 표현 probe: 모양 98.46 · 색 99.49 · 장면 100. 같은 조건 채점 민감도 4.46 [측정] |
| 그려지지 않는다, 늦은 가림에서만 | 예측 미래에 물체다운 토큰이 남는 슬롯: 늦은 가림 **0** · 이른 · 중간 가림 3 · 가림 없음 4–5 [측정]. VOBench 늦은 가림 · 방향 A 정확도 13.9 % (우연 50 아래) [측정] |
| 빈 미래가 싸다 (결과 편향) | VOBench 늦은 가림 A 13.9 / B 94.4 · 실제 영상 4 중항 A 25 / B 70 [측정]. 무엇이 있었든 "없음" 쪽 미래가 surprise 가 낮다 |

- 이전 v11 분석 논문의 막 1–2 ("정보는 남고 배치가 무너진다") 를 압축해 여기에 넣는다.
- 공동 연구자 계획의 능력 표로 옮기면: 개체화 · 앞뒤 (encoder) 는 됨, **부재 (능력 6) 는 릴리즈가 이미 잘함 — 빈 미래가 싸서**. 진짜 실패는 위치 유지 · 재등장 (능력 4 · 5) 이다.

### 막 2. 원인 — 학습 미래에서 영속은 흔한 답이 아니다 (거의 있음)

| 주장 | 근거 |
|---|---|
| 실제 영상의 학습 미래에는 재등장이 드물다 | 가려진 내용이 2 초 안에 돌아오는 비율 (물체 단위, 점 추적기): 움직이는 내용 0.31 · 정지 내용 0.43 [측정] |
| 그래서 L1 의 최적은 "빈 미래" 다 | 칸 · 차원별 L1 의 최적 = 조건부 중앙값 [이론]. 재등장이 절반 미만이면 중앙값은 "안 돌아옴" |
| 정지 물체의 영속처럼 보이는 것은 시간 평균이다 | 최근 8 블록 평균만으로 정지 · 늦은 가림 물체 유지 100 % [측정, 블록 AR] |

- ⚠️ 이 막의 근거 일부는 사용자의 블록 AR 에서 잰 것이다. 본문은 릴리즈 predictor 로 통일해야 하므로, 재등장률은 그대로 쓰고 "시간 평균" 은 릴리즈에서 다시 잰다 (§4 의 E2).
- 이 레포 규칙 "목적함수를 원인으로 걸지 않는다" 와의 관계: 주장은 **"같은 목적함수 아래에서 학습 데이터가 정한다"** 이고, 데이터만 바꾸는 post-train 으로 검증한다. 목적함수 탓은 discussion 한 문단으로 둔다.

### 막 3. 안 되는 것 — 은닉을 감독하면 읽힘만 오른다 (있음)

같은 데이터에서 감독 구조만 바꾼 판들. 다섯 가지가 같은 꼴이다.

| 개입 | 학습 데이터 | 읽힘 | 그려짐 · 이식 |
|---|---|---|---|
| 보조 기억 모듈 (predictor 고정) | 3D 합성 v1 | — | 손실은 3.2 % 줄지만 재등장 칸에 특혜 없음 (배경 보정) [측정] |
| 칸 분류 head | 3D 합성 v1 | 가려진 칸 재현율 0 → 0.64 | 다른 생성기 칸 IoU 20.8 = "문맥 끝 그대로" 19.8 [측정] |
| 이동량 head | 3D 합성 v1 | VOBench 이동 오차 −31 % | VOBench 채점 61.7 → 58.8 [측정] |
| predictor 열기 + 출력 head | 3D 합성 v1 | 출력에서 재현율 0.64 | VOBench 늦은 가림 61.8 → 60.6 (p 0.48) [측정] |
| **공정 비교: 대조군 · 보조 head · 경로 안 (in-path)** | 3D 합성 v1 | 0.69–0.75 | 네 세트 모두 대조군과 구별 안 됨 (p 0.31–1.00) [측정] |
| 대조군 · 모듈 · head | VOBench (재등장 보상 큼) | head 1.00 | 생성기 안 75.7 → 87–92 **셋 다 같이**, IntPhys 2 · 실제 영상 셋 다 릴리즈 근처 [측정] |

- 이유 [이론]: 학습 미래가 같으면 출력의 최적이 같다. 경로 안 판도 시험 때는 자기 추측을 쓰는데 그것은 문맥의 함수라 최적을 안 바꾼다.
- 재등장 보상이 작은 데이터 (3D 합성 v1) 와 큰 데이터 (VOBench) **둘 다에서** 구조가 대조군을 못 이긴다. "바닥 효과라서 구조 차이가 안 보였다" 는 반론을 막는다 [측정].
- **이 막은 공동 연구자 계획의 "보조 head 없이, 관찰만으로" 원칙을 실험으로 정당화한다.** 음성 결과지만 논문의 기둥이다.

### 막 4. 되는 것 — 학습 미래를 바꾸면 출력이 바뀌고 엔진을 넘는다 (있음, seed 1)

| 세트 | 릴리즈 | B (SSv2) | **C (+가림)** | D (+비영속) | C 대 D (같은 쌍) |
|---|---:|---:|---:|---:|---|
| VOBench 방향 A (360 쌍) | 68.3 | 72.8 | **77.2** | 65.8 | 41 / 0 |
| VOBench 늦은 가림 · A (36) | 13.9 | 13.9 | **41.7** | 11.1 | 11 / 0 |
| VOBench 늦은 가림 · B (36) | 94.4 | 91.7 | 91.7 | 88.9 | 1 / 0 |
| **VOBench 늦은 가림 방향 평균 (72)** | 54.2 | 52.8 | **66.7** | 50.0 | 12 / 0 |
| IntPhys 1 영속 (60) | 70.0 | 68.3 | **76.7** | 65.0 | 7 / 0 |

- **엔진을 넘는다** — Blender (WROP) 로 배운 것이 Unreal (VOBench) · IntPhys 1 에서 보인다 [측정]. 앞선 VOBench post-train 은 같은 생성기 안에서만 올랐다.
- **엔진 익숙함이 아니라 가림 내용이다** — 같은 엔진 · 같은 양의 D 는 오히려 내려간다 [측정].
- **편향 이동이 아니라 문맥 조건화다** — A 가 오를 때 B 가 그대로라 방향 평균이 52.8 → 66.7 로 오른다 (C 대 B 12 / 2, p 0.01) [측정, 비교표에서 계산]. "가림막 뒤엔 뭔가 나온다" 로 기울었다면 B 가 내려가 평균이 제자리였어야 한다 [이론].
- 단서: 늦은 가림 · A 는 41.7 % 로 아직 우연 아래이고, 쌍 차이 중앙값이 0 근처다. "확실히 그린다" 가 아니라 "강한 반대 편향을 없앴다" 까지다 [측정]. seed 하나.

### 막 5. 경계 — IntPhys 2 · 실제 영상에서 멈춘다 (원인 미측정)

| 세트 | 릴리즈 | B | C | D |
|---|---:|---:|---:|---:|
| IntPhys 2 (500 쌍) | 54.6 | 52.8 | 53.6 | 53.4 |
| IntPhys 2 영속 (120) | 58.3 | 50.0 | 55.0 | 56.7 |
| 실제 영상 4 중항 (40) | 47.5 | 42.5 | 42.5 | 42.5 |

원인 후보 셋 — 이것을 가르는 것이 남은 실험의 중심이다:
1. **렌더 외형에 걸린 행동** [추측] — 배운 영속이 "합성처럼 보이는 장면" 에서만 켜진다. 같은 꼴이 운반에서 이미 재졌다: VOBench 를 섞은 AR 은 옮길지를 렌더 외형으로 정했다 (흐름 모양만으로 합성 / 실제 구별 AUROC 0.82–0.84) [측정, 다른 능력]. 실제 영상의 결과 편향이 C 에서 전혀 안 줄었다 (A 25 → 20) 는 것도 이쪽과 맞는다.
2. **IntPhys 2 가 재는 것** [측정] — 같은 결과 영상을 짝마다 가능 · 불가능으로 엇갈려 넣어서, 결과만 보는 surprise 는 설계상 50 % 다. 지금까지 잰 모든 모델의 문맥 항이 0 이다. C 의 문맥 항은 아직 안 쟀다.
3. **실제 평가가 너무 작다** [이론] — 40 쌍은 표준오차 약 ±8 pt 이고 판마다 갈린 쌍이 4 개뿐이다. 지금 크기로는 "안 넘어간다" 도 말할 수 없다.

| E3 | B · C · D seed 2 개 더 | GPU 4 장 × 약 8 시간 | 막 4 확정 | 막 4 철회 — 일찍 아는 게 싸다 |
| **E4** | 용량-반응: WROP 몫은 50 % 로 고정하고, 그 안의 가림 계열 비율만 0 / 25 / 50 / 100 % (0 = D, 100 = C 라 새 판은 둘) | GPU 4 장 × 약 4 시간 | 단조 증가 → "학습 미래가 정한다" 의 인과 증거, 엔진 노출이 같으니 교란 없음 | 계단 · 포화 → 문턱이 있다는 것 자체가 결과 (C 의 이득이 첫 400 step 에 다 생긴 것과 맞물림) |
| **E5** | 실제 영상 가림 합성 (추적한 움직이는 점 묶음 위로 가림막이 지나가 내용이 돌아오게) 으로 post-train. **선행 조건: 실제 평가 200 쌍 이상** | 데이터 생성 + GPU | 실제 영상 · IntPhys 2 영속이 오름 → 방법 논문으로 닫힌다 (막 5 원인 = 외형) | 안 오름 → 붙인 가림막 지름길 또는 IntPhys 2 는 영속 밖 능력. 분석 논문으로 닫힌다 |
| E6 | WROP 생성기 개조: 문맥에서 물체 지우기 · 재등장 시간 / 자리 비틀기 (곡선) | Blender 4.4 결정 필요 | 기억의 인과 증거 · 곡선 그림 | — (E1 이 대부분 대신한다. 시간이 남으면) |

**E5 제안 관문 (레포 8 줄)** — 이미 `imagine-seg` 추적 감독 설계 §7 에서 통과시킨 안 (가) 를 그대로 쓴다. 요점: 생성 · 비교는 미래 토큰 L1 그대로 (토큰을 옮기지 않음) · 릴리즈 구조, 모듈 없음 · 학습 미래에 재등장이 들어가 최적이 바뀜 [이론] · 시험 입력에 라벨이 안 들어감 · 판정은 실제 가림부터. 경로 감독 (나) 는 최적을 안 바꾸므로 (가) 위의 비교 판으로만.

**실제 평가셋** — 공동 연구자 계획에 "준비된 실제 영상 평가셋 (다양한 가림막 · 사라짐 · 생김)" 과 주행 VoE 가 있다. 이것을 받아 오는 것이 E5 보다 먼저다. 40 쌍으로는 E5 가 성공해도 말할 수 없다.

## 6. 공동 연구자 계획과의 관계

| 계획 항목 | 이 스토리에서 | 이유 |
|---|---|---|
| 관찰만으로, 보조 head 없이 | **본선** | 막 3 이 실험으로 정당화 |
| A · B · C 판, C − 부재 | **본선** (+ D 를 더함) | 막 4 |
| 능력 1–6 분리 측정 | 막 1 의 표로 압축 | 1 · 3 은 v11 probe 로 이미 있음, 6 은 릴리즈가 이미 높음 |
| 부재 클립 | **대조로** 유지 | 부재는 원래 쉬우니, 목적은 능력 6 을 올리는 것이 아니라 C 가 "뭔가 나온다" 로 빠지지 않는지 막는 것 |
| 재등장 tuning curve · context ablation | E6 로 뒤로 | E1 (방향 평균 · 문맥 항) 이 기억 대 사전 지식을 학습 · 생성 없이 대부분 가른다 |
| 도메인 사다리 · leave-one-out | 그림 4 | 그릇 계열 이식은 예측 오차로만 재져 있고 보통 이식 범위 안 — 위반 판별로 다시 재야 주장 가능 |

| Peekaboo (문맥에서 물체 토큰 지우기) | 선택 | 시험 때 가림은 가림막 토큰으로 오지 빈 토큰으로 오지 않는다 → 형식이 다르다 [이론] |
| 부작용 점검 | **본선** | B 가 IntPhys 2 영속을 58.3 → 50.0 으로 떨어뜨렸다 (p 0.07) [측정]. 표준 평가 · 보류 예측 손실을 같이 보고 |

## 9. 위험과 다른 framing

- **E5 가 실패하면** — 제목 1 (분석) 로 간다. 막 5 가 "배운 영속은 외형에 걸려 있다" 가 되려면 외형을 바꾼 대조 (예: VOBench 를 실제 질감 쪽으로 옮긴 판) 가 하나 필요하다 [추측].
- **E1 이 문맥 항 0 을 내면** — 막 4 가 "강한 반대 편향을 지운다" 로 약해진다. 그래도 막 3 대비 (구조 0 · 데이터 양) 는 남는다.
- **방법 논문 framing ("관찰만으로 영속 가르치기")** — 지금 근거로는 이르다. 실제 영상 이식이 서기 전에는 쓰지 않는다.
- **v11 분석 논문과의 관계** — 하나로 합치기를 권한다. v11 의 "정보는 남고 배치가 무너진다" 가 막 1 이 되고, 09-03 비판 ("corner case") 은 §1 의 planning 논리로 답한다. 정렬 사상 (frozen 개입) 은 부록으로 내린다. 둘로 나누는 것도 가능하지만 v11 단독은 "그래서 어떻게 고치나" 가 비어 있다.
