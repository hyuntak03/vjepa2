# Imagine-then-Predict: V-JEPA2 Predictor Post-training 지침

> 2026-10-31 사용자가 준 원문을 그대로 옮겼다. 고치지 않는다 — 바뀐 결정은 이 폴더의 다른 문서에 날짜와 함께 적는다.
> 데이터 생성 계획: `DATA_PIPELINE_2026-10-31.md`

> 목적: V-JEPA2 predictor가 가려진 물체를 "상상"하고, 그 상상을 이용해 재등장을 예측하도록 post-training한다.
> 대상 능력: object permanence (완전 가림 동안 물체의 존재·위치 유지)
> 상태: 초안 v0 (2026-10-31). 하이퍼파라미터는 모두 시작값이며 튜닝 대상.

---

## 0. 배경과 철학

### 이전 시도에서 배운 것
- predicted feature 전체에 보조 head를 달아 가려진 물체의 shape/color를 regression → **head는 학습되지만 IntPhys2 surprise는 개선 안 됨.**
- 해석: regression target이 클립 안에서 상수라서, predictor가 물체 attribute를 모든 토큰에 broadcast하는 **shortcut**으로 해결. "무엇을 봤나"는 기억하지만 "어디에 아직 있나"는 학습 안 됨.
- 더 근본적으로: **decodable ≠ used.** surprise는 predictor 출력과 target의 거리로 계산되므로, 정보가 feature 안에 있어도 출력 예측에 쓰이지 않으면 점수는 그대로.

### 설계 원칙
1. **Localized supervision**: 토큰·프레임마다 정답이 달라야 broadcast shortcut이 막힌다 → per-token amodal mask.
2. **In-path, not side-head**: 상상(mask)이 예측의 *원인*이 되도록 forward 경로 안에 넣는다.
3. **Surprise 위치 정렬**: 학습 신호가 평가 시 surprise가 계산되는 곳(예측 구간의 재등장)에 걸리게 한다.
4. **No impossible videos**: 학습에는 현실에서 관찰 가능한 영상만 쓴다. impossible 영상은 평가 전용.

### Framing
amodal mask는 외부 label이므로 엄밀히 "관찰만으로"는 아니다. 주장은 다음과 같이 잡는다:
> perception(segmentation)은 이미 갖췄다고 가정하고, 그 위에서 *상상*을 학습한다. (cf. position paper "World Models Should Learn to Perceive Before They Act")

## 1. 고정된 결정 사항

| 항목 | 결정 |
|---|---|
| Backbone | V-JEPA2 pretrained |
| Encoder (context / target) | **동결** |
| Predictor | pretrained predictor에서 시작해 **post-training** |
| JEPA target | 동결 encoder에 **가려진 영상**을 넣은 출력 (setting (a): 실제 관찰 그대로) |
| 상상 신호 | amodal mask (in-path conditioning) |
| 학습 데이터 | SSv2 + 자동 가림 합성 (파일럿), 이후 K400 추가 |
| 평가 데이터 | IntPhys2, 자체 driving VoE 벤치마크 (학습에 미사용) |

## 2. 데이터 파이프라인 (SSv2 + 자동 가림 합성)

V-JEPA2 사전학습 분포에 SSv2/Kinetics가 포함되어 있으므로, 같은 영상으로 vanilla baseline을 돌리면 도메인 효과가 제거되고 **가림 경험의 효과만** 남는다.

### 2.1 클립 준비
- 클립 길이·해상도·fps는 **IntPhys2 평가 세팅과 동일**하게 맞춘다 (`T_total`, `H×W`).
- context 구간 `T_ctx`와 예측 구간 `T_pred`도 평가 프로토콜과 동일하게 정의.
- 파일럿 규모: SSv2에서 가림 클립 1~2만 개.

### 2.2 Target 물체 추출 (SAM2)
1. 첫 프레임에 automatic mask generation → SAM2로 클립 전체 propagate.
2. 필터 (모두 만족해야 target 후보):
   - 면적: 프레임 대비 약 2~15% (SSv2는 물체가 크므로 상한 필수)
   - 추적 안정성: 프레임 간 mask 연속성 기준 통과, 중간에 끊기지 않음
   - 움직임: centroid 변위가 임계값 이상
   - (K400 사용 시) 사람 클래스 편중 방지 필터
3. **원본에서 물체가 다 보이므로, 이 mask가 곧 amodal GT.**

### 2.3 Occluder bank
- SA-1B 또는 COCO에서 물체 cutout 수집.
- 크기는 target bbox를 완전히 덮도록 스케일 (여유 margin 포함).
- 경계에 Gaussian blur (Amodal SAM의 TAOS 방식 참고).

### 2.4 가림 스케줄 (가장 중요)
- 순서: **물체가 context 앞쪽에서 충분히 보임 → 완전 가림 → 예측 구간 안에서 재등장.**
- 제약:
  - 가림 전 visible 프레임 ≥ `k_vis`
  - 완전 가림 프레임 수 `d_occ` (target mask의 ≥95%가 occluder에 덮인 프레임)
  - 재등장은 반드시 `T_pred` 안
- 두 모드를 섞는다:
  - **moving occluder**: occluder가 물체 위를 가로질러 지나감
  - **static occluder**: 물체의 이후 궤적 위에 정지한 occluder를 배치
- 통제 변수로 저장: occluder 폭, `d_occ`, 물체 속도, 재등장 타이밍 (분석용).
- occluder는 우선 화면 고정(screen-space)으로 시작. 카메라 움직임 보정은 후순위 비교 실험.

### 2.5 품질 필터
- 완전 가림 조건 미달 클립 제거
- 추적 실패/끊김 클립 제거
- (선택) VLM으로 비정상 합성 필터링

### 2.6 저장 포맷 (클립당)
```
occluded_video      # context encoder 입력, JEPA target 입력
clean_video         # (현재 세팅에선 미사용, 추후 setting (b)용)
amodal_mask[t]      # 프레임별, SAM2 on clean
occluder_mask[t]
occ_interval        # (start, end) 완전 가림 프레임 인덱스
meta                # occluder 폭, 속도, mode 등
```

### 2.7 혼합 비율
- 학습 배치: **가림 클립 50% + 원본 SSv2 50%**
- 원본 클립에는 mask loss를 걸지 않음 (또는 visible mask로 걸지 여부는 ablation).

## 3. 모델 수정

### 3.1 구조
```
occluded video ─▶ [Encoder (frozen)] ─▶ context tokens
                                          │
                       + mask tokens (예측 위치)
                                          ▼
                        Predictor layers [1 .. L_split]
                                          │
                                          ├─▶ Mask head (linear) ─▶ occupancy logit (per token)
                                          │                               │
                                          │          ŝ = sigmoid(logit) 또는 GT (scheduled sampling)
                                          │                               │
                                          ◀── + ŝ · e_mask  (learned vector) ◀┘
                                          ▼
                        Predictor layers [L_split+1 .. L]
                                          ▼
                               predicted features ─▶ JEPA loss
```

### 3.2 세부
- `L_split`: predictor depth의 절반 근처에서 시작 (ablation: 1/4, 1/2, 3/4).
- Mask head: 토큰 차원 → 1 (linear). **가볍게 유지** (무거우면 head가 일을 흡수).
- Mask embedding `e_mask`: 학습 가능한 벡터 1개, **zero-init** → 학습 시작 시 pretrained predictor 동작을 그대로 보존.
- 예측 대상 토큰 위치에만 occupancy 예측 (context 위치 포함 여부는 ablation).

## 4. 학습

### 4.1 Task
- 평가와 동일: context = 앞쪽 `T_ctx`, 예측 = 뒤쪽 `T_pred`의 feature.
- forgetting 방지를 위해 V-JEPA 기본 multiblock masking 배치를 소량 혼합 (예: 20%).

### 4.2 Loss
```
L = L_jepa + λ · (L_bce + L_dice)
```
- `L_jepa`: L1(predicted, sg(Encoder(occluded_video)))  — 예측 위치 토큰
- `L_mask`: amodal GT를 토큰 그리드(spatial patch × tubelet)로 다운샘플 (패치 내 비율 → soft target 또는 threshold)
- `λ` 시작값: 1.0 (L_jepa 스케일 보고 조정)

### 4.3 Scheduled sampling
- 3.1의 ŝ에 들어가는 값:
  - 학습 초반: GT mask 100%
  - 선형으로 감소 → 후반: 예측 mask 100%
- 목적: predictor가 mask 경로에 **의존하는 습관**을 먼저 만들고, 이후 자기 상상으로 대체.

### 4.4 최적화 (시작값)
- 학습 대상: predictor 전체 + mask head + `e_mask`
- LR: pretraining보다 낮게 (예: 1e-5 ~ 5e-5), warmup 후 cosine
- 파일럿: 수 epoch, 매 epoch IntPhys2 permanence 서브셋 surprise 모니터링

## 5. 비교군 (같은 데이터 · 같은 step · 같은 init)

### 5.1 메인 테이블

| | mask 없음 | aux head | imagine-then-predict |
|---|---|---|---|
| target = occluded (a) | **vanilla post-train** | decodability만 | **본 method** |
| target = clean (b) | 관찰 기반 (method 1·2 계열) | – | method + 관찰 신호 |

- 1차 목표: (a) 행 세 칸. "head로 붙이면 안 되고, 경로 안에 넣어야 된다"를 정면으로 검증.
- (b) 행은 2차.

### 5.2 Ablation
- **modal vs amodal**: visible mask로 조건화 → amodal이 이겨야 "상상" 주장 성립
- `L_split` 위치
- scheduled sampling 유무 (GT 고정 / 예측 고정)
- 원본 클립에 visible-mask loss 적용 여부
- 기존 regression head 결과 → motivation 실험으로 포함

## 6. 평가

1. **IntPhys2 permanence 조건**
   - 표준 프로토콜
   - 재등장 시점에 정렬한 surprise
   - (진단) 물체 영역 토큰만으로 계산한 surprise
2. **자체 driving VoE 벤치마크**: 도메인 일반화
3. **Held-out 합성 클립**: 가려진 영역 mask IoU (mIoU_full, mIoU_occ)
4. **원본 능력 유지**: 일반 SSv2/K400 클립 예측 loss가 vanilla 대비 크게 악화되지 않는지

---

## 7. Sanity check (필수)

- **개입 테스트**: inference 시 mask 경로에
  - (i) 0을 넣음, (ii) 다른 위치로 이동한 mask, (iii) GT mask
  를 넣고 surprise 변화를 본다. 변하지 않으면 predictor가 mask를 무시하는 것 → 본 method의 핵심 주장 실패.
- **Shortcut 확인**: vanilla 대비 predicted feature 변화량(Δ)을 토큰별로 시각화. 물체 위치에 집중되어야 함 (전 토큰 균일 = broadcast).
- **Artifact 확인**: occluder 경계만 보고 맞추는지 — blur 강도 바꿔도 결과 유지되는지.

## 8. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| predictor가 mask 입력 무시 | scheduled sampling, 개입 테스트로 감시, `e_mask` 스케일 조정 |
| 합성 경계 artifact 학습 | Gaussian blur, 평가 도메인 분리(IntPhys2/driving) |
| SSv2 물체가 너무 큼 | 면적 상한, occluder 크기 제한 |
| 일반 예측 능력 저하 | 원본 50% 혼합, multiblock 소량 혼합, 낮은 LR |
| "관찰만으로" 원칙 위배 지적 | perception-first framing, (b) 행 관찰 기반 결과와 함께 제시 |
