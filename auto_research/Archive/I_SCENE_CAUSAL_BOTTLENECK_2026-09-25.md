## 1. 왜

지금까지는 **관찰** 과 **상관** 까지다.
- 관찰: 멈춤이 거리로 모인다.
- 상관: reach 가 긴 predictor 는 attention 거리 감쇠가 완만하다.

병목 후보는 셋이고, 셋을 **개입** 으로 가른다.
- (a) **attention 규칙**: 양방향 (release 학습 규칙) 이 문제다.
- (b) **거리 제한 조회**: 미래 질의가 멀리 있는 문맥 내용을 attention 으로 충분히 가져오지 못한다.
  - (b1) 어디서 가져올지 모른다 (방향 선택성 없음).
  - (b2) 알지만 양이 모자라 가까운 복사 key 에 진다.
- (c) **encoder**: encoder 토큰이 내용을 자리에 묶어 옮길 수 없다.

## 2. 측정 (물체 라벨 없음, 토큰 장 전체)

| 기호 | 뜻 |
|---|---|
| s | 16×16 격자 칸 |
| L | 마지막 문맥 튜블릿 |
| i | 미래 슬롯 0–7 |
| **u_i(s)** | 미래 슬롯 i 의 칸 s 내용이 L 에서 있던 칸 (출처) |
| d_i(s) | ‖s − u_i(s)‖∞ (칸) |
| hc_L | 문맥 16 장만 본 LN target encoder 의 L 토큰 (인과) |

- **출처 찾기 판독 (파라미터 없음).** ĉ_X(i, s) = argmax_r cos(X_i[s], hc_L[r]).
  - X = h_{8+i} 는 encoder 천장, X = p_i 는 predictor 다.
- **적중.** hit_X = ‖ĉ_X − u‖∞ ≤ 1.
- **합의 토큰.** hit_enc = 1 인 토큰이다 (판독이 맞는 자리, decoder 검증 먼저).
- **reach 곡선.** A_X(d) = P(hit_X | d, 합의). R50 = A 가 첫 구간의 절반으로 떨어지는 d.
- **soft.** cos(X, hc_L[u]) − cos(X, hc_L[s]). 진짜 출처를 복사 자리보다 더 닮았나를 본다 (d ≥ 1).
- **attention 관측** (base 판, head 평균, 층 평균 · 앞/중/뒤 1/3). 미래 질의 (i, s) 의 확률 질량 셋 (모두 L 안):
  - p_src: 진짜 출처 key
  - p_ring: 같은 Chebyshev 거리 ring 평균 (출처 제외)
  - p_copy: 자기 칸 key
- **개입 효과.** ΔA(d) = 같은 토큰의 (개입 − 그 predictor 의 base) 다. CI 는 clip bootstrap 이다.
- **망가뜨림 판정.** 가까운 거리 (d < 2) 의 A 가 0.05 넘게 떨어지면 "고친 게 아니라 망가뜨린 것" 으로 읽는다.

## 3. 개입 · 예측 · 판정 (돌리기 전에 적음)

| 개입 | 조작 | 가르는 것 | 예측 → 판정 |
|---|---|---|---|
| **I3 규칙** | release 가중치 그대로 attention 규칙만 교체: full · prefix (Ariel 규칙) · isolated (미래 블록 서로 차단). Ariel 에는 full | (a) | ΔR ≈ 0 → **"양방향 attention 은 병목이 아니다"** |
| **I2 RoPE** | 공간 RoPE 위치를 s 배. 전 토큰 또는 미래 질의 행만 | (b) 의 거리 척도 | R(s) ≈ R(1)/s 이고 가까운 거리가 유지되면 RoPE 거리 감쇠가 원인. 가까운 거리가 무너지면 해석 불가 |
| **attention 관측** | p_src vs p_ring vs p_copy | (b1) vs (b2) | p_src ≫ p_ring 인데 p_src 가 거리로 줄고 p_copy 가 이기면 → (b2) "방향은 알지만 양이 모자란다". p_src ≈ p_ring 이면 → (b1) |
| **I1 조회 보조** | 미래 질의 (i, s) → 진짜 출처 key (L, u) 의 logit 에 +β (β = 1, 2, 4). 대조: 반대 방향 출처 +4. 인공 팬은 등속이라 문맥 외삽 = 정답이다. 자연 영상에는 **인과 추정** 판 (문맥 끝 flow 등속 외삽) 도 같이 돈다 | 충분성: 가져오기만 하면 멀리 놓나 | 세기별로 R 이 늘고 반대 대조가 줄면 → 조회가 율속이다. encoder 내용은 옮겨질 수 있다 (c 기각) |
| **필요성** | 진짜 출처 key 에 −4 | 필요성 | R 과 가까운 거리 적중이 준다 |
| **정답 없는 개입** | anticopy (미래 질의 → 모든 문맥 튜블릿의 같은 칸 key 에 −β) · temp (미래 질의 행 logit ×τ) | (b2) 를 정답 없이 고칠 수 있나 | anticopy · temp 로 R 이 늘면 "복사 경쟁" 이 병목이다. 이것은 곧 학습 없는 개선이다 |
| **E encoder 등변성** | 창을 3 칸 민 clip 의 z · h 와 원래 clip 의 3 칸 이동판의 cos (정렬 vs 비정렬) | (c) 의 보조 증거 | 정렬 ≫ 비정렬이면 encoder 토큰은 대체로 위치에 옮겨질 수 있다 |

**어느 결과로도 문장이 선다.**
- I3 무효 + I1 유효 + (b2) 관측 → **"병목은 predictor 의 거리 제한 조회다. 방향은 알지만 먼 출처의 가중이 가까운 복사 key 에 진다. encoder 와 attention 규칙은 아니다."**
- I1 이 정답 출처로도 무효 → 조회 뒤 렌더링 (내용 변환) 문제다.
- E · I1 이 모두 무효 → encoder 쪽이다.

**교란과 대응.**
- 개입은 학습 분포 밖이다 → 세기별 반응, 가까운 거리 대조, 반대 방향 대조로 막는다.
- I1 은 출처를 알려 주므로 "우리가 옮겨 준 것" 이라는 반론이 있다 → 정답 없는 개입 (anticopy · temp) 과 attention 관측으로 보완한다.
- 인공 팬은 카메라 이동뿐이다 → 자연 영상 (여러 독립 운동) 으로 재현한다.

**검사.** 개입 없는 hook 출력이 원래 출력과 같다 (상대 L1: release 0.0, Ariel 4.2–4.9e-4; 모든 rank 첫 clip).

- ⚠️ **2 차 검증 (확정, [`VERIFY_ISCENE2_2026-09-26.md`](VERIFY_ISCENE2_2026-09-26.md) §2)**: 정확 칸 (R −0.005 / A −0.087 / N1 −0.138) · 슬롯 0–1 제외 · 합의 필터 (A −0.21, N1 −0.31) 모두 같은 방향. ar_pA 출력이 복사 argmax 로 무너지지는 않지만 (5–14 %) 늦은 걸음에서 복사 쪽으로 표류한다 (cc − ct +0.04 ~ +0.07, 관측). "자기 출력이 입력 분포 밖" 은 **해석**이지 검정된 것이 아니다.

- ⚠️ **2 차 검증 (시사, 단서 대폭, [`VERIFY_ISCENE2_2026-09-26.md`](VERIFY_ISCENE2_2026-09-26.md) §4)**: τ = 0.05 계수는 재현되나 **τ 의존**이 크다 — τ 0.02 에서는 팬 포함 모든 판에서 슬롯 > 칸, τ 0.1 에서는 둘 다 ≈ 0. 균등 지도의 귀무 ρ 는 0 이 아니라 **0.5** 다. 거울 분석 (슬롯 고정, 거리 삼분위) 에서 팬의 슬롯 효과가 거리 효과보다 작지 않다 → "팬에서는 슬롯 효과가 작고" **철회**, "팬은 둘을 가르기 어렵다" 로. 표준화 계수로 Ariel 실영상은 시간 > 거리 (2–3 배). 복사 칸 지배는 없음 (확인).
- v3 물체는 ρ ≈ 1 (1–2 칸) → .4 (6–9 칸) 로 "처음엔 진실 속도, 뒤에서 멈춤" 이 연속 판독에서도 보인다.
