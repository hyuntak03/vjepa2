## 0. 결론

1. **먼 슬롯 물체다움의 소실은 이 knockout 8 명세 어느 것으로도 되돌아오지 않는다.** 공통 문턱 (0.357) 에서 clean 은 슬롯 0 0.97 → 8 0.28 → 10 0.11 → 14 0.00.
   초기층 (L0–6) 미래→미래를 끊으면 슬롯 8 +0.010 [−0.009, +0.030] (0 포함), 10 +0.054 [+0.041, +0.066], 14 +0.071 [+0.060, +0.080] — 소실 폭의 6–7 %.
   더 엄격한 슬롯 0 문턱 (0.427) 에서는 ≤ +0.02. 뒤층 (L7–11) 에서 끊으면 오히려 낮아진다 (슬롯 8 −0.077 [−0.088, −0.066]).
   다른 튜블릿 사이만 전 층에서 끊은 mmx_all 이 가장 크지만 (슬롯 8 +0.090 [+0.074, +0.108], 14 +0.098 [+0.086, +0.111]) 역시 소실 폭의 13 % / 10 % 다.
   **단서 (같은 비중)**: 되살아난 먼 슬롯 봉우리 (mm_L0-6 슬롯 14 물체다움 171 clip) 는 97 % 가 진실 칸도 마지막 칸도 아닌 **궤적 선분 위 중간 자리** (진행률 중앙값 0.42) 이고,
   같은 시나리오 다른 clip 의 봉우리도 0.89 가 그 선분 위에 떨어진다. 그 clip 의 물체가 이어진다는 증거가 못 된다. 또 mm_L0-6 은 기준 슬롯 2 의 물체다움을 −0.23 깎는다.
2. **초기층 미래→미래를 끊으면 중간 슬롯 (4–6) 봉우리가 마지막으로 본 칸에 머문다.** 슬롯 6 마지막 칸 적중 0.36 → 0.63 (Δ +0.274 [+0.255, +0.292]);
   진실과 마지막 칸이 3 칸 이상 떨어진 1,848 clip 에서 진실 0.58 → 0.24 · 마지막 0.19 → 0.53. 진실 적중 − 귀무 (같은 시나리오 다른 clip 의 진실 칸) 는 0.19 → **−0.06**
   (Δ −0.246 [−0.263, −0.228]) — 위치 사전확률 아래다. 전 슬롯 L1 도 0.573 → 0.599 (+4.6 %). mmx_all (튜블릿 안 공간 상호작용은 남김) 도 같은 방향이다 (슬롯 6 마지막 칸 0.59, 적중 − 귀무 −0.05).
3. **미래→문맥을 끊으면 층에 따라 다르게 무너진다.** L0–6 에서 끊으면 슬롯 0 적중 0.99 → 0.43 (귀무 0.38) — 적중 − 귀무 0.38 → **0.05**, 위치가 사전확률 수준이다.
   L7–11 에서 끊으면 argmax 칸은 clean 과 같게 남고 (적중 − 귀무 슬롯 0 / 4 / 6 = 0.38 / 0.40 / 0.19, clean 0.38 / 0.41 / 0.19) 출력이 **목표 공간을 벗어난다**:
   L1 0.573 → 0.937 (+64 %), 슬롯 0 max cos 0.80 → 0.20, median cos 0.28 → 0.09. 이 이탈이 외형에 특정한지는 재지 않았다.
4. **H2/H3 정정은 부정 결과로만 선다** — 뒤층 미래→미래 간선을 끊어도 먼 슬롯 물체다움은 돌아오지 않는다. "흐림이 초기층에서 시작된다" 와 "H4 와 같은 기제" 는
   이 데이터로 서지 않는다 (§6 의 2 단 경로 차단 · mmx_L0-6 · H4 고정 문턱 재분석 뒤에 다시 묻는다).

## 1. 왜

H2 (뒤층을 지나며 먼 슬롯의 물체다움이 사라짐) 와 H4 (미래를 한꺼번에 질의하면 빨리 사라짐) 를 합치면 가설이 선다:
"뒤층의 미래 튜블릿 사이 attention 이 먼 물체를 공통 미래로 지운다". 가설이 틀리면 흐림의 자리를 다른 곳에서 찾아야 한다 — 어느 쪽이든 병목 지도가 좁혀진다.
결과: 뒤층 판본은 기각 (끊어도 안 돌아온다). 초기층 판본은 공통 문턱에서 효과가 작다 (소실의 6–7 %). **간선 한 종류로 소실이 좁혀지지 않았다.**

## 2. 방법

`analysis/attention/knockout/runner.py` 의 `clean_forward` / `resume` (층별 residual 캐시, resume = 실제 forward 와 비트 동일 설계) 으로
predictor 만 명세마다 이어 돌린다. 인코더는 배치당 한 번. SDPA bool mask (True = attend), **자기 자신은 항상 남긴다** (keep_self).
표기 "A → B" = A 토큰이 질의, B 토큰이 키 (A 가 B 를 읽는다). **문맥 질의 행은 어떤 명세에서도 건드리지 않는다.**

| 명세 | 끊는 간선 (행 = 미래 질의만) | 층 |
|---|---|---|
| clean_null | 없음 (bool mask 경로 기준선; clean 과 상대 차 0.0007) | 전부 |
| mm_L7-11 / mm_L0-6 / mm_all | 미래 → 미래 (같은 튜블릿 안 포함, 자기 자신만 남김) | 뒤 / 앞 / 전부 |
| mmx_all / mmx_L7-11 | 미래 → **다른 튜블릿의** 미래 (같은 튜블릿 안 공간 상호작용은 남김) | 전부 / 뒤 |
| mc_L7-11 / mc_L0-6 | 미래 → 문맥 | 뒤 / 앞 |

**읽기** (파라미터 없음, H4 와 같은 템플릿): 슬롯 k (튜블릿 32+2k) 진실 물체 칸의 LN(h) 토큰을 템플릿으로, p 의 256 토큰과 cos → argmax 칸, 대비 = max − median.

| 기호 | 정의 |
|---|---|
| 물체다움 @ref_A | 대비 ≥ **0.357** = clean_null 슬롯 0–2 대비의 10 백분위 (모든 명세 공통; 원 판의 공통 문턱) |
| 물체다움 @ref_B | 대비 ≥ **0.427** = clean_null 슬롯 0 만의 10 백분위 (기준 슬롯 1–2 손상과 무관) |
| 물체다움 @명세별 | 원 판 방식 (명세마다 자기 슬롯 0–2 의 10 백분위) — 분해·기록용으로만 |
| 진실 적중 | \|argmax − T_k\|_∞ ≤ 1 (18 px 칸, 16×16) |
| 귀무 | 같은 시나리오 다른 clip 전부의 진실 칸 T_k^j 에 대한 적중 평균 (위치 사전확률의 정확한 기대값) |
| 적중 − 귀무 | 그 clip 의 물체 자리를 짚은 몫 |
| 마지막 칸 적중 | \|argmax − L\|_∞ ≤ 1, L = 문맥 마지막 튜블릿 (프레임 30–31) 의 물체 칸 |
| 그밖 | 진실 칸도 마지막 칸도 아님 |
| sep | \|T_k − L\|_∞ ≥ 3 인 clip — 두 3×3 창이 겹치지 않아 진실과 마지막 칸을 가를 수 있다 |
| 길위 | argmax 가 선분 L → T_k 에서 유클리드 1.5 칸 안. 귀무 = 같은 시나리오 다른 clip 봉우리를 이 clip 선분에 대 본 비율 · 256 칸 면적 비율 |
| L1 | mean_토큰 \|p − LN(h)\| |
| CI | clip 복원추출 paired bootstrap (B = 2000, seed 0), Δ = 명세 − clean_null 의 95 % 백분위 구간 |

mc 명세는 척도가 무너져 (슬롯 0 대비 중앙값 0.114 / 0.090 vs clean 0.513) 공통 문턱에서 물체다움이 전 슬롯 0 이다. **mc 의 물체다움은 어느 문턱으로도 해석하지 않고**
위치 (적중 − 귀무) · L1 · cos 로만 읽는다.

## 4. 해석 — 병목 지도 갱신

"끊으면 무엇이 되나" 로만 적는다 (§5-1). 원인 자리 ("이 간선이 X 를 나른다") 는 쓰지 않는다.
```
미래 mask 토큰 (위치만 다름)
  L0–6  미래→문맥 끊음 : 위치가 사전확률 수준 (슬롯 0 적중 − 귀무 0.38 → 0.05)
  L0–6  미래→미래 끊음 : 중간 슬롯 (4–6) 봉우리가 마지막으로 본 칸에 머묾 (슬롯 6 적중 − 귀무 0.19 → −0.06, 마지막 칸 0.36 → 0.63)
                          먼 슬롯 물체다움 +0.05–0.07 (슬롯 10–14), 슬롯 8 은 0 과 구별 안 됨
  L7–11 미래→미래 끊음 : 위치 거의 그대로, 물체다움은 조금 낮아짐 (슬롯 8 −0.08)
  L7–11 미래→문맥 끊음 : argmax 칸은 남고 출력이 목표 공간 밖 (L1 +64 %, max cos 0.80 → 0.20)
  먼 슬롯 소실 자체   : 8 명세 어느 것도 되돌리지 않는다 (최대 mmx_all 슬롯 14 +0.10)
```
- **간선 한 종류로 소실이 좁혀지지 않는다.** 가능한 읽기는 둘이다 — (a) 소실이 여러 경로에 나뉘어 있다, (b) 끊지 않은 2 단 경로 (문맥 토큰 경유) 가 섞임을 대신 나른다.
  이 데이터로는 못 가른다 (§6 의 첫 실험이 (b) 를 닫는다).
- 미래 질의끼리의 직접 간선이 없을 때 중간 슬롯 봉우리가 마지막 칸에 머무는 것은 H5 정정판 (자기 예측 되먹임은 첫 두 걸음 뒤 1 칸 해상도에서 전진을 멈추고, 물체다움은 느리게 옅어질 뿐 유지되지 않는다) 과 **방향이 같다.** 다만 여기서 먼 슬롯의
  "붙듦" 자체가 작아 (+0.05–0.07) 원 판의 "존재는 유지되고 운동만 느리다 — 둘은 다른 기제" 로 합치지는 않는다.
- H3 의 "공통 미래로 수렴 (D_t 감소)" · H4 의 "한꺼번에 질의하면 빨리 사라짐" 과의 연결은 **가설** 로 남긴다 (H4 도 공통 문턱으로 다시 쟀다 — 0.357 에서 single − joint k 8–10 ≈ +0.09~+0.12 로 여기 mmx_all (+0.090 / +0.051, 슬롯 8 / 10) 과 비슷하다; 명세별 D_t 는 미측정).
- 먼 슬롯 소실이 간선 차단으로 크게 돌아오지 않는다는 것은 RollOutV2 의 거리 한계 (p 의 물체다운 토큰은 마지막 관측 자리에서 약 2–3 칸 안에서만 유지, CLAUDE.md §5-5) 와
  충돌하지 않는다. 그 이상은 이 실험이 말하지 않는다.

## 5. 못 하는 주장

1. knockout 은 **학습 때 없던 개입** 이다 (분포 밖). "이 간선이 없으면 X 가 된다" 까지만 — "이 간선이 X 를 나른다 / 정한다 / 만든다" 는 아니다.
   mc_L7-11 처럼 출력이 목표 공간을 벗어나는 명세 (L1 +64 %) 는 특히 "무엇이 빠졌나" 보다 "분포 밖으로 밀렸다" 가 먼저다.
2. keep_self 설계 (자기 자신은 항상 봄) 가 결과에 섞인다.
3. **mm/mmx 는 미래 질의 행만 끊는다.** 문맥 질의 행은 그대로라 문맥 토큰이 l 층에서 미래를 읽고 미래가 l+1 층에서 그 문맥을 읽는 **2 단 경로가 열려 있다** —
   "미래끼리 섞임을 없앴다" 는 못 쓴다. 또 **mm 은 같은 튜블릿 안 공간 상호작용까지 끊는다** (미래 토큰이 문맥 + 자기 자신만 봄). 그래서 mm_L0-6 효과를 튜블릿 사이
   (시간) 섞임으로 돌릴 수 없다. mmx_L0-6 는 돌리지 않았다 — mmx_L7-11 ≈ clean 이므로 mmx_all ≈ mmx_L0-6 이라고 짐작할 수 있지만 층 사이 상호작용을 무시한 짐작이다.
4. **문턱**: 명세별 문턱은 기준 슬롯 손상을 먼 슬롯 효과로 바꾼다 (원 판의 오류, §3-1 분해). 공통 문턱은 mc 명세를 척도 붕괴로 전부 0 으로 만든다.
   mc 의 물체다움 (명세별 문턱의 mc_L7-11 슬롯 10 0.31, mc_L0-6 0.57–0.91 포함) 은 어느 쪽으로도 해석하지 않는다. @ref_A 와 @ref_B 는 결론 방향이 같고 크기만 다르다.
5. **귀무가 높다** (슬롯 0 0.61, 슬롯 6 0.46). RollOut_v3 자유 운동은 시나리오 안 궤적이 거의 같다 (다른 clip 봉우리의 0.87–0.98 이 이 clip 선분 위). 위치 주장은 적중 − 귀무 로만 하고,
   먼 슬롯의 "길 위" 봉우리를 그 clip 의 물체로 읽지 않는다. clean 의 먼 슬롯 적중 − 귀무가 음수라 먼 슬롯 +Δ 는 배치 개선이 아니다 (§3-2).
6. bootstrap 은 clip 을 독립으로 본다. 같은 시나리오 clip 은 궤적을 공유해 CI 가 실제보다 좁을 수 있다. 창 하나 (C16/P32), 데이터 하나 (RollOut_v3 자유 운동 6 법칙),
   모델 하나 (ViT-H). 다른 창 · v11 · IntPhys 에서는 안 돌렸다.
7. "평균 쪽으로 흐린다" 는 잰 적이 없다 (명세별 D_t 없음). mc_L7-11 의 목표 공간 이탈이 외형 (색 · 모양) 에 특정한지도 재지 않았다 (중심화 cos · probe 없음).
8. 템플릿이 진실 h 물체 토큰 하나라, 대비는 "그 물체처럼 보이는 봉우리가 있나" 이지 물체 정체성을 읽는 probe 가 아니다.

```
          + 미래 토큰끼리 섞인다 → 중간 슬롯 자리 맞춤 ↑, 먼 슬롯 물체는 공통 미래 쪽으로 흐려짐 (차단 시 슬롯 10 물체다움 0.11 → 0.43)
  L7–11 : 문맥을 다시 읽어 "무엇처럼 보이나" (대비·외형) 를 만든다 (차단 시 대비 0.51 → 0.11, 자리는 그대로)
```
원 판의 "H3 · H4 가 같은 곳 — 초기층의 미래↔미래 섞임 — 을 가리킨다" 와 "섞임을 없애면 존재는 유지되지만 진행은 느리다 — 존재의 소실과 운동의 느림은 서로 다른 기제" 도
