## 0. 결론

1. **문맥 encoder 관측을 되먹이면 (ar_z) frozen predictor 는 매 걸음 물체를 새 칸으로 옮긴다 — 한 걸음 전이는 있다.**
   칸이 바뀌는 clip 에서 새 칸 T_j 착지 .78–.96 / 옛 칸 T_{j−1} ≤ .10 (C16 j1–7, n = 924–1,344). 진행률 1.00 (복사 기준선 .67–.90).
   j3–7 전진 기울기 **0.367 [0.358, 0.376] 칸/튜블릿**, 진실 0.442 의 83 %. 이것은 물체 위치에 한정한 말이다.
2. **자기 예측을 되먹이면 (ar_p) 물체는 첫 두 걸음은 진실만큼 가다가 1 칸 해상도에서 전진을 멈춘다.**
   C16 along 0.41 / 1.06 / 1.43 칸 (진실 0.38 / 0.83 / 1.29) 뒤로 j3–7 기울기 **−0.009 [−0.017, −0.002]**.
   j7 적중 .10 은 위치 귀무 .28 **아래**다 (−0.18 [−0.20, −0.17]). 무작위 자리가 아니라 뒤처진 자리에 남는다는 뜻이다.
   **멈춘 자리는 속도 3 분위마다 그 분위 진실의 j2 자리와 같다** (0.85 / 1.36 / 1.77 칸 vs 0.91 / 1.31 / 1.66). 고정 거리에서 걸리는 것이 아니라 걸음 수에 묶인 멈춤이다.
   되먹임 없이 한 번에 예측해도 (os) j≈3 뒤로는 전진하지 않는다 (기울기 +0.024). **자기 예측 되먹임은 이 지평을 늘리지 않는다.**
3. **같은 어댑터 길로 참 미래를 넣은 ar_h (ar_p 와 길이 같은 상한) 도 j ≥ 4 에서는 새 칸보다 되먹인 칸에 다시 놓는다**
   (T_{j−1} .60 / .75 / .69 / .57 vs T_j .29 / .11 / .06 / .16, 기울기 0.222 = 진실의 50 %). 누수가 있는 낙관적 팔인데도 그렇다.
   → 막힘은 **자기 예측의 내용** (ar_h − ar_p) 과 **target/p 공간 → 문맥 자리라는 길** (ar_z − ar_h) 둘 다에 걸쳐 있다. 어댑터의 형식 손실만은 배제된다 (ar_zA 와 ar_z 의 argmax 차이 0.27 %).
4. 물체다움은 os 보다 **느리게 옅어질 뿐 유지되지는 않는다** (C16 j7 p10 / p25 / p50: ar_p .88 / .38 / .07 vs os .57 / .18 / .04).
   되먹인 물체 토큰을 다시 놓는 것인지 지속 (능력 2) 인지는 이 측정으로 가를 수 없다.

## 1. 왜

기제 R: 미래 토큰끼리 상태를 넘기지 않는다 (`mask→mask` 차단 −1.4). 되먹임을 **강제**하면 결과는 둘 중 하나로 읽을 계획이었다.
지속이 늘면 "한 걸음 전이는 있고 구조가 잇지 않을 뿐" (쓰는 방식이 병목), 안 늘면 "한 걸음 전이 자체가 상태를 진화시키지 않는다" (학습된 계산이 병목).
초판 판정은 "둘 다 아니고 제 3 의 경우 — 존재는 이어지지만 운동이 이어지지 않는다" 였다.

> ⚠️ 개정 판정: **한 걸음 전이는 있다** (ar_z, §3-2). 자기 출력으로 이으면 j≈2 뒤로 전진하지 않는다 (§3-3). 그런데 같은 길로 참 미래를 넣어도 (ar_h) 반쯤 막힌다.
> 그래서 "쓰는 방식이 병목" 에 가깝지만, 그 '방식' 안에서 **내용 (자기 예측)** 과 **길 (target/p 공간 토큰을 문맥 자리에)** 이 섞여 있다. 이 판으로는 둘 중 하나로 가르지 못한다.

## 2. 방법

```
어댑터   A(y) = a ⊙ LN(y) + b      (a, b ∈ R^1280, clip 자신의 문맥 토큰에서 LN(z)_c → z_c 최소제곱)
ar_p    Z_0 = z (문맥 C/2 튜블릿);  p_j = predictor(Z_j, 질의 = 튜블릿 C/2 + j);  Z_{j+1} = [Z_j ; A(p_j)]
ar_z    Z_{j+1} = [Z_j ; z*_j]          z*_j = 문맥 encoder 를 j 까지 늘린 문맥에 돌린 새 튜블릿 토큰 (참 관측)
ar_zA   Z_{j+1} = [Z_j ; A(LN(z*_j))]   문맥 encoder 토큰의 LN 왕복 + 어댑터 (형식 손실 검사)
ar_h    Z_{j+1} = [Z_j ; A(h_j)]        h = LN(target_encoder([32−C, 48))) 의 튜블릿 j — p 와 같은 길 (target 공간 → 어댑터) 의 참 미래.
                                        ⚠️ 창 전체를 양방향으로 보므로 h_j 는 j 이후 프레임 정보를 담는다 (누수 → 낙관적 상한)
os / single   한 번에 (P = 16) / 튜블릿 하나만
```

읽기 (파라미터 0): 템플릿 = 진실 시각 h 의 물체 칸 토큰 → cos argmax 칸 a_j · contrast (max − median cos). 1 칸 = 18 px, 16×16 격자.
T_j = 미래 튜블릿 j (프레임 32+2j, 33+2j) 의 진실 칸, L = 문맥 마지막 튜블릿 (프레임 30, 31) 의 칸.

| 양 | 정의 |
|---|---|
| 적중 | 1[max\|a_j − T_j\| ≤ 1] (Chebyshev ≤ 1 칸) |
| **위치 귀무** | 같은 시나리오 · 같은 j 에서 ok 인 clip 끼리 진실 칸을 섞어 잰 적중, 20 번 평균 (H23 §3-2 방식. 섞는 풀을 ok clip 으로 한정한 것만 다르다) |

| along | (a_j − L)·u 칸, u = 마지막 관측 → T_7 방향 단위벡터. **기울기** = clip 마다 j3..7 최소제곱 기울기의 평균 |
| 걸음 방향 | along 한 걸음 변화가 > 0.5 (앞) / ≤ 0.5 (제자리) / < −0.5 (뒤) |
| 진행률 | ((a_j − L)·d)/\|d\|², d = T_j − L, \|d\| ≥ 3 칸 (H4 와 같음). 표본: 팔별 물체다움 p10 (초판) · **공통** (거르지 않음) · 공통 물체다움 |

### 3-6. 읽기 검증 — "전진을 멈춘다" 가 자의 기본값이 아닌 이유, 그리고 남는 한계

CLAUDE.md §6 은 **"p 가 슬롯 4 이후 멈춘다"** 를 철회했다. 학습된 attentive 자는 물체를 놓치면 토큰 평균 읽기 (기본값) 를 내는데, 그 기본값이 '멈춤' 처럼 보였기 때문이다.
여기서의 멈춤은 다음 점에서 그 경우와 다르다.

1. **자가 없다.** 읽기는 진실 템플릿과의 cos argmax 이고 파라미터가 0 이다. 학습된 기본값이 없다.
2. **물체가 남아 있는 표본에서도 멈춘다.** 물체다움 p25 부분집합에서 ar_p 진행률은 j6–7 에서 .33 이고, 멈춘 자리는 0.79 / 1.28 / 1.64 칸이다 (3-4).
   공통 표본 (.40) 과 6 시나리오 전부 (j7 적중 .02–.18, 5/6 에서 귀무 아래, along 0.90–1.85 칸 vs 진실 3.09–3.96) 에서도 같다.
3. **멈춘 자리가 고정된 기본값이 아니다.** 마지막 관측 (stay, along 0) 도 장면 고정 자리도 아니고, clip 속도에 비례한다 (3-4).
4. **귀무 아래**다 (−0.18). argmax 가 흩어진 결과였다면 귀무 근처에 있어야 한다.

남는 한계:
- **1 칸 해상도.** clip 하나 안에서 칸 경계를 넘지 않는 연속 표류는 argmax 에 안 보인다. 2,352 clip 평균 기울기의 CI 상한 (−0.002 칸/튜블릿) 은 '모집단 평균으로 앞으로 가는 표류는 없다' 까지만 말한다. 그래서 문장은 "1 칸 해상도에서 전진을 멈춘다" 로 쓴다.
- 물체답지 않은 12–25 % (C16 j3–7, p10 미달) clip 의 argmax 는 기본값처럼 행동할 수 있다. 주장은 물체다운 부분집합에서 확인한 범위로 한정한다.
- **§5-5 의 거리 한계와의 관계.** 거리 한계는 "p 의 물체다운 토큰은 마지막 관측에서 약 2–3 칸 안에서만 유지된다" 는 것으로, **있음** (물체다움) 에 관한 RollOut_v2 결과다.
  여기의 멈춤은 **전진** (argmax 위치) 에 관한 것이다. 0.8–1.8 칸 (거리 한계 안쪽) 에서, 속도에 비례하는 자리에서 일어난다 → 거리 한계로는 ar_p 가 멈추는 자리를 설명하지 못한다.
  두 결과는 서로 다른 양이라 모순이 아니다. 같은 판에서 두 양을 가르는 것은 next 로 둔다.

## 4. 해석

- **한 걸음 전이는 문맥 encoder 관측에서 출발하면 있다** (ar_z). CLAUDE.md 의 전이 ◐ 판정과 맞다. 전이 실패는 **자기 출력 공간을 거쳐 이을 때** 나타난다.
- **전진 지평은 마지막 문맥 encoder 관측에서 약 2–3 튜블릿 (4–6 프레임) 이다.** os · single · ar_p 가 모두 그 근처에서 전진을 멈추고, 멈춘 자리는 속도에 비례한다.
  자기 예측을 되먹여도 이 지평은 늘지 않는다 (ar_p 는 진실의 j2 자리, os 는 j3 자리 근처). 새 encoder 관측을 넣으면 (ar_z) 매 걸음 지평이 새로 열린다.
- **ar_h 가 ar_p 의 올바른 상한이다** (같은 길 = target/p 공간 토큰 → 어댑터 → 문맥 자리). ar_h 는 j ≥ 4 에서 copy 기준선 수준으로 떨어진다.
  그래서 ar_p − ar_z 차이 (기울기 −0.009 vs 0.367) 는 둘로 나뉜다. **내용** (ar_h − ar_p = 0.23) 과 **길** (ar_z − ar_h = 0.145) 이다.
  ar_h 는 누수로 낙관적이므로 길의 몫은 **하한**이고 내용의 몫은 과대 추정일 수 있다. C8 은 내용 0.31 · 길 0.07.
- 멈춤을 설명하는 후보 (**모두 미검증 가설**):
  (a) 되먹인 p/h 토큰에 predictor 가 읽는 형태의 속도 부호가 약하다 (초판 주장, 강등).
  (b) 분포 밖 튜블릿이 3–4 개 쌓이면 predictor 가 가장 최근 되먹인 튜블릿의 물체를 그 자리에 다시 놓는다 (ar_h 의 T_{j−1} 착지와 ar_p 의 순전진 0 이 같은 행동으로 읽힌다. 기제가 아니라 행동 기술이다).
  (c) 전환 시점 (j3–4) 은 되먹인 **개수**에 묶여 있다 (ar_p 에서 속도와 무관하게 j≈2–3 에서 멈춘다).
  셋 모두 GPU 실험이 필요하다 (§6).
- use case: 자기회귀 rollout 은 world model 을 planning 에 쓰는 기본 방식이다. "자기 예측 되먹임이 전진 지평을 늘리지 않는다" 는 그쪽에 닿는다.
  단 이것은 V-JEPA 2 (action 없음) 의 v3 자유 운동 결과다. AC predictor 는 다른 모델이며 여기서 재지 않았다.

### 폐기한 해석 (기록 — 다시 쓰지 말 것)

- ⚠️ **철회 — "느린 걸음의 복리 수축"**: 초판 §4 는 "p 는 한 걸음마다 진실 변위의 ≈ 60 % 만 옮긴다 (H3·H4 진행률). 그 느린 걸음이 다음 걸음의 문맥이 되면 … 복리로 수축해 멈춘다" 고 썼다.
  60 % 는 H4 의 누적 진행률이지 걸음당 비율이 아니다. ar_p 의 첫 두 걸음은 진실만큼 가고 (1.06 / 1.43 vs 0.83 / 1.29) 그 뒤 급정지한다. 기하급수 수축의 모양이 아니다. **다시 쓰지 말 것.**
- ⚠️ **정정 — "ar_h 는 조금 덜 옮긴다 (분포 차)"**: j ≥ 4 에서 copy 기준선 수준이다 (3-2, 3-3).
- ⚠️ **철회 — "되먹임으로 존재는 유지된다 (0.88)"**: p10 문턱에서만 성립한다 (p25 .38, p50 .07). 초판의 H2 인과 표현 ("뒤층이 …") 도 개입 근거가 없어 거둔다.
- ⚠️ **철회 — "어느 쪽도 상태를 진화시키지 않는다 — 사용자 가설의 가장 직접적인 행동 증거"**: ar_z 의 한 걸음 전이와 모순된다.

## 5. 못 하는 주장

1. 되먹인 입력은 분포 밖이다 (p 는 수축돼 있고 문맥 encoder 출력이 아니다). ar_zA = ar_z 는 **형식** 손실만 배제한다. 공간 전환 (target/p → 문맥 자리) 의 비용은 ar_h 가 보이듯 남는다.
2. **ar_h 는 누수가 있는 낙관적 팔이다.** h 는 [32−C, 48) 전체를 양방향으로 본 target encoder 출력이라 h_{j−1} 이 j 이후 프레임 정보를 담는다. 인과 버전 (target encoder 를 튜블릿 j−1 까지만) 은 돌리지 않았다. 그래서 '길' 의 몫은 하한이다.
3. **"되먹인 자리에 다시 놓는다" 는 행동 기술이다.** ar_p 의 argmax 는 같은 칸을 그대로 두지 않고 ±1 칸 흔들린다 (j4–7 같은 칸 .42–.55). 뜻하는 것은 순전진이 0 이라는 것뿐이다. attention 이 되먹인 튜블릿을 복사한다는 기제는 재지 않았다.
4. **1 칸 해상도.** clip 안의 칸 이하 표류는 안 보인다 (3-6). "멈춘다" 는 항상 "1 칸 해상도에서 전진을 멈춘다" 로 쓴다.
5. 물체다움은 os 기준의 상대 문턱이고 문턱에 민감하다 (3-5). 되먹인 물체 토큰을 다시 놓는 것과 **지속** (능력 2) 은 이 측정으로 가를 수 없다. 능력 2 에 대한 주장은 하지 않는다.
6. "되먹인 상태에 속도가 약하다" 는 **측정하지 않았다** (가설 (a)).
7. '한 걸음 전이' 는 **물체 위치**에 한정한다. 전 토큰 L1 (채점 지표) 에서 ar_z 는 j1–6 에서 os 보다 나쁘다 (C16 j2 .607 vs .562).
8. 걸음 수 대 거리는 argmax 전진에 대해서만, 그리고 속도 폭 1.85 배 (5.5–10.3 px/튜블릿) 안에서만 갈랐다. 더 넓은 속도 범위에서는 재지 않았다.
9. 적중은 j ≤ 4 에서 변별력이 거의 없다 (모든 팔 .91–.99, 귀무 .53–.61, copy 1.00). 전이 판정에 적중을 쓰지 않는다.
10. 미래는 8 튜블릿 (16 프레임) 까지만 봤다. 진행률은 칸 단위로 양자화된다 (중앙값이 .33 / .50 / .67 등에 몰린다. 그래서 along 평균과 기울기를 같이 적었다).

## 6. next

- **길 교체**: 가능 clip 의 (p, z*) 짝으로 맞춘 p → z 사상 (채널별 또는 선형) 으로 ar_p 를 되먹인다. 멈춤이 풀리면 길의 문제다 (GPU, frozen, 재학습 없음).
- **혼합 되먹임**: 처음 k 튜블릿은 z*, 그 뒤는 p 를 넣는다. 멈춤이 '마지막 encoder 관측에서의 걸음 수' 에 묶였는지 (가설 (c)) 확인한다.
