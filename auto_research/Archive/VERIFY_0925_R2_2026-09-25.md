## 0. 질문에 대한 답: "미래를 튜블릿 1 개씩만 예측하게 해서 이어붙였더니 된다" 는 뜻인가?

아니다. 다섯 문서 어디에도 그런 결론은 없다.

- **이어붙인 실험은 P3 · P3b 뿐이다.** 그 안에서도 결과는 무엇을 이어붙였느냐에 따라 갈린다.
  - 릴리즈 predictor 가 **자기 예측** 을 이어붙이면 두 걸음 간 뒤 멈춘다. 기울기 −0.012 [−0.042, +0.018], 진실은 0.44 다.
  - "된다" 로 보인 `ar_z` (0.361) 는 매 걸음 **진짜 다음 프레임** 을 encoder 에 넣은 탐침이다. 예측기로는 쓸 수 없다.
  - P3b 에서는 역사와 마지막 토큰 가운데 **어느 한쪽만 참 관측** 이어도 격차의 약 78 % 가 회복된다 (외형 템플릿). "마지막 토큰 하나가 정한다" 는 기각됐다.
- **학습된 predictor 비교의 주 결과 (P2) 는 이어붙이기가 아니다.** 미래 16 튜블릿을 forward 한 번 (one-shot) 으로 낸다. Ariel 의 block-causal 은 그 한 번 안에서 attention 에 건 제약일 뿐이고, 예측을 입력으로 되먹이지 않는다.
- 이어붙이기로 한정하면, Ariel 만 자기 예측을 이어서도 진실의 **약 절반 속도** 로 j7 까지 간다 (0.226 [0.171, 0.277]).
- M2 · M13 · M5 · M6 · E-SSv2 는 모두 one-shot 이다. 바꾼 것은 입력 토큰이다.

## 2. 2 차 뒤 결합 이야기 (6 줄)

1. **읽기.** predictor 입력 z 에서 가시 물체의 방향과 속력이 선형으로 읽힌다. SSv2 방향은 z 0.89–0.97, 픽셀 기준선 0.41–0.70 이다. v3 z_last 의 법칙 안 속력 R² 는 .949 (검증자 .955) 다. 등급은 **확정 (가시 운동 한정)**. 가속과 가림 아래 상태는 확인하지 않았다. "encoder 가 여러 프레임을 경계 토큰에 적분한다" 는 **가설** 이다 (M6 bndM 은 있음 붕괴와 분포 밖 입력에 교란됨).
2. **릴리즈 one-shot.**
   - 가시 물체를 진실 속도로 약 3 튜블릿 옮긴 뒤 속도에 비례한 자리에서 멈춘다. 멈춘 자리 b 는 4.60, 진실은 6.07 이다. 경로는 s1 에서 약 2 칸, s2 에서 약 3 칸에서 정체한다. t10 적중−귀무는 −0.14 [−0.18, −0.09] 다. 있음은 경과 시간에 따라 준다. 등급은 **확정 (행동)**.
   - "3" 이라는 수와 SSv2 의 정방향 약 3 슬롯 윤곽은 판독에 따라 달라지므로 **시사**.
   - 기전 귀속 셋은 **철회** 한다: 마지막 토큰이 정한다, 역사 토큰이 뒤로 끈다, 속도를 한 걸음만 쓴다. 남는 기전은 M4 (변위 2–3 칸에서 문맥 물체 토큰을 직접 조회해야 함, 필요성만) 이고 등급은 **시사**.
3. **되먹임.**
   - 매 걸음 참 인과 관측을 넣으면 전진한다 (0.361, 탐침). 릴리즈가 자기 예측을 이어붙이면 j3 부터 멈춘다. 등급은 **확정 (행동)**.
   - 역사와 마지막 토큰 가운데 한쪽만 참이어도 격차의 약 78 % 가 회복된다 (외형 템플릿). 등급은 **시사**.
   - 누적 탓인지 마지막 토큰 질 탓인지는 **미결** 이다 (tf_last_pA 팔이 필요하다).
4. **역사.**
   - v3 자연 조건에서 predictor 입력의 역사 토큰은 **자리** 를 거의 바꾸지 않는다 (hist_swap \|Δ\| ≤ .02, hist_none 진행 0.547 vs 0.542). 대신 **있음** 에 기여한다 (−.08 ~ −.28). 등급은 **확정 (범위 한정)**.
   - 이어붙인 역사 (v11 −0.231) 와 따로 인코딩한 역사 (±0.2–0.4 칸) 에서는 자리가 움직인다. 이음 교란이 남으므로 **시사**.
   - "뒤처짐의 원인은 역사" 는 **철회**.
5. **같은 encoder 위의 학습된 predictor (존재 증명).**
   - pv1 과 Ariel 은 stride 1 에서 약 8 튜블릿까지 진실 기울기로 간다. t3–7 기울기는 0.52 / 0.48 (진실 0.46), t10 적중−귀무는 +0.24 [0.17, 0.31] / +0.26 [0.21, 0.31] 이다. t8–11 에는 기울기가 절반이 되고 t12–15 에는 약 5 칸에서 멈춘다.
   - 등급은 **확정 (가시 · 등속에 가까운 운동 · stride 1–2 · arc 제외, 문서 정정 조건)**.
   - s2 에서는 8 튜블릿 동안 7 칸 (진실 7.25) 까지 따라간다. 그래서 멈춤은 고정 거리가 아니라 걸음 수 쪽이고, 각 predictor 의 학습 지평 (8) 근처다. 등급은 **시사** (교차 비평이 검증자 경로 JSON 에서 읽음).
   - 네 창 모두에서 릴리즈 이상인 것은 Ariel 뿐이다. 자기 예측을 이어붙여도 Ariel 은 0.226 으로 진실의 절반 속도다.
   - "encoder 충분 · predictor 병목" 은 **철회를 유지** 한다. 요인은 분리되지 않았다.
6. **평가.**
   - IntPhys 1 최고 칸에서 복사 85.00 과 릴리즈 88.89 는 구분되지 않는다 (n.s.). 양방향 표적 번짐으로 사건 전 튜블릿 판별이 90.4 % 이고 인과 표적이면 50.0 % 다. SSv2 에서 복사 대비 L1 이득의 61–79 % 는 흐림이 재현한다. 등급은 **확정 (프로토콜 민감)**.
   - VoE 순위와 외삽 순위는 **IntPhys 1 에서만** 어긋난다. v11 에서는 릴리즈가 두 순위 모두 최하다. 등급은 **시사 (지평 · fps · 표적 교락)**.

## 4. 가장 결정적인 다음 frozen 실험 하나

**encoder 문맥 길이 × predictor 실험: 경계 토큰을 문맥 끝 L 프레임만 보고 인코딩하고, 릴리즈와 Ariel 에 똑같이 넣는다.**

**설계**
- 데이터: RollOut_v3 자유 운동 784 clip (궤적 56, M6 와 같은 clip), stride 1, 문맥 raw [16,32), 미래 16 튜블릿.
- 경계 토큰 (튜블릿 6–7) 을 L ∈ {4, 8, 12, 16} 프레임으로 인코딩한다. `enc(x, masks=[튜블릿 8−L/2 … 7 의 토큰])` 로 RoPE 위치를 보존한다 (M6 bndM 경로를 재사용; L=4 는 bndM, L=16 은 hist_none 과 같다).
- **predictor 입력은 경계 2 튜블릿뿐이다.** 역사 토큰은 넣지 않는다. M6 2×2 에서 역사 토큰이 경계를 본 인코딩이라 생긴 오염을 피하기 위해서다. 기준 팔은 원래 인코딩의 full (8 튜블릿) 이다.
- predictor 두 종:
  - 릴리즈: 문맥 위치 6–7.
  - Ariel ep43: 문맥 위치를 0–1 로 다시 매긴다. 그러면 학습 분포 안 (C=2) 이고 `build_prefix_mask` dense 폴백 버그를 타지 않는다. 로그에서 `kind='prefix'` 를 확인한다.
- 대조: L=4 를 독립 4 프레임 clip 으로 인코딩한 판. 마스크 인코딩이 분포 밖이라서 생기는 효과의 크기를 잰다.
- 저장: 두 템플릿의 16×16 cos 지도 전체 (fp16). argmax 만 저장한 탓에 생긴 번짐 문제와 판독 의존 문제를 CPU 에서 다시 읽을 수 있게 한다.

**판독 (미리 고정)**
- 주: 경로 기울기 t0–2 / t3–7 / t8–11 (외형 템플릿, arc 제외), X3 식 멈춘 자리 b (법칙 고정효과).
- 보조:
  - t4 / t8 / t10 적중 − 전수 귀무 (두 템플릿).
  - 있음 = 연속 contrast. 문턱은 predictor 마다 빈 장면 귀무의 P95 로 잡는다 (0.357 을 옮기지 않는다).
  - 위치는 있음을 통과한 칸에서만 본다.
- CI: 궤적 56 군집 bootstrap 2000, L=16 과의 짝 차이.

**판정 규칙 (돌리기 전)**
- 릴리즈:
  - L 을 4 에서 16 으로 늘릴 때 t0–2 기울기 · b · 있음이 단조로 오르고 L=4 와 L=16 이 CI 로 갈리면: "encoder 가 여러 프레임의 운동을 경계 토큰에 통합한다" 를 시사로 올린다.
  - L ≥ 8 에서 평평하면 (기울기 \|Δ\| ≤ 0.05, 있음 ±0.03): abstract (i) 후반을 지운다.
- Ariel:
  - L=4 의 t3–7 기울기가 L=16 의 0.8 배 이상이면: 약 8 튜블릿 외삽에 필요한 상태는 마지막 4 프레임 안에 있다. 지평을 늘린 것은 predictor 쪽이다. 구성적 국소화가 가장 강해진다.
  - 0.5 배 미만이면: 학습된 predictor 도 encoder 의 다중 프레임 통합에 기댄다. 분업 문장은 "encoder 가 통합하고 predictor 가 외삽한다" 가 된다.
- 어느 결과든 abstract (i) · (iii) 과 README 의 "분업 귀속 미결" 이 한 문장으로 정해진다.

**하네스 질문**
1. 세우는 beat: 읽기와 구성적 국소화.
2. 결과가 어느 쪽이어도 beat 가 선다 (위 판정 규칙).
3. 이미 답이 있나: M6 는 L=4 극단 하나라 있음 붕괴로 결론이 나지 않았다. M13 enc_last 는 RoPE 위치가 어긋났다. 아직 미해결이다.
4. 교란: 마스크 인코딩이 분포 밖이라는 점은 용량 사다리와 독립 clip 판으로 다룬다. 있음 붕괴는 있음 통과 조건부 위치로 다룬다. 가속과 가림 아래 통합은 이 실험으로 말할 수 없다.
5. 재학습: 없다.
6. 표본: 궤적 56 개, 기존 기울기 CI 폭 약 ±0.03–0.05.
