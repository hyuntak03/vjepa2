## 0. 한 문장

> **사람은 관측만으로 intuitive physics 를 갖추고 그것으로 plausible future 를 상상한다.
> 지금의 world model 은 마지막 관측에 보이는 것만 짧게 외삽하고, 거기 안 보이는 것 (가려진 물체) 과 거기 없는 것 (가속의 누적 · 낙하 · 벽 · 꼭대기에서 되돌아옴) 은 예측하지 못한다.
> 필요한 정보는 encoder 에 있고 실패는 predictor 의 미래 예측에 있다 — 다시 학습해도 도메인 밖에서는 같다.
> 목표는 action 없이 관측만으로 intuitive physics 를 따르는 미래를 예측하는 predictor 이고, Ariel 을 넘어야 한다.**

**AC (action-conditioned) 는 그 predictor 위의 post-training — 논문의 작은 subsection 이다** (사용자 10-08). 스토리 초안은 [`09b_AC_STORY.md`](09b_AC_STORY.md) 에 있고 **아직 최종이 아니다** (사용자 10-10). "(1) 이 먼저여야 AC 도 효과" 는 실험 전까지 가설이다.
⚠️ "아직 최종 아님" 은 레포 문서 (정본 §2-5 · CLAUDE.md §0) 에 아직 없다. 그쪽은 10-08 판 ("작은 subsection + 실험 하나") 그대로다.

## 4. 읽는 규칙 (이 아카이브 공통)

- **등급**: 확정 (적대 검증 통과) · 1 차 (검증 전) · 시사 · 철회 · 문헌 · ★ 미실행. 원 문서의 등급을 따른다.
- **모든 점수는 복사 기준선과 같이 읽는다.** VoE 점수는 예측 없이 풀릴 수 있다 (02 장).
- **"보이는 것 / 안 보이는 것 / 없는 것" 은 마지막 관측 (문맥 끝) 기준이다.** 문맥 가운데 가림은 처리한다 — "context 에서 안 보이면 못 한다" (전부로) 는 금지.
- **학습된 자 (readout) 로 읽은 값** 은 자 검증 (held-out · encoder 대조 · 파라미터 0 검사 · 빈 장면 오탐) 과 같이 읽는다. 자는 대상이 없어도 기본값을 낸다 (03 장 §5).
- **대체된 판의 수치** 는 "대체된 판" 이라고 밝힌 채로만 쓴다 (예: presence 자 → identity_r8).
- **문서끼리 모순** 이면 한쪽을 지우지 않았다 — 조건 차이를 표로 남겼다 (각 장 끝 · 11 장).
- **금지 표현** 은 10 장 끝 표 (정본 §7). 원 문서가 그렇게 쓴 문장을 옮긴 곳에는 `(원 문서 표현 — 현재 금지)` 를 달았다. **α · 보정 · 헤지 계수는 값을 옮기지 않았다.**
