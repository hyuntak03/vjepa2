## 읽는 법

1. **가림 late 가 가장 크게 오른다** (+24~+30; vanish 는 50→100, static shape 54→94). late 안에서 k=1~4 가 전부 같이 오르고 (flat 84–86, ramp 84–90, static 84–89) — 릴리즈의 "k 무관 바닥" 이 "k 무관 천장" 으로 바뀐다.
2. **비가림·early·mid 도 오른다** (visible +4~+13, early/mid +7~+24). 릴리즈에서 이미 낮던 ramp visible shape 69.9 → 94.6. 즉 이득의 상당 부분은 가림 특이가 아니라 **v11 도메인 전체에 대한 적응**이다 (in-domain, 외형 holdout 없음).
3. **vanish 의 방향 비대칭이 사라진다**: 릴리즈 moving late vanish 는 A (물체→빈) 0 / B (빈→물체) 100 이었는데 post-FT 는 100/100. static late vanish 도 A 65 → 87, B 72 → 100.
4. **모양 순서 편향이 사라진다**: 등가속+가림 recall 이 릴리즈 cylinder 89 / cube 93 / … / sphere 34 / torus 4.5 → post-FT 82–91 로 평평 (torus +77). 비가림에서도 torus 40 → 90. 릴리즈의 "특정 모양으로 흘러내린다" 는 이 predictor 에는 없다.
5. **color 는 덜 오른다** (late +7~+9, moving; static late +23). color late 는 75–80 에 머물러 shape (82–94) 보다 낮다 — 남은 실패의 대부분이 색이다.
6. **IP1-FT 대조군 (IntPhys1 로 같은 레시피)**: static 가림은 v11-FT 와 거의 같이 오르는데 (early/mid +18~+35, late +12~+15) **moving 은 전혀 안 오르고 early/mid vanish 는 오히려 −23~−49 (A 방향)**. 즉 "정지 물체가 가림막 뒤에 그대로 있다" 는 IntPhys1 에서도 배워지는 일반 규칙이고, **움직이는 물체를 가림막 너머로 옮기는 것은 v11 에서만** 배워졌다 — 그게 RollOut 에서 v11 속도를 강요하는 것과 같은 항목이다.
7. held-out 은 문맥(block) 만 새 것이다. 같은 6 장면·7 모양·8 색·같은 속도. 도메인 밖 일반화는 `RESULTS_2026-09-16.md` (RollOut_v2, IntPhys1 −11.7) 에서 본다.
