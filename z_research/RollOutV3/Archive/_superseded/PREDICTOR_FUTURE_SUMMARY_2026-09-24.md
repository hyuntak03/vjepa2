# p 는 어떤 미래를 만드나 — 지금까지 정리 (2026-09-24)

> **한 장 요약.** RollOutV3 에서 오늘까지 한 것 · 확인된 것 · 접은 것 · 다음. 세부는 링크한 문서가 정본이다.
> 수치는 `exp_results/presence/`·`exp_results/windows/readings.npz` (자 지문 `dcd24d8a8a47`) 와
> `figures/behavior/CONTEXT_R2.md` 에서 다시 확인했다. RollOut_v2 수치는 CLAUDE.md §5-5 인용이다.

## 0. 결론 (현재)

**p 는 "마지막으로 본 상태를 그대로 연장" 하는 쪽에 가깝다.** 방향·속도는 이어 가고, 문맥에 없던 변화
(낙하·정지·가속 변화) 는 넣지 않으며, 그렇게 연장한 물체는 **미래 8~10 튜블릿 근처에서 사라지고 깜빡인다.**

| 부분 | 상태 |
|---|---|
| 물체가 튜블릿 수로 정해진 자리에서 사라진다 · 깜빡인다 | **확인됨** (v3, 두 자에서 재현) |
| 문맥에 없던 변화를 넣지 않는다 (연장) | **작업 가설** — 근거는 RollOut_v2 와 09-19 결과. v3 에서 직접 확인 안 함 |
| 속도·가속도를 얼마나 정확히 이어받나 | **이 자로는 못 잰다** (§4) |

연장 가설은 09-19 능력 정의의 현재 판정 (읽기 ✅ · 지속 ❌ · 전이 ◐ 방향·속도 O 가속도 X · 영속 ❌) 을
한 문장으로 묶는다. 다만 한 문장으로 묶인다는 것 자체가 증거는 아니다 — §3 의 검정이 필요하다.

## 1. 질문과 도구

**질문:** predictor 가 대체 어떤 미래를 만드나. 그래서 p 의 미래 토큰에서 **물체가 있나, 어디 있나** 를 읽는 위치 자를 가져왔다.

**자 = `attn`** — learnable query 1 개의 attention pooling + head 2 개 (좌표 · 있음/없음), **5,123 파라미터**, p·z·h 마다 하나.
학습셋 `training_v8` (RollOut_v2_training 14,360 clip), v3 는 test 로만 쓴다. 정본 `../README.md` §1~2.

| 표현 | AUROC | recall | precision | 위치 L2 평균 / 중앙 |
|---|---:|---:|---:|---:|
| `p` (predictor) | 0.986 | 94.1 % | 97.8 % | 16.1 / 13.5 px |
| `z` (context encoder, 창 전체) | 0.997 | 99.1 % | 98.4 % | 10.8 / 9.0 px |
| `h` (target encoder) | 0.997 | 99.0 % | 98.2 % | 10.6 / 8.8 px |

**자가 답할 수 있는 해상도 = "있다/없다" + "대략 어느 칸" (1 칸 = 18 px = 물체 반폭).** 그보다 작은 차이는 못 읽는다.
이 한계를 넘어서 재려다 §4 에서 길을 잃었다.

**데이터 `RollOut_v3`** — 8 법칙 × 392 clip, 64 프레임, 사건은 f32 고정, 창 16 개 (C·P ∈ {4,8,16,32}).
`ledge`·`wall` 은 가능 196 + 불가능 196 의 짝이다 — 불가능 쪽이 **"그대로 이어 간" 미래** (떠 가기 · 벽 통과) 이고,
f0~f32 문맥이 픽셀 단위로 같다 (최대차 0.000 px).

## 2. 확인된 것 (v3)

### 2-1. 자가 v3 로 옮겨 간다
`z`·`h` 의 recall 96.7~99.6 %, 위치 8.0~10.0 px. '없다' 오작동 `z` 0.0~5.7 % · `h` 0.1~4.1 % (16 창).
같은 튜블릿을 P 만 바꿔 재면 `p` 위치가 0.06~0.09 칸 안에서 같다 — **자가 창을 타지 않는다.**

### 2-2. 물체가 사라지는 자리는 튜블릿 수가 정한다
`p` recall 이 50 % 를 깨는 튜블릿 (P=32): **C4 t3 · C8 t6 · C16 t10 · C32 t8.**

- **P 와 무관** — C16 에서 P=16 과 P=32 가 같은 튜블릿에서 같은 값 (t7 90.1 vs 86.5 %)
- **속도와 무관** — 속도 3 분위가 모두 t10, 그때 이동 거리만 3.8 → 4.6 → 5.4 칸으로 따라 변한다
- **문턱과 무관** — 문턱 −1 ~ +1.5 에서 모두 t10. presence logit 자체가 t9 3.4 → t10 −1.0 으로 **절벽**
- **자의 고장이 아니다** — 같은 자리에서 `z` logit 은 오히려 오른다 (5.8 → 11.1)

### 2-3. 깜빡인다
C16/P32 recall t8 99 → t9 91 → **t10 12** → t11 35 → **t12 67** → **t13 7 %**. 8 법칙 중 7 개가 같은 t12 에서 되살아난다. **원인은 모른다.**

### 2-4. 이식 대조
C32/P32 후반 (t9~t14) 에 `h` 자를 `p` 에 걸면 23~48 % 만 '있다' 이고, 그때 위치 오차가 37.5 px (2 칸).
같은 `h` 자가 `h` 에는 94~97 %. → **"창 후반이라 자가 깨진다" 는 배제.**

정본: `RECALL_TUBELET_LIMIT_2026-09-24.md`, `../exp_results/windows/{WINDOW_SUMMARY,CROSS_HEAD}.md`.

## 3. 작업 가설 — 마지막 관측 상태의 연장

**뜻:** 마지막으로 본 상태 (위치·방향·속도) 를 그대로 늘여 붙인다. **"정지 복사" 가 아니다** —
"물체를 마지막 관측 자리에 둔 채 머문다" 는 이미 철회됐다 (CLAUDE.md §6, 자의 기본값이었다).

| 관찰 | 가설과 | 출처 |
|---|---|---|
| 방향·속도는 이어 간다 | 맞음 | 09-19 전이 ◐ |
| 가속도는 반영하지 않는다 | 맞음 | 09-19 |
| 선반: 떨어지지 않고 선반 높이 유지 (392 쌍 100 %) | 맞음 | RollOut_v2, §5-5 |
| 벽: 멈추지 않고 2 슬롯 통과한 뒤 물체를 놓친다 | 맞음 (멈추지 않음) | RollOut_v2, §5-5 |
| 가림이 문맥 경계에 걸리면 p 의 미래에 처음부터 물체다운 토큰이 없다 | 맞음 (마지막 관측 = 물체 없음) | v11, §5-5 |
| 연장한 물체가 일정 길이 뒤 사라진다 | 연장의 한계 | v3 §2-2, v2 거리 한계 |

**⚠️ 이 가설이 아직 결론이 아닌 이유**
1. **자유 운동 법칙 (flat·ramp·arc) 으로는 가를 수 없다.** 거기서는 "연장한 미래" 와 "실제 미래" 가 같은 궤적이다.
   p 가 거기서 맞게 움직여도 연장인지 물리를 아는 건지 모른다.
2. **가를 수 있는 ledge·wall 의 증거는 v2 것이다.** v3 에서는 v8 자가 선반 낙하 구간을 못 읽는다 (§5-1).
3. **v11 증거는 v5 자 + attention 질량으로 낸 것**이다. presence head 로는 아직 안 쟀다.

**검정 (결과가 어느 쪽으로도 나올 수 있는 것)**
- **A. v3 `ledge`·`wall` 짝, 자 없이.** 미래 튜블릿마다 p 가 "실제 미래" 의 h 와 "연장한 미래" (불가능 짝) 의 h 중
  어디에 더 가까운가. 문맥이 픽셀 단위로 같아 p 도 같다. 우리 표준 채점 (matched pair latent L1) 을 튜블릿별로 읽는 것.
- **B. v11 가림.** 늦은 가림은 문맥 끝에 물체가 가려져 있어 "마지막 관측 상태" 와 "세계 상태" 가 갈린다.
  연장이면 p 의 미래에 물체가 없고, 영속이 있으면 물체가 다시 나온다.

## 4. 시도했다가 접은 것 — 법칙별 운동학 (기록)

"behavior 를 수치로" 하려고 flat_v/a/d 등에서 **p 가 속도·가속도를 얼마나 이어받나** 를 재려 했다. 전부 접었다.

| 시도 | 접은 이유 |
|---|---|
| 궤적 R² (그대로 이어 가기 대비) | 자유 운동에서 이어 가기 ≈ 실제라 무엇이든 0.99 |
| R² 를 z 대비로 (z = 상한) | z 는 미래를 직접 보므로 공정한 상한이 아니다 (사용자) |
| 부호 검정 · 후보 2~3 개 투표 · 오차 막대 | 설명이 어렵고 복잡하다 (사용자) |
| 물리 파라미터 복원 | 물리 법칙을 맞히는지 보는 게 아니다 (사용자) |
| clip 간 회귀 R² (문맥 상태 → p 의 이동) | 한 법칙 안 clip 속도가 비슷해 t1 이동 차이 SD **3 px** < 자 오차 z **6.3** / p **12.2 px** → 미래를 직접 보는 z 도 R² **0.05**. 곡선이 오르는 건 행동이 아니라 신호 대 잡음 |
| 같은 속도끼리 평균 낸 R² + 기울기 (16 창) | 아래 |

마지막 시도는 자 검사를 통과했고 (z R² 0.88~0.99, 기울기 0.83~1.05) 모양도 창과 무관했다
(p 기울기 P32: 8 프레임 뒤 0.90~1.09 → 16 프레임 뒤 0.55~0.64 → 24 프레임 뒤 0.32~0.41).
그래도 접는다:

1. **v3 의 설계 축은 창 (C, P) 이지 법칙이 아니다.** 법칙은 장면을 다양하게 하는 측정 도구다.
2. **전이는 09-19 에 이미 정리됐다** (방향·속도 O, 가속도 X). 더 정밀하게 다시 잴 이유가 약했다.
3. **자의 해상도 (~1 칸) 아래를 재려 했다.** 짧은 창은 P4 전부, P8 대부분이 판정 불가였다.
4. ⚠️ **철회 — "p 는 8 프레임 뒤부터 물체를 덜 보낸다".** 기울기가 줄어드는 시점이 '있다' 비율이 떨어지는 시점과 겹친다.
   물체가 흐려지면 자가 기본값 쪽으로 끌리는데, CLAUDE.md §6 의 "p 가 슬롯 4 이후 멈춘다" (기각) 와 같은 함정이다.

**다시 시도하지 말 것:** v3 한 법칙 안에서 clip 간 회귀로 속도 이어받기 재기 · 기울기 감소를 "p 가 느려진다" 로 읽기.
산출물은 `../figures/behavior/` (보류 표시) 와 `../exp_results/windows/BEHAVIOR.md` (초안) 에 남겨 둔다.

## 5. 이 결과로 못 하는 주장 (결론과 같은 비중)

1. **선반 낙하 구간 (t9~t14) 은 판정 불가.** `ledge` C16/P32 에서 `z` recall 57~90 %. 학습셋의 그 높이 양성이 적고
   빈 장면 가중 9.0 배가 겹쳤다는 가설이 있으나 **검증 안 함** (`--no-weights` 재학습으로 가를 수 있다, ~15 분).
2. **가림에서 이 자를 믿을 근거가 없다.** 학습셋에 "가림막 뒤 = 없다" 음성이 없다. 구조물 속 (안 보임) 물체를 26~29 % '있다' 로 읽는다.
   **v11 가림에 그대로 걸면 "유지한다" 고 말하기 쉽다** — h 를 가려진 프레임에 걸어 자 검사를 먼저 해야 한다.
3. **RollOut_v2 의 "거리 한계 2~3 칸" 과 v3 의 "튜블릿 수" 는 잰 것이 다르다** (물체다운 토큰 위치 vs 있음/없음,
   stride 3 vs 1, 가림 유무). 한쪽으로 일반화하지 않는다. 모순인지 아닌지 **조건 표로 아직 안 갈랐다.**
4. **C8 수치 단독 인용 금지** (깜빡임 때문에 첫 교차점이 불안정). t0~t7 의 몇 pt 차이는 자의 미탐 바닥 (5.9 %) 안이다.
5. **두 자가 "둘 다 없다" 에 합의하는 정도는 52~76 %** 로 강하지 않다. 절벽 위치를 한 칸 단위로 못 박지 않는다.
6. **파라미터 없는 대조가 없다.** 예전 `rule_auc` 는 버그였다.
7. **깜빡임의 원인을 모른다.**
