# RollOutV3 / new_archive — p 는 어떤 미래를 만드나 (정리 2026-09-25)

> **이 문서가 new_archive 의 정본이다.** 앞 판 (2026-09-24) 은 [`_superseded/README_2026-09-24.md`](_superseded/README_2026-09-24.md) 에 그대로 있다.
> 수치는 모두 감사 산출물 (`_audit/`) 이나 각 실험 폴더의 json 에서 가져왔고, 칸마다 출처 파일을 적었다. 감사에서 약해지거나 반박된 주장은 그 사실을 함께 적었다.
> 기호: **p** = predictor 미래 출력 · **z** = context encoder (online) · **h** = target encoder (EMA) · **자** = attn 위치·있음 readout (§1) · **1 칸 = 18 px = 물체 반폭** · t = 미래 튜블릿 번호 (t0 = 첫 미래 튜블릿).
> 모델은 V-JEPA 2 ViT-H 릴리즈이고 frozen 이다. 능력 정의는 2026-09-19 사용자 결정 (1 읽기 · 2 지속 · 3 전이 · 4 영속, [`STATE_EVOLUTION_CAPABILITIES_2026-09-19.md`](../../context_encoder_analysis/Archive/STATE_EVOLUTION_CAPABILITIES_2026-09-19.md)) 을 따른다.
> **물리 장면은 측정 도구다. "물리를 아는가" 는 묻지 않는다.** 사건 (ledge 낙하, wall 정지) 은 정의에서 빠진 common sense 문제라서 참고로만 적는다.

## 0. 한 장 요약

**결론.** p 의 미래는 마지막으로 본 장면을 복사한 것이 아니다. p 는 본 방향·속도로, 궤적마다 다른 만큼 물체를 옮긴다.
다만 멀리 갈수록 덜 옮기고, 일정 튜블릿이 지나면 자가 물체를 찾지 못한다. 또 문맥 끝에 가려진 움직이는 물체는 다시 보여야 할 미래에서도 '있음' 으로 읽히지 않는다.
**p 의 미래에 물체가 있는지는 문맥 끝 (마지막 관측) 에서 물체가 보였는지를 따른다.** 정체 (shape · color) 는 encoder 가 가려진 프레임에도 싣고 p 에서도 선형으로 읽힌다. 하지만 p 쪽 수준은 문맥을 복사한 기준선을 넘지 않는다.

## 1. 측정 도구

**자 (`attn`)** 는 learnable query 1 개로 토큰 256 개를 attention pooling 하고 head 둘 (xy 좌표 · presence logit) 을 붙인 readout 이다. 파라미터는 5,123 개이고 p · z · h 마다 하나씩 있다.
학습셋은 `training_v8` (RollOut_v2_training 14,360 clip) 이고, v3 와 v11 에는 test 로만 건다.
파일은 `../exp_results/presence/` 에 있다 (`summary.json` 의 `thr_val_fpr5`, `attn_bias_px.json`). 지문은 `dcd24d8a8a47` 이고, 지문이 다르면 `rollout3_paths.check()` 가 실행을 멈춘다.

|---|---|---|---|
| 문턱 (val 음성 5 % 오탐, 하나만 쓴다) | +0.83 | −0.66 | −0.96 |
| AUROC | 0.986 | 0.997 | 0.997 |
| recall / precision | 94.1 / 97.8 % | 99.1 / 98.4 % | 99.0 / 98.2 % |

출처: [`../figures/readout/ERRORS.md`](../figures/readout/ERRORS.md), [`../README.md`](../README.md) §2.

- **encoder 대조.** v3 16 창에서 z · h 자는 recall 96.7–99.6 %, 위치 8.0–10.0 px 다. '없다' 오작동은 z 0.0–5.7 %, h 0.1–4.1 % 다. v3 에는 음성이 0 개라서 이 값이 곧 자의 오작동률이다 (`../README.md` §3).
- **파라미터 없는 교차검증.** 자 자체에 대한 것은 아직 없다 (예전 `rule_auc` 는 버그였다, `../README.md` §4-4). 그래서 결론마다 자 없는 비교를 따로 붙였다. v3 에는 템플릿 argmax (`auto_research/Archive/H23_PREDICTOR_LAYERS_TRAJECTORY_2026-09-24.md` §3-4), v11 에는 vanish matched-pair latent 비교 (§5) 를 쓴다.
- **읽는 규칙** (2026-09-24 교차 검토, `auto_research/Archive/CROSS_REVIEW_2026-09-24.md`):
  (1) 문턱은 하나만 쓴다.
  (2) 적중은 귀무와 함께 읽는다. 귀무는 v3 에서는 같은 법칙의 다른 궤적, v11 에서는 같은 조건의 빈 장면이다.
  (3) v3 의 표본 단위는 **궤적**이다 (법칙마다 14 개, clip 은 외형 복사본이다). v11 은 block, 또는 (궤적, k) 단위로 센다.
  (4) 능력 증거로 쓰는 값에는 **복사 기준선**을 붙인다.

**알려진 실패 구역.** 아래 칸에서 나온 값은 p 탓인지 자 탓인지 가르지 못한다.
1. **화면 가장자리 36 px 안, 그리고 화면 밖.** 가리지 않은 v11 에 h 자를 걸어도 flat t5 는 69 %, t6–t7 은 0 % 만 '있다' 로 읽힌다 (`_audit/v11_presence/tables.txt`).
2. **가림.** 자는 가림 음성을 배운 적이 없다. v11 에서 가려진 물체를 h 자는 33.3 %, z 자는 19.4 % '있다' 로 읽는다 (`../exp_results/v11/V11_READOUT.md` §0). training_v8 에서 구조물 속에 있어 안 보이는 물체는 26–29 %, 판과 겹쳤지만 보이는 물체는 94–97 % '있다' 로 읽힌다 (`ERRORS.md`). 그래서 가려진 칸의 '있다' 는 과대 추정일 수 있고, 가려진 칸의 '없다' 는 보수적인 판정이다.
3. **선반 낙하 구간.** `ledge` C16/P32 t9–t14 에서 z recall 이 57–90 % 로 빠진다 (`../README.md` §4-1). 이 구간은 판정 불가다.
4. **attention 이 퍼질 때 나오는 기본값.** 자는 풀링 벡터에서 좌표를 회귀한다. 그래서 물체다운 토큰이 없으면 토큰 평균 자리를 낸다. 후반 튜블릿에서 보이는 위치 정체나 속도 0 을 "멈춤" 으로 읽지 않는다 (CLAUDE.md §6 에서 같은 해석을 철회했다). attention top1 은 진단에만 쓰고, 판정은 presence logit 으로만 한다.

**h 자를 주 도구로 쓰지 않는 이유.** h 자를 p 에 걸면 (`p@h`) 문턱과 치우침이 h 기준이라 p 에 맞지 않는다.
v3 C16/P32 flat_v 에서 `p@h` 의 attention top1 은 0.147 (t0) 에서 0.017–0.030 (t8–t15) 으로 무너진다. 같은 칸의 h@h 는 0.09–0.25 를 유지한다. 그런데도 `p@h` 는 t4–t9 에서 82–100 % '있다' 를 낸다 (`readings.npz` 에서 다시 계산).
y 도 위로 끌린다. flat · wall 에서 t0 +18–21 px, t7 +34–46 px, C16/P32 t14 +60–65 px 이고, 같은 칸의 h@h y 는 −2.7~+1.1 px 다 (`v3_signed_error_hhead/values.json`).
그래서 h 자는 **자 의존성 검사**로만 쓴다. 두 자가 같은 방향을 가리킬 때만 주장한다.
p 자기 자에도 위험이 있다. 첫째, p 에서 진실을 복원하도록 학습됐으므로 p 의 체계적 어긋남을 되돌려 읽을 수 있다. 둘째, p 자의 attention top1 도 0.18 (t0) 에서 0.03–0.06 (t8–t15) 으로 퍼진다. 셋째, 화면 x 에 고정된 짝/홀 교대 (§3) 는 p 자기 자로 읽을 때만 나타난다.

## 2. `v3_signed_error/` (+ `v3_signed_error_hhead/`) — 축마다 앞섬 (+) / 뒤처짐 (−)

### 왜 했나
|오차| 그림 (옛 `v3_l2_error`, 뺐다) 에는 방향이 없다. 그래서 세 가지를 가를 수 없었다: 마지막 자리에 멈춤 (복사), 본 운동을 그대로 늘임 (등속 연장), 진실을 따라감.
작업 가설 "p 의 미래 = 마지막 관측 상태의 연장" ([`../Archive/PREDICTOR_FUTURE_SUMMARY_2026-09-24.md`](../Archive/PREDICTOR_FUTURE_SUMMARY_2026-09-24.md) §3) 이 맞다면 다음이 보여야 한다: 감속 법칙은 앞서고, 가속 법칙은 뒤처지고, 포물선과 낙하는 덜 떨어지고, 벽에서는 계속 간다. 부호로 재면 이것을 가를 수 있다.
부호 정의는 사용자가 정했다 (2026-09-24). 같은 날 네 번 바뀌었고, 버린 정의는 `_superseded/{screen_sign, along_1row}/` 에 있다.
`_hhead` 는 같은 그림을 **h 로 배운 자**로 읽은 것이다. p 자기 자가 p 의 어긋남을 되돌려 읽는지 가르는 **자 의존성 검사**이고, 독립 실험이 아니라 이 절에 합쳤다.

### 무엇을 쟀나 (정의)
- **입력.** `../exp_results/windows/readings.npz` (자 지문 `dcd24d8a8a47`) 의 가능 clip 2,744 개 = **궤적 112 개**다. 자유 운동 6 법칙은 궤적 14 개 × 외형 28 복사, ledge · wall 은 궤적 14 개 × 14 복사다 (`data_csv/rollout_v3/index.csv`, 궤적 = (scenario, primary, secondary)). 사건은 f32 에 고정했다. 문맥은 `[32−C, 32)`, 예측은 `[32, 32+P)` 이고, C · P ∈ {4, 8, 16, 32} 로 창이 16 개다.
- **진실과 읽은 값.** 진실 X(t) = GT 프레임 (32+2t, 33+2t) 의 평균이다. 읽은 값 x̂ = 자 좌표 − 치우침 (§1) 이다. '있다' = logit > `thr_val_fpr5` 다.
- **부호.** s_a(t) 는 clip 마다, 축마다 정한다. 그 튜블릿에서 GT 가 축 a 로 1 px 이상 움직이면 그 방향의 부호를 쓴다. 덜 움직이면 직전 부호를 쓴다 (시작값은 문맥 끝 속도의 부호). 끝까지 한 번도 안 움직인 축은 x 는 +, y 는 "위 = +" 로 둔다 (패널에 `no GT y-motion: + = above` 로 표시).
  **오차_a(t) = (x̂_a − X_a) · s_a** 이고, + 는 GT 운동 방향으로 앞섬, − 는 뒤처짐이다.
- **그림.** 법칙마다 '있다' 로 읽힌 clip 의 평균을 그린다. 그 튜블릿에서 clip 과반이 '없다' 면 0 에 빨간 점을 찍는다.
  - 초록 선 = 같은 계산을 z 에 한 것 (z 자, 자 검사).
  - 파선 = 등속 연장 (x0 + v0·(t+1) − X)·s.
  - 쇄선 = 복사 (x0 − X)·s.
  - x0 = GT 프레임 30–31 의 평균, v0 = x0 − (GT 프레임 28–29 의 평균).
  - ⚠️ 2026-09-25 에 16 장씩 기준선을 넣어 다시 그렸다. 그 전에는 C4_P4 · C4_P8 두 장에만 기준선이 있었다. `values.json` 은 바이트 단위로 같다.
- **`_hhead`.** 읽는 키는 `C{c}_P{p}_p@h` 이고, 문턱 −0.96 과 치우침 (−1.11, +5.58) 은 h 의 것이다. p 기준으로 다시 보정하지 않았다. 초록 선은 여기서도 z 다 (같은 자 대조인 h@h 가 아니다).
- **옛 `v3_l2_error` 에서 옮긴 규칙.** 빼는 칸은 없다 (C4/P4·P8 의 t0 에서 z·h '없다' 는 0–7 % 였다). 물체가 화면에 있는데 z 가 clip 의 10 % 넘게 '없다' 로 읽은 칸 (hfail) 은 `values.json` 에만 표시한다.
- **판정은 그림이 아니라 감사 (`audit_v3_motion.py`) 로 한다.**
  - 궤적 단위로 센다: 외형 복사본을 먼저 평균하고, 궤적 14 개 bootstrap 4,000 회로 95 % CI 를 낸다.
  - 기준선은 셋이다: **복사** · **등속 연장** · **1 튜블릿 늦은 추적** (지연 추적은 법칙 대비를 ≈ 0 으로 예측한다).
  - 귀무 = 같은 법칙의 **다른 궤적** 진실이다.
  - 창은 넷이다: C16/P16 · C16/P32 · C32/P32 · C8/P32.

- **H_copy — p 는 물체를 마지막 관측 자리에 둔다.** 기각되면 p 의 미래에 운동이 들어 있다는 뜻이고, 기각되지 않으면 전이 ❌ 다. → **기각** (t1 부터, 네 창, §3 의 기울기로 두 자 모두).
- **H_ext — p 는 문맥 끝 속도를 그대로 늘인다 (가속 무시).** 이 가설이 맞으면 두 자와 자 없는 argmax 가 모두 "flat_d 앞섬 · flat_a 뒤처짐" 을 연장 크기로 보여야 한다. 반대로 진실을 추적하거나 한 튜블릿 늦게 추적한다면 법칙 대비는 ≈ 0 이어야 한다. → **미확정**. p 자는 연장 크기를 보이고, h 자와 argmax 는 반대 방향이다. 연장과 진실의 차이도 자의 해상도 (1 칸) 보다 작다.

## 3. `v3_trajectory/` — 마지막 관측 자리에서 옮긴 양 (위치–시간 · 속도–시간)

### 왜 했나
오차 그림만으로는 p 가 실제로 어떤 궤적을 그리는지가 보이지 않는다. 그래서 문맥 마지막 튜블릿에서 옮긴 양 (변위) 을 GT (문맥 구간 포함) · p · z 로 겹쳤다.
이 좌표계에서는 **복사 = 0 선**이고, **등속 연장 = 문맥 구간 GT 기울기를 이어 그은 직선**이다. "p 는 어떤 미래를 만드나" 를 가장 직접 보여 주는 그림이다.

### 무엇을 쟀나 (정의)
- 가능 clip 만 쓴다. p 는 p 자 (문턱 +0.83, p 치우침), z 는 z 자 (문턱 −0.66, z 치우침) 로 읽는다.
- 위치 = (값 − x0) × 뒤집기 (y 는 위 = +) 다. x0 는 문맥 마지막 튜블릿의 GT 다.
- 속도 = 튜블릿 사이 차분 (px/튜블릿) 이다. p · z 의 속도는 t 와 t−1 이 모두 '있다' 인 clip 만 쓴다.
- GT 는 법칙의 clip 전부로 평균하고, p · z 는 그 튜블릿에서 '있다' 인 clip 만으로 평균한다 (두 평균의 clip 집합이 다르다). 과반이 '없다' 인 칸에서는 p 선을 끊고 빨간 점을 찍는다.
- 그림은 16 행 (8 법칙 × x, y) × 2 열 (위치 · 속도) 이고, 창마다 한 장이다.
- ⚠️ 그림의 x 축은 "0 = 문맥 마지막 튜블릿" 이라서 미래 t0 가 1 에 그려진다. 이 README 의 t 는 미래 튜블릿 번호다.
- 연장선은 그림에 없다. 복사는 0 선으로만 암묵적으로 있다. 수치 판정은 감사가 한다.
  - **법칙 안 변위 기울기**: 궤적 평균으로 읽은 변위를 GT 변위에 회귀한 기울기다. 복사면 0, 진실 추적이면 1 이 나온다. 이 기울기가 능력 정의 3 의 "문맥 조건끼리 진실 미래가 다를 때 예측 미래도 그만큼 다르다 (gain ≈ 1)" 를 궤적 단위로 잰 값이다.
  - **변위 귀무**: 다른 궤적의 GT 변위와 비교한 오차다.
  - **'있다' 절벽**.
  - **짝/홀 교대**.

- 교대가 p 의 특징에서 오는지 p 자에서 오는지.

⚠️ **앞선 철회와의 관계** (조건 차이를 적고 어느 쪽도 지우지 않는다).
`PREDICTOR_FUTURE_SUMMARY` §4 는 두 가지를 접었다: "v3 한 법칙 안에서 clip 간 회귀로 속도 이어받기 재기" 와 "기울기 감소를 'p 가 느려진다' 로 읽기". 이번 감사는 조건이 다르다.

| | 09-24 접은 시도 | 이번 감사 |
|---|---|---|
| 회귀 단위 | clip (외형 28 복사가 섞인다) | **궤적 평균** (외형 복사를 먼저 평균) |
| 자 검사 | z R² 0.05 (신호 < 자 잡음) | **z 기울기 0.88–1.03** 통과 |
| 기울기가 줄 때의 '있다' | 떨어지는 시점과 겹침 | C16/P32 t5–t9 에서 0.89–0.99 (높음) |
| 자 끌림 | 배제 못 함 | **여전히 배제 못 함** (top1 이 퍼진다) |

→ t2–t4 의 ≈ 1 은 **확실**로 쓴다. t6–t9 의 감소는 argmax 와 같은 방향이지만 자 끌림을 배제하지 못해 **조건부**다.

### 검증하는 가설
- **H_copy** → 기울기 0 을 예측한다 → **기각** (t2–t4 ≈ 1).
- **H_track (진실을 따라간다)** → 모든 t 에서 기울기 1, 변위 귀무 ≈ −6 ~ −18 px 를 예측한다 → t2–t4 에서만 지지, 그 뒤는 기울기와 귀무 모두 약해진다.
- **H_persist (지속: 물체가 거리와 무관하게 미래에 남는다)** → '있다' 가 z 처럼 유지되어야 한다 → C16/P32 에서 **기각** (t10 에 0.10). 창에 따라 모양이 다르다.

## 4. `v3_gif/` — 영상 위의 진실 · p · h (삽화, 주장 없음)

### 왜 했나

  - 흰 고리 = 그 튜블릿의 진실 (흰 선 = 지나온 경로).

### 검증하는 가설
- **H1 영속 — 문맥 끝에 가려진 물체가 다시 나타나는 튜블릿에서 p 가 물체를 담는가.** p '있다' 가 h 와 visible 수준이면 영속 ✅ 이고, 빈 장면 귀무 수준이면 ❌ 다. 이 경우 p 의 미래는 물체가 안 보이는 마지막 관측 상태를 따른 것이다. → **움직이는 물체에서 ❌** (자 · 자 없는 비교 · 두 궤적 모두 같은 방향). 어느 결과가 나와도 결론은 선다.
- **H2 교란 — 장면에 판이 서 있어서 자나 p 가 판에 속는다.** mid (판이 있고 문맥 끝에 물체가 보임) 가 visible 수준이면 기각된다. → mid flat 은 자 없는 비교 98–100 % 로 대체로 기각되지만, mid ramp 와 static 에서는 판이 자를 오염시킨다.
- **H3 static 복원.** → 이 자로는 **판정 불가**다. 자 없는 비교 41–82 % 는 부분 복원을 시사한다.
- **H4 (부수) visible 위치가 복사를 이기는가.** → 이긴다 (t2 부터). 하지만 약 60–77 px 에서 포화한다 (RollOutV2 의 거리 한계 40–60 px 와 같은 현상).

## 6. `v11_probe/` — 정체 (shape 7 지 · color 8 지) 는 어디서 읽히나 (평균 풀링 선형 probe)

### 왜 했나
§5 에서 위치·있음 자는 late 가림의 움직이는 물체를 p 의 미래에서 '없음' 으로 읽었다. 그러면 다음 질문이 생긴다: **p 가 물체 정보를 잃은 것인가, 아니면 '여기 물체가 있다' 는 형태로만 없는 것인가.**
사용자 가설 넷을 하나씩 검사한다 (앞 판 §9):
- (a) encoder 는 가려진 프레임에서도 정체를 싣는다 → (3)
- (c) p 에서도 정체가 읽힌다 → (5)
- (d) p 는 encoder 와 다르게 놓아서 encoder 머리가 이식되지 않는다 → (6)
- (2) 는 encoder 가 정체를 읽는가를 보는 기준선이다.
CLAUDE.md §5-2 의 attentive probe 결과를 값싼 도구 (평균 풀링 선형) 로 다시 보려는 목적도 있다. 캐시만 쓰고 재학습은 없다.

### 무엇을 쟀나 (정의)
- **clip.** `data_csv/intphysgen_v11_full/index_probe.csv` 에서 가능 · `probe_type==obj` 인 것. visible 3 조건 (sym_k=0) 과 late 3 조건 (sym_k 1..4) 을 합쳐 **9,408 clip / 5,376 block** 이다. 라벨은 `shape_pre` · `color_pre` 다 (가능 변이라 pre = post).
- **특징** (`v11_pooled_features.py`, fp16, 튜블릿마다 256 토큰 평균):
  - z = context encoder 를 문맥 16 샘플에만 돌린 것 (`ctx_masked` = predictor 입력, affine-free LN), (n, 8, 1280).
  - p = predictor 미래 8 튜블릿 (LN 을 다시 걸지 않음).
  - h = target encoder 를 32 샘플 전부에 건 것 (LN), (n, 16, 1280).
- **풀링.**
  - z_all = 문맥 8 튜블릿 평균.
  - **z_hid** = 두 샘플이 모두 hidden 인 문맥 튜블릿의 평균 (k=2,3 → t7, k=4 → t6–7).
  - z_t7 = 마지막 문맥 튜블릿 (**복사 기준선**).
  - p_fut = p 8 튜블릿 평균.
  - h_fut = h 튜블릿 8–15 평균.
- **probe.** source train 통계로 표준화한 뒤 multinomial logistic 을 맞춘다 (L-BFGS float64). λ 는 train 안의 block hold-out 으로 고른다.
- **감사의 대조 probe.** 닫힌 해 ridge (레포 probe 코드와 독립). 표기는 `logistic / ridge` 다.
- **split.** 레포 `WMADataset._split` 을 쓴다: block 단위, train 0.5, seed 0, condition 층화. train 4,692 / test 4,716 clip 이고 겹치는 block 은 0 이다. CI 는 test block bootstrap 1,000 회다.
- **(6) 이식.** encoder 머리를 p 에 그대로 건다 (raw). 또는 직교 Procrustes 를 거친다: train clip 짝으로 SVD((p−μp)ᵀ(S−μS)) = UΣVᵀ, R = UVᵀ 를 구하고, 라벨은 쓰지 않고 clip 짝은 쓴다.

- 이식 수치의 크기 비교. raw 이식은 probe 에 따라 최대 약 48 pt 다르다 (z 머리 → h_fut raw shape: logistic 83.7 vs ridge 35.5).
- ~~"(4) encoder 안에서도 이식이 안 된다 — 정보는 있는데 자리가 다르다"~~ (앞 판 §7). 풀링 불일치가 섞인 기준선이다.
- "표현이 회전했다". 잰 것은 "clip 짝으로 맞춘 직교 사상 하나가 이식을 되돌린다" 이다.
- 조건 안 95–99 % 를 수준으로 인용하는 것. 쌍둥이 공유 split 의 값이므로 쌍둥이 없음 · 장면 hold-out 값을 같이 적는다.
- 토큰 수준 결론. 평균 풀링은 위치를 버린다.

### 검증하는 가설
- **(a) encoder 는 가려진 프레임에도 정체를 싣는다.** 실패했다면 정체는 보이는 프레임에만 국소적이었을 것이다. → **확인** (95.7 / 93.9). 다만 "그 프레임 혼자 안다" 와 "앞 프레임에서 옮겨 왔다" 는 가르지 못한다.
- **(c) p 에서 정체가 읽힌다.** 실패했다면 "정보 손실" 로 읽혔을 것이다. → **확인**. 다만 **복사 수준**이다. 그래서 이 결과는 "p 가 문맥이 가진 정체를 잃지 않는다" 까지만 세우고, 영속의 증거가 되지 않는다.
- **(d) p 는 encoder 와 다르게 놓는다.**
  - raw 불일치가 크고 직교 사상으로 돌아온다면 정렬 개입 (CLAUDE.md §10 #4 Procrustes p→h) 의 근거가 된다.
  - raw 불일치가 작다면 이식 실패는 조건 이동 (가림막 존재) 뿐일 것이다.
  - → **둘 다 있다.** raw 에서는 p 만 어긋나고 (방향), 조건 이동은 네 표현 모두에 있다 (§7).

## 7. `v11_geometry/` — 풀링 표현 기하: p 의 정체 배치는 encoder 와 다른가, 가림이 그것을 만드는가

### 왜 했나
사용자가 PCA · t-SNE · CKA 로 "z · p · h 가 표현으로서 어떻게 다른가 (visible vs late)" 를 보자고 했다. 이유는 둘이다.
1. §6 (6) 에서 encoder 머리가 raw p 에 안 통했다. 그것이 다른 표현이라서인지, 가림이 만든 것인지를 라벨 없는 기하로 확인하려 했다.
2. CLAUDE.md §10 #1 "부분공간 겹침 / Procrustes (beat 5)" 의 풀링 판이다. 겹침이 작으면 "배치가 바뀐다" 가 확정되고, 크면 개입이 채점층으로 좁혀진다. 어느 쪽이 나와도 결론이 선다.

### 무엇을 쟀나 (정의)
- §6 과 같은 9,408 clip 과 같은 split 을 쓴다. 표현 (clip 당 D = 1280) 은 넷이다:
  - z_all
  - p_fut
  - h_fut
  - h_ctx (h 튜블릿 0–7 평균, z 와 같은 프레임을 보는 다른 encoder)
- **resid** = 장면 칸 (env × condition × sym_k, 60 칸) 평균을 train 으로만 추정해 뺀 것이다 (라벨은 쓰지 않는다).
- **분산 몫** = 집단 평균이 설명하는 분산 / 전체 분산.
- **이식 (G5).** visible 에서 train 한 선형 probe (λ = 1e-3 고정) 로 late 를 test 한다. resid 이식은 late 칸 평균 (라벨 없는 late train clip) 을 쓴다.
- **클래스 평균 부분공간 (G6 · G7).**
  - 중심화한 클래스 평균의 span 이다 (shape rank 6, color rank 7).
  - captured = ‖M U‖² / ‖M‖².
  - 교차 적합: 한쪽 표현은 block 절반에서, 다른 쪽 표현은 나머지 절반에서 추정한다.
  - split-half 천장으로 정규화한다.

## 단서

- **모든 v3 · v11 존재·위치 수치는 학습된 자로 읽었다.** 자에 대한 파라미터 없는 교차검증은 아직 없다. 결론마다 자 없는 비교 (v3: 템플릿 argmax, v11: vanish latent 쌍) 를 따로 붙였고, 그것과 방향이 같은 결론만 "확실" 로 올렸다.
- **자의 알려진 실패 구역** (가장자리 36 px, 가림 '있다' 편향, 선반 낙하 구간, attention 이 퍼질 때 나오는 기본값) 에 걸친 값은 읽지 않았다 (§1).
- **v3 의 유효 표본은 궤적이다** (법칙마다 14 개). 그림은 clip 평균이고 CI 가 없다. 판정은 `_audit/v3/` 의 궤적 단위 CI 로 한다.
- **v11 움직이는 팔은 궤적 둘** (l2r · r2l) 이다. 결론의 범위는 "이 고정 기하 (팔마다 속도 하나, 두 방향)" 다. 크기는 방향에 따라 다르다 (last flat t3: 0.06 vs 0.41).
- **v11 정체 probe 의 조건 안 95–99 % 는 외형 쌍둥이를 공유하는 split 의 값이다** (test 의 82.8 %). 수준을 인용할 때는 쌍둥이 없음 · 장면 hold-out 값을 같이 적는다.
- **late 에는 가림막이 장면에 있다** (CLAUDE.md §8-5). visible ↔ late 비교는 "가려짐" 과 "가림막 존재" 를 가르지 않는다. mid 와 last 는 k 가 같아도 가려진 길이 (k vs 2k 샘플) 와 판의 위치가 다르다.
- **평균 풀링은 위치를 버린다.** §6 · §7 은 토큰 수준 결론이 아니다.
- **이식 크기는 probe 에 따라 최대 약 48 pt 다르다.** 주장은 방향과 "같은 조건 짝 Procrustes 로 돌아온다" 까지만 한다.
- 모델은 하나 (ViT-H 릴리즈, frozen) 이고, 합성 데이터 두 세트다.
- 이 README 의 G5 이식 차 CI 와 (4) 풀링 대조는 스크래치 감사 (`/tmp/claude-1070/.../scratchpad/audit/v11_probe_geom_audit.json`, 레포 밖) 에서 왔다. 영구 산출물이 필요하면 `audit_v11_identity.py` 에 A3 · A4 를 옮겨야 한다.
