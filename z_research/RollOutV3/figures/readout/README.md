`fig_readout_train.png` 은 **자를 배운 세트**의 그림이다 — 세트가 바뀌어도 파일 이름은 그대로고 제목에 세트 이름이 들어간다.

## 용어

| 말 | 뜻 |
|---|---|
| **recall** | 물체가 **보이는** 칸을 "있다" 고 맞힌 비율 |
| **precision** | "있다" 고 답한 칸 중 실제로 있던 비율 |
| **specificity** | 물체가 **없는** 칸을 "없다" 고 맞힌 비율 (= 1 − 오탐률) |
| **AUROC** | 문턱과 무관한 분리도. 양성 한 칸의 점수가 음성 한 칸보다 높을 확률 |
| **제외 칸** | 학습에서 뺀 칸 — **판과 겹침** (물체가 보인다) · **구조물 속** (물체가 안 보인다). 정답이 없다 |
| **L2 오차** | `‖pred − truth‖₂`, px. 1 칸 = 18 px = 물체 반폭 |

⚠️ **v3 에는 음성이 한 칸도 없다** → v3 에서는 recall 만 정의된다.

## `fig_readout_train.png` — 자를 배운 세트 (training_v8 test)

| 표현 | AUROC | recall | precision | specificity | L2 평균 / 중앙 |
|---|---|---|---|---|---|
| `p` | 0.986 | 94.1 % | 97.8 % | 94.5 % | 16.1 / 13.5 px |
| `z` | 0.997 | 99.1 % | 98.4 % | 95.7 % | 10.8 / 9.0 px |
| `h` | 0.997 | 99.0 % | 98.2 % | 95.2 % | 10.6 / 8.8 px |

- **`p` 의 실패는 한 방향** — precision 은 셋이 비슷하고 (97.8~98.4 %) recall 만 `p` 가 5 pt 낮다
- **제외 칸은 두 종류로 갈라 읽는다** (그림 맨 아래 캡션). 판과 겹친 물체 (보임) 는 94~97 % "있다",
  **구조물 속 물체 (안 보임) 는 26~29 % "있다"** — 둘 다 자연스러운 방향이다.

## `fig_readout_v3.png` — 자가 못 본 세트

| P | `z` recall · L2 ('있다' 만) | `h` recall · L2 | `p` recall · L2 |
|---|---|---|---|
| 4 | 99.4 % · 8.5 px | 99.5 % · 8.7 px | 96.5 % · 15.4 px |
| 8 | 99.6 % · 8.9 | 99.6 % · 8.7 | 90.8 % · 16.0 |
| 16 | 99.5 % · 8.6 | 99.6 % · 8.0 | 82.8 % · 17.0 |
| 32 | 96.7 % · 9.9 | 97.4 % · 9.4 | 60.3 % · 25.6 |

- **`z`·`h` 는 P 에 거의 안 움직인다** — 자가 창을 안 탄다. 위치는 8~10 px (반 칸 안)
- **`p` 만 움직인다** — recall 96.5 → 60.3 %. (b)↔(c) 의 차이 (P=32: 32.2 → 25.6 px) 가 "놓쳤다고 스스로 말한 칸" 의 몫이다

## `fig_recall_by_tubelet.png` — 언제 놓치나

읽을 것:
- **`z`·`h` 는 16 칸 전부에서 평평**하다 → `p` 의 하락은 predictor 의 성질이다
- **`p` 는 t8 근처에서 절벽**이다 (P=32: C4 t3 · C8 t6 · C16 t10 · C32 t8)
- **깜빡임도 남는다** — C16/P32 에서 t10 12 % → t12 67 % → t13 7 %
- ⚠️ 창을 평균하지 않는다 (평균하면 어느 창에도 없는 봉우리가 생긴다)

## 읽을 때 붙는 단서

- 에러바 = **clip 을 재표집한 95 % bootstrap CI** (비율·평균 2,000 회 · AUROC 600 회)
- 좌표는 **"있다" 고 답한 칸에서만**, **치우침을 뺀 뒤** 잰다
