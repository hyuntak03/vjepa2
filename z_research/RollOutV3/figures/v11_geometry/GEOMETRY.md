# v11 풀링 표현 기하 — z · p · h 는 표현으로서 어떻게 다른가 (2026-09-24)

> 모든 수치는 `results.json` 에서 다시 뽑았다 (`v11_pooled_geometry.py --tables` 가 그 파일만 읽어 표를 찍는다).
> 그림 5 장은 같은 실행의 산출물이다 (seed 0). 마지막 두 번의 전체 실행에서 `--tables` 출력이 한 자리도 다르지 않았다 (순열 · bootstrap 포함).
> `fig_cka.png` 만 colorbar 잘림을 고친 뒤 같은 `results.json` 에서 `fig_cka()` 로 다시 그렸다.

## 0. 결론 먼저

1. **풀링 벡터의 전역 기하는 장면이 정한다.** env × condition × k (60 칸) 평균이 분산의 **75–81 %** 를 설명한다 (네 표현 공통).
   shape 는 3.1–3.9 %, color 는 0.5–0.6 % 다. 그래서 raw CKA (0.967–0.996) · PCA (표현별 PC1/2 의 칸 η² 0.96–0.99) · t-SNE 섬 (env kNN 1.00) 은
   **네 표현이 장면 배치를 같게 놓는다**는 것 말고는 알려 주지 않는다.
2. **표현 사이의 차이는 대부분 상수 이동이다.** 모든 쌍 (h_ctx vs h_fut 포함) 이 선형 분류기로 test 100 %, **중심 방향 한 축만으로도 100 %** 갈린다.
   p_fut 과 h_fut 의 짝 제곱거리 가운데 **81–84 %** 가 중심 이동 몫이다. p_fut 은 노름이 작고 (17.1–17.4 vs 18.4–18.5) 퍼짐이 작다
   (RMS 반경 비 p/h_fut: visible 0.80, late 0.74).
3. **클래스 배치는 p_fut 만 다르다.** 장면 칸 평균을 빼고, clip 이 겹치지 않는 block 절반끼리 교차 적합해 split-half 천장으로 나누면,
   클래스 평균 구조의 공유 몫 (captured variance, 정규화) 은 **z_all · h_ctx · h_fut 사이 0.89–0.96, p_fut 과 나머지 셋 사이 0.77–0.83** 이다.
   visible 에서도 같다 — 가림 조건만의 현상이 아니다.
4. **visible → late 이식은 raw 에서 네 표현 모두 무너진다** (선형 probe shape 39–49 %, color 32–38 %). p 만의 현상이 아니다.
   late 쪽 장면 칸 중심을 맞추면 (라벨 없는 late train clip 사용) 대부분 돌아오고, 그때 **p_fut 이 가장 낮다**
   (shape z 89.6 / **p 81.4** / h_fut 94.6 / h_ctx 87.6, color 91.9 / **80.4** / 93.8 / 93.1).
5. 같은 표현 안의 visible vs late 클래스 부분공간 겹침은 네 표현이 비슷하다 (정규화 captured shape 0.94–0.95, color 0.94–0.97). **p 가 가림에서 특히 더 어긋나지는 않는다.**

**미결 한 줄** — 3 의 "p 의 클래스 배치가 다르다" 가 풀링 (위치 정보를 버림) 에서 생긴 것인지 토큰 수준에서도 있는지는 이 자료로 못 가른다 (토큰 단위 부분공간 / Procrustes 가 다음, CLAUDE.md §10 #1).

## 1. 정의

| 기호 | 정의 |
|---|---|
| `z_all` | context encoder (online, `ctx_masked`) 를 **문맥 16 샘플만** 넣어 얻은 8 튜블릿의 평균. 토큰별 affine-free LN. predictor 의 입력 그 자체 |
| `p_fut` | predictor 출력, 미래 8 튜블릿 평균. LN(target) 추정치이며 다시 LN 하지 않는다 |
| `h_fut` | target (EMA) encoder 를 32 샘플 전체에 걸고 튜블릿 8–15 평균. LN. p 가 맞추도록 학습된 공간 (대조군) |
| `h_ctx` | 같은 h 의 튜블릿 0–7 평균. **z 와 같은 프레임, 다른 encoder** (단 target 은 미래 샘플도 보고 계산한다) |
| visible / late | `sym_k == '0'` (visible 3 조건, 4,704 clip) / `sym_k ∈ 1..4` (가림 3 조건, 문맥 끝 가림, 4,704 clip) |
| split | 레포 하네스 `WMADataset._split` 를 그대로 호출 — block 단위, train 0.5, seed 0, condition 층화. train 2,688 block (4,692 clip) / test 2,688 block (4,716 clip), 겹침 0 |
| **raw / resid** | raw = 풀링 벡터 그대로. **resid = 장면 칸 (env × condition × sym_k, 60 칸) 평균을 뺀 것.** 칸 평균은 **train clip 으로만** 추정 (칸당 34–218 clip), 클래스 라벨은 안 쓴다 |
| participation ratio | PR = (Σλ)² / Σλ² (공분산 고유값) |
| linear CKA | ‖XᵀY‖²_F / (‖XᵀX‖_F‖YᵀY‖_F), 열 중심화. 95 % CI = block bootstrap 200 회. 순열 기준선 = clip 짝을 섞은 20 회 평균 |
| debiased CKA | unbiased HSIC (Song et al. 2012, 대각 0 인 선형 Gram) 로 만든 CKA |
| Fisher 비 | tr(S_B) / tr(S_W). [ ] 안은 라벨을 섞은 50 회 평균 |
| NCC | train clip 클래스 중심 → test clip 최근접 중심 (유클리드) |
| 선형 probe (참고) | softmax 회귀, train 표준화, L2 λ = 1e-3 **고정** (test 로 고르지 않음), LBFGS 300 회 |
| 클래스 평균 부분공간 | 중심화한 클래스 평균 (shape 7 → rank 6, color 8 → rank 7) 의 span. 두 부분공간의 principal angle cos θ 로 **mean cos²** 를, 한쪽 클래스 평균 구조가 다른 쪽 부분공간에 담기는 몫으로 **captured** 를 잰다 |
| 교차 적합 (xfit) | A 를 train 절반으로, B 를 test 절반으로 (그리고 반대로) 추정해 비교 → 두 추정이 같은 clip 을 공유하지 않는다. **/ ceiling** = xfit ÷ √(A split-half × B split-half) |

## 2. 분산은 어디에 있나 — 장면이 지배한다

`results.json → variance` (raw 분산에서 각 요인의 집단 평균이 설명하는 몫; resid_* = 칸 평균을 뺀 뒤 남은 분산에서의 몫)

| 표현 (all) | env | condition | 칸 (env×cond×k) | travel_dir | shape | color | 남은 분산 / raw | resid shape | resid color | resid travel_dir |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| z_all | 0.401 | 0.352 | **0.810** | 0.173 | 0.037 | 0.005 | 0.192 | 0.194 | 0.027 | 0.251 |
| p_fut | 0.361 | 0.374 | **0.784** | 0.201 | 0.039 | 0.005 | 0.218 | 0.179 | 0.023 | 0.283 |

| h_ctx | 0.359 | 0.376 | **0.791** | 0.225 | 0.031 | 0.005 | 0.211 | 0.146 | 0.022 | 0.358 |

- 칸 평균을 빼면 shape 몫이 3–4 % → 15–19 % 로 커진다. color 는 뺀 뒤에도 2–3 % 다.
- 평균 풀링은 튜블릿당 256 토큰 전부 (배경 포함) 를 더한다 — 물체가 차지하는 토큰은 일부라 배경 (env) 이 커지는 것은 예상된 결과다.

### PCA (`fig_pca_joint.png`, `fig_pca_by_rep.png`, `fig_explained_variance.png`)

- **joint PCA** (표현 × 조건당 1,000 clip, 같은 clip): PC1 32.5 % 는 **표현 정체** (η²_rep 0.99), PC2 15.3 % 는 env (η²_env 0.78).
  표현 정체가 joint 분산의 **36.8 %** (between-rep share 0.368). 즉 세 표현이 PC1 위에서 세 덩어리로 떨어진다 (`fig_pca_joint.png` (a)).
- **표현별 PCA, raw**: PC1/PC2 의 칸 η² 0.96–0.99, shape/color η² ≤ 0.011 — 네 표현 모두 (`fig_pca_by_rep.png` (a)–(l)).

## 3. CKA — 전부 천장 근처다 (`fig_cka.png`)

| 쌍 | raw visible | raw late | raw all [95 % CI] | resid visible | resid late | resid all |
|---|---:|---:|---:|---:|---:|---:|
| z_all–p_fut | 0.986 | **0.996** | 0.988 [0.988–0.989] | 0.986 | **0.986** | 0.980 |
| z_all–h_fut | 0.967 | 0.971 | 0.968 [0.968–0.969] | 0.962 | 0.928 | 0.942 |
| z_all–h_ctx | 0.984 | 0.980 | 0.981 [0.981–0.981] | 0.964 | 0.951 | 0.954 |
| p_fut–h_fut | 0.990 | **0.972** | 0.977 [0.976–0.978] | 0.986 | **0.931** | 0.963 |
| p_fut–h_ctx | 0.982 | 0.979 | 0.976 [0.976–0.977] | 0.969 | 0.923 | 0.941 |
| h_fut–h_ctx | 0.975 | 0.992 | 0.979 [0.979–0.980] | 0.980 | 0.964 | 0.967 |

- debiased CKA 는 linear 와 소수점 셋째 자리까지 같다 (n = 4,704 ≫ 유효 차원 ~6). 순열 기준선 0.001–0.002.
- ⚠️ `fig_cka.png` 의 색 범위는 **0.90–1.00 으로 잘랐다** (값이 0.92–1.00 에 몰려 있어서). 색 차이가 커 보여도 수치 차이는 최대 0.08 이다.
- 조건 6 개로 쪼개도 raw 0.957–0.998, resid 0.954–0.998.
- **late 에서 p_fut 은 입력 z_all 과 0.986, 목표 h_fut 과 0.931 (resid).** visible 에서는 둘 다 0.986 이다. 같은 late 에서 z_all–h_fut 도 0.928 이라
  "late 에서 h_fut 이 문맥 쪽 표현 (z, p) 과 멀어진다" 로 읽힌다.

**CKA 가 세우는 것** — 네 표현이 같은 clip 을 거의 같은 상대 배치로 놓는다 (장면, 그다음 운동 방향·모양).
**못 세우는 것** — "z 와 h 가 같다" · "p 가 h 를 잘 맞춘다". 선형 CKA 는 상위 몇 PC (PR ~6) 가 정하고, 그 PC 는 장면·운동 방향이다. 물체 정체 구조는 CKA 에 거의 안 들어간다 (§5·§6 에서 따로 잰다).

## 6. 클래스 평균 부분공간 겹침

기준선: 1280 차원 무작위 부분공간의 mean cos² = **0.0047** (rank 6) / **0.0055** (rank 7) (해석값 r/d 와 일치, 1,000 쌍).
라벨 순열 (독립) 기준선은 0.23–0.45 — 데이터의 비등방성 때문에 무작위보다 훨씬 크다. **무작위 기준선만으로는 아무 결론도 안 선다.**

### 6-1. 같은 clip 으로 잰 겹침 — 순열 (공유) 기준선이 거의 같다

(raw, shape, visible) z_all–p_fut mean cos² 0.746 vs 순열 공유 0.765 · h_fut–p_fut 0.683 vs 0.735 · z_all–h_fut 0.860 vs 0.809.
라벨을 섞어도 (같은 섞음을 두 표현에) 겹침이 0.66–0.85 로 남는다. 두 표현이 clip 마다 강하게 상관돼 있어 **어떤 clip 묶음이든 평균의 방향이 같이 움직인다.**
그리고 split-half 천장 (서로 다른 clip 절반, 같은 표현) 이 0.37–0.81 로 **교차 표현 겹침보다 낮다** — 같은 clip 을 쓰면 표집 잡음까지 공유된다는 뜻이다.
→ 같은 clip 겹침 (`mean_cos2`) 은 표현 비교에 쓰지 않고, 아래 교차 적합만 읽는다.

  클래스 구조가 없는 것은 아니다 — 정규화 전 xfit captured 가 shape 에서는 순열 p95 보다 한참 위다 (vis: z–p 0.772 / h_fut–p 0.768 vs p95 0.520 / 0.572).

- 이 차이는 **visible 에서 이미 있다** — 가림이 만든 것이 아니다.
- 같은 표현 안의 visible ↔ late 는 네 표현 모두 0.94–0.97 로 비슷하다. **p 의 클래스 배치가 가림에서 특히 더 바뀌지는 않는다** (이 측정으로는).

**부분공간이 세우는 것** — 풀링 벡터에서 p 의 클래스 평균 배치가 encoder 표현 셋과 다른 방향 조합을 쓴다 (정규화 captured 약 0.8 vs 0.95).
**못 세우는 것** — "표현이 회전했다" 는 쓰지 않는다. 잰 것은 rank 6/7 클래스 평균 부분공간의 principal angle 과 captured variance 뿐이고,
직교 사상 (Procrustes) 으로 옮겨지는지는 재지 않았다. 부분공간이 다르다는 것은 회전 · 다른 방향과의 혼합 · 약한 방향의 잡음 어느 것으로도 생길 수 있다.

## 9. 단서 (결론과 같은 무게)

- **z 와 p/h_fut 은 다른 프레임이다.** z_all 은 문맥 16 샘플, p_fut·h_fut 은 미래 16 샘플을 요약한다. h_ctx 가 "같은 프레임, 다른 encoder" 대조인데,
  target encoder 는 32 샘플 전체를 보고 문맥 튜블릿을 계산하므로 순수한 같은 입력 대조는 아니다.
- **late 는 가림막이 장면에 있다** (§8-5). visible ↔ late 차이는 "가려짐" 과 "가림막 존재" 를 가르지 않는다. k=1 은 완전히 가려진 문맥 튜블릿이 없다 (k=2,3 → 튜블릿 7, k=4 → 6,7). z_all 은 가려진 튜블릿을 포함해 평균했다.
- **resid 이식은 late 쪽 중심을 쓴다** — 라벨은 안 쓰지만 표적 조건의 unlabeled 통계를 쓰는 중심 맞춤이다. 순수한 이식 수치는 raw 쪽이다.
- **평균 풀링은 공간·시간 구조를 버린다.** 여기 수치는 토큰 수준 기하에 대한 주장이 아니다.
- 선형 probe 는 λ = 1e-3 고정, 조정 없음. train 정확도 ~1.0 으로 포화 — 조건 안 수치는 천장이고 대조는 이식 줄에서만 읽는다 (CLAUDE.md §7-3 과 같은 이유).
- 부분공간 split-half 천장이 낮은 칸이 있다 (raw color late 0.37–0.39) — 약한 방향의 추정 잡음이 크다. 그래서 captured (가중) 과 resid 를 주로 읽는다.
  raw color 의 같은 표현 vis–late 정규화 값이 1 을 넘는 것 (1.02–1.12) 도 이 잡음 때문이고, raw color 부분공간 수치는 순열 p95 를 못 넘는다 (§6-2 ⚠️).
- **t-SNE 의 전역 거리 · 섬 크기는 의미가 없다.** 표현 × 조건당 300 clip (1,800 점) 부표본 하나, seed 0 하나다. 정량 판단은 kNN 과 원공간 지표로만 한다.
- joint PCA 는 표현 × 조건당 1,000 clip 부표본 (seed 0). 그 밖의 지표는 전 clip (조건당 4,704) 이다. 클래스당 clip: shape ~672, color 576–600 (조건별).
- CKA 의 bootstrap CI 는 block 을 다시 뽑은 것이다. 부분공간 · Fisher 순열은 clip 라벨 순열이다 (block 구조 무시).
- 단일 모델 (ViT-H), 단일 데이터셋 (v11), 가능 변이 · 물체 있는 clip 만 (CLAUDE.md §1-4).

## 10. 판정 (CLAUDE.md §12)

- **beat** — beat 5 (부분공간 겹침, §10 #1) 의 풀링 판. p 의 클래스 부분공간이 encoder 셋과 다르다 (0.8 vs 0.95) 는 결과는 어느 쪽이 나왔어도 beat 5 에 들어갈 자리가 있었다.
- **corner case 인가** — 아니다. 핵심 차이 (p 의 클래스 배치, p 의 좁은 분포) 는 visible 에서 이미 있다. 가림은 여기서도 testbed 다.
- **use case** — 평가 방법론 쪽. 풀링 벡터 비교 (CKA, t-SNE) 는 장면이 지배해 표현 차이를 가린다 — 이런 지표로 "p 와 h 가 같다" 를 주장하면 안 된다.
- **재학습** — 필요 없다. 캐시만 썼다.

독립 재계산 (float64 numpy, 별도 코드) 으로 split (겹침 0) · CKA (전 쌍, 소수 셋째 자리) · 영역 분류 (NCC 1.000) · NCC 정확도 (최대 차 5e-6) ·

1. **§7 t-SNE 섬 해석** — 작은 섬은 60 개 장면 칸이 아니라 **env** 를 따른다 (10-NN: env 1.00, 칸 0.66). 표현 × visible/late 는 **여섯** 무리로 이웃을 공유하지 않는다 (10-NN 1.00).
   "env 로 같은 모양" 은 수치 근거가 없으니 읽지 않는다
2. **resid 는 칸 평균만 뺀 것이다** — resid 에서도 visible vs late 가 이웃으로 0.95 갈리고 env 도 0.43~0.48 (우연 0.25). 평균은 같아도 공분산이 다르다.
   그래서 resid 의 visible→late 이식도 공분산 이동을 건너는 것이다 ("대부분 평균 이동" 으로 읽지 말 것)
3. **§2 PCA** — resid PC1 은 **진행 방향** (η² 0.86~0.91), resid PC2 는 "shape 축" 이라기보다 **{sphere, torus} 대 나머지** 의 두 갈래 (이 이진 분할만으로 η² 0.81~0.85, 전체 shape η² 0.84~0.88)
4. **§5-1 순위 ("z_all 이 가장 크고 h 둘이 가장 작고 p 가 중간")** 는 shape (raw·resid) 와 color visible 에서만 성립한다. color late 는 Fisher 가 p 최저 · h_fut 최고, NCC 도 h_fut 최고.
   §5-2 의 "p_fut 이 가장 낮다" 는 **선형 probe 기준**이다
5. **§4 노름 · 퍼짐** — z · h 는 토큰마다 affine-free LN (토큰 노름 √D) 을 거쳤고 p 는 다시 LN 하지 않는다. **p 가 짧고 좁은 것의 일부는 정규화 방식에서 온다** —
   학습된 기하로 읽지 말 것 (p 에 토큰 LN 을 건 대조는 토큰 수준 p 가 있어야 한다)
6. **표본 균형** — PCA · t-SNE 표본은 **visible/late 로만** 층화했고 나머지 (6 조건 · k · shape · color · env) 는 무작위다
   (t-SNE: 조건 89~108, k 61~91, shape 74~105, color 66~94, env 132~184). "클래스 수 (조건별)" 는 "visible/late 각각" 의 뜻이다
7. **그림 색** — color 패널의 클래스 색은 물체 색과 무관한 팔레트 칸이다 ('red' 가 파랑으로 그려진다). shape 와 같은 8 색을 다시 쓴다 — 표식 모양 · 직접 라벨로 읽을 것
