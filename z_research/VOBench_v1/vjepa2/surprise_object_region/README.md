# VOBench — 물체 자리 토큰만으로 다시 채점 (보조 분석, 2026-10-13)

> 주 결과는 전체 토큰 채점이다 (`../surprise/`). 이 폴더는 "실제 물체가 있는 자리에서만 보면 어떤가" 를 보는 보조 읽기다.

**방법** (`z_research/scripts/analysis/vobench_object_region_score.py`, 다시 돌리지 않고 채점 실행의 `token_surprise.npz` 를 다시 셈):
튜블릿마다 `label.json` 의 물체 상자 (중심 ± 1.1 × 반폭 · 반높이, 구르는 물체는 반지름) 와 겹치는 32 px 칸만 쓴다. 쌍의 두 영상에 같은 토큰 = 그 block 의 A · B arm 상자 합집합.
가려진 튜블릿도 실제 자리 (가림막 뒤) 그대로. 평균 토큰 비율 **7.1 %** (256 중). 모델 = token_surprise 가 있는 release · AR ep40.

| 쌍 정확도 % (전체 토큰 → 물체 자리) | release prim | release real | AR ep40 prim | AR ep40 real |
|---|---|---|---|---|
| overall | 71.7 → **80.4** | 81.9 → 84.7 | 81.9 → 78.5 | 86.4 → 82.6 |
| 보일 때 모양 · 색 (visible · early · mid) | 63–75 → **90–96** | 76–100 → 97–100 | 75–83 → 79–90 | 78–96 → 89–100 |
| late permanence | 55.6 → 50.0 | 61.1 → 55.6 | **98.6 → 56.9** | **100 → 58.3** |
| late permanence A (있는데→있는) | 19.4 → 16.7 | 22.2 → 19.4 | **100 → 16.7** | **100 → 16.7** |
| late 모양 · 색 | 54 · 64 → 43 · 50 | 63 · 74 → 53 · 46 | 60 · 67 → 57 · 60 | 64 · 71 → 57 · 57 |
| late 모양+색 · 이동 | 60.8 → **48.3** | 65.8 → **47.5** | 56.7 → **50.8** | 62.5 → **52.5** |
| late 모양+색 · 정지 | 50.0 → 37.5 | 79.2 → 58.3 | 95.8 → **95.8** | 91.7 → 79.2 |

- **보일 때는 물체 자리만 보면 오른다** — 특히 release 의 모양 · 색 (primitive 63–75 → 90–96). 전체 토큰 채점에서는 배경 토큰이 신호를 묽힌다.
- **late 는 물체 자리에서 보면 두 모델 모두 chance 이하** (이동 모양+색 48–53). 물체가 다시 나타난 실제 자리에서 예측은 어느 쪽 미래에도 가깝지 않다.
- **AR 의 late permanence 우위는 물체 자리에서 사라진다** (98.6 → 56.9, A 방향 100 → 16.7 = release 와 같다) — AR 이 이긴 곳은 배경 토큰이었다 (토큰 Δ 의 presence without placement 와 같은 결론, 독립 확인). 실제 자리에는 AR 도 '빈 장면' 쪽을 그린다.
- 예외: **AR 의 late 정지 물체는 물체 자리에서도 맞는다** (95.8 / 79.2) — 움직이지 않으면 제자리에 그린다.

⚠️ 단서
- 보조 분석 — 주 결론은 전체 토큰 (메모리 '채점 해석은 전체 토큰'). 물체 자리 채점은 "정답 자리에 그렸나" 를 요구하므로 자리 · 외형을 같이 잰다.
- 상자 크기 (×1.1) 에 따라 수치가 바뀔 수 있다 (토큰 7 % 안팎) — 민감도는 `--margin` 으로 (미실행).
- 칸 24–144 쌍. AR 은 타깃 공간이 달라 release 와 쌍 정확도만 비교.
- v11 의 옛 결론 "물체 토큰만 보면 더 나빠진다" (CLAUDE.md §6) 와 다르게 보이는 칸이 있다 — v11 은 가림 조건이 대부분이고, 여기서도 late 는 나빠진다. 보일 때만 오른다.
