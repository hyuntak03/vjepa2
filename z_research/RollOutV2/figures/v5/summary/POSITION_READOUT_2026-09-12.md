# RollOut v2 — 위치 readout 결과 (학습셋 v5, 2026-09-12)

predictor 출력 `p` 가 미래 8 tubelet 각각에서 물체를 **어디에** 두는지를, 별도 학습셋에서 정한 위치 자(readout)로 읽어
같은 자로 읽은 encoder (`z`, `h`) 와 나란히 놓는다. 모든 수치는 `exp_results/v5/**/{fit,test}.json`, `preds.npz`,
`figures/v5/v11_vanish/**/readout.npz` 에서 다시 계산한 값이다 (계산 스크립트는 §재현).

> ⚠️ **정정 이력 (2026-09-12 저녁).** decoder 검증 (§2-3) 뒤에 세 곳을 정정했다 — wall "벽 속에서 멈춤" (§4-3), v11 "마지막 관측에 머문다" (§5-4), 슬롯 7 비율 요약 (§5-4).
> 원문은 지우지 않고 남겼다. **읽는 규칙**: 위치 주장은 그 슬롯의 attention 질량 (`attn_diag.md`, `two_futures_attn.md`) 이 균등 (0.035) 을 넘을 때만 유효하다.
> 자는 물체가 없어도 위치 (기본값 = 토큰 평균 읽기) 를 내기 때문이다. 폐기·정정 목록은 §8.

## 1. 설계

| 항목 | 값 |
|---|---|
| 자 (readout) | attentive: 쿼리 q (1280) → softmax over 256 토큰 → pooled (1280) → Linear(1280→2). **3,842 파라미터**. tubelet 마다 독립 (T 를 batch 로) |
| 학습셋 | `RollOut_v2_training` (v5 합본) **8,064 clip** = 사물 없음 4,480 (line_x 1,344 / line_z 896 / line_xz 896 / still 1,344) + 사물 1개 3,584 (prop_x 1,792 / prop_still 1,792; 절반은 같은 깊이 판이라 관통·가림) |
| 학습 라벨 | tubelet (2 샘플) 평균 픽셀 위치, 미래 8 tubelet. `visible_by_sample` (화면 안 ∧ 판에 안 가려짐) 인 튜블릿만 → **49,001 / 64,512 행** |
| 학습 | Adam lr 1e-3, batch 32 clip, **300 epoch**, seed 0. p / z / h 각각 같은 설정으로 따로 |
| 표현 | p = predictor 출력 (2048 토큰, LN 없음) · z = context encoder 에 32 frames 전부 (`isolated_ctx:0_32`, LN, 미래 8 tubelet 사용) · h = target encoder 32 frames (`target`, LN, 미래 8 tubelet) |
| test | `RollOut_v2` 5,488 clip 중 **가능(possible) 4,704 clip**, 7 시나리오. v2 는 fitting 에 전혀 안 씀. 추가로 IntPhysGen v11 vanish 셀 |
| 단위 | px = 288 화면. **1 토큰 칸 = 18 px = 물체 반폭** (물체 폭 36 px) |

지표
- **L2**: 슬롯별 유클리드 오차의 평균 (in_frame 슬롯). 칸 단위 = ÷18.
- **gain**: clip 단위로 (읽은 슬롯 0→7 변위) 를 (진실 변위) 에 회귀한 기울기. 1 = 진실만큼 움직임, 0 = 안 움직임.
  슬롯 0 = 미래 첫 tubelet (문맥 마지막이 아니다). 한 시나리오의 clip 들에 대해 `dr = 읽기[7] − 읽기[0]` 을 `dt = 진실[7] − 진실[0]` 에 `np.polyfit(dt, dr, 1)` 한 기울기.
  출발점 오차는 빼고 **미래 구간에서 얼마나 움직였나** 만 본다. `fig_motion_gain` 막대 위 숫자는 **기울기 그 자체** (2026-09-17 변경: 그 전에는 dt·dr 의 clip 간 상관을 적어 막대 값으로 오독됐다 — flat_a p 는 상관 0.97 / gain 0.57). 상관은 `plot_rollout2_summary.py` 가 stdout 에 찍고, §3-1 표의 corr (슬롯별 상관 평균) 과는 다르다.
  진실 변위의 clip 간 퍼짐이 작으면 (std < 2 px 인 축은 그림에서 뺌, ramp y 는 4.5 px) 기울기가 불안정하다.
- **echo**: 마지막 문맥 위치를 8 슬롯에 그대로 찍었을 때의 L2 (움직임 없는 기준선).
- **α** (v11 가림): 읽기가 가림막 기준으로 물체 쪽으로 간 비율. 1 = 물체 위, 0 = 가림막 위, 0.5 = 둘의 중간.

남는 단서: C 는 "물체 세계에 더 가깝다" 를 재는 것이지 p 의 내용을 직접 보는 것은 아니다. 다만 채점기가 쓰는 바로 그 거리이므로, 채점이 보는 p 안에 물체가 없다는 뜻이다.

### 3-2. 읽는 법

- **지면 등속 (flat_v)**: p 도 물체 위 (0.71 칸), 진행 0.85. 유일하게 encoder 에 가까운 셀.
- **지면 등가속 (flat_a)**: L2 1.07 칸, 진행 0.57 — 가속을 절반쯤만.
- **중력 (arc, fall) / 경사 (ramp)**: L2 0.9~1.4 칸, 진행 0.4~0.5. encoder (0.5~0.6 칸, gain ≈ 1) 의 2~2.5 배. 위치는 물체 근처인데 시간이 절반쯤만 흐른다.
- **ledge, wall**: L2 2.1 / 1.8 칸 = 물체 폭 이상. echo (움직임 없음) 보다는 가깝다 (ledge 37 vs 54) — 아예 멈춘 건 아니다. 그러나 wall 은 echo (16.6) 가 p (32.0) 보다 **더 가깝다**: 벽 앞에 그냥 두는 것이 predictor 를 읽는 것보다 정확하다.
  ⚠️ 정정 (§4-3): ledge/wall 의 8 슬롯 L2 는 물체가 사라진 슬롯 (ledge 5~7, wall 3~7) 의 기본값을 포함한다. 물체가 있는 슬롯만의 비교는 §4-3.

## 4. 두 미래 판정 — ledge / wall (pos·imp 쌍 392)

pos / imp 클립은 문맥이 byte 단위로 같아 p 도 같다. 그래서 읽은 p 궤적이 **가능 진실 (낙하 / 정지)** 과 **불가능 진실 (부유 / 통과)** 중 어느 쪽에 가까운지로 판정한다. 슬롯 1~7, 둘 다 화면 안인 슬롯만.

|---|---|---|---|---|---|---|---|---|

**→ "predictor 는 선반 끝에서 떨어지지 않고 선반 높이를 유지한 채 수평으로 조금 (진실의 절반) 나아가다 멈춘다."** 392 쌍 전부 (100 %) 에서 읽은 궤적이 낙하보다 부유 진실에 가깝다.
⚠️ §4-3 으로 다시 읽으면: **"부유" 는 선다** (슬롯 3~4 에서 attention 이 부유 궤적에 0.43 / 0.39, 기본값은 낙하 쪽). **"나아가다 멈춘다" 는 정정** — 슬롯 5~7 은 물체 질량 0.23 으로 흐려지는 구간이라 "멈춤" 이 아니라 "물체가 약해짐" 이다.

### 4-4. pos / imp attentive probe — "predictor 의 미래는 어느 클립처럼 보이는가" (2026-09-12, `rollout2_probe_pos_imp.py`)

위치 자와 독립인 두 번째 판정. 시나리오마다 (ledge, wall) **target encoder h 의 32 frames 토큰** (문맥 2048 + 미래 2048) 에 pos / imp 라벨로 attentive probe 를 학습하고
(질의 1개 cross-attention 16 head → LN → Linear(2); block 단위 50/50 split, 학습 392 clip / test 392 clip, 25 epoch, lr 5e-5, seed 0),
test block 에서 미래 자리에 **predictor p (16 frames)** 를 끼운 입력을 판정한다. 문맥 자리는 h_ctx 또는 z16 (`ctx_masked`, context encoder 16 frames, 캐시 `rollout_v2_z16_vith`).
pos / imp 쌍은 p 를 공유하므로 [z ; p] 의 정확도는 **구조상 50 %** 이고, 읽을 것은 **P(imp)** — probe 가 predictor 의 미래를 "불가능 클립" 으로 보는 확률이다.

| test 입력 | 학습 문맥 = h_ctx: ledge acc / P(imp) | wall acc / P(imp) | 학습 문맥 = z: ledge | wall |
|---|---|---|---|---|
| [h_ctx ; h_fut] (학습 분포) | 100 % / – | 100 % / – | 100 % | 100 % |
| [z16 ; h_fut] | 100 % / – | 100 % / – | 100 % | 100 % |
| **[z16 ; p]** | 50 % / **0.911** (97 % 가 "부유") | 50 % / **0.697** (76 % 가 "통과") | 50 % / **0.963** (99 %) | 50 % / **0.895** (92 %) |
| [z16 ; LN(p)] | 50 % / 0.836 | – | 50 % / 0.901 | – |
| [h_ctx ; p] | 94.4 % (pos 89 / imp 100) | 78.3 % (pos 64 / imp 92) | 68.9 % | 49.0 % |

- probe 도 predictor 의 미래를 ledge 97~99 % "부유", wall 76~92 % "통과" 로 읽는다 — 위치 자의 두 미래 판정 (§4-1, 4-3) 과 같은 방향이고, 자를 안 거친 독립 근거다.
- 문맥 자리까지 h 로 두면 ([h_ctx ; p]) 정확도가 94 / 78 % 로 오르는데, 이는 문맥 h 와 미래 p 의 **이음새** (h 와 p 의 좌표계 차이) 를 probe 가 잡는 것이라 "predictor 가 가능 쪽" 이라는 증거가 아니다. 학습 문맥을 z 로 바꾸면 [h_ctx ; p] 는 69 / 49 % 로 무너진다 (문맥 소스 불일치).
- wall 의 P(imp) 0.70~0.90 은 ledge (0.91~0.96) 보다 낮다 — §4-3 과 맞는다: wall 의 p 는 2 슬롯만 통과하고 물체를 잃는다.
- 그림: `figures/probe_pos_imp/fig_confusion_all_{h_ctx,z}.png` (2 행 시나리오 × 4 열 test 입력, 클래스당 196), `fig_confusion_{h,zp}.png` (구판). 수치 `exp_results/probe_pos_imp/probe_pos_imp.json`.
- 단서: probe 는 h 토큰 (LN) 으로 학습했고 p 는 LN 없는 predictor 출력이다. LN(p) 로 넣어도 결론은 같다 (0.84 / 0.90). 확률은 probe 의 보정이 안 된 값이라 "97 %" 를 확률로 읽지 말고 방향으로 읽는다.

## 7. 단서

- **자의 정밀도 하한 ≈ 0.4~0.6 칸 (7~11 px).** 이보다 작은 차이는 읽지 않는다. p 와 encoder 의 차이 (flat 0.3 칸 ~ ledge 1.5 칸) 는 그 밖이다.
- **v11 속도 (18 px/tubelet) 는 학습셋 상한 (12) 밖.** k=0 에서 z 의 슬롯 7 −24 px 는 화면 가장자리 (x ≈ 298) 효과와 속도가 섞인 것. p 의 절대 거리 ("3.5~5 칸에서 멈춤") 는 그래서 z 대비로 읽는다 (p 65~90 px vs z 100~115 px).
- **h, z 는 미래 frame 을 실제로 본 특징**이라 p 와 "정확도 경쟁" 이 아니라 자의 상한이다. p 의 주장은 "같은 자로 encoder 는 X 를 읽는데 p 에서는 Y 가 읽힌다" 까지다.
- **p 자에 사물 clip 이 들어간 것**: 판 뒤 슬롯은 라벨에서 뺐지만 (visible 마스크), 판 근처에서 predictor 가 무엇을 그리는지는 학습셋이 모른다. p 판정이 v4 (사물 없는 자) 와 같아서 이 오염은 결과에 안 나타났다고 본다.
- **"멈춘 세상" vs "여러 미래의 평균"** 은 위치만으로는 안 갈린다. 5-3 의 attention 분산 (가림에서 균등) 은 후자 쪽 (물체 표현이 번짐) 과도 맞는다. 이 둘을 가르려면 p 토큰의 물체다움 (예: h 물체 토큰과의 cos) 을 슬롯별로 봐야 한다.
- **자는 물체가 없어도 위치를 낸다.** attention 이 퍼지면 Linear(토큰 평균) 이 나온다 (기본값). v11 은 마지막 관측 위치가 화면 중심이라 기본값과 겹치고, wall 은 기본값이 정지 자리 옆 (11~16 px) 이다. 8 슬롯 평균 지표 (L2, 두 미래 비율, 슬롯 7 ratio) 는 이 기본값을 섞는다. → 슬롯별 attention 질량과 같이 읽는다 (§2-3, 4-3, 5-4).
- **학습셋에는 "물체 없는 p" 가 없다.** 화면 밖·판 뒤 튜블릿은 손실에서 뺐으므로 자는 "없음" 을 배운 적이 없다. presence head + 빈 장면 clip 을 붙이면 깔끔해지지만 (2026-09-12 논의), attention 질량·기본값 거리·자 없는 검사 (C) 로 같은 답이 나와 **하지 않기로 했다**. 하려면 `empty` / `empty_prop` 두 시나리오 (~500 씩) 가 필요하다.
- **학습셋 판 뒤 튜블릿을 자가 16~20 px 로 읽는 것** (스크래치 확인) 은 p 가 가려진 물체를 갖고 있다는 증거가 아니다 — 그 자리가 곧 판의 자리라 판 토큰을 읽어도 맞는다. 인용하지 말 것.
- **v11 만으로 자를 학습하면 자리 prior 를 외운다** (§2-3 E). 위치를 고루 덮는 학습셋이 필요했던 이유.
- ledge / wall 두 미래 판정은 **자를 사물 셋으로 정한 뒤** 처음 유효해졌다. v4 자로는 ledge 90 % 낙하 (v2 구 데이터, p_B 자) 같은 값이 나왔었는데 그건 자가 선반에 끌린 결과였다.

**남아 있는 주장 (근거 위치)**
