# 무효 — 한 실행에 창 16·32 를 섞었다 (2026-09-21)

공식 코드는 **창마다 모델을 그 프레임 수로 짓는다** (`eval.py:149 init_model(frames_per_clip=...)`).
우리 하네스는 프로세스당 한 번만 짓는데 여기 실행들은 `window_sizes=[16,32]` 를 한 번에 줬다.
- VideoMAEv2 는 즉시 죽었다 (sinusoid 위치표 고정 → `2048 vs 4096`)
- V-JEPA 는 죽지 않았지만 **공식과 다른 위치 인코딩**으로 돌았다 (모델은 32 로 지어졌는데 16 을 먹였다)

지금은 창마다 실행을 나누고 tag 에 `_w{N}` 을 붙인다 (`run_all.sh`).
