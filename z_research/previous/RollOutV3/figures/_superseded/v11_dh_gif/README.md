# v11_dh_gif — **쓰지 않는다** (2026-09-25)

`D_h(t) = |h(물체 clip) − h(빈 clip)|` (v11 vanish `pos_a` − `pos_b`, 토큰마다 1280 차원 평균) 를 16×16 지도로 그린 GIF.
결과물은 전부 `_superseded/` 에 있다. **물체 위치를 보여 주지 못해서 물렸다.**

## 왜
- 짝은 맞다: 두 clip 의 픽셀 차이는 물체 주변에만 있다 (물체 반경 30 px 밖 0–5 %, `_superseded/checks.json`).
- 그런데 target encoder 출력은 **화면 전체가 바뀐다.** 물체 clip 과 빈 clip 의 토큰 코사인 중앙값 0.52.
  같은 빈 clip 에 눈에 안 보이는 잡음 (정규화 입력에 1e-3) 만 더해도 토큰이 평균 0.125 (fp32) · 0.235 (bf16) 변한다.
  같은 clip 을 두 번 넣으면 0.0000 이다 — 수치 잡음이 아니라 모델이 전역으로 반응한다.
- 그래서 차이 지도의 최댓값이 물체 칸 (±1 칸) 에 드는 튜블릿은 **15 %** (19/126) 뿐이다.
  주성분으로 줄여도 (상위 3–128 개, 9 쌍 토큰에 맞춘 PCA) 0–12 %, 토큰 평균을 빼도 11 % 다.

## 다시 시도하지 말 것
- 토큰 차이의 크기로 물체 자리를 찾는 것 (전체 차원 · PCA 상위 · 토큰 평균 제거 모두).
  물체 정보는 학습된 자 (attention query) 가 찾는 특정 방향에 있고, 전역 흔들림이 크기를 지배한다.
