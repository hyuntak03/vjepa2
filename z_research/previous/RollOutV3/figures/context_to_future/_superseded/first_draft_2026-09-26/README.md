# 첫 판 (2026-09-26) — 계수 · 분산 몫 그림

회귀 계수 (β_v · β_a · β_x) 와 분산 몫 (η²) 으로 그린 첫 판이다. 사용자가 "너무 어렵다" 고 해서 같은 날 **진짜 궤적과 p 궤적을 겹친 그림** (`../1_motion.png` …) 으로 바꿨다.
같은 그림은 지금 `../detail_*.png` 로 다시 그려진다 (이름만 다르다). 이 폴더는 기록이다.
