## 한 줄 결론

**라벨과 가중치에는 버그가 없다. 문제는 두 가지다.**
1. **v11 가림막은 학습셋에 없는 물건이다.** 재질 · 깊이 · 자세가 다르고, 누운 판 · 움직이는 판은 학습셋에 한 장도 없다.
   v11 가림 장면의 빈 장면 오탐이 h 에서도 뜨는 것과 맞아떨어진다.
2. **'있다' 는 '물체 전체가 화면 안' 이라는 뜻이다.** 음성의 35 % 는 가장자리에 걸려 일부 잘린 물체다.
   그래서 v11 visible 이동 조건의 t6 · t7 은 학습 정의로는 '없다' 가 정답이다.

## A. 라벨 산술 — 문제 없음

- `visible = in_frame ∧ ¬prop_intersects ∧ ¬scenery_intersects`: 459,520 샘플 전부 성립
- `ignore = (in_frame ∧ prop_intersects) ∨ scenery_intersects`: 전부 성립
- 미래 튜블릿: 양성 72,907 · 음성 26,664 · 제외 15,309. 학습 요약 (`exp_results/presence/summary.json`) 과 정확히 같다

## B. 음성이 무엇인가 — 정의를 알고 읽어야 한다

| 음성의 출처 | 튜블릿 | 비율 |
|---|---:|---:|
| 빈 장면 clip | 7,360 | 28 % |
| 물체가 완전히 화면 밖 | 8,933 | 34 % |
| **중심은 화면 안인데 가장자리에서 일부 잘림** | **9,403** | **35 %** |
| 튜블릿 두 샘플 중 하나만 화면 안 | 968 | 4 % |

`in_frame_by_sample` 은 "물체 **전체**가 프레임 안" 이다 (데이터 README §3). 물체 반폭은 17.8 px 이다.
중심이 가장자리에서 17.8 px 안으로 들어오면 음성이 된다. 1 px 움직이면 라벨이 뒤집히는 경계라, 그 근처에서는 자가 흔들리는 것이 정상이다.

**v11 에 대입하면** (visible, 가능 변이, 물체 있는 clip 1,568 개씩):

- t6 · t7 에서 h 의 '없다' 는 자의 약점이 아니다. **배운 대로 답한 것이다.**

## C. 판 자세 ↔ 라벨 — 작은 누수가 남는다

| 재는 것 | 가중 전 | balance_weight 적용 |
|---|---:|---:|
| 판 있음/없음 ↔ 튜블릿 라벨 (bits) | 0.0030 | **0.0012** |
| **판 자세 (폭·높이·두께·기울기·깊이) ↔ 튜블릿 라벨** | 0.0471 | **0.0361** |
| 라벨 엔트로피 | 0.838 | |

- 데이터 README 의 "방해물 0.0232 → 0.000000" 은 **clip 단위 · 판 종류** 기준이다. 튜블릿 단위 · 자세 단위로는 0.036 bits (라벨 엔트로피의 4.3 %) 가 남는다.
- **빈 장면에만 나오는 자세** (208 clip): `60×700 블록 y620` 144 · `350×400 블록 y620` 48 · 거대 판 기울기 ±6 · ±14 16.
  **물체와만 나오는 자세** (1,792 clip): 물체 평면을 가로지르는 폭 60 블록 (`y260`, prop 팔).
- 누수의 방향: 앞의 자세는 '없다' 쪽을 가르칠 수 있다. 그래서 **오탐 ('있다') 을 설명하지는 못한다.**

## D. split — "held-out" 은 외형 held-out 이다

- block = clip 이다 (block 당 clip 1 개). 학습 코드는 clip 단위로 나눈다 (scenario 층화, 50 / 15 / 35).
- 화면 좌표열이 완전히 같은 궤적 (외형만 다른 복사본) 이 여러 split 에 걸친다: 7,877 궤적 중 **1,780** 개.
  test 의 물체 clip 4,706 개 중 **2,149 개 (46 %)** 는 같은 궤적이 train 에도 있다.
- 튜블릿 단위 위치 자라 112 칸이 모두 train 에 있으므로 영향은 작다. 다만 학습셋 test 수치는 "새 궤적" 이 아니라 **"새 외형 (모양 · 색 · 배경)"** 에 대한 일반화로 읽는다. 진짜 held-out 은 v3 · v11 이다.

## 결론에 미치는 영향

- **moving · last 가림의 영속 ❌ (p 7–28 % vs h 86–100 %)** — 그대로 선다. 거기서 걱정할 것은 '있다' 오탐인데, 이 조건의 빈 장면은 해당 칸 (flat t3, ramp t3–t5) 에서 p 0 % 다. 같은 결론이 자 없는 vanish 짝 비교 (block 98–100 %) 로도 나온다.
- **static 전부 · moving mid 의 자 presence** — 판정 불가. 이미 "static untestable" 로 적어 둔 것과 맞고, 이유가 하나 더 붙는다 (누운 판).
- **visible t6 · t7** — '없다' 가 정답인 칸이다. by-k 그림에서 이 칸의 p '있다' (ramp t6 0.91) 는 p 쪽 오탐이다.
