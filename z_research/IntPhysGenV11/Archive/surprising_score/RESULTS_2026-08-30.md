## 1. 무엇을 어떻게 쟀나

### 채점 규칙

```
surprise(clip) = mean | predictor(context) − LN(target_encoder(clip))[future] |
정답           ⟺  surprise(impossible) > surprise(possible)
chance         =  50%
```

- `distance: l1`, `loss_exp: 1.0`, `target_layer_norm: true`(affine-free, target 에만), `mask_index: 0`
- `mask_index: 0` 이 critical — 릴리즈 체크포인트에서 학습된 mask token 은 `[0]` 하나뿐이다
- `scoring.pairing: matched` — block 의 가능×불가능 조합 4개 중 **context 가 픽셀 단위로 같은 2쌍만** 쓴다.
  그래야 predictor 출력 `p` 가 두 조건에 동일해지고, 채점이 "p 가 어느 미래에 가까운가" 로 환원된다.
  ⚠️ `pairing` 기본값은 `cross` 다. 안 쓰면 전수 4쌍 채점이 조용히 돌아간다.

### 프레임

```
raw 100 프레임 (0..99)   stride 3   splice 48
context    16장   raw  0, 3, ..., 45
predictor  16장   raw 48, 51, ..., 93
target enc 32장 전부
```

디스크에는 34장이 있다 (`0,3,…,96,99`). 96·99 는 예측 창 밖이라 읽지 않는다.

### 모델

dual_encoder: true   context_encoder_key: encoder   target_encoder_key: target_encoder
predictor: {embed_dim 384, depth 12, num_heads 12, num_mask_tokens 10}
dtype: float32   autocast: float16          ← 공식 Garrido 재현 관례
use_rope: true   uniform_power: false
```

### 지표

한 쌍 `{A,B}` 는 **양방향**으로 렌더된다 (`A→B` 와 `B→A`). 두 방향은 같은 두 후보 미래를
역할만 바꿔 쓴다. 그래서:

```
sensitivity = (acc(A→B) + acc(B→A)) / 2 − 50      편향을 제거한 탐지력
bias        = |acc(A→B) − acc(B→A)| / 2           한쪽으로 쏠린 정도
```

**고정된 편향만 작동하면 두 방향의 합이 100 이 되어 sensitivity 가 0 이 된다.**
정확도는 둘이 섞인 값이라 단독으로 읽으면 안 된다. 실측 예 (vanish, k=4, 전 조건 합):

```
빈 → 물체 나타남   95.2%
물체 → 사라짐      13.7%
                  ─────
        acc        54.5%      sensitivity  +4.5      bias  40.8
```

sensitivity/bias 는 **양방향이 다 있는 쌍**마다 계산해 평균한다. `n pair-type` 이 그 쌍 개수다.

## 3. 관찰

### (1) 가림 길이는 무관하다

`sensitivity`, 조건을 합친 값:

```
             k=0    k=1   k=2   k=3   k=4
permanence   50.0   11.3   7.4   6.9   4.5
shape        34.3    5.0   5.2   6.2   5.2
colour       31.6   13.1  12.9  13.5  20.8
```

가림막이 생기는 순간 절벽처럼 떨어지고 **그 뒤로는 평평하다.** shape 은 k=1 과 k=4 가 5.0 vs 5.2 다.
가려지는 시간을 4배로 늘려도 아무 일도 일어나지 않는다.

→ CLAUDE.md §10-5 의 "가림 길이 통제 세트: L1 이 IntPhys 수준까지 오르는가" 는 **아니오**.

### (2) 가속이 shape 을 깎는다 — 가림이 없을 때만

`Moving`, 가림 없음:

| violation | ramp(가속) | flat(등속) | 차이 |
|---|---:|---:|---:|
| permanence | 100.00 | 100.00 | 0.0 |
| **shape** | **69.05** | **89.88** | **+20.8** |
| colour | 76.79 | 86.01 | +9.2 |

가림이 있으면 그 차이가 거의 사라진다 (shape 52.4 vs 57.7, permanence 둘 다 정확히 50 근처).

→ **예측을 불확정하게 만드는 것이면 무엇이든 signal 을 지운다.** 가림은 그중 가장 강한 사례다.
⚠️ 이 대비는 "등속 vs 등가속도" 이고 쐐기 유무는 조작의 구현이다 (CLAUDE.md §8-5).

⚠️ **정정 (2026-08-30)** — "가림이 있으면 차이가 사라진다" 를 **"가림 하에서는 가속이 무관하다"
로 읽으면 안 된다.** 가림 조건의 ramp 54.46 / flat 56.85 는 둘 다 chance 근처라 **바닥 효과**와
구분되지 않는다. 정확한 서술은 **"가림 하에서는 둘 다 이미 바닥이어서 가속의 효과를 잴 수 없다"**
이다. 근거: `HYPOTHESIS_SCALAR_ORDER_2026-08-30.md` §1-(5).

### (3) permanence 의 bias 가 k 와 함께 커진다

```
        k=0   k=1   k=2   k=3   k=4
bias     0.0  31.0  29.5  33.5  40.8
sens    50.0  11.3   7.4   6.9   4.5
```

**가림이 길수록 "물체가 있는 미래" 로 더 확실히 쏠린다.** sensitivity 는 줄고 bias 는 는다.
k 가 무관하다는 (1) 과 결이 다른 관찰이므로 함께 인용할 것 — **탐지력은 k 에 무관하지만
편향의 크기는 k 와 함께 커진다.**

### (4) colour 만 k=4 에서 튄다

`sensitivity` 가 k=1~3 에서 13 근처인데 k=4 에서 **20.8** 로 오르고 bias 는 13 → 7 로 떨어진다.
다른 두 위반과 반대 방향이다. 셀당 n=504 라 우연으로 보기 어렵다. **설명 미상.**
경쟁 가설 둘 — (a) 가림막이 넓어지면 배경 토큰 구성이 바뀌어 색 스칼라의 분리가 좋아진다,
(b) k 가 커지면 미래 반쪽의 남은 가시 프레임 구성이 달라진다. 색 `s` 를 k 별로 따로 적합해
`std(s)` 가 k 와 함께 커지는지 보면 갈린다 (`HYPOTHESIS_SCALAR_ORDER_2026-08-30.md` §5 E5).
**갈리기 전까지는 설명 미상으로 남긴다.**

### (5) static_occlusion 의 vanish 가 이동 조건과 다르다

```
static_occlusion       vanish  acc 70.54  sens +20.54  bias  3.57
moving_occlusion       vanish  acc 50.00  sens  +0.00  bias 50.00
moving_occlusion_flat  vanish  acc 52.01  sens  +2.01  bias 47.99

정지 조건에서만 permanence 탐지가 살아남는다(+20.5). 이동 조건 둘은 **완전 상쇄**다.

- ⚠️ **후속 문서 있음** — 표 E/F 의 방향 편향이 전이별 21개(색 28개)가 아니라 **1차원 외형 순서**
  라는 가설과 그 검증 계획: `HYPOTHESIS_SCALAR_ORDER_2026-08-30.md`.
  `moving_visible` k=0 에서 shape **21/21**, color **28/28** 이 하나의 전순서와 모순 없이 일치한다
  (재계산 없이 아래 표에서 직독 가능).

- 셀당 n 은 조건×k×violation 기준 **vanish 89~90 / shape 134 / color 134** 쌍이다.
  방향별로 쪼개면 vanish 는 방향당 ~45, shape 은 쌍당 6~7, color 는 쌍당 4~5 다.
  **쌍 단위 수치는 단독 인용 금지** — 합=100 패턴이 여러 쌍에서 반복된다는 집합적 증거로 쓸 것.
- `moving_visible` 과 `moving_occlusion` 은 ramp, `*_flat` 은 평지다. `static` 은 평지.
- 방향 정의: vanish 는 `role`(imp_vanish/imp_appear), shape/color 는 `pre → post`.
- 모델 하나(ViT-H)뿐이다. ViT-L 미실행.
