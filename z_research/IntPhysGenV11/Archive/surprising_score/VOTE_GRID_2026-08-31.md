# 투표 행렬이 말하는 predictor 의 행동 (2026-08-31)

대상: `figures/surprise/04_object_order/fig_vote_grid_{shape,color}.pdf`

행 = 문맥 물체, 열 = 출력이 간 물체. **모든 칸 = 출력이 열 물체 쪽으로 간 비율(%).**
행·열은 지킴 순으로 정렬돼 있고 **모든 패널에서 같은 순서**를 쓴다.
따라서 **흰 칸 = 그쪽으로 가지 않았다.**

---

## 1. 흰 영역이 두 종류다

| 패턴 | 어디 | 뜻 |
|---|---|---|
| **판 전체가 희다** | 정지·등속의 `k=0` | 문맥 물체에서 아예 움직이지 않는다 |
| **상삼각만 희다** | `k>0` 전부, 그리고 등가속 `k=0` | 움직이긴 하는데 **한 방향으로만** 움직인다 |

shape 실측 (비대각 평균 %):

| arm / k | 상삼각 | 하삼각 | 순서와 어긋난 칸 |
|---|---:|---:|---:|
| Static k=0 | 3.9 | 8.0 | 21/42 |
| Static k=1 | 25.0 | 78.6 | 4/42 |
| flat k=0 | 8.6 | 11.6 | 21/42 |
| flat k=1 | 13.1 | 66.7 | 8/42 |
| **ramp k=0** | **5.1** | **56.8** | **8/42** |
| ramp k=2 | 11.9 | 79.8 | 1/42 |
| ramp k=4 | 9.5 | 85.7 | **0/42** |

- `k=0` 정지·등속은 상·하삼각이 둘 다 한 자릿수이고 어긋난 칸이 **21/42 (= 절반, 동전 던지기)**.
  구조가 없는 게 아니라 **정렬할 신호 자체가 없다.**
- `k>0` 이 되면 하삼각만 채워진다. 어긋난 칸이 0~8 로 떨어진다.
- **등가속은 `k=0` 에서 이미 갈라져 있다** (5.1 / 56.8). 가림이 순서를 만드는 게 아니다.

## 2. 여기서 얻는 것

### (1) 혼동이 아니다

혼동이라면 `A→B` 와 `B→A` 가 둘 다 중간값이어야 한다 (대칭).
실제로는 **한쪽이 ~0, 다른 쪽이 ~100** 이다.
→ **두 후보 사이에서 헷갈리는 게 아니라, 어느 쪽이 제시되든 같은 쪽을 고른다.**

### (2) 이행적이다

어긋난 칸이 등가속+가림에서 42 중 **0~4** 개다.
`A>B`, `B>C` 이면 `A>C` 가 성립한다 → **물체 하나짜리 점수**로 전부 접힌다.
비교 대상이 무엇이든 결과가 바뀌지 않는다.

### (3) 방향은 고정, 목적지는 아니다

⚠️ **"특정 물체로 몰린다" 는 성립하지 않는다.**
비대각 질량이 최다 목적지 열에 몰리는 비율은 **21~40%** 다 (균등이면 16.7%).
등가속 `k=0` 의 40.4% 가 최대이고, `k>0` 에서는 23~29% 로 오히려 흩어진다.
최다 목적지도 패널마다 바뀐다 (`cylinder` / `cube` / `capsule`).

→ 정확히는 **"순서의 위쪽으로 흘러내린다"** 이지 **"cylinder 를 만든다" 가 아니다.**
`torus` 행이 여섯 도전자에게 거의 균등하게 새는 것과 같은 그림이다.

### (4) 상삼각이 비는 것은 정렬의 부산물이 아니다

정렬은 **대각선이 단조**가 되는 것만 보장한다. 짝비교가 순환적이거나 잡음이면
진한 칸이 양쪽 삼각형에 흩어진다 — `k=0` 정지·등속이 정확히 그 상태다 (21/42).
**증거는 그림의 모양이 아니라 어긋난 칸 수와 Hodge R² 다** (0.82–0.91, 기준선 0.286).

## 3. color 는 다르다

| arm / k | 상삼각 | 하삼각 | 어긋난 칸 |
|---|---:|---:|---:|
| Static k=0 | 14.9 | 21.4 | 25/56 |
| **Static k=1** | **47.6** | **46.4** | **30/56** |
| flat k=1 | 19.0 | 47.6 | 18/56 |
| ramp k=2 | 13.1 | 40.5 | 21/56 |

- 이동 팔에는 약한 순서가 있다 (하삼각 40~48 vs 상삼각 13~21)
- **정지+가림에는 순서가 없다** — 상삼각 47.6 ≈ 하삼각 46.4, 어긋난 칸 30/56.
  그 셀 채점이 55.4% 인 것과 일치한다. **져도 아무 데로나 진다.**
- 최다 목적지 열 비중 15~22% (균등 14.3%) — shape 보다도 흩어진다

**색은 "순서로 진다" 가 아니라 "그냥 진다".** shape 과 같은 문장으로 쓰면 안 된다.

## 4. precision / recall — 능력 차이인가 편향인가

한 경기는 문맥 A, 후보 `{A, B}` 이고 출력이 A 아니면 B 로 확정된다. 그래서 검출 문제로 읽힌다.

- **recall(X)** = X 가 문맥일 때 X 를 지켜낸 비율 — **투표 행렬의 대각선**
- **precision(X)** = 출력이 X 였을 때 정말 X 가 문맥이었던 비율
- 2지선다이므로 **chance 는 둘 다 50**

갈라지는 지점은 이것이다:

| | recall | precision |
|---|---|---|
| **능력 차이**라면 | 벌어진다 | **같이** 벌어진다 |
| **편향**이라면 | 벌어진다 | **50 에 눌린다** (순수 1차원 편향의 예측값이 정확히 50) |

### 등가속 + 가림 (shape)

| 물체 | recall | precision | F1 |
|---|---:|---:|---:|
| cylinder | **89.6** | **51.5** | 65.4 |
| cube | 86.5 | 51.6 | 64.6 |
| pyramid | 59.4 | 58.2 | 58.8 |
| capsule | 58.3 | 53.3 | 55.7 |
| cone | 47.9 | 55.4 | 51.4 |
| sphere | 36.5 | 64.8 | 46.7 |
| **torus** | **3.1** | **75.0** | **6.0** |

**recall 폭 86, precision 폭 24.**

- **`cylinder` 의 높은 recall 은 정보가 없다** — precision 51.5 는 chance 50 과 사실상 같다.
  cylinder 가 아닐 때도 cylinder 를 만든다. **순수 편향의 예측값에 정확히 앉아 있다.**
- **`torus` 는 정반대다** — 거의 안 만들지만(3.1), 만들면 대개 맞다(75.0).
- → **능력 차이가 아니라 과생산/과소생산이다.**

### 조건 대비

| 조건 | recall 폭 | precision 폭 |
|---|---:|---:|
| 정지 · 비가림 | **6** | **12** |
| 등가속 · 비가림 | 57 | 40 |
| 등가속 + 가림 | **86** | **24** |

- 정지·비가림은 일곱 물체가 전부 우상단 구석에 몰린다 — **편향이 없다** (대조군)
- 등가속은 가림 없이도 이미 벌어져 있다
- 가림이 붙으면 recall 만 더 벌어지고 **precision 은 오히려 50 쪽으로 눌린다**

### color

같은 방향이지만 훨씬 약하다 (등가속+가림 recall 폭 39, precision 폭 13).
정지+가림은 §3 대로 순서 자체가 없다.

그림: `figures/surprise/04_object_order/fig_precision_recall_{shape,color}.pdf`

⚠️ **모든 FN 은 상대의 FP 다.** 그래서 recall 과 precision 의 음의 상관(−0.93) 자체는
구조적이다. 정보는 상관 부호가 아니라 **두 폭의 대비(86 vs 24)** 에 있다.

## 5. 한 문장

**predictor 는 "무엇인지 헷갈리는" 게 아니라 "같은 쪽으로 미끄러진다".**
방향은 하나로 고정돼 있고, 목적지는 흩어져 있으며,
많이 만들어지는 물체일수록 **그 출력이 맞을 확률은 동전 던지기에 가깝다.**
