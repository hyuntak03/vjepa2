## 0. 30초 요약

**제기된 의견**: 표 E/F 의 방향 편향 `bias(X→Y)` 가 전이별로 21개(색 28개) 따로 있는 게 아니라,
도형마다 고정된 스칼라 `s` 하나로 `bias(X,Y) ≈ s(Y) − s(X)` 처럼 쓰인다.
즉 채점이 "위반 탐지" 가 아니라 **미래 도형의 고정 순위 읽기**로 축퇴했다.

**이미 확인된 것** (표에서 직접, 재계산 없음):
`moving_visible` k=0 셀에서 방향 편향의 부호가 **shape 21/21, color 28/28 모두**
하나의 전순서(total order)와 모순 없이 일치한다. 우연 확률 각각 2.4e-3, 1.5e-4.

```
shape   cylinder < cube < capsule < cone < pyramid < sphere < torus
color   blue < cyan < green < orange < red < purple ≲ magenta ≈ yellow
```

**틀린 부분** (원 의견 그대로 쓰면 안 되는 것):
1. **순수 스칼라 모델은 이미 반증돼 있다.** 그 모델은 `acc(X→Y)+acc(Y→X)=100` 을 강제하는데,
   실제로는 `cone→sphere 200`, `cyan→red 200`, `capsule→cone 194` 처럼 200 근처 쌍이 여럿이다.
   → 축퇴는 **부분적**이다. 올바른 진술은 "편향(반대칭 성분)이 1차원이고, 탐지력(대칭 성분)은
   별개로 존재하며 가림·가속이 그것만 지운다" 이다.
2. **`s ∝ ‖LN(h)‖` 는 원리적으로 불가능하다.** `layer_norm(h, (h.size(-1),))` 은 affine-free 라
   모든 토큰의 노름이 정확히 `sqrt(1280)` 로 상수다 (§3-3).
3. **실루엣 면적도 불가능하다.** v11 이 렌더 픽셀 기준으로 이미 등화했다 (§3-4).
4. **R² 를 0 기준으로 읽으면 안 된다.** 무작위 반대칭 데이터의 기대 R² 가 shape 0.286 / color 0.250 이다 (§3-2).

**남은 진짜 질문**: `s` 를 **채점 밖에서** 예측하는 게 무엇인가. 후보는 `d(S) = mean|mu_h − LN(h_S)|`
(= §5-4b 의 `α(mu)` 를 도형 단위로 일반화한 것). 이게 맞으면 beat 8(외형 편향)과
beat 11(L1 최적해 = 조건부 중앙값)이 한 줄로 이어진다.

## 1. 원 의견 (그대로 보존)

### (1) bias 는 21개가 아니라 스칼라 하나
표 E `moving_visible` k=0 을 방향별로 읽으면 편향의 부호가 전이 `X→Y` 가 아니라
**splice 이후 도형 `Y` 만으로** 결정된다.

```
capsule→cylinder   0.0 / 93.8      cube→cylinder    6.2 / 81.2
cone→cylinder      6.2 / 100.0     cylinder→torus   100.0 / 18.8
cylinder→pyramid   100.0 / 12.5    sphere→torus     81.2 / 12.5
```
미래가 cylinder 면 안 걸리고 torus 면 걸린다. 21쌍 전부에서 순서를 뽑으면 추이성이 성립한다.
→ 21개 자유도가 7개(사실상 6개)로 줄어든다. **"편향들의 집합" 이 아니라 "1차원 순서"** 라는 게
훨씬 강한 주장이다.

즉시 할 것: 21쌍 bias 에 최소제곱으로 `s` 적합, R² 보고. 그다음 `s` 가 무엇과 상관되는지 —
실루엣 면적, 엣지 길이, 그리고 특히 `‖LN(h_future)‖` 또는 `mean|LN(h)|`.

### (2) confusion matrix 와의 상관은 null 이 나올 것이고 그게 정상
`s(Y)−s(X)` 는 반대칭, probe confusion 은 유사도라 대칭. 구조가 달라 상관이 안 나오는 게 맞다.
v10 무상관이 설계 탓인 줄 알았는데 21쌍 전수인 지금도 null 이면 결측이 아니라 결과다.
대신 confusion 의 비대칭 성분이 아니라 **각 도형의 주변(marginal) confusion 총량**과 `s` 를 비교할 것.

### (3) vanish 의 0/100 이 메커니즘을 그대로 보여준다
표 D `moving_occlusion` 은 전 k 에서 object→empty 0.0 / empty→object 100.0. 완전 축퇴.
`p` 가 뭉개져 있으면 `mean|p − LN(h)|` 는 target 에 물체가 있을 때 항상 크다.
**위반이 아니라 target 의 양을 재는 것.** vanish 는 `s` 가 두 값뿐인 특수 케이스다.
static 은 약하다(k=1 에서 78.6/76.8) — 물체가 안 움직여 `p` 가 위치를 안다.
→ **편향의 크기는 `p` 의 불확실성에 비례한다.** 셀별 bias vs `d(p, mean_p)` 로 직접 잴 수 있다.

### (4) 이것이 beat 들을 하나로 묶는다
`moving_visible`(ramp, 가림 없음)에서 이미 shape bias 26.79, flat 은 4.17.
가림 없이 가속만으로도 같은 편향 서명이 나온다. 축퇴를 일으키는 건 occlusion 이라는 특정 조건이
아니라 **예측 불확실성 그 자체**다. 불확실성을 만드는 방법 셋 — 가림(cliff), 가속(ramp),
그리고 k(한 번 가리고 나면 더 안 늘림) — 이 전부 같은 결과를 낸다.

> 예측이 불확실해지면 `p` 는 조건부 중앙값으로 붕괴하고,
> 채점은 위반 탐지에서 고정된 외형 순서 읽기로 축퇴한다.

### (5) 고쳐야 할 것 두 개
- 관찰 (2) 의 "가림이 있으면 차이가 사라진다" 는 **바닥 효과**다. occlusion 에서 ramp 54.46 vs

- colour 만 k 와 함께 오른다 (k=1→4: sta+occ 52.98→61.90, mov+occ 69.64→75.60, flat 66.67→75.00).
  전 조건 일관이라 우연이 아니다. 색 `s` 를 k 별로 따로 적합해 분산이 k 와 함께 커지는지 볼 것.

## 2. 즉시 확인된 것 — 완전 전순서 (재계산 없음, 표 E/F 직독)

방향 규약: `A→B` 열 = `pre=A, post=B` 인 clip 의 정확도. 문맥일치 쌍이므로 `p` 가 동일하고
정답 ⟺ `|p − h_B| > |p − h_A|`. 따라서 `acc(A→B)` 가 높다 ⟺ `d(B) > d(A)`,
여기서 `d(S) = |p − LN(h_S)|`. **`s ≡ d` 로 읽으면 된다.**

### shape — `moving_visible`, k=0, 방향당 n=16, 21쌍 전수

```
cylinder < cube < capsule < cone < pyramid < sphere < torus
```

| 검사 | 결과 |
|---|---|
| 부호가 이 순서와 일치하는 쌍 | **21 / 21** |
| `|bias| ≥ 15` 인 강한 쌍만 | **15 / 15** (7개 노드 전부 덮음) |
| 우연히 전순서가 될 확률 | `7!/2^21 = 2.40e-3` |

최소·최대의 극단성: `capsule→cylinder 0.0 / 93.8`, `cone→cylinder 6.2 / 100.0`,
`cube→cylinder 6.2 / 81.2` — cylinder 가 미래면 세 경우 모두 거의 못 잡는다.
`cylinder→torus 100.0 / 18.8`, `capsule→torus 100.0 / 6.2` — torus 가 미래면 거의 다 잡는다.

### color — `moving_visible`, k=0, 방향당 n=12, 28쌍 전수

```
blue < cyan < green < orange < red < purple ≲ magenta ≈ yellow
```

| 검사 | 결과 |

## 3. 비판적 검토 — 원 의견에서 고쳐야 할 것

### 3-1. 순수 스칼라 모델은 이 데이터로 이미 반증된다

잡음 없는 순수 스칼라 모델은 `acc(X→Y) = 100·[d(Y)>d(X)]` 이므로
**`acc(X→Y) + acc(Y→X) = 100` 을 항상 강제**한다. 그런데 표 E/F 에는

```
cone→sphere      100.0 / 100.0   합 200      cyan→red      100.0 / 100.0   합 200
capsule→cone     100.0 /  93.8   합 194      blue→orange   100.0 /  91.7   합 192
pyramid→sphere   100.0 /  93.8   합 194      green→magenta  91.7 /  91.7   합 183
```
합이 200 인 쌍은 **순수 스칼라 모델에서 확률 0** 이다. 모델은 그 자체로 틀렸다.

**올바른 재진술 — 대칭/반대칭 분해:**

```
acc(X→Y) = 50 + sens(X,Y) + b(X,Y)
sens(X,Y) = [acc(X→Y)+acc(Y→X)]/2 − 50     대칭     진짜 탐지력
b(X,Y)    = [acc(X→Y)−acc(Y→X)]/2          반대칭   방향 편향
```
- 가설이 말하는 것은 **`b` 에 대해서만**이다: `b(X,Y) ≈ g(s(Y) − s(X))`, `g` 단조.
- `sens` 는 스칼라 모델이 아무 말도 하지 않는 별개 성분이다.
- `moving_visible` k=0 shape 은 `sens +19.05`, `bias 26.79` — **축퇴가 부분적**이다.
- 완전 축퇴는 `sens → 0` 인 곳에서만 일어난다: 가림(shape sens 5.0~5.2), 이동 vanish(sens 0.00).

**따라서 논문에 쓸 문장은 "채점이 스칼라 읽기로 축퇴했다" 가 아니라**

> 방향 편향은 처음부터 1차원 외형 순서다. 탐지력은 그와 독립인 별개 성분이고,
> 가림과 가속이 지우는 것은 탐지력뿐이다. 탐지력이 0 이 되면 남는 것은 순서뿐이라
> 채점이 외형 순서 읽기로 **완전히** 축퇴한다.

이게 원 의견의 (1)(3)(4) 를 전부 포함하면서 반증 가능한 형태다.

### 3-2. R² 의 **기준선**이 0 이 아니다 — Hodge 분해로 읽어야 한다

> ⚠️ **§4-2 의 "confusion 상관 0" 과 전혀 다른 이야기다. 여기는 probing 이 필요 없다.**
> `bias` 21개를 도형 스칼라 `s` 7개로 적합했을 때의 설명력을 어디에 견주느냐의 문제일 뿐이고,
> 표 E/F 만 있으면 계산된다. 혼동을 막기 위해 이 절에서는 "null" 대신 **기준선** 이라고 쓴다.

`K7` 위의 반대칭 함수 공간은 21차원, 그중 gradient 부분공간(`s(Y)−s(X)` 꼴)은 6차원이다.
`s` 는 숫자 7개지만 차이만 쓰이므로 자유도가 6이다. **21개를 6개로 맞추는 것**이라
아무 의미 없는 난수를 넣어도 R² 가 6/21 = 0.286 은 그냥 나온다. color 는 7/28 = 0.250.

수치 확인 (난수 20,000회, `numpy` 만):
```
n=7  무작위 bias 21개를 s(7개)로 적합 -> 평균 R2 = 0.2852 (±0.134)   이론값 6/21 = 0.2857
n=8  무작위 bias 28개를 s(8개)로 적합 -> 평균 R2 = 0.2499 (±0.112)   이론값 7/28 = 0.2500
```
**산포가 크다(±0.134).** R² 0.45 는 기준선에서 1.2σ 밖에 안 된다.
**단일 R² 로는 아무것도 못 말한다** — 그래서 아래 split-half 를 건다.

| 검정 | 무엇 |
|---|---|
| 기준선 | `R² > 0.286` (shape) / `> 0.250` (color) 이어야 의미 있음. **단일 R² 는 산포가 커서 불충분** |
| permutation null | 도형 라벨을 섞어 재적합, R² 분포를 1000회로 |
| **split-half 예측 R²** | 블록의 절반으로 `s` 적합 → 나머지 절반의 `b` 예측. **이게 유일하게 못 속이는 검정** |
| 잔차 | curl(순환) 성분이 큰 쌍을 보고할 것. 거기가 모델이 쌍-특이적으로 뭔가 하는 곳이다 |

R² 단일 숫자를 보고하지 말고 **gradient 성분 비율 + permutation p + split-half 예측 R²** 셋을 보고한다.

### 3-3. `‖LN(h)‖` 는 상수다 — 그 상관은 원리적으로 못 잰다

`evals/world_model_analysis/eval.py:542` · `:748`
```python
h = torch.nn.functional.layer_norm(h, (h.size(-1),))
```
affine-free LayerNorm 을 **마지막 차원(1280)** 에 건다. 그러면 모든 토큰이 정확히 평균 0, 표준편차 1 →
`‖token‖₂ = sqrt(1280)` 로 **모든 clip, 모든 도형에서 상수**다.
`mean|LN(h)|` 도 단위분산 벡터의 평균절대값이라 분포 첨도로만 흔들리는 거의 상수다.

→ **`s ∝ ‖LN(h)‖` 는 검정할 대상이 아니라 항등적으로 거짓이다.** 대신 재야 할 것:

```
d(S) = mean_over(clip: future=S) mean_over(token,dim) | mu_h − LN(h_clip) |
mu_h = 전체 clip 의 LN(h) 평균 (미래 반쪽 토큰만)
```
`p` 도 pairing 도 쓰지 않으므로 **채점과 독립**이다. 이게 §5-4b 의 `α(mu)` 를 도형 단위로
일반화한 값이고, v10 에서 방향 비대칭을 r=0.948 로 설명한 바로 그 양이다 (CLAUDE.md §5-4c).

### 3-4. 실루엣 면적도 원리적으로 못 잰다 — v11 이 이미 등화했다

`V11_DESIGN.md §3`: 첫 등화(`equalise_extent: "mean"`)가 잘못된 양을 맞춰 렌더 픽셀에서
cube 가 평균보다 22% 넓고 cone 이 18% 좁아 **면적 2.6배** 차이가 남아 있었고,
`shape_scale_fix` 로 **렌더된 실루엣 기준**으로 다시 등화했다:

```
cube 0.819   cylinder 0.938   pyramid 0.987   capsule 1.003
sphere 1.046   torus 1.083    cone 1.217
```

→ 실루엣 면적은 설계상 7개 도형에서 같다. **면적으로는 `s` 를 설명할 수 없고, 그게 오히려 결과를 강화한다** —
가장 뻔한 기하 지름길을 제거한 뒤에도 완전 전순서가 남았다는 뜻이다.

남은 기하 후보: **윤곽선 길이 · 곡률 · 구멍(torus 만 있다) · 고주파 텍스처/음영량.**
관찰과 맞물리는 점: `s` 최대가 torus(유일하게 구멍), 최소가 cylinder(가장 밋밋한 실루엣).
`shape_scale_fix` 값과 `s` 순서는 일치하지 않는다 (cone 1.217 인데 `s` 는 중간) — 크기 보정의 잔여가 아니다.

색 순서에도 같은 종류의 후보가 있다. 배경은 `concrete_brick · grass_hewn · checker_steel · hex_rust` 로
**적갈·초록·회청**이다. 관측 순서에서 낮은 쪽이 blue·cyan·green(배경에 있는 색), 높은 쪽이
magenta·yellow(배경 팔레트에 없는 색)다. 즉 `s ≈ 장면 평균으로부터의 거리` 라는 §3-3 의 예측과 결이 같다.
⚠️ red 가 중간(5위)인 건 이 설명과 안 맞는다. **가설일 뿐 확인 안 함.**

### 3-5. `s` 적합은 설명이 아니라 압축이다

`s(S) := 미래가 S 인 clip 의 평균 surprise` 로 정의하면 순서와 정확도 패턴은 **정의상** 일치한다.
그건 발견이 아니라 재기술이다. 내용은 두 곳에만 있다:

1. **순서의 일관성** — 21쌍/28쌍이 모순 없이 한 줄로 정렬되는가 (§2 에서 확인됨)
2. **`s` 를 채점 밖에서 예측하는 것이 있는가** — `d(S)`(target encoder 캐시만), 기하량, 텍스처

**(2) 없이 (1) 만 보고하면 리뷰어가 순환논법이라고 쓴다.** E1 과 E2 는 반드시 붙어 다녀야 한다.

### 3-6. 셀 단위 n — occluded 셀에서 쌍별 `s` 적합 금지

표 E 의 `n/방향` 은 k=0(visible) 셀에서 **16**, occluded k 셀에서 **4** 다. color 는 12 / 3.
방향당 n=4 면 정확도의 이산 격자가 25%p 단위이고 bias 의 SE 가 ~18%p 다.

| 적합 단위 | 방향당 n | 가능? |
|---|---:|---|
| 조건 × k × 쌍 | 4 (color 3) | ❌ |
| 조건 × 쌍 (k 합산) | 16 (color 12) | ⚠️ 경계 |
| 조건 arm × 쌍 (visible/occluded 만) | 32~64 | ✅ |
| 전체 × 쌍 | 96 (color 72) | ✅ |

→ **E1 은 전체 및 arm 단위로 적합하고, 조건별은 6개 셀에 한해 arm 이 아니라 조건 단위(k 합산)로만 한다.**
RESULTS 문서 §4 의 "쌍 단위 수치는 단독 인용 금지" 와 같은 제약이다.

## 4. 이 틀이 이미 있는 결과를 설명한다

### 4-1. v10 의 "역설적" −0.549 가 예측값이 된다

CLAUDE.md §5-4c: `pyramid→cylinder` 는 채점 0% 인데 pyramid recall 96%,
`cylinder→pyramid` 는 채점 100% 인데 cylinder recall 46%. corr(방향 비대칭, recall(A)) = **−0.549**.

스칼라 모델에서 `acc(A→B) ≈ 50 + g(s(B) − s(A))` 이므로 **`s(A)` 가 크면 `acc(A→B)` 가 작다.**
그리고 `s(A)` 가 크다 = 전역 평균에서 멀다 = 표현이 구별적이다 = probe recall 이 높다.
따라서 **corr(acc(A→B), recall(A)) < 0 은 모델의 예측이지 역설이 아니다.**
v11 의 순서에서도 같은 부호가 나오는지가 E4 다.

### 4-2. confusion 과의 상관 0 은 구조적으로 강제된다 — 증거력이 없다

> ⚠️ **§3-2 의 R² 기준선과 무관하다.** 저기는 채점 결과만으로 하는 적합의 기준선이고
> probing 이 필요 없다. 여기는 probing 이 나온 뒤에야 계산되는 상관이다.
> 값이 나오는 이유도, 그 값이 뜻하는 것도 서로 아무 관계가 없다.

`b(X,Y)` 는 반대칭, confusion 유사도 `C(X,Y)` 는 대칭. 두 벡터는 내적이 항등적으로 0 에 가깝다.
→ **"상관 0.00" 은 관측이 아니라 정의의 귀결이다.** 이걸 "표현 유사도가 아니라 스칼라 크기에서 온다"
의 증거로 쓰면 안 된다. 원 의견 (2) 의 후반부 — **주변 confusion 총량 vs `s`** — 만이 정보를 담는다.
사전 등록 예측: `corr(s(S), recall(S)) > 0`, `corr(s(S), Σ_X C(X→S)) < 0`.

### 4-3. vanish 0/100 은 `s` 가 두 값뿐인 극단 사례

표 D `moving_occlusion` 전 k 에서 object→empty 0.0 / empty→object 100.0, `sens 0.00`.
`s(물체有) > s(빈)` 이고 `sens = 0` 이면 스칼라 모델이 정확히 0/100 을 예측한다.
static 에서만 살아남는 것(`sens +20.54`)은 `sens` 성분이 남아 있다는 뜻이고,
이는 §3-1 의 분해와 정확히 일치한다.

## 5. 수정된 실험 순서

전부 **토큰 캐시 + 이미 있는 산출물** 로 되고 **GPU 가 필요 없다.**
`per_block.json` + `index_probe.csv` + `features.cache_dir/v11_vith/target.npy` 면 충분하다.

### E1. Hodge 적합 — `b` 는 gradient 인가 (30분)

| 항목 | 내용 |
|---|---|
| 입력 | 표 E/F 의 `b(X,Y)`, 전체·arm(visible/occluded)·조건 단위 |
| 방법 | `b = argmin ‖b − (s(Y)−s(X))‖²`, gauge `Σs = 0`. gradient 성분 비율 = R² |
| 기준 | R² > **0.286**(shape) / **0.250**(color). permutation p<0.01. **split-half 예측 R² 보고** |
| 부산물 | curl 잔차 상위 쌍 목록 — 여기가 쌍-특이적 구조가 있는 곳 |
| 판정 | split-half 예측 R² 가 0.6 이상이면 "1차원" 주장 성립 |

### E2. `s` 의 외부 예측자 — 순환논법 차단 (1시간)

| 후보 | 계산 | 사전 등록 예측 |
|---|---|---|
| **`d(S) = mean|mu_h − LN(h_S)|`** | target 캐시만, `p`·pairing 미사용 | **`corr(s, d) > 0.8`** — 맞으면 beat 8 ↔ beat 11 직결 |
| 윤곽선 길이 / 곡률 | v11 프레임에서 물체 마스크 경계 | torus 최대, cylinder 최소여야 |
| 실루엣 면적 | — | **설계상 상수. 검정 대상 아님 (§3-4)** |
| `‖LN(h)‖`, `mean|LN(h)|` | — | **항등적으로 상수. 검정 대상 아님 (§3-3)** |
| 색: 배경 팔레트로부터의 거리 | 배경 4종의 평균 RGB | magenta·yellow 최대, blue·green 최소 |

### E3. 편향 ∝ `p` 의 불확실성 (1시간)

셀(조건 6 × k 5 = 24) 단위로 `bias` 와 `‖p − mu_p‖` 를 상관. `p` 는 문맥일치 쌍에서 동일하므로
셀 평균 `‖p − mu_p‖` 가 곧 "predictor 가 얼마나 커밋했나" 다.
- 사전 등록: **`corr(bias, ‖p−mu_p‖) < −0.7`** (커밋할수록 편향 작다)
- 이게 나와야 §1-(4) 의 "불확실성이 원인" 이 서사가 아니라 수치가 된다
- 함께: `sens` 와도 상관 (예측: > +0.7)

### E4. `s` 의 조건 불변성 — 가장 강한 버전 (30분)

6개 조건에서 각각 `s` 를 적합해 7-벡터 6개를 얻고 15개 상관을 본다.
- 사전 등록: **조건 간 corr > 0.8** — 즉 `s` 는 고정이고 **스케일만** 조건에 따라 변한다
- 성립하면: "고정된 외형 순서 × 불확실성이 정하는 이득(gain)" 이라는 2-파라미터 모델이 되고
  E1(순서) 과 E3(이득) 이 하나로 합쳐진다. **논문 그림 하나로 beat 4~8 을 묶을 수 있다**
- 안 성립하면: 조건마다 순서가 회전한다는 뜻이고 "1차원" 주장은 셀 단위로만 써야 한다

### E5. color × k 이상 (30분)

색 `s` 를 k 별로 따로 적합해 `std(s)` 가 k 와 함께 커지는지 본다.
경쟁 가설 두 개를 함께 적을 것:
- (a) 가림막이 넓어져 배경 토큰 구성이 바뀌고 색 스칼라의 분리가 좋아진다 (원 의견)
- (b) k 가 커지면 미래 반쪽의 **깨끗한 프레임 구성**이 달라진다 — 남은 가시 프레임이 물체가
  크고 중앙에 있는 쪽으로 치우칠 수 있다. `metadata.csv` 의 가시 프레임 수/타이밍으로 확인 가능
→ (a)/(b) 가 안 갈리면 **설명 미상으로 남긴다.** 지금 문서도 그렇게 적혀 있다.

### 순서
```
E1 → E2   (이 둘은 반드시 함께. E2 없이 E1 만이면 순환논법)
E4        (성립하면 논문 구조가 바뀐다)
E3        (통합 서사의 수치)
E5        (남은 이상)
probing + confusion  — 예정대로. 위 틀로 읽으면 §4-2 가 해석 지침이 된다
```
