# 데이터 구성 디버깅 (2026-11-09 ~)

- **질문**: AR 이어 학습에서 어떤 데이터 · 음성 구성이 합성 (VOBench · IntPhys1 Surrogate) 을 L1 만 판 수준으로 지키면서 IntPhys2 late 와 real 을 올리나?
- **답 (05:21 KST, 1 묶음)**: **사라짐 음성만** (나타남 · 바꿔치기 음성 없음, λ 1) 이 통과 — 합성 그대로 (VOB 판 · 움직임 99.5, Sur 움직임 80.0), real 66.3 → 73.2 (75/72), real 48 +9.4. 다만 IP2 late 는 +2.5 (53.3) 로 작다.
- **다음**: 사라짐만을 바탕으로 IP2 late 를 올리는 판 (3 묶음: 약한 나타남 · v4bc4f · SSv2 섞기 · λ 1.25 · 음성 수) + 2 묶음 손실 설계, 통과판 공식 IntPhys1 · 2.

## 용어
| 용어 | 뜻 |
|---|---|
| L1 만 판 | 같은 데이터로 음의 손실 없이 이어 학습한 판 (그 데이터의 기준) |
| 음의 손실 | 불가능 미래 (이어 붙인 미래) 에서 예측을 밀어내는 손실 max(0, margin − L1) |
| 사라짐 · 나타남 · 바꿔치기 음성 | 물체 있는 문맥 + 빈 미래 · 빈 문맥 + 물체 미래 · 같은 장면 다른 속도의 미래 |
| 합성 유지 칸 | VOBench v3 4 칸 (판 · 지나가는 × 움직임 · 정지) · Surrogate 2 칸 |

## 규칙 (사용자 지시)
1. 데이터를 바꾸면 **그 데이터의 L1 만 판**을 같이 돌리고 그것과 비교한다 (2026-11-09).
2. 통과 = 합성 유지 칸이 L1 만 판보다 3 점 넘게 떨어지지 않고, **IntPhys2 late 와 real 95 가 둘 다 L1 만 판보다 높다**. IntPhys1 late · real 48 은 참고.
3. 바꿔치기 음성은 쓰지 않는다 (사용자 "바꿔치기는 별로").
4. 벤치 칸을 흉내 낸 데이터는 새로 만들지 않는다. 기존 요소 중 벤치를 보고 만든 것은 표시한다: v4c (VOB 지나가는 가림막) · v4d · v4e (VOB 가속 칸 하락) · v4f (real bench 틀린 사건). v4bc4 자체는 사용자가 좋다고 판단.
5. GPU 는 꽉 채워 여러 판을 동시에, 판정 표는 `z_research/scripts/analysis/transfer_table.py`.

### 학습 없는 측정 (11-09 02:40–03:00 KST) — latent 잡음 바닥 [측정]
- 블록 latent (LN target encoder, 블록별) 은 **보이지 않는 화소 ±1 잡음에 토큰 |차| 0.47** 움직인다 (±2: 0.55). 실제 한 블록 시간 변화는 0.49, 토큰 크기 0.67.
- 같은 묶음 가능 vs 불가능 미래 차이는 그 잡음의 **1.1–1.25 배** (target 보이는 블록 1.24 · 안 보이는 블록 1.11). 공간 평균 (2×2 … 전체) 은 비율을 키우지 않는다 (잡음이 공간 상관).
- target 토큰 영역 (미래 토큰의 2–3 %) 에 latent 차이의 2–4 % · 보이는 블록에 76–88 % (블록 비율 75–88 %) → 공간 · 시간 어느 쪽으로도 몰려 있지 않다.
- 해석 [이론]: single 판 음의 손실 "L1 ≥ 1" 은 잡음 바닥을 밀어 예측 전체가 쏠린다 (가능 미래 L1 0.47 → 0.62). 물체 토큰 · 블록 마스크는 신호가 몰려 있지 않아 실패.
  채점은 8 블록 × 256 토큰 × 1280 차원 평균이라 잡음이 상쇄되고 물체 몫이 쌓인다.
