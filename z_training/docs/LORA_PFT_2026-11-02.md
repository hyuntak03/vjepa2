# encoder LoRA 를 붙여 같이 이어 학습한 8 판 (2026-11-02)

> **질문** 시트 Object_permanence 의 이어 학습 8 판에서 문맥 encoder 까지 LoRA 로 열면 물체 영속 판별이 달라지는가.
> **답** 릴리즈 계열은 합성 벤치 (VOBench v3) 에서 크게 오른다 (4 판 모두, 예: └ V4 panel 82.8 → 98.5). 실제 영상 벤치 (IntPhys 2 late · real world) 는 대부분 +0–10 pt 로, 한 판 한 칸씩 보면 신뢰구간 안이다. AR 계열은 어느 벤치에서도 일관된 변화가 없다 [측정].
> **다음** 릴리즈 + LoRA 의 실제 영상 이득이 진짜인지 보려면 seed 를 바꿔 반복하거나 시험 쌍을 늘려야 한다. AR 은 LoRA 를 늘리는 쪽으로 더 갈 근거가 없다.

## 용어

| 용어 | 뜻 |
|---|---|
| 이어 학습 | 이미 학습된 predictor (릴리즈 또는 AR 기본판) 에서 출발해 새 데이터로 더 학습하는 것. 시트의 "└ … Post Training" 행 |
| LoRA 없는 판 | 시트에 이미 있는 이어 학습 8 판. predictor 만 학습하고 encoder 둘은 얼린다 |
| LoRA 판 | 이번 8 판. LoRA 없는 판과 같고, 문맥 encoder 에 LoRA 를 붙여 predictor 와 같이 학습한다 |
| LoRA | encoder 선형층 128 개 (32 블록 × attention qkv · 출력 투영 · MLP 두 층) 마다 W x 에 (α/r)·B(A x) 를 더한 것. 원래 W 는 얼리고 A · B 만 학습한다. r = 8, α = 16, 학습 파라미터 524 만 개. B 가 0 에서 시작하므로 처음에는 원래 encoder 와 출력이 같다 |
| 문맥 encoder | predictor 에 들어가는 문맥 토큰을 만드는 encoder. 릴리즈 계열은 online encoder, AR 계열은 블록별 target encoder |
| 타깃 encoder | 손실과 채점의 정답 토큰을 만드는 target encoder (EMA). 두 계열 모두 얼린다 |
| 입력 경로 복사본 | AR 계열에서 쓰는 방식. 문맥과 정답이 같은 target encoder 라서, 그것을 복사해 입력 쪽에만 LoRA 를 단다 |
| LoRA 학습률 배수 | LoRA 파라미터의 학습률 = predictor 학습률 일정 × 10 |
| 정답률 | 짝마다 surprise(불가능) > surprise(가능) 이면 정답 (같으면 0.5). chance 50 % |
| rwpT | real world permanence 의 보류 절반 (48 영상 · 96 쌍). real permanence 로 이어 학습한 판에서는 이 열만 학습에 안 쓴 영상이다 |

## 1. 왜 했나

- 사용자 지시 (2026-11-02): "그대로 context encoder LoRA 붙여서 같이 학습하는 것까지 해줘. sheet 에 있는 것들 다."
- 가설: predictor 만 학습하면 encoder 가 만든 문맥 토큰에 없는 정보는 끝내 못 쓴다. encoder 를 조금 열면 영속 판별이 오를 수 있다 [추측].

## 2. 무엇을 어떻게 했나

### 2-1. 8 판

LoRA 없는 판과 데이터 · 전역 batch · step 수 · 학습률 일정 · seed · 창 · 좌우 반전 · 학습 중 검증이 같다. 다른 것은 LoRA 하나다. 학습 설정이 같은지는 병합된 설정끼리 비교해 확인했다 [측정].

| 시트 행 | LoRA 를 단 곳 | 길이 | 전역 batch |
|---|---|---|---|
| 릴리즈 └ V4 | 문맥 encoder (online) | 2,000 step | 48 |
| 릴리즈 └ V4 + 음의 손실 | 문맥 encoder (online) | 2,000 step | 48 |
| 릴리즈 └ VOBench | 문맥 encoder (online) | 500 step (20 epoch) | 32 |
| 릴리즈 └ real permanence | 문맥 encoder (online) | 180 step (30 epoch) | 16 |
| AR └ V4 | 입력 경로 복사본 | 2,000 step | 48 |
| AR └ V4 + 음의 손실 | 입력 경로 복사본 | 2,000 step | 48 |
| AR └ VOBench | 입력 경로 복사본 | 510 step (30 epoch) | 48 |
| AR └ real permanence | 입력 경로 복사본 | 180 step (30 epoch) | 16 |

- VOBench 두 판만 GPU 수가 다르다. LoRA 없는 판은 GPU 4 장, 이번에는 8 장이다. 그래서 GPU 당 batch 를 반으로 줄여 전역 batch 를 맞췄다. 한 epoch 의 step 수도 원판과 같게 고정했다 (릴리즈 25, AR 17).
- 타깃 encoder 는 모든 판에서 얼린다. 정답 토큰이 움직이지 않게 하려는 것이다.

### 2-2. 확인한 것

- **LoRA 없는 체크포인트 채점은 그대로다** [측정]. 릴리즈 └ V4 (LoRA 없음) 의 IntPhys 1 late 를 바뀐 채점기로 다시 냈다. 영상별 surprise 360 개가 원래 결과와 비트 단위로 같았다 (GPU 1 장 · 8 장 둘 다).
- **채점기가 LoRA 를 읽는다** [측정]. 스모크 체크포인트 (20 step) 를 LoRA 있음 / 없음으로 채점했다. predictor 는 같다. 영상별 surprise 360 개가 전부 달랐다 (최대 차이: 릴리즈 0.0070, AR 0.0048).
- **학습 시작 상태가 LoRA 없는 판과 같다** [측정]. 학습 전 검증 (VOBench late 432 쌍) 이 릴리즈 60.9–61.6 % / AR 73.4 % 다. LoRA 없는 판은 61.1–61.6 % / 73.1 % 다. surprise 평균 차이는 1e-4 수준으로, bf16 잡음 정도다.
- **스모크에서 학습이 돈다** [측정]. 손실이 기록되고, LoRA 기울기 크기가 0 이 아니고 (0.005–0.04), 저장물에 LoRA 가중치 256 개 텐서가 들어간다. LoRA 학습률은 predictor 의 정확히 10 배다 (저장된 optimizer 학습률로 확인).

### 2-3. 이전 AR LoRA 판의 학습률 배수 (⚠️ 정정)

- 2026-10-25 의 IntPhys2 AR LoRA 판 (시트 "AR predictor w/ IntPhys2" LoRA 행) 은 설정에 학습률 배수 10 이 적혀 있다. 그런데 **실제로는 1 배로 학습됐다** [측정]. 그 판 체크포인트의 optimizer 에서 LoRA 학습률이 predictor 와 같다.
- 원인: 배수를 WSD 일정만 읽는 방식으로 넣었는데, 그 판은 warmup + cosine 일정이었다.
- 이번 8 판은 일정 종류와 상관없이 배수가 곱해지게 고쳤다. 그래서 이번 AR 판의 LoRA 학습률은 그 옛 행의 10 배다. main 의 릴리즈 LoRA 판은 처음부터 10 배였다.

## 4. 해석

- **릴리즈 계열: 합성 벤치는 LoRA 로 확실히 오른다** [측정]. VOBench v3 묶음 16 칸이 모두 오른다. 그중 11 칸 (표의 굵은 칸) 은 +7 pt 이상이다. 학습 중 검증 (VOBench late) 도 4 판 모두 오른다 (+3–12 pt).
- **릴리즈 계열: 실제 영상 벤치는 대부분 같은 방향이지만 작다** [측정].
  - real world 는 4 판 모두 오른다: 전체 +0.5–4.7 pt, rwpT +1.0–4.2 pt.
  - IntPhys 2 late 는 3 판이 오른다 (+3–10 pt).
  - 한 칸씩 보면 모두 신뢰구간 안이다. 4 판이 같은 방향인 것은 우연만으로는 덜 그럴듯하다 [추측]. 하지만 판끼리 데이터 일부와 출발점이 겹쳐 독립이 아니다.
- **AR 계열: LoRA 가 바꾸는 것이 없다** [측정].
  - IntPhys 2 late 는 4 판 모두 +3–5 pt 지만 50–54 % 로 여전히 chance 근처다.
  - real world · VOBench v3 는 오르는 판과 내리는 판이 섞인다.
  - IntPhys 1 late 의 AR └ VOBench 90 → 70 은 쌍 6 개 차이다.
- **왜 계열마다 다른가는 재지 않았다.** 두 가설이 있다 [추측].
  - 릴리즈는 LoRA 가 문맥을 한 번에 보는 encoder 를 바꾸지만, AR 은 블록 하나 (2 장) 씩만 보는 복사본을 바꿔 움직임 정보를 더할 여지가 작다.
  - AR 은 이미 합성 벤치가 천장 근처라 오를 칸이 적다.
- **단서.**
  - seed 하나씩이다.
  - LoRA 학습률 배수는 ×10 이다. 옛 IntPhys2 AR LoRA 행은 실제로 ×1 이었다 (2-3).
  - VOBench 두 판은 원판과 GPU 수가 달라 데이터 순서가 다르다. 전역 batch · step 수는 같다.
