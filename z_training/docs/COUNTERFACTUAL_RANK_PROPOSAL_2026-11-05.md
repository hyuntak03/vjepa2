# 장면 안 반사실 순위 손실 — 제안과 학습 전 측정 (2026-11-05)

- **질문**: 음의 손실 (negative loss) 말고, 반사실을 더 효율적으로 쓰는 학습이 있나 (사용자 11-05: "counterfactual 한 그런 게 좋은 것 같기도").
- **답**: 같은 장면의 형제 영상 미래를 음성으로 두고, 자기 미래가 가장 가깝도록 순위를 매기는 손실을 제안한다. 학습 전에 재 보니, 지금 음의 손실은 속도 바꿔치기 순위를 우연 수준으로 망가뜨렸다 (84 → 55 %). 순위 손실은 바로 그 자리를 겨눈다 [측정 + 이론].
- **다음**: 손실 구현과 CPU 검사, 그리고 v4a 데이터로 L1 · 음의 손실 · 순위 손실 세 판 비교. 학습은 사용자가 올리라고 할 때 올린다.

## 용어

| 용어 | 뜻 |
|---|---|
| 묶음 | 같은 장면에서 target 운동만 바꾼 영상들 (속도 4 단계, v4a 평면 trapdoor 는 정지 단계 하나 더) + target 을 뺀 빈 장면 1 |
| 형제 미래 | 같은 묶음의 다른 영상의 미래 16 장. 문맥 k 에 형제 j 의 미래를 붙이면 불가능 영상이 된다 (사라짐 · 나타남 · 바꿔치기) |
| S[k, j] | 문맥 k 로 굴린 예측과 형제 j 미래 정답 사이 토큰 L1 평균 = 채점기 surprise. AR 은 정답이 블록별이라 이어 붙인 불가능 영상의 surprise 와 같다 |
| 자기 미래 1 등 비율 | 행 k 에서 S[k, k] 가 형제들보다 작은 비율 (짝마다 · 행 전체) |
| 순위 손실 | 행 k 마다 −log softmax(−S[k, ·] / τ) 의 자기 칸. τ = 온도 |

## 1. 왜 했나

- 음의 손실 (짝 없음, 불가능 L1 을 margin 1 위로 밀기) 은 real 장면 판별 D 와 치우침 c 를 움직였다. 그런데 합성 성능은 조금 내려갔다 [측정, LAMBDA_ABLATION.md].
- 짝 손실 (가능 − 불가능 선형) 은 합성 손해는 없앴지만, real 치우침 이동도 같이 없앴다 [측정].
- 가설: 음의 손실의 합성 손해는 가까운 음성 (속도만 다른 바꿔치기 미래) 에서 온다. 불가능 L1 을 절대 margin 으로 밀면, 가능 미래와 가까운 바꿔치기 미래에서 멀어질 때 가능 미래에서도 같이 멀어진다 [추측 → 아래 측정].

## 2. 무엇을 어떻게 쟀나 (학습 없음)

- v4a 학습 묶음 120 개 (평면 trapdoor 60 · 나머지 60, seed 0) 를 학습과 같은 창 (2 장 간격 32 장, 시작 0, 문맥 8 블록) 으로 굴려 S 행렬을 만들었다.
  - 묶음은 가림막을 판 · trapdoor 로 좁힌 첫 판 (지금 이름 v4a_bt) 에서 뽑았다. 그 뒤 v4a 기본은 v4 가림막 전부로 바뀌었다 (벽 · 서 있는 물체 묶음은 이 측정에 없다).
- 비교 대상: AR 기본판 (v4 이전) · AR + v4 L1 · AR + v4 음의 손실 λ 1. 그리고 같은 공간의 복사 기준선 (마지막 문맥 블록 반복) 으로, 연속성만으로 맞히는 바닥을 잰다.

## 3. 결과 [측정]

자기 미래 1 등 비율 (%), 괄호 = 상대 margin (S[k, j] − S[k, k]) / S[k, k] 중앙값.

| 짝 종류 | 복사 | AR 기본판 | AR + v4 L1 | AR + v4 음의 손실 |
|---|---:|---:|---:|---:|
| 사라짐 (단계 → 빈 장면) | 43.1 | 64.6 | 99.6 (5.5 %) | 99.2 (9.4 %) |
| 나타남 (빈 장면 → 단계) | 76.2 | 85.3 | 99.3 (11.8 %) | 95.5 (15.3 %) |
| **바꿔치기 (속도 ↔ 속도)** | 50.0 | 53.3 | **84.2** (1.3 %) | **54.7** (0.1 %) |
| 정지 → 빈 장면 | 79.3 | 89.7 | 98.3 | 100.0 |
| 정지 ↔ 움직임 | 61.9 | 72.2 | 99.6 | 96.1 |
| 행 전체 1 등 | 26.0 | 35.6 | 74.8 | 46.7 |

## 4. 해석

- **음의 손실의 합성 손해는 바꿔치기에서 난다.** 속도 순위가 84 → 55 % (우연 50) 로 무너졌다. 사라짐 · 나타남은 그대로 높다 [측정]. 그래서 "가까운 음성을 절대 margin 으로 밀면 가능 미래에서도 멀어진다" 는 가설과 맞는다 [해석]. VOBench 하락과 직접 이어지는지는 아직 안 쟀다.
- **사라짐 · 나타남은 학습 데이터에서 이미 포화다.** v4 로 학습한 판은 99 % 다. 정지 단계도, 정지를 본 적 없는 AR + v4 가 98 % 로 이미 맞힌다 [측정]. 그래서 v4a 의 정지 단계를 L1 로만 학습하면 합성에서는 배울 것이 적다. real 정지 장면의 실패 (PerceptionTest 사라짐 25–29 %) 는 합성 능력 부족보다 전이 문제일 가능성이 크다 [추측].
- 복사 기준선은 바꿔치기 50 %, 행 전체 26 % 다. 연속성만으로는 형제를 못 가른다. 그래서 순위 손실이 렌더 연속성 지름길로 풀릴 여지는 작다 [측정].

## 5. 제안: 장면 안 반사실 순위 손실

손실 = L1 (지금 그대로) + λ · 평균_k [ −log softmax(−S[k, ·] / τ)_k ]. 한 rank 의 배치 = 한 묶음 (영상 5–6 편, 지금 rank 당 6 과 같다).

| 관문 | 채운 내용 |
|---|---|
| 1 latent 유효성 | AR 이 굴린 미래 블록 토큰과 형제 미래의 블록별 정답 (LN) 을 채점기와 같은 L1 로 비교한다. 픽셀 가정 없음. 블록별 정답이라 S[k, j] = 이어 붙인 불가능 영상의 surprise [이론, 채점기 정의] |
| 2 틀 | 블록 AR 그대로. 손실만 더한다. 구조 · 출력 나누기 없음 |
| 3 최적해 | L1 만이면 토큰마다 조건부 중앙값이다. 위치가 불확실하면 물체 칸 중앙값이 배경이 되어 "사라짐이 싸다" 가 된다 [이론]. 순위 손실은 토큰을 합친 S 로 비교해 토큰별로 분리되지 않는다. 그래서 자기 미래가 형제보다 가까워야 하는 쪽으로 최적이 옮겨진다. softmax 라 margin 이 τ 보다 크면 기울기가 0 이 되어, 이미 맞는 곳은 L1 최적 그대로 둔다 (음의 손실 hinge 는 학습 내내 활성 0.96–1.00 이었다 [측정]). 형제 미래 = 문맥에 없는 정보지만 학습 때만 쓰고 시험 때는 필요 없다. 음성은 전부 불가능 영상이라 위반을 흡수하지 않는다 |
| 4 판별 상한 | 해당 없음 (오라클 안 씀) |
| 5 이미 기각 | 장난감 대조 학습 R4 (일반 음성, 실제 영상) 는 조건화를 못 만들었다 (갈림 0.09). 이번 음성은 같은 장면 반사실이라 차이가 조건 하나뿐이다. 반사실 쌍 이어 학습 (cf_ft) 은 가능 변형 L1 이었지 순위가 아니다. 영상 모드 정답에 순위를 걸면 시간 위치 지문이 지름길이다 (auto_research README) → **블록별 정답 (AR) 에만** 건다 |
| 6 사용자 조건 | 미래 예측 유지 (L1 주 항). IntPhys 2 · VOBench 같이 판정. 실제 영상은 형제 미래가 있는 realneg 사건 (SSv2 281 × 가능 · 불가능 · 인공물 가능) 에도 같은 손실을 건다 |
| 7 근거 태그 | 본문 표기 |
| 8 측정 도구 | 복사 기준선 행 전체 1 등 26 %, 바꿔치기 50 % — 연속성만으로는 안 풀린다 (§3) |

효율 [계산]: 영상마다 형제 4–5 개가 음성이고, 추가 영상 읽기 · 인코딩이 없다 (정답은 어차피 묶음 영상마다 만든다). 음의 손실은 영상당 음성 0.5 개에, 다른 영상 하나를 더 읽는다. step 당 반사실 비교가 약 10 배다.

단서
- 묶음 단위 배치는 step 당 장면 수를 48 → 8 로 줄인다. 기울기 분산이 커질 수 있다 [추측].
- 사라짐 · 나타남은 합성에서 포화라 순위 손실이 그 칸에서는 거의 안 민다. real 치우침을 옮기려면 real 사건을 같은 손실에 넣어야 할 가능성이 크다 [추측]. 합성과 실제는 외형으로 구분된다 (흐름 모양 AUROC 0.82–0.84, auto_research). 그래서 합성에서만 배우면 합성에서만 적용할 위험이 있다.
- 짝을 놓친 대안 — 반사실 문맥 차이 손실 (Δp ≈ Δh, 토큰 L1): 토큰마다 분리되는 L1 이라 위치가 불확실하면 Δ 의 중앙값이 0 이 되어 같은 문제를 물려받는다 [이론]. 권하지 않는다.
