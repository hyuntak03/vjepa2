## 용어

| 용어 | 정의 |
|---|---|
| 블록 | 연속 2장 (fps 4 라서 0.5초) |
| 정답 토큰 | 블록을 고정 target encoder 에 넣고 LN 한 것, shape (256, 1280). **문맥 정답 토큰** = 관측 구간 블록 (predictor 입력), **미래 정답 토큰** = 채점에서 예측과 비교하는 대상 |
| 예측 토큰 | predictor 가 만든 미래 블록, shape (256, 1280). **TF 한 걸음** = 정답 과거를 모두 보고 다음 블록 하나만 만든 것. **굴린 예측** = 자기 예측을 되먹여 여러 블록을 이어 만든 것 |
| 블록 AR (기준선) | 미래 latent 를 블록 하나씩 만드는 predictor. 처음부터 학습, 자연 영상 (K710 · SSv2 · HowTo100M 1 %), 70 epoch |
| 판독기 | 블록 토큰에서 물체 정체 (49 지선다) · 위치 · 속도를 읽는 작은 head (0.07M 파라미터). query 1개 attention 으로 칸을 모은 뒤 선형 출력 3개 |
| 합성 감독 | 3D 합성 클립 (물체 1개, 실제 상태 라벨 있음) 으로 판독기 손실을 predictor 에 거는 것. 손실 가중치 0.05, 자연 영상 batch 와 매 step 함께 |
| 이어 학습 | 이미 학습한 predictor 를 특정 데이터로 몇 epoch 더 학습하는 것 (손실은 같은 latent L1) |
| 광류 | RAFT 로 구한 픽셀 움직임. fps 4 연속 두 장 사이, 16×16 칸 평균 (dx, dy) |
| VOBench P / R | VOBench 의 primitive / realistic 장면 쌍 정확도 (chance 50) |
| gravity P / R | VOBench gravity, 블록 정의 (가능 영상이 모든 불가능 영상보다 surprise 가 낮아야 정답) |
| IntPhys1 가림 늦은 판 | IntPhys 1 가림 쌍 90개, 위반 시점 직전에서 문맥이 끝나는 고정 창 |
| IntPhys2 고정 창 | IntPhys 2 학습에 안 쓴 장면 절반 252 쌍. 사람 라벨 위반 시점 앞 16장 = 문맥, 뒤 16장 = 미래 |

## 1. 지금 돌고 있는 것

### 1-1. 이 기계 (GPU 8장) — 정답 토큰 판독기 감독

**왜 했나**
- 앞선 3D 합성 감독은 판독기 성능이 좋았다. 예측 토큰에서 위치 오차 7~14 px 였다 [측정].
- 그런데 그 판독기를 정답 토큰에 씌우면 102~110 px 로 틀렸다. 굴린 예측에서는 물체 칸을 전혀 보지 않았다 (물체 칸 가중치 0) [측정].
- 즉 predictor 가 물체를 맞는 자리에 그리지 않고, 다른 칸에 따로 상태를 적었다. 판독기는 그 칸을 읽는 법을 같이 배웠다 [추측: 측정과 맞는 설명].
- 가설: 판독기를 정답 토큰에서만 학습하고 predictor 쪽에서는 고정하면, 예측이 encoder 와 같은 방식으로 물체를 담아야만 손실이 내려간다.

**무엇을 어떻게 했나**
- 판독기는 **정답 토큰** (문맥 + 미래) 에서만 학습한다. 이때 판독기만 업데이트된다.
- predictor 는 **가중치를 고정한 같은 판독기**로 자기 예측 (TF 한 걸음 · 굴린 예측) 에 손실을 받는다. 이때 predictor 만 업데이트된다.
- 둘 다 물체가 **보이는 블록**에만 손실을 건다. 가려진 블록의 정답 토큰에는 물체 정보가 없기 때문이다 [이론].
- 나머지는 기존 3D 합성 감독과 같다: 데이터, 판독기 구조, 가중치 0.05, 70 epoch, 처음부터 학습.
- 학습 전 확인 [측정]: 정답 토큰으로 학습한 판독기는 처음 보는 클립의 정답 토큰에서 위치 20 px, 방향 cos 0.99 였다. 같은 판독기로 기준 AR 예측을 읽으면 110~118 px, 기존 3D 합성 감독 예측은 67~72 px 였다.

**진행**
- KST 12:32 시작. 지금 epoch 5/70 (step 1,293 / 20,580). epoch 당 약 16분.
- 끝 예상: **10/25 KST 06:20 전후** (모니터 기준, 3.1초/step).

**결과 (지금까지, 학습 로그)** [측정]

같은 판독기 (정답 토큰에서만 학습) 로 보이는 블록의 위치를 읽은 오차:

| | 정답 토큰 | TF 한 걸음 | 굴린 예측 |
|---|---|---|---|
| 기준 AR (학습 전 확인) | 20 px | 110 px | 118 px |
| 이번 학습, step 270 | 31 px | 104 px | 112 px |
| **이번 학습, 지금 (epoch 5)** | **21.5 px** | **22.7 px** | **24.9 px** |

- 굴린 예측의 물체 정체 맞힘: epoch 1 의 0 % → 지금 86 % (우연 2 %).
- 판독기 attention 이 몇 칸에 몰린다: 집중도 153배 (균등 = 1).

**해석**
- 판독기 기준으로는 의도대로 됐다. 예측 토큰이 정답 토큰과 거의 같은 오차로 읽힌다 [측정].
- 하지만 **그 몰린 칸이 실제 물체 칸인지는 아직 모른다.** 또 다른 자리에 코드를 적는 우회일 수도 있다 [추측]. epoch 4 체크포인트로 판독기 attention 위치와 운반 이득을 재는 검사가 지금 돌고 있다 (GPU 2장, 메인 학습 세션).
- 채점은 아직 판단할 시점이 아니다. 기존 3D 합성 감독도 epoch 4~6 부터 올랐다. 판단 기준은 **epoch 10~15 이후 VOBench late 가 기존 범위 (68~75) 를 넘는가**다.
- 위치가 맞게 읽힌다고 물체를 옮겨 그렸다는 뜻은 아니다. 운반 이득과 pixel decoder 그림으로 따로 확인해야 한다.

## 3. 지금까지 알게 된 것

**① 학습한 벤치마크 안에서만 오른다** [측정]
- VOBench 를 넣으면 VOBench 와 gravity 만 오른다 (90 / 91, gravity 75 / 58). IntPhys 2 는 그대로다 (51~53).
- IntPhys 2 로 이어 학습하면 IntPhys2 고정 창만 오른다 (52.0 → 63.5). VOBench 는 그대로이고 gravity 도 그대로다.
- 서로 넘어가지 않는다.

**② 합성 감독은 판독기를 속였다** [측정]
- 판독기 성능은 좋았는데 채점은 그대로였다. 같은 판독기를 정답 토큰에 씌우면 100 px 넘게 틀렸다.
- 예측이 encoder 와 다른 방식으로 상태를 적었다는 뜻이다. 지금 정답 토큰 판독기 감독이 이 우회를 막는 시도다.

**③ 예측 안의 공간 모델 — 어디가 비어 있나** [측정]

| 능력 | 지금 블록 AR | 근거 |
|---|---|---|
| 읽기: 입력에서 위치 · 속도를 안다 | ✅ | 문맥 정답 토큰 → 속도 R² 0.79 |
| 유지: 예측을 굴리는 동안 상태를 들고 간다 | ❌ | 굴린 예측 → 속도 R² 0.05 |
| 갱신: 속도대로 위치를 옮긴다 | ❌ | 운반 이득 0.2~0.3 (정답 0.78) |
| 그리기: 상태를 맞는 자리 토큰으로 낸다 | ❌ | 정답 토큰 판독기로 예측을 읽으면 110 px |
| 영속: 가려져도 들고 있다 다시 낸다 | ◐ | 영속 위반은 잘 잡지만 (VOBench 83~100) 다시 나타난 자리는 틀림 |

**④ 구조가 못 옮기는 것은 아니다** [측정]
- 3D 합성만으로 학습하면 운반 이득이 0.72 까지 간다.
- 자연 영상과 섞어 학습하면 같은 합성 검증 클립에서도 못 옮긴다.
- 왜 자연 영상 학습이 "안 옮기는 예측"을 최적으로 만드는지는 아직 모른다 [추측 단계]. "미래가 불확실해서 평균으로 간다"는 설명은 TF 한 걸음도 못 옮긴다는 측정과 맞지 않는다.

**다음 후보** (아직 method 관문 8줄을 통과하지 않음 [추측])
- 판독기 시간 일관성: 정답 토큰 판독기로 굴린 예측을 블록마다 읽고, 읽은 위치 · 속도가 운동 규칙을 따르게 한다. 라벨이 필요 없어 가려진 블록에도 걸 수 있다. 정답 토큰 판독기 감독이 먼저 되어야 한다.
- 잠재 움직임 코드: 학습 때 두 블록에서 작은 움직임 코드를 추정해 AR 에 넣고, 시험 때는 문맥에서 예측한 코드를 쓴다. 사용자가 말한 "움직임을 스스로 추정하는 규약"에 가장 가깝다. 채점 때 미래에서 코드를 뽑으면 위반을 흡수하므로 금지.
- 라벨 감독 (SFT): 같은 문맥 짝에서 surprise(불가능) > surprise(가능) + 여유 손실을 latent L1 과 함께 건다. 라벨이 IntPhys 2 · VOBench 학습 분할에 이미 있다. 한 도메인 라벨로 학습하고 다른 도메인에서 시험해 판정한다.
