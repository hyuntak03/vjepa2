# 불가능 미래 음의 손실 — BlenderTrack v4 이어 학습 두 판 (2026-11-02)

> **질문** 학습 중에 불가능한 미래를 보여 주고 그 미래에서 멀어지라는 손실을 주면, 가능 · 불가능 판별이 나아지는가 (릴리즈 출발 · AR 기본판 출발 두 판).
> **답** 아직 모른다. 두 판을 2026-11-02 18:52 KST 에 8 GPU 로 올렸다. 스모크에서는 손실 셋이 기록되고 불가능 샘플이 절반쯤 섞였다.
> **다음** 학습이 끝나면 자동 채점 (IntPhys 1 late · IntPhys 2 late · real world permanence) 과 학습 중 VOBench late 검증을 대조 판 (손실 L1 만) 과 나란히 본다.

## 용어

| 용어 | 뜻 |
|---|---|
| 가능 샘플 | 학습 목록의 영상 하나를 그대로 쓴 학습 창 (32 장 = 문맥 16 장 + 미래 16 장) |
| 불가능 샘플 | 문맥 16 장은 영상 X 에서, 미래 16 장은 같은 묶음의 다른 영상 Y 에서 가져와 이어 붙인 학습 창 |
| 묶음 | 장면 하나를 고정하고 target 속도만 4 단계로 바꾼 영상 A_0..A_3 와 target 이 없는 빈 장면 B, 모두 5 편 |
| 이음 | 문맥과 미래가 갈리는 원본 프레임 번호 32. 창 시작 0 이면 문맥 = 0..30, 미래 = 32..62 / 시작 1 이면 1..31, 33..63 |
| 가림 이음 통과 | target 이 원본 프레임 31 · 32 에서 완전히 안 보인다 (main 생성기의 hidden_splice). 이음이 화면에 안 드러난다 |
| 샘플 L1 | 그 샘플의 미래 토큰 전부에 대해 \|예측 − LN(target encoder 출력)\| 의 평균. 가능 샘플 손실과 같은 정의 |
| 굴린 L1 | AR 판에서 문맥만 보고 미래 8 블록을 차례로 굴려 낸 예측의 샘플 L1 (채점이 쓰는 양) |
| TF L1 | AR 판에서 매 블록을 정답 앞 블록들로 맞힌 예측 (teacher forcing) 의 샘플 L1, 블록 1..15 |
| 경계 | 불가능 손실 = max(0, 경계 − 샘플 L1). 이 판은 경계 1 |
| hinge 활성 | 불가능 샘플의 L1 이 경계보다 작아 음의 손실이 기울기를 내는 상태 |

## 1. 왜 했나

- 사용자 지시: "release, ar 둘 다 v4 로 학습하는데, 대신 impossible 도 넣고 impossible 은 1 − L1 으로 negative loss 걸어주도록."
- 가설: 지금 손실 (가능 미래에 가까워지기) 만으로는 불가능 미래와의 거리가 거의 벌어지지 않는다. 대조 판의 학습 중 검증 (VOBench late) 에서 가능 · 불가능 surprise 차이가 릴리즈 0.0067, AR 0.0253 이다 [측정]. 불가능 미래에서 직접 멀어지게 하면 그 차이가 커질 것이다 [추측].

## 2. 무엇을 어떻게 했나

### 2-1. 두 판과 대조

| 판 | 출발 | 대조 (손실만 다름) |
|---|---|---|
| 릴리즈 판 | 릴리즈 V-JEPA 2 ViT-H predictor | 대조 릴리즈 판 (같은 목록 · 전역 48 · 2,000 step · seed 0 · lr 5e-5 warmup 1 epoch + cosine · 좌우 반전 0.5) |
| AR 판 | AR 기본판 (블록 AR, 상태 되먹임, ep70) | 대조 AR 판 (위와 같은 데이터 · 길이, 문맥 8 블록 → 미래 8 블록) |

데이터 목록 · batch · step · seed · lr · 창은 대조와 같다. 다른 것은 불가능 샘플과 그 손실뿐이다.

### 2-2. 불가능 샘플

정의는 main 의 시험 VoE 와 같다. 이음은 프레임 32 다.

| 종류 | 문맥 | 미래 | 무엇이 불가능한가 |
|---|---|---|---|
| vanish | A_k | B | 가림막 뒤로 간 target 이 사라진다 |
| appear | B | A_k | 없던 target 이 가림막 뒤에서 나온다 |
| swap | A_k | A_j (j ≠ k) | 문맥의 속도 k 와 다른 속도 j 의 때 · 자리로 다시 나온다 |

- 영상을 디스크에 새로 쓰지 않는다. 학습기가 두 영상을 읽어 문맥 16 장 · 미래 16 장을 이어 붙인다. 좌우 반전은 이어 붙인 창 전체에 같은 결정으로 건다.
- 가림 이음 통과 [측정]: 단계 영상 9,000 편 중 **8,995 편 (99.94 %)**. 모든 단계가 통과한 묶음 2,246 / 2,250.
- 만들 수 있는 짝 [측정]: vanish 8,995 · appear 8,995 · swap 26,972. 짝을 만들 수 있는 문맥 영상 11,245 / 11,250.

### 2-3. 짝 고르기 — 지시와 다르게 한 것 하나

- 지시: 샘플마다 확률 0.5 로 불가능, 세 종류 고르게, 묶음 · 단계 무작위.
- 한 것: 샘플마다 확률 0.5 로 불가능 (그대로). 단, **문맥은 뽑힌 영상 자신**이다. 뽑힌 영상이 A_k 면 vanish_k 또는 swap_k_j (반반), B 면 appear_k (k 무작위).
- 결과 비율 [측정, 20 만 번 뽑기]: 가능 0.500 · vanish 0.202 · appear 0.101 · swap 0.198. 세 종류가 고르지 않다.
- 이유 [이론]:
  - 가능 미래와 불가능 미래는 대부분의 토큰 (배경) 이 같다. 그 토큰에서 가능 손실의 기울기와 음의 손실의 기울기는 방향이 정반대다 (\|p − a\| − \|p − a\| = 0).
  - 같은 문맥이 가능 · 불가능으로 같은 확률로 나오면 두 기울기가 상쇄되고, 문맥마다 목적함수가 아래로 막힌다 (\|p − 가능\| − \|p − 불가능\| ≥ −\|가능 − 불가능\|).
  - 묶음 · 단계를 무작위로 고르고 종류를 고르게 하면, 빈 장면 문맥은 가능 0.1 대 불가능 (appear) 0.167 이 된다. 그 문맥에서는 배경 토큰을 정답에서 **밀어내는** 힘이 남는다. 경계에 닿을 때까지 빈 장면의 가능 예측이 나빠질 수 있다.
- 샘플마다 고르는 난수는 영상 번호를 섞는다. 모든 rank 의 loader worker 난수가 같은 seed 라서, 섞지 않으면 rank 8 개가 같은 불가능 결정을 반복한다.

### 2-4. 손실

| 샘플 | 릴리즈 판 | AR 판 |
|---|---|---|
| 가능 | 샘플 L1 (대조와 같다) | TF L1 + 굴린 L1 (대조와 같다) |
| 불가능 | max(0, 1 − 샘플 L1) | max(0, 1 − 굴린 L1) |

- batch 손실 = 샘플 손실의 평균 (가능 · 불가능 샘플 가중 평균). 불가능만 있거나 없는 batch 도 같은 식이다. 불가능이 없으면 대조의 손실과 같은 값이다.
- **1 − L1 대신 max(0, 1 − L1)**: 1 − L1 은 아래로 끝이 없어 예측을 멀리 보낼수록 계속 줄어든다. L1 이 1 을 넘으면 0 으로 막았다.
- **AR 판은 불가능 샘플에서 TF 를 뺐다** (지시는 TF + 굴린 합). 이유 [이론]:
  - 문맥 자리 TF (블록 1..7) 는 가능한 영상 X 의 앞부분을 맞히는 것이다. 여기에 음의 손실을 걸면 같은 X 의 가능 샘플 손실과 정확히 상쇄되어 문맥 TF 학습 신호가 사라진다.
  - 미래 자리 TF (블록 9..15) 는 이음 뒤의 관측 (이미 사라진 target, 이미 바뀐 속도) 을 보고 다음 블록을 맞힌다. 관측과 맞는 예측이라 "불가능" 이 아니다.
  - 굴린 L1 은 문맥만 보고 낸 미래라 채점 (rollout surprise) 과 같은 양이다. 경계 1 도 두 판에서 같은 크기의 L1 (약 0.5) 에 걸린다. 합 (약 0.91) 에 걸면 여유가 0.09 뿐이다.
  - config 의 `ar_terms: sum` 으로 지시대로의 합도 돌릴 수 있다.
- 경계 1 의 뜻 [이론]: 정답 토큰은 LN 을 거쳐 차원마다 평균 0 · 분산 1 이다. 정규분포로 보면 0 벡터를 예측한 L1 은 0.80, 상관없는 토큰끼리의 L1 은 1.13 이다. 1 은 "평균을 찍은 예측보다 멀고, 상관없는 토큰보다는 조금 가깝다" 는 자리다.
- 경계가 사실상 안 닿는다 [측정 + 이론]: 스모크에서 불가능 L1 은 가능 L1 과 거의 같다 (아래 3 절). 삼각부등식으로 L1(예측, 불가능) ≤ L1(예측, 가능) + L1(가능, 불가능) 이고, 두 미래는 target 토큰에서만 다르다. 가능 예측을 지키면서 불가능 L1 을 1 까지 올릴 수 없으므로, hinge 는 학습 내내 켜져 있을 것이다 [추측]. 그러면 손실은 사실상 "가능 L1 − 불가능 L1 + 상수" 다.

- 손실 셋 (가능 L1 · 불가능 L1 종류별 · 불가능 손실) 이 step 로그와 epoch 기록에 남는다 [측정].
- 이어 붙인 창 3 개 (vanish · appear · swap) 를 PNG 로 떠서 문맥 끝 3 장 · 미래 앞 3 장을 눈으로 봤다. 이음 앞뒤에 target 이 가림막 뒤에 있어 이음이 안 보인다 [측정].
- 저장물은 `predictor` 키를 가진 표준 형식이다. 채점기가 대조 판과 같이 읽는다 [측정].
- 4 step 이라 불가능 L1 이 커지는 속도는 아직 모른다. 8 GPU run 의 step 로그 `neg … imp` 와 epoch 기록에서 본다.

## 3-1. 8 GPU run 초반 (epoch 2 = 200 step) [측정]

| 판 | 학습 가능 L1 (ep1 → ep2) | 학습 불가능 L1 (ep1 → ep2) | hinge 활성 | VOBench late 정확도 (대조 ep2 · 대조 ep20) | 검증 가능 surprise (대조 ep2) | 검증 차이 (대조 ep2) |
|---|---:|---:|---:|---:|---:|---:|
| 릴리즈 | 0.669 → 0.804 | 0.689 → 0.845 | 0.95 | **76.9 %** (68.8 · 74.3) | 0.766 (0.576) | 0.0143 (0.0049) |
| AR (굴린 L1) | 0.515 → 0.706 | 0.529 → 0.729 | 1.00 | **82.4 %** (81.9 · 80.3) | 0.505 (0.479) | 0.0280 (0.0228) |

- 판별 정확도는 오르는데, **가능 L1 도 불가능 L1 과 같이 오른다**. 4 절 셋째 줄의 경우 (예측이 흐트러짐) 가 실제로 나타나고 있다.
- 릴리즈 판은 검증의 가능 surprise 도 0.576 → 0.766 으로 올랐다. AR 판은 검증 쪽이 0.505 로 덜 올랐다 (학습 도메인 굴린 L1 은 0.706).
- 불가능 L1 이 1 에 닿으면 hinge 가 꺼진다. 그 뒤 가능 L1 이 어디서 멈추는지가 다음 관찰거리다.

## 4. 해석과 주의

- 가능 샘플 수가 대조의 절반이다 (같은 2,000 step × 48 중 절반이 불가능). 대조보다 가능 L1 이 덜 내려가도 손실 탓만은 아니다 [이론].
- 배경 토큰에서 두 손실이 상쇄되므로 배경 예측을 붙잡는 힘이 batch 잡음 수준으로만 남는다. 가능 L1 이 대조보다 오르면 이 때문일 수 있다 [추측].
- 불가능 L1 이 끝없이 커지는지는 epoch 기록의 `neg.imp_l1` 과 `neg.pos_l1` 을 같이 본다. 둘이 같이 오르면 판별이 아니라 예측이 흐트러진 것이다.
