| 가변 창 로더 | `app/vjepa_frozen/var_window.py`, `z_training/data/build_fps4_table.py` | step 마다 문맥 C · 예측 K ∈ {2,4,8,16,32} 장 (25 조합 균등), 전부 fps 4 정수 간격, 패딩 없음 (n4 ≥ W 인 영상만), rank 당 B = 950 // W. 데이터셋은 그 창을 채울 수 있는 것 중 가중치로 |
| kind=ar KV rollout | `src/models/rollout_predictor.py` `rollout_kv` | 원판 `rollout` 과 값 · grad 동일 (C8K16 fp32 출력 차 6e-6) |
| 힌트 cross-attn | `HintCrossAttn` · `ar.encode_hints` · `ar.hint_count` | 층마다 self-attn 뒤 병목 cross-attn (384→96, 4 head, 3D RoPE, up-proj 0 초기화, gate 없음). 위치 b 가 블록 b+1 의 무작위 patch 일부를 본다 (그 patch 만 encoder 에 넣어 누수 0). **teacher forcing 에만**, rollout · val · 채점은 힌트 없음. 일정 = 확률 아닌 정해진 값 `round(0.10 · sin²(π(t−0.05)/0.85) · 256)` — epoch 7 (1 개) → epoch 33 (26 개) → epoch 61 (마지막). 힌트 위치는 (seed, rank, step) 전용 생성기 (2026-10-12 수정 전에는 rank 끼리 같았다 — 힌트가 0 인 구간에서 고쳐 영향 없음) |
| 상태 되먹임 | `ar_feedback: state` (kind=ar 옵션) | rollout 때 출력 LN(proj(·)) 대신 `predictor_norm` 출력 (384) + type[1] 을 다음 블록 자리에 그대로. teacher forcing 은 관측 + type[0]. 기본값 `output` 은 기존과 같다. KV 판 vs 매 걸음 재계산 출력 차 2e-6 · grad 차 2e-10 |
| kind=ar 채점 경로 | `analysis/intphys2/model.py` `_ArBlockEncoder` · `_ArScorer` | 채점 코드 무수정. 문맥 · 타깃 모두 블록별 target_encoder (학습과 같다), 힌트 없음, KV rollout. 학습 val 경로와 출력 · 타깃 차 0 (CPU 소형 검증). 힌트 가중치 (`hint_attn.*`) 는 로드 때 버린다 |
| 벤치 채점 · 요약 | `z_training/eval_bench.sh` · `eval_bench_summary.py` | IntPhys1 A.8 (창 32 · 16, skip [2,5,10]) + IntPhys 2 Main (창 16 · 32 · 48, 열별 최고) |
| chain · 모니터 | `z_training/chain_ar.sh` · `monitor_ar.sh` | 학습 → 채점 → 다음 학습 → 채점. tmux 세션 이름은 `=` 로 정확히 일치시킨다 (앞부분 일치로 `_hint` 세션을 잡던 버그) |

### 손실 · 힌트 사용

- ar (rollout) 손실은 epoch 20 부터 0.55 근처에서 평평하다 (epoch 20 0.552 → 69 0.550, lr 상수 구간). lr 감소 구간 (64–70) 에서 0.5503 → 0.5473
- tf 손실은 힌트 정점 근처 (epoch 35–40) 0.523, 힌트가 빠지며 0.532 — 차이 약 0.008 (힌트 자리는 손실에서 뺐다)
- 힌트 모듈은 쓰였다: up-proj ‖W‖ 이 epoch 8 의 0.6–1.1 에서 epoch 40 의 6.7–11.2 (같은 층 self-attn proj 평균 14.8) 로 자라고, 힌트가 0 이 된 epoch 62 이후 grad 없이 멈춘다
- in-loop val (IntPhys1 60 쌍) 은 epoch 8 이후 78–82 %

### ⚠️ 단서

- 91.67 vs 88.89 는 180 쌍 중 5 쌍 차이 (표준오차 약 2pt) — 구분되지 않는다. 격자 최고는 descriptive
- **타깃 정의가 릴리즈와 다르다** — AR 은 블록별 LN(target_encoder), 릴리즈 채점은 창 전체 LN(target_encoder)
- tube 기준선 대비 +9.4pt 는 같은 데이터 · step · lr 모양이지만 학습 방식과 타깃 정의가 같이 바뀌었다
- 힌트 효과는 힌트 없는 짝 run 이 없어서 모른다 (출력 되먹임 기준선 `natural_ar_vw` 는 epoch 4 에서 사용자 결정으로 중단)
- IntPhys 2 는 릴리즈 모델을 우리 하네스로 잰 값이 없다
