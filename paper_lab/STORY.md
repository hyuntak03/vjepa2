# 논문 스토리 (paper_lab 정본)

**질문**: 관측만으로 학습한 latent 블록 AR predictor 가 intuitive physics 를 따르는 그럴듯한 미래를 내게 하려면 무엇을 바꿔야 하나. 그 이야기가 CVPR 논문으로 서나.
**답 (v3.2, 공정한 시험 뒤)**: V-JEPA 2 표적 공간에서 관측만으로 학습한 블록 AR predictor 둘은, 마지막 관측에 가려진 움직이는 물체의 정답 자리 칸 예측 토큰을 물체 쪽으로 보내지 않는다. 마지막 관측에 없는 낙하도 예측 없는 기준선 이상으로 고르지 않는다 (오라클을 통과한 물체 자리 채점) [측정]. 학습된 블록 AR 은 데이터가 보상하는 운반의 약 4–13 % 만 옮기고, 학습률 · 예산을 키워도 그대로다 [측정, 사전 등록 재현]. 공정한 시험 (기준 학습률, 기준 step 의 5 %, seed 둘) 에서도 입력 가림막 과제는 먼 칸에서 옮기지 못했다 (−0.5 %) [측정, 사전 등록]. 얼림 · 존재는 Xie & Alanwar 의 결과다.
**다음 할 일**: 사용자 결정 셋을 기다린다: D8 방향 · D10 옮기는 연산을 구조에 넣는 학습 판 (선반 판을 주 판정 축으로) · D11 DINOv2 표적 블록 AR (§8). method 결과 (리뷰 F1) 는 아직 없다.

판: v3.1 (라운드 2 리뷰 반영, 2026-10-22) · 근거 = 근거표 v3.2 (#1–#85, 공정한 시험 #85 반영, 진행자 1 검증 83/83) + 라운드 2 요약 + 계획표 §11 · §13 · 방향 선택지 = 계획표 §9 · 두 판 원문과 판 2 원문은 백업 사본 (부록) · 작성: 진행자 3 (파일 이름은 부록)

## 0. 용어표 (팀 정본)

이 표가 팀 전체의 정본이다. 근거표 · 계획표 · 리뷰 · 영어 초안은 이 용어만 쓴다.
새 개념이 필요하면 작성자 (진행자 3) 에게 먼저 알린다. "쓰지 않는 말" 은 옛 문서에서 같은 개념을 부른 다른 이름이다.

### 0-1. 모델과 부품

| 용어 | 정의 | 논문 용어 (영어) | 쓰지 않는 말 |
|---|---|---|---|
| latent world model | 영상을 encoder 로 토큰으로 바꾸고, predictor 가 미래 토큰을 **토큰 공간에서** 예측하는 모델 (JEPA 계열). 이 팀의 "world model" 은 이것만 가리킨다. 재구성용 latent 를 예측하는 생성형 (예: Cosmos) 은 "공간이 다른 비교" 로만 쓰고, 우리 판정 규칙상 근거로 쓰지 않는다 | latent world model (JEPA-style) | world model (한정 없이), 세계 모델 |
| **latent 예측** | 픽셀이 아니라 표적 encoder 의 토큰 공간에서 미래를 예측하는 것. 우리 predictor 의 출력 · 손실 · 채점이 모두 이 공간에 있다. 픽셀로 되돌리지 않는다 (decoder 없음) | latent prediction | 영상 예측, 미래 프레임을 그린다 |
| **표적 공간** | 예측 손실과 채점이 이뤄지는 토큰 공간. 지금은 표적 encoder 의 블록 토큰 (layer norm 뒤). 표적 떨림 · 칸보다 작은 이동에 대한 반응 · 운반 신뢰도 κ 는 이 공간에서 잰다 | target space | 정답 공간, latent 공간 (어느 공간인지 없이) |
| **자기지도 latent · 재구성용 latent** | 자기지도 latent = 픽셀로 되돌리도록 학습하지 않은 encoder 의 토큰 (V-JEPA 2 · DINOv2). 재구성용 latent = decoder 로 픽셀을 되살리도록 학습한 토크나이저의 토큰 (Cosmos). 둘 다 latent 예측이고, 표적 공간을 고르는 손잡이도 둘 다 있다 (라운드 2 I1) | self-supervised latent · reconstruction latent | "표적 공간 손잡이는 JEPA 만", 픽셀 생성형 (Cosmos 에 대해) |
| 문맥 encoder | V-JEPA 2 ViT-H 의 online encoder. 고정. 문맥 영상을 토큰으로 바꾼다 | context encoder | online encoder |
| 표적 encoder | 같은 체크포인트의 EMA encoder. 고정. 실제 미래 영상에서 표적 토큰을 만든다. 블록 AR predictor 는 문맥 토큰도 이것으로 만든다 | target encoder | target encoder (한국어 본문), 목표 encoder, 타깃 encoder, 정답 encoder, EMA encoder |
| predictor | 문맥 토큰을 받아 미래 블록의 토큰을 내는 transformer. 이 논문에서 학습하는 유일한 부품 | predictor | 예측기, dynamics model |
| 릴리즈 predictor | V-JEPA 2 공개 predictor. 입력 = 영상 토큰 + 미래 자리의 mask 토큰. 미래 8 블록을 한 번에, 양방향 attention 으로 낸다. 12 층, 폭 384 | released V-JEPA 2 predictor | release, 공개 predictor, pretrained predictor, inpainter, 기존 predictor |
| **블록 AR predictor** | 입력 = 문맥 블록 토큰. 블록 인과 attention (앞 블록만 본다). 미래를 한 블록씩 내고, 낸 것을 다음 입력으로 되먹인다. V-JEPA 2-AC 의 행동 조건 predictor 와 같은 꼴이라 planning 으로 이어진다. **이 논문의 본선** | block-autoregressive (block-AR) predictor | AR, AR predictor, 자기회귀 predictor, 블록 문맥 모델 |
| 기준 블록 AR predictor | 지금의 비교 기준. 자연 영상으로 70 epoch 관측 학습한 블록 AR predictor, 은닉 되먹임 (2026-10-14 사용자 결정) | observation-only block-AR baseline | vast AR, vast AR-state, AR ep70 |
| Ariel 판 | 2026-09 에 자연 영상으로 관측 학습한 predictor 셋 (한 번에 내는 것 · 문맥 양방향에 미래 인과 · 블록 AR). 기록용 비교 대상 | prior observation-only predictors | Ariel full / prefix / AR (구분 없이 "Ariel") |
| 영상 문맥 predictor | 입력 = 영상 토큰 (encoder 가 문맥 창을 한 번에 인코딩). 블록 AR 처럼 한 블록씩 낸다. 판이 둘이라 수치마다 판을 적는다: **블록 표적 판** = 정답이 블록 토큰 · **영상 표적 판** = 정답도 영상 토큰. 두 판은 데이터 · 학습량도 다르다 | video-context predictor (block-target / clip-target) | ctxt, 영상 문맥 모델, 판 구분 없는 "영상 문맥" |
| 되먹임 방식 | 블록 AR 이 다음 걸음 입력으로 넣는 것. **출력 되먹임** = 예측 토큰 (1280 차원). **은닉 되먹임** = 출력 투영 직전 벡터 (384 차원) | output feedback / hidden feedback | 상태 되먹임, state feedback, AR-state |
| 미세조정 predictor | 릴리즈 또는 블록 AR predictor 를 특정 합성 세트 (예: VOBench 가능 영상) 로 이어 학습한 것. 그 세트로 재면 도메인 안이다 | fine-tuned predictor | post-FT, PFT, post-training (이 뜻으로) |
| AC predictor | 행동을 함께 입력받아 미래 블록을 내는 predictor (V-JEPA 2-AC 꼴). 로봇 planning 에 쓴다 | action-conditioned (AC) predictor | |
| AC 후속 학습 | 관측 학습을 마친 predictor 위에서 행동 조건 학습을 잇는 것. 대조 = 처음부터 AC 학습 (AC 처음부터) | action-conditioned post-training | AC fine-tune, AC post, AC scratch (한국어 본문) |

### 0-2. 시간 · 공간 단위와 토큰

| 용어 | 정의 | 논문 용어 (영어) | 쓰지 않는 말 |
|---|---|---|---|
| 프레임 | 영상 한 장. 256 × 256 px 로 줄여 넣는다 | frame | 장 (단위로는 써도 됨) |
| 블록 | 연속 두 프레임. encoder 의 시간 단위. 초 단위는 표본 추출 속도에 따라 다르다 (VOBench 0.2 초, 블록 AR 학습 0.5 초). 수치마다 초를 같이 적는다 | block (two frames, one temporal tubelet) | 튜블릿, 슬롯, tubelet, t9–t16 |
| 칸 | 토큰 격자의 한 자리. 한 블록 = 16 × 16 = 256 칸. 1 칸 = 입력 16 × 16 px | cell | 패치, 토큰 자리 |
| 블록 토큰 | 한 블록 (2 장) 만 표적 encoder 에 넣고 layer norm 한 출력. shape (256, 1280). 블록 AR predictor 의 입력 · 출력 공간 | block tokens | 블록별 latent, 블록 문맥 |
| 영상 토큰 | 문맥 창 전체 (16 장 = 8 블록) 를 한 번에 encoder 에 넣은 출력. shape (8 × 256, 1280). 토큰마다 창 안 다른 블록의 내용이 섞인다 | clip tokens | 창 토큰, window latent |
| 문맥 · 문맥 블록 | predictor 가 보는 과거 블록들 (보통 8 블록 = 16 장) · 그중 한 블록 | context · context block | 과거, history (주장에서) |
| **마지막 관측** | 문맥의 마지막 블록. "보이는 것 · 안 보이는 것 · 없는 것" 의 기준점 | last observation | 문맥 끝, 경계, boundary, anchor, 마지막 프레임, 마지막 문맥 블록 |
| 예측 걸음 k | 마지막 관측 뒤 k 번째 미래 블록 (k = 1 … 8) | step k | 슬롯 k, 튜블릿 k, horizon k |

| rollout | 블록 AR 이 자기 예측을 다음 입력으로 되먹이며 여러 걸음을 차례로 내는 것 | rollout | 굴리기, open-loop, 자기회귀 굴림 |

### 0-3. 채점과 기준선

| 용어 | 정의 | 논문 용어 (영어) | 쓰지 않는 말 |
|---|---|---|---|
| surprise 점수 | 한 영상의 미래 블록에서 예측 토큰과 표적 토큰의 L1 차이를 토큰 평균한 값. 클수록 예상 밖 | surprise | 놀람, latent L1 오차 (점수 뜻으로) |
| 가능 · 불가능 쌍 | 문맥이 픽셀 단위로 같고 미래만 다른 두 영상. 하나는 물리적으로 가능, 하나는 불가능 | matched possible / impossible pair | matched pair, 문맥일치 쌍, VoE 쌍 |
| 쌍 정확도 | 불가능 영상의 surprise 점수가 더 큰 쌍의 비율. 우연 50 % | pairwise accuracy | VoE 정확도, matched 정확도 |
| 전체 토큰 채점 · 물체 자리 채점 | surprise 점수를 모든 칸 평균으로 · 두 미래의 물체 자리 (3 × 3 칸 합집합, 렌더 라벨) 만으로 낸 것. 같은 쌍 · 같은 규칙. 존재 · 외부 벤치마크의 주 결론은 전체 토큰. **자리 · 운반은 전체 토큰이 오라클을 통과 못 하므로 물체 자리 채점을 주로 하고 전체 토큰을 병기한다** (사용자 결정 D6 의 기본값) | all-token score · object-region score | 공 칸 |
| **복사 기준선** | 마지막 관측의 토큰을 모든 예측 걸음에 그대로 둔 '예측'. 모델과 같은 채점 공간에서 잰다 | copy baseline | copy, 순수 복사, 마지막 latent 복사, No-Dynamics |
| 복사 대비 이득 (Δ복사) | 모델의 쌍 정확도 − 복사 기준선의 쌍 정확도. 예측이 보탠 몫 | gain over copy (Δcopy) | predictor 몫, margin |
| leakage | 벤치마크가 예측 없이 풀리는 정도. 예측 없는 기준선 둘 (복사 기준선 · 문맥 평균 복사) 중 높은 쪽의 쌍 정확도로 잰다. 말 자체를 바꿀지는 사용자 결정 D7 (기본값: 유지) | leakage | 누수 (옛 문서에서 다른 뜻으로도 썼다) |
| 문맥 평균 복사 | 학습 없이 같은 칸의 문맥 블록 토큰을 평균해 모든 예측 걸음에 둔 '예측'. 복사 기준선과 같은 공간에서 잰다. 끝 가림 존재 점수의 귀무다 | context-average copy | 문맥 평균 기준선, 평균 복사 |
| 같은 공간 기준선 셋 | 모델과 같은 채점 공간에서 잰 학습 없는 예측 셋: 복사 기준선 · 문맥 평균 복사 · 정답 자리 오라클. 모든 VoE · 고른 미래 칸에 같이 낸다 | three same-space references | |
| 정답 자리 오라클 | 마지막으로 다 보인 물체 3 × 3 칸의 표적 토큰을 실제 미래 자리 칸에 넣은 학습 없는 latent 예측. 나머지 칸 (바탕 토큰) 은 마지막 관측 블록 또는 배경 평균 토큰이다. 채점 도구가 "성공" 을 볼 수 있는지 재는 상한이다 | true-position oracle | 운반 오라클과 섞어 쓰기 (운반 오라클은 정답 궤적으로 물체 토큰을 옮긴 것, §0-7), 캔버스 |
| 오라클 통과 칸 · 판정 불가 칸 | 정답 자리 오라클이 같은 채점에서 기준선을 분명히 넘는 칸 · 넘지 못하는 칸. **실패 주장과 합격선은 오라클 통과 칸에만 쓴다.** 판정 불가 칸의 모델 실패는 도구 탓과 못 가른다 | oracle-passing cell · not-judgeable cell | |
| 복사가 틀리는 쌍 | 복사 기준선이 틀리는 쌍만 모은 부분집합. 예측이 있어야 맞히는 쌍 | copy-hard pairs | copy-hard (한국어 본문) |
| 고른 미래 | 후보 미래가 여럿인 묶음에서 surprise 가 가장 낮은 후보가 진짜 미래인 비율. 우연 = 1 / 후보 수 | future-choice accuracy | argmin, block 정확도 |
| 세 세계 판독 | 후보 미래 셋 (계속 움직임 · 마지막 본 자리에 멈춤 · 사라짐) 의 고른 미래. Xie & Alanwar 2026 의 설계라 그 논문을 말할 때만 쓴다 | three-world readout (Xie & Alanwar) | |
| 멈춘 미래 | 자연 영상에서 마지막 관측 프레임을 반복해 만든 후보 미래. 복사 기준선이 늘 고르는 후보다 | frozen future | 멈춤 후보 (중력 세트의 다른 후보와 섞인다) |
| 도메인 안 · 밖 | 평가 세트가 학습 세트와 같은 분포인가 (안) 아닌가 (밖). 같은 세트에서 떼어 둔 test 도 도메인 안이다 | in-domain / out-of-domain | 분포 안 held-out 을 "일반화" 로 읽는 것 |

### 0-4. 능력 (무엇을 재나)

| 용어 | 정의 | 논문 용어 (영어) | 쓰지 않는 말 |
|---|---|---|---|
| intuitive physics (조작적 정의) | 아래 네 능력을 **행동으로** 잰 것. 모델 안에 무엇이 있는지 ("중력을 안다") 는 말하지 않는다 | intuitive physics (operational) | 물리 이해, 물리 엔진, 중력을 안다 |

| 안 보이는 것 | 문맥에는 있었지만 마지막 관측에서 가려진 물체 | hidden at the last observation | 가려진 것 (시점 없이) |
| 없는 것 | 문맥 어디에도 아직 드러나지 않은 변화. **3a 추세** (가속의 누적 · 꼭대기에서 되돌아옴) 와 **3b 사건** (받침 끝 낙하 · 벽 충돌) | absent from the observation (3a trend, 3b event) | 새 정보, 사건 (3a · 3b 구분 없이) |
| 읽기 | 문맥 토큰에서 물체의 위치 · 속도 · 정체를 꺼낼 수 있는가 | readability | encoder 충분성 |
| 지속 | 보이던 물체를 정체를 지키며 미래 걸음으로 이어 가는가 | continuation | 상태를 이어 감, state 유지 |
| 전이 | 문맥이 드러낸 추세 (3a) 와 장면이 촉발하는 사건 (3b) 대로 미래를 바꾸는가 | transition (trend / event) | 적분, 법칙 적용 |
| 영속 | 마지막 관측에서 가려진 물체가 미래에도 있는가 (존재) 와 어디에 있는가 (자리) | permanence (presence / placement) | 기억, memory |
| 무엇 · 어디 | 물체의 존재 · 정체 · 물체의 자리 · 속도 | what · where | appearance / motion 얽힘 |
| latent 자리 판정 | 정답 자리 칸 (물체가 있어야 할 미래 칸) 의 예측 토큰이 가능한 미래의 표적 토큰 쪽에 더 가까운가. 물체 자리 채점으로 잰다. 정본 문장: "정답 자리 칸의 예측 토큰이 물체 쪽이다 · 물체 쪽으로 가지 않는다" | latent placement (object-cell tokens) | 자리에 놓는다 · 안 놓는다, 화면에 놓는다, 그린다, 붙인다 |
| latent 판독 | latent 예측을 읽는 방법: 전체 토큰 L1 (surprise) · 물체 칸 토큰 L1 (물체 자리 채점) · 토큰 유사도 판독 (운반 이득) · 토큰 위 학습된 판독기. "옮겨 간다 · 정답 자리" 는 모두 물체 칸의 예측 토큰에 대한 말이다 | latent readout | |
| **운반** | predictor 가 물체의 토큰 내용을 실제 변위만큼 옮겨 미래 칸에 두는 것 (토큰 공간의 일이다) | carry | transport, 진행, progression |
| 운반 이득 | (예측 변위 · 실제 변위) / \|실제 변위\|² 의 중앙값. 1 = 실제만큼 옮김, 0 = 제자리 (복사와 같음). 예측 위치는 파라미터 없는 판독으로 읽는다: 마지막 관측 표적 토큰의 물체 3 × 3 칸을 본으로 삼아, 예측 블록에서 cosine 이 가장 큰 칸 주변의 가중 중심 (픽셀). 실제 위치는 렌더 라벨. 수치마다 세 가지를 같이 적는다: 어느 걸음인지 (rollout 첫 걸음 · 정답 입력 한 걸음), 어느 판인지, 정답 상한 | carry gain | gain, 진행량, 진행 비율, integration gain |
| 운반 신뢰도 (κ) | 점 손실의 최적 예측이 '실제 움직임으로 옮긴 토큰' 을 쓰는 비율. 옮긴 토큰이 다음 블록 정답을 잘 맞힐수록 커진다. 데이터의 성질이다. 운반 이득 (모델이 실제로 옮긴 비율) 과 다르다 | carry reliability (κ) | 운반 신뢰 계수, 옮김 몫 |
| 위약 차분 운반 몫 (κ_Δ) (라운드 2) | 실제 흐름 방향으로 옮긴 블록에 붙는 계수에서, 90° 돌린 방향으로 옮긴 블록에 붙는 계수를 뺀 값. 방향과 무관한 공간 상관을 빼고 남는 진짜 운반 몫이다. 데이터 판 (실제 다음 블록) 과 모델 판 (예측 블록) 을 같은 식으로 잰다 | placebo-differenced carry share | κ (위약 없이) |
| 먼 칸 (라운드 2) | 끝 가림 움직이는 물체에서, 마지막으로 보인 자리에서 1.5 칸 넘게 떨어진 미래 블록. 가까운 칸의 '제자리' 와 운반을 가른다 | far blocks | |
| 도달 거리 | 마지막 관측 자리에서 몇 칸까지 내용을 옮겨 놓는가 | reach | reach (한국어 본문), 거리 한계, 운반 거리 |

### 0-5. 판독과 진단

| 용어 | 정의 | 논문 용어 (영어) | 쓰지 않는 말 |
|---|---|---|---|
| 판독기 | 고정된 토큰 위에 학습한 작은 head. 토큰 → 물체 위치 (위치 판독기) 또는 정체 (정체 판독기). 쓰면 떼어 둔 test 정밀도 · encoder 대조 · 파라미터 없는 교차검증을 같이 낸다 | readout (position / identity) | 자, 위치 자, decoder, probe, ruler |
| 파라미터 없는 판독 | 학습 없이 토큰끼리 비교해 읽는 것 (예: 예측 토큰이 후보 미래 중 어디에 가까운가) | parameter-free readout | |
| 마지막 관측 바꿔치기 | 문맥의 마지막 블록만 픽셀로 바꾸고 (멈춤 · 역방향 · 2 배) 미래가 따라가는지 보는 실험. 대조 = 그 앞 블록만 바꿈 | last-observation swap | anchor 이식, transplant |
| 따름 지수 | 마지막 관측 바꿔치기에서 미래 위치가 조작을 따르는 정도. 0 = 원래 궤적 그대로, 1 = 조작한 마지막 관측의 운동을 등속으로 이은 궤적. 예측 걸음 k 마다 위치 판독기로 잰다 | follow index | anchor 따름 |
| 역사 값 | 문맥을 마지막 c 블록으로 잘랐을 때 잃는 '복사 대비 손실 감소분' 의 몫 = (L_c − L_8) / (L_복사 − L_8). L = 예측 토큰과 표적 토큰의 토큰 평균 L1. 0 = 잘린 블록이 아무것도 안 보탰다, 1 = 이득 전부가 잘린 블록에서 왔다 | history value | 과거 값, 문맥 자르기 손실 |
| 물체 자리 몫 | 물체만 다른 두 미래의 표적 토큰 차이 (토큰마다 \|Δ\| 평균) 가운데 물체 자리 r × r 칸에 있는 비율. 그 칸의 면적 비율과 나란히 적는다. 몫 ≈ 면적이면 차이가 칸 전체에 고르게 퍼진 것이다 (**표적 비국소성**) | object-region share (target non-locality) | 국소성, 물체 몫 |
| 정답 상한 | 같은 판독 · 같은 지표를 예측 토큰 대신 실제 미래의 표적 토큰에 건 값. 판독기 자체의 한계를 보인다 (운반 이득에 같이 적는다) | true-target ceiling | 측정 바닥 |
| 문맥 평균 해 | 예측 토큰 ≈ 같은 칸 문맥 블록 토큰들의 가중 평균. 균등 평균이 아니라 최근 블록 위주다 (가중치 합 ≈ 1). 정지 물체는 지키고 움직이는 물체는 옛 자리에 남기는 쪽으로 간다. 순수 평균은 아니어서 일부는 운반한다 | context-average solution | 블록 평균 해, 평균 붕괴, hedging, 헤지 |
| 표적 떨림 | 보이지 않는 픽셀 변화 (예: ±1/255) 에도 표적 encoder 의 블록 토큰이 크게 바뀌는 성질. 그래서 내용이 같아도 블록마다 블록 토큰이 새로 흔들린다. 블록 AR 에서는 이 떨림이 두 자리에 나타난다 (아래 둘) | target jitter | 표적 잡음, encoder 과민성, 목표 encoder 잡음 |
| 입력 쪽 떨림 | predictor 에 들어가는 문맥 블록 토큰의 표적 떨림. 여러 블록 평균 · 마지막 관측 수축이 이것을 줄인다. 이론상 예측을 평균 · 수축 쪽으로 당기는 것은 이쪽이다 [이론] | input-side jitter | |
| 정답 쪽 떨림 | 예측 손실의 정답인 미래 표적 토큰의 표적 떨림. 문맥과 독립이고 대칭이면 L1 의 최적 예측을 바꾸지 않고 손실 바닥만 올린다 [이론] | target-side jitter | 표적 쪽 떨림 ("표적 떨림" 과 헷갈린다) |
| 마지막 관측 수축 | 마지막 관측의 블록 토큰을 어떤 평균 쪽으로 일정 비율 당긴 예측. 학습 없는 기준으로도 쓰고, 학습된 predictor 의 예측을 같은 꼴로 읽을 때도 쓴다 (예측 ≈ a · 마지막 관측 + 상수, a 가 수축 계수). **어느 평균 쪽인지 꼭 적는다**: 문맥 평균 쪽 (역사가 들어간다) · 칸별 데이터셋 평균 · 같은 블록 이웃 평균 · 원점 쪽 (역사가 없다) | last-observation shrinkage | 수축 (무엇 쪽인지 없이), 마지막 블록 수축 |

### 0-6. 데이터와 학습

| 용어 | 정의 | 논문 용어 (영어) | 쓰지 않는 말 |
|---|---|---|---|
| 관측 학습 | 행동 없이 영상만으로, 미래 블록의 표적 토큰을 예측하는 손실로 predictor 를 학습하는 것 | observation-only training | action-free, 순수 관측 |
| 예측 손실 | 우리 predictor 의 학습 손실. 점 손실 꼴이다: 예측 토큰과 표적 토큰의 L1 을 칸 · 차원 평균한 것 | prediction loss | latent loss |
| **점 손실** | predictor 가 미래 블록의 칸마다 벡터 하나 (점) 를 내고, 실제로 일어난 미래의 표적 토큰 하나와 거리 (우리는 L1) 를 재는 손실. L = 칸 · 차원 평균 \|p − h\|. 미래가 불확실하면 최적의 점은 가능한 정답들의 요약값이 된다 (L1 이면 차원별 조건부 중앙값, L2 면 평균). 그래서 "반쯤 옮긴" 예측이 최적일 수 있다. 반대말: 분포를 내는 손실 (확률적 · 다중 미래) | point-estimate loss (token-wise L1) | pointwise L1 (정의 없이) |
| 물체 라벨 보조 손실 | 합성 영상의 물체 정체 · 위치 · 속도 라벨로, 예측 토큰 위 작은 head 에 거는 보조 손실 | auxiliary object-label loss | 상태 감독, state supervision, state head |
| 자연 영상 | 사람이 찍은 영상 (K710 · SSv2 · HowTo100M 등). 관측 학습의 주 데이터 | natural video | 실영상, real video |
| SSv2 자체 검증 1 % | SSv2 에서 자체로 떼어 둔 1 % (공식 val 아님). Ariel 판 학습 영상과는 겹치지 않는다. **기준 블록 AR 과 릴리즈는 SSv2 거의 전부로 학습해, 이들에게는 도메인 안이다**. 깨끗한 자연 영상 보류는 K710 | SSv2 held-out 1 % split | SSv2 val |
| 합성 testbed | 물리 조건을 통제해 만든 평가용 영상. 지금 판 = VOBench 와 중력 세트, 이전 판 = IntPhysGen v11 | controlled synthetic testbed | |
| VOBench | 가림 시점 × 운동 × 위반 (사라짐 · 모양 · 색) 을 통제한 합성 testbed. 물체 집합 둘 (primitive · realistic) 을 따로 보고한다 | VOBench | |
| 가림 시점 · **끝 가림** | 물체가 언제 가려지나: 앞 · 가운데 · 끝. 끝 가림 = 마지막 관측에서 물체가 가려져 있다 (위반이 가려진다) | early / mid / late occlusion | late, 문맥 끝 가림 |
| 중력 세트 | 같은 문맥에 후보 미래가 여럿인 VOBench 부분집합. **선반 낙하** (받침 끝에서 낙하 vs 같은 높이 직진) 와 **포물선** (후보 미래 9 갈래) | gravity set: ledge, arc | ledge · arc (한국어 본문) |
| 합성 학습 영상 | 학습에 섞는 물리 시뮬레이션 영상 (2D · 3D, 물체 라벨 있음) | synthetic physics clips | phys2d, phys3d |
| 외부 벤치마크 | IntPhys 1 · IntPhys 2 · GRASP · InfLevel. 공식 프로토콜 격자 전체로 잰다 | external benchmarks | |

### 0-7. 계획표 용어 (방법 후보 · 학습 없는 기준, 2026-10-21 진행자 2 제안)

| 용어 | 정의 | 논문 용어 (영어) | 쓰지 않는 말 |
|---|---|---|---|
| 잡음 평균 표적 | 같은 블록에 보이지 않는 픽셀 잡음 (예: 표준편차 2/255) 을 여러 번 더해 각각 표적 encoder 에 넣고, layer norm 뒤 평균한 표적 토큰. shape 은 블록 토큰과 같다. 시간 방향 평활이 아니다 | noise-averaged target | 평활 표적, smoothed target (시간 평활로 읽힌다) |
| 떨림 억제 부분공간 | 표적 떨림 방향은 작게, 영상 내용 차이 방향은 크게 남기는 고정 선형 사영. 이 사영으로 줄인 표적 토큰 공간 | jitter-robust subspace | 잡음 대비 신호 부분공간, 백색화 공간 |
| 운반 오라클 | 정답 궤적을 써서, 문맥에 보인 물체 토큰들의 평균을 미래 자리로 옮기고 나머지 칸은 물체 없는 문맥 블록 평균으로 채운 학습 없는 예측. predictor 가 아니라 "운반하면 손실이 얼마나 주나" 의 기준 | carry oracle | 운반 oracle |
| 경로 정렬 평균 | 칸마다 변위를 추정하고, 그 경로를 따라 과거 블록 토큰을 평균해 미래 토큰을 내는 predictor 출력 방식 | trajectory-aligned averaging | flow warp, 토큰 옮겨 붙이기 (이건 정답 위치로 직접 잘라 붙인 옛 실험) |
| 입력 가림막 | 학습 때 입력 영상에만 단색 직사각형 가림막을 임의의 문맥 블록부터 마지막 관측까지 그리고 인코딩하는 것. 정답은 가리지 않은 영상의 표적 토큰이다. 실제 가림막 토큰이라 평가 (VOBench 끝 가림) 와 같은 꼴이다. 역사를 쓰지 않으면 풀리지 않는 칸을 만든다 | input occluder | 입력 토큰 가림 (0 토큰 판, 구현만 남김), 입력 가림 (픽셀 가림막), 마스크 학습 |

## 1. 한 문장 기여 (v3.1 · 라운드 2 반영)

**가제 (영어, 자리 표시)**: Block-AR Predictors on a Frozen V-JEPA 2 Encoder Shrink the Last Observation Instead of Carrying What Is Hidden
- 범위 (리뷰 F4 · I1): 오라클을 통과한 채점으로 잰 것은 V-JEPA 2 ViT-H 표적 공간의 블록 AR 둘뿐이다. 다른 latent 계열은 물체 자리 채점으로 재기 전까지 제목 · 서론에서 일반화하지 않는다 (G20 · G21).
- 제목의 "shrink" 는 #58 (다른 팀 · 미커밋) 에 기댄다. 재현 전까지 자리 표시다.

**틀 (사용자 2026-10-22)**: 이 논문은 **latent 예측** 논문이다.
- 원인이 latent 표적 공간의 성질이라는 주장은 라운드 2 에서 약해졌다. 운반 보상 (κ_Δ) 은 픽셀 판에서만 사후 검사를 통과했고, 떨림은 V-JEPA 2 encoder 자체의 성질이다 (DINOv2 0.052 vs 두 장 블록 0.259 vs 한 장 복제 0.359. 두 장 블록 탓이 아니다). 칸 미만 비매끄러움은 ViT 공통 쪽이다 [측정, #81 · #84 · 근거표 §3-2b]. latent 는 이 논문의 틀이지 원인 주장이 아니다. "κ 는 latent 고유" 는 쓰지 않는다.
- 표적 공간을 고르는 손잡이는 JEPA 만의 것이 아니다. 맞는 구분은 자기지도 latent (V-JEPA 2) 와 재구성용 latent (Cosmos 토크나이저) 다 (리뷰 I1).

**꼴 (판 2 정정 · 공정한 시험 뒤)**: 진단 + 평가 규약 + 사전 등록 부정 결과 하나 (공정한 시험, 범위 좁게). κ 법칙 (리뷰 I8) 은 G19 결과로 철회하고, "데이터 보상의 약 4–13 % 만 옮긴다" (사후 발견 → 사전 등록 재현) 로 대체했다 (아래). 작은 예산의 파일럿은 기여가 아니라 "판정 아님" 의 기록이다.
- ⚠️ **철회 (라운드 2 F1)**: 판 2 의 "쉬운 처방 여섯이 이 예산에서 못 바꿨다 · 신호 없음 · 확대 학습은 하지 않는다". 파일럿은 기준 학습 표본의 0.23 % 짜리 짧은 시험이었다 (최대 lr 1/10, 1e-6 까지 감쇠, seed 하나). 연속 지표로는 가림막 팔이 옳은 쪽으로 움직였고, 학습 중 커졌다 [측정, #76]. 다시 쓰지 말 것. 판 2 원문은 백업 사본 (부록).
- 리뷰 F1 (method 결과 없음) 은 그대로 치명이다. 방향은 D8, 공정한 시험은 D9 다 (둘 다 사용자 결정 대기, §8).

**공통 진단 (기여 문장의 앞 절)**
> V-JEPA 2 표적 공간에서 관측만으로 학습한 블록 AR predictor 둘에서, 마지막 관측에 가려진 움직이는 물체의 정답 자리 칸 예측 토큰은 물체 쪽으로 가지 않는다. 마지막 관측에 없는 낙하도 예측 없는 기준선 이상으로 고르지 않는다 [측정, #67 · #68]. 학습된 predictor 는 역사를 쓰는 대신 마지막 관측을 수축하고, 예측 없는 문맥 평균에 가까운 해에 있다 [측정, 수축은 다른 팀 · 미커밋, #58 · #69].

**경계 (리뷰 F3)**
- 가려진 물체의 존재 실패와 '마지막 본 자리에 얼림' 은 **Xie & Alanwar 2026 의 결과**다. 우리 몫이 아니다.
- 그 논문은 이 원고를 바꿨다 (Figure 1 (b) 삭제 · 가림만 팔 · 기여 재구성). 그래서 동시 연구가 아니라 선행으로 인용 · 논의한다 (CVPR 2027 공고, 리뷰어 R1 확인). Frozen Flows Forget 도 같다.
- 우리 몫은 셋이다: 오라클로 검사한 물체 자리 채점 · 그 채점으로 처음 판정한 선반 낙하 · 블록 AR 에서 잰 같은 공간 기준선 셋.

**공정한 시험 문장 [측정, 사전 등록 (계획표 §6), 이어 학습 · 기준 step 5 % 한정, #85]**
> 기준 학습률 · 전역 배치로 기준 step 의 5 % 를 seed 둘로 이어 학습해도, 입력 가림막 과제는 가려진 움직이는 물체를 마지막 관측 근처에서만 조금 더 남기고 (전체 칸 자리 여유 +0.39 · +0.57 %), 먼 칸에서는 오히려 덜 남긴다 (−0.45 % [−0.78, −0.17] · −0.53 % [−0.80, −0.30]). 이진 차는 모두 ±1.4 점 안이다. 학습 곡선 (먼 칸, e2 → e8: −0.23 · −0.49 · −0.77 · −0.49 %) 도 0 위로 가지 않는다. 미리 정한 판정 기계의 출력은 '그 밖' 이다 (먼 칸 구간이 0 아래, 성공 조건과 반대 방향).
- 단서 (같은 무게):
  - 크기가 오라클 거리의 0.5 % 라 "해친다" 로 키우지 않는다.
  - 범위는 "입력 가림막 과제 + 같은 손실 · 같은 표적 공간 · 이어 학습" 이다. 표적 공간 손잡이는 공정한 예산에서 검정하지 않았다 (리더 04:20 좁힘).
  - 길이는 기준 step 의 5 % 로, R2 가 권한 10 % 에 못 미친다.
  - 기준 팔 자체도 학습률 재가열로 자리 여유가 −2.0 · −2.5 % 떨어졌다. 그래서 비교는 같은 조건 기준 팔과만 한다.
- 떨어지지 않은 칸: 자연 영상 L1 0.559 (기준 블록 AR 0.561) · IntPhys 1 끝 가림 움직임 75.0 (= 기준) · 거짓 운반은 기준과 같다. 보조로, 보이는 움직이는 물체의 운반 이득은 가림막 팔 0.31 · 0.29 > 기준 팔 0.24 · 0.24 다.
- 운반 몫 (#81): 공정한 시험 팔 넷 모두 4 fps 0.007–0.008 · 8 fps 0.018 이다 (데이터 0.134 · 0.189). 기준 블록 AR 과 차가 0.01 미만이다 → "학습률 · 예산을 키워도 옮기는 양은 그대로" [측정, 이 범위].

**파일럿 문장 (판정 아님, 공정한 시험 전 기록)**
> 학습 신호를 바꾼 독립 시험 넷 (무작위 · 움직이는 칸 입력 가림막, 운반 가중과 떨림 억제 사영을 함께 건 판, 짧은 문맥 run) 은 작은 예산 (팔당 2,000 step, 기준 학습 표본의 0.23 %, 최대 lr 1/10, seed 하나) 에서 이진 주 지표를 복사 수준 (50.6–52.6 vs 51.1) 에서 움직이지 못했다 [측정, #72 · #76]. 같은 팔들을 연속 지표 (자리 여유) 로 보면, 가림막 팔은 정답 자리 쪽으로 오라클 거리의 1.0–1.5 % 움직였고 (구간 0 위), 1,000 → 2,000 step 사이 커졌다 [측정, #76]. 그래서 이 결과는 "이 처방이 듣지 않는다" 의 근거가 아니다. 지금 배제하는 것은 "이 예산에서 오라클 거리의 약 3 % 이상 옮김" 뿐이다 [측정, 근사 · 리뷰어 계산, #76]. 그리고 그 작은 이동은 가까운 칸 몫이다. 먼 칸 (마지막으로 보인 자리에서 1.5 칸 넘게) 에서는 모든 모델이 복사 수준이고 (41 안팎, 오라클 94.3), 가림막 팔은 반대쪽으로 −2.1 % 움직였다 [측정, #82]. 단서: 연속 지표는 결과 뒤에 더한 지표이고, 미리 정한 판정은 이진이라 그대로다 (#76).

- 세는 법 (리뷰 I3):
  - 독립 시험은 넷이다. A2c 는 학습 중 AX 에서 거의 안 움직였다 (매개변수 거리가 AX − A0 의 6 %, #76). 사실상 같은 모델이다.
  - 판정된 것은 가림 과제 두 판 (AX · A4) 이다.
  - 운반 가중은 판정 못 한 성분이다. A1 · A1′ 은 사영과 늘 같이 들어갔고, 사영 공간에서도 정지 물체가 −8.3 [−18.1, +1.4] 떨어져 적응 비용이 섞인다 (#74).
  - 짧은 문맥 run 은 대조가 아니라 다른 처방 하나다.

**운반 몫: κ 법칙의 철회와 대체 측정 (라운드 2, G19 · 계획표 §11-1)**
- ⚠️ **철회**: "관측 학습 predictor 는 점 손실이 그 표적 공간에서 최적으로 만드는 만큼 옮긴다 (다른 팀: 모델 0.18 ≈ 데이터 0.21)". 우리 도구로는 재현되지 않는다.
  - 미리 정한 판 셋 (토큰 옮기기 · 렌더 · 2D 합성) 은 도구 검사를 못 넘었다. 복사를 정답 자리에 넣어도 옮긴 블록 계수가 0.11–0.74 로 나와, 회귀가 옮김과 복사를 못 가른다 (기준 ≤ 0.10) [측정, 근거표 §3-2b]. 그래서 판정 불가다.
  - 사후 위약 판에서 보면, 위약 전 계수 0.19–0.21 (다른 팀 0.18 과 비슷) 은 90° 돌린 방향에도 똑같이 나오는 공간 상관이었다 [측정, 사후, #81].
  - 다른 팀 κ (#70) 와 표적 공간 여섯의 κ 비 (#78) 도 같은 회귀 꼴이면 복사 몫이 섞였을 수 있다. 그래서 둘 다 "다른 팀 수치 · 우리 도구로는 재현 불가" 로만 쓴다.
- **대신 선 문장 [측정, 사후 발견 → 사전 등록 재현, #81]**
> 자연 영상 (4 fps, 픽셀을 흐름만큼 옮긴 뒤 인코딩하는 판) 에서 데이터가 보상하는 운반 몫 κ_Δ 는 0.152 [0.128, 0.177] 이다. 그런데 학습된 블록 AR 은 모두 0.005–0.011 만 옮긴다 (기준 블록 AR 0.007, Ariel 판 0.011, 파일럿 · 짧은 문맥 · 물체 라벨 보조 손실 판 모두 같다). 데이터 보상의 약 4–7 % 다. 12 fps 에서도 데이터 0.241 vs Ariel 판 0.032 다. **사전 등록 재현** (계획표 §11-1, 결과 전 규칙 고정, K400 val 다른 표본 300): 4 fps 데이터 0.134 [0.115, 0.153] vs 모델 0.007–0.010, 8 fps 데이터 0.189 vs 모델 최대 0.025. 모델 몫은 최대 7.5 % · 13 % 다.
- 읽기 [추측]:
  - 실패는 "점 손실의 최적이 반쯤 옮김이다" 만으로는 설명되지 않는다. 학습된 predictor 는 그 최적에도 한참 못 미친다.
  - 이것은 고리 ④ (역사 대신 마지막 관측 수축) · ⑤ 와 같은 방향이다.
  - 그래서 열린 질문이 바뀐다: "학습된 predictor 는 왜 데이터가 보상하는 만큼도 옮기지 않나". 이 질문의 답은 아직 없다.
- 단서 (같은 무게):
  - 처음은 사후 판이었다 (미리 정한 판은 판정 불가). 새 표본 · 다른 fps 의 사전 등록 재현으로 섰다. 그래도 자연 영상에는 오라클 같은 비자명 검사가 없다.
  - 흐름 추정 (Farneback) 오차는 데이터 κ_Δ 를 낮추는 쪽이다 (일관 칸만 보면 0.344). 그래서 4–13 % 는 넉넉한 쪽 추정이다.
  - "옮긴 몫이 학습 데이터의 κ 를 따라가나" 는 2D 합성 κ 가 판정 불가라 검정하지 못했다. 모델 몫은 학습 데이터 · 예산 · 창 설계와 무관하게 같다.
  - 데이터 κ_Δ 0.15 는 결정적 렌더 기대치 (0.35 기준) 보다 낮다. 그래서 "자연 영상의 불확실성 몫" 읽기는 남지만, "latent 고유" 주장은 약해진다 [사후].
- Cosmos 긴장 (리뷰 I2): 그 칸은 우리 규칙상 판정 불가라 근거도 반례도 아니다. 점 손실 원인 문장은 위 철회로 이미 약해졌다.

  - **낙하 · 되돌아옴은 예측 없는 기준선 이상으로 고르지 않는다.** 선반 30.6 은 우연 50 · 문맥 평균 41.0 아래이고, 포물선 11.1 은 우연이다 [측정]. 오라클은 둘 다 100 이라 도구 탓이 아니다.
  - 전체 토큰으로 보면 선반은 판정 불가 (오라클 11.8) 이고, 포물선은 꼭대기 48 · 66 만 판정된다. 거기서도 문맥 평균 복사를 넘지 못한다 (#23). 결론은 물체 자리 채점과 같다.
  - ⚠️ **한계 둘째 (#86, 사전 등록)**: 추적 기준선 (문맥 프레임만으로 추적 + 2 차 외삽) 은 끝 가림 판에서 76.1 (먼 칸 69.0) 로 학습된 블록 AR (51.4 · 41.3) 을 넘는다 (먼 칸 자리 여유 차 +41.5 % [+30.5, +53.9]) [측정]. 그러나 선반 판에서는 5.6 % [2.1, 9.7] 다 (라벨 위치를 줘도 0 %, 기준 블록 AR 30.6, 오라클 100) [측정]. 가려진 정지 물체에서도 63.9 (= 복사) 로 실패한다. 그래서 method 판정의 주 축은 추적 기준선이 못 푸는 판 (선반) 으로 옮긴다 (D10). ⚠️ 정정: 앞 판의 "선반 판은 추적 기준선이 0 %" 는 라벨 추적 판의 값이었다.
  - ⚠️ **한계 (리더 · 진행자 2, 계획표 §11-2)**: VOBench 끝 가림 판은 라벨 추적 판 하나로 풀린다. 라벨로 마지막에 다 보인 물체 3 × 3 토큰을 외삽 궤적 자리에 붙이면, 끝 가림 이동이 등속 외삽 86.7 · 2 차 맞춤 95.3 (= 오라클) 이다. 기준 블록 AR 은 51.4 다 [측정, 라벨 = 완벽한 지각 가정]. VOBench 의 움직임이 모두 등속 · 등가속이라서다. 그래서 이 판은 학습된 predictor 의 실패를 보이는 데는 유효하다. 그러나 method 의 이득을 말할 때는 이 기준선을 같이 내야 하고, 궤적이 결정적이지 않은 판 (자연 영상 · 무작위 힘) 이 필요하다.

### 2-3. 다시 학습해도 도메인 밖에서는 같다

- 미세조정은 도메인 안에서만 오른다 [측정, #24 · #41].
  - 같은 칸 IntPhys 1 은 창 32 칸에서만 −6.7 [−12.2, −1.7] 이고, 창 16 칸은 0 이다.
  - 미세조정 뒤 선반 72 / 72 는 전체 토큰 판정 불가 칸의 값이라 "낙하를 배웠다" 로 쓰지 않는다.
- 2D 합성 물리로 미세조정하면 도메인 밖 포물선은 1 / 36 으로 복사 (4 / 36) 아래다 [측정, #25].
- 기준 블록 AR 의 변형은 운반 · 사건을 고치지 못했다 [측정, 대부분 다른 branch 문서, #42 · #43].
- 같은 구조를 3D 합성만으로 학습하면 운반 이득이 0.23 → 0.62 로 오른다. 단 도메인 안이다 [측정, 다른 팀 · 미커밋, #40].
- 다른 latent 모델도 전체 토큰 점수로는 같은 쪽이다 [측정, #7 · #48]. 전체 토큰은 자리를 못 보는 도구라 물체 자리는 안 쟀다 (G20 · G21). 일반성 근거로 쓰지 않는다.
- Cosmos-Predict1-4B (재구성용 latent 를 예측하는 생성형) 는 **우리 판정 규칙상 근거가 아니다** (리뷰 F4 · R2).
  - 쓸 수 있는 것: 보이는 칸 91.7 [측정, #71].
  - 끝 가림 이동 52.9 · 선반 0 / 144 는 전체 토큰 꼴 점수다. 우리 공간에서 같은 칸의 전체 토큰 판정은 오라클을 못 넘고 (58.3 · 11.8, R2), Cosmos 공간에는 오라클이 없다. 그래서 "같은 쪽으로 실패" 로 쓰지 않는다.
  - 원인 문장과의 긴장은 §1 운반 몫 절에 적었다.

**하나로 묶는 읽기 (리뷰 I11, 근거표 고리 ⑧) [추측].** 라운드 2 에서 이 읽기를 감싸려던 κ 법칙은 철회했다 (§1). 이 읽기도 "점 손실 최적" 에 기대는 한 같은 단서를 받는다. ③ ④ ⑤ 는 "토큰 L1 이 보상하는 '번진 평균' 쪽 해" 하나로 읽을 수 있다. 짧은 걸음에서는 입력 쪽 떨림을 지우는 마지막 관측 수축에 마지막 관측의 속도 외삽이 더해진다. 먼 걸음에서는 움직이는 물체를 번지게 하는 평균이다. rollout 은 자기 예측을 되먹이므로 수축이 걸음마다 겹치고, 속도 코드가 줄어든다. '무엇' 이 전역 성분으로 이어지는 것은 이 한 줄로 설명되지 않으므로 따로 쓴다.

**기준 블록 AR 도 가까운 걸음에서는 마지막 관측에 묶인다 (#65).** 앞 블록만 조작하면 k1 에서 +0.05 / +0.06 칸 움직인다. 이 값은 '마지막 관측만' 예측 (0.00) 쪽이고, '가중 평균' 예측 (−0.09) 과는 부호가 반대다. 마지막 관측을 멈추게 하면 −1.30 칸 움직인다. 이 값은 정적 예측 (0.86 이하) 보다 커서, 모델이 마지막 관측의 움직임도 잇는다 [측정]. 그래서 묶는 읽기를 고친다: 짧은 걸음 = 마지막 관측 수축 + 마지막 관측 속도 외삽, 먼 걸음 = 번지는 평균 [추측].

## 5. 작은 예산의 파일럿: 시도한 학습 신호 변경 (판정 아님 · 라운드 2 정정)

**한 줄**: 파일럿 다섯 (AX · A1 · A1′ · A2c · A4) 과 사용자 짧은 문맥 run 은 작은 예산에서 이진 주 지표를 움직이지 못했다. 여섯 팔이 50.6–52.6 이고, 복사는 51.1, 오라클은 95.3 이다 [측정, #72 · #76]. 연속 지표 (자리 여유) 로는 가림막 팔이 옳은 쪽으로 오라클 거리의 1.0–1.5 % 움직였다 [측정, #76]. 그래서 판정이 아니다 (라운드 2 F1).

**예산 (#76)**: 팔당 2,000 step × 전역 배치 12 = 24,000 clip 이다. 기준 블록 AR 학습 (20,580 step × 512 ≈ 1,054 만 clip) 의 0.23 % 다. 최대 lr 은 5e-5 로 기준 5.2e-4 의 1/10 이고, 1e-6 까지 감쇠한다. seed 는 팔마다 하나다. 짧은 문맥 run 은 30 / 70 epoch 다. A0 는 같은 step 기준이다.

**왜 이 팔들이었나 (진단에서)**
- 가려진 움직이는 물체의 미래는 앞 블록에서만 온다. 그런데 학습된 predictor 는 역사 대신 마지막 관측을 수축한다 [측정, #58].
- 점 손실 (칸마다 점 하나를 내고 실제 미래 토큰 하나와 L1 을 재는 손실, 용어표 §0-6) 의 최적 예측은 실제 움직임으로 옮긴 증거를 운반 신뢰도 κ 만큼만 쓴다. κ 는 자연 영상 0.21 · 결정적 3D 합성 0.32 다. 기준 블록 AR 이 실제로 옮기는 계수 0.18 은 자연 영상 최적과 거의 같다 [측정, 다른 팀 · 미커밋, #70]. ⚠️ 정정 (라운드 2): 이 "최적과 거의 같다" 는 우리 도구로 재현되지 않았다. 위약 판 (사전 등록 재현) 에서 모델은 데이터 보상의 약 4–13 % 만 옮긴다 (§1, #81).
- 입력 쪽 떨림이 평균 · 수축을 보상한다 [측정, #66].
- 그래서 고친 곳은 셋이었다: 과제 (역사를 요구), 손실 (운반 가중), 표적 공간 (떨림 억제 사영).

**읽는 법**
- **AX (가림만) 의 이진 지표는 '있던 자리에 둔다' 쪽이다.** 주 지표는 그대로이고 가려진 정지 물체만 오른다. 결과는 Xie & Alanwar 의 '마지막으로 보인 자리에 얼림' 과 같은 꼴이다 [측정, #73]. 개입은 다르다 (그쪽 = predictor mask token, AX = 입력 영상 가림막).
  - 단서 1: 정지 칸은 문맥 평균이 이미 100 이다.
  - 단서 2: 이어 학습만으로도 정지 칸이 −4.2 떨어졌다.
- **A1 · A1′ 은 같은 꼴로 실패한다** [측정, #74].
  - 원래 공간 채점에서는 정지 물체 · 거짓 운반 · 자연 영상 L1 이 무너진다.
  - 이 붕괴는 두 팔의 공통 성분인 떨림 억제 사영의 공간 차이에서 온다. 사영 공간 채점에서는 사라지거나 (A1′) 준다 (A1).
  - 주 지표 무변화는 사영 공간에서도 같다 (51.9 · 50.8).
  - 그래서 "정답 의존 가중의 편향" 으로 설명할 필요가 없다. 떨림 억제는 이 예산에서 method 성분으로 쓰지 않는다.
- **짧은 문맥 run 도 같은 칸에서 같다** [측정, #75].
  - 기준 블록 AR 과 시간 척도 (4 fps · 0.5 초) 는 같다. 다른 것은 창 · 되먹임 · 손실 · 데이터 · 학습량 다섯이다.
  - 문맥 2 블록 입력이면 보이는 운반은 좋아지지만 (82.5), 정지 물체 79.2 · 포물선 0 / 72 로 떨어진다.
- **A2c · A4 도 같다** [측정, 2,000 step 이어 학습 한정, #76].
  - A2c (원래 공간 문맥 판 가중) 는 AX 와 주 지표 · 보조 칸이 거의 같다. 단서: A2c 는 AX 와 매개변수 거리가 0.25 다 (AX − A0 거리의 6 %). 문맥 판 가중이 이 세기에서 학습을 거의 움직이지 않았다는 뜻이다. 그래서 "가중은 효과가 없다" 로 쓰지 않는다.
  - A4 는 AX 와 매개변수 거리가 2.3 인데도 출력은 거의 같다.
  - A4 는 미리 적은 가설 [추측: 무작위 가림막이 정지 배경을 덮어 '얼림' 만 배운다] 을 보려던 팔이다. 움직이는 칸을 덮어도 이진 주 지표는 −0.6 [−1.9, +0.6] 이다. 그러나 연속 지표는 +0.99 % 로 0 위다 (R2). 작은 예산이라 가설 기각이 아니다 (라운드 2 정정).
  - 가림막을 쓴 세 팔 (AX · A2c · A4) 은 모두 가려진 정지 물체만 올린다 (+9.7 · +11.1 · +9.7).
  - 주 지표의 위반별 영속 칸은 모든 팔이 방향 A 0 · B 100 으로 갈린다. 모든 팔이 한쪽 미래를 늘 고른다 [측정, #72].
  - 도메인 밖 확인 셋 (IntPhys 1 끝 가림 판 · 포물선 꼭대기 48 고른 미래 · 선반 물체 자리) 은 A0 · AX · A2c · A4 가 같다 (87.2–87.8 · 20.8 · 29.9). 거짓 운반 · 자연 영상 L1 · 자연 영상 운반 이득도 같다.
  - ⚠️ 정정 (라운드 2): 이진 지표의 AX − A0 e5 → e10 변화는 −0.6 [−2.2, +0.8] 이다 [측정, #72]. 그러나 연속 지표 (자리 여유) 의 AX − A0 는 1,000 step +1.23 % → 2,000 step +1.45 % 로, 그 증가 +0.22 % [+0.12, +0.32] 가 0 위다 [측정, #76]. 미리 정한 '짧다' 기준 (이진 지표 4 점 증가) 은 이 lr 감쇠 아래서 거의 통과할 수 없었다. 그래서 "늘어나는 추세가 없어 확대 학습은 하지 않는다" 는 **철회**한다. 확대 여부는 D9.
- **연속 지표 (자리 여유, 오라클 거리 몫, A0 대비)** [측정, #76]: AX +1.45 % [+1.01, +1.91] · A2c +1.50 % · A4 +0.99 % [+0.67, +1.34] · A1 −3.56 % · A1′ −3.40 %. 이진 지표의 불일치 쌍은 가림막 세 팔이 A0 와 8 / 360 뿐이다. 구간이 좁은 것은 효과가 없어서라기보다 모델이 거의 안 바뀌어서다. 단서 (같은 무게): 연속 지표는 결과 뒤에 더한 것이고, 미리 정한 판정 (규칙 (c)) 은 이진이라 그대로다. 크기는 오라클이 내는 차의 1–2 % 다 (#76).
- **먼 칸 자리 여유 (마지막으로 보인 자리에서 1.5 칸 넘게, 300 쌍)** [측정, #82]: 오라클 94.3 · 복사 39.7 · 문맥 평균 40.3 · 기준 블록 AR 41.3 · A0 40.7 · AX 41.3 · Ariel 판 41.0. 자리 여유 (A0 대비): AX −2.09 % [−2.81, −1.43] · A2c −2.08 · A4 −2.09. 가림막 팔의 전체 칸 +1.0–1.5 % 는 가까운 칸 몫이다. A1 은 +11.44 % 이지만 원래 공간 채점이 흐린 팔이라 읽지 않는다 (#74). 단서: 결과 전에 정한 지표 (계획표 §6) 이나, 파일럿에는 결과를 본 뒤 건 점검이다.
- 세는 법: 독립 시험 넷 (AX · A4 · A1 / A1′ · 짧은 문맥 run). A2c 는 AX 와 사실상 같은 모델이다 (§1).
- 쓰지 않는 말: "어떤 학습 신호로도 안 된다" · "신호 없음". 시도한 팔 · 예산 크기를 같은 문장에 적는다.
