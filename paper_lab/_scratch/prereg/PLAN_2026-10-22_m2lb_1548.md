| 운반 · 운반 이득 | 물체 내용을 실제 변위만큼 옮겨 미래 자리에 두는 것 · (예측 변위 · 실제 변위) / \|실제 변위\|² |

| 운반 오라클 | 학습 없는 기준. 정답 궤적 자리에 문맥에서 보인 물체 3 × 3 칸 토큰들의 평균을 놓고, 나머지 칸은 물체가 없던 문맥 블록의 평균 |

| **입력 가림막** | 학습 때 입력 영상에만 단색 직사각형을 임의의 블록부터 창 끝까지 그리고 인코딩한다 (문맥 안에서 시작하면 마지막 관측까지 이어진다). 정답은 가리지 않은 영상의 표적 토큰. Xie & Alanwar 2026 의 '시간 일부 마스크' 를 mask token 이 없는 블록 AR 에 맞춘 것 (0 토큰 판은 구현만 남겼다) |

| **점 손실** | predictor 가 미래 블록의 칸마다 벡터 하나 (점) 를 내고, 실제로 일어난 미래의 표적 토큰 하나와 L1 거리를 재는 손실 (칸 · 차원 평균 \|p − h\|). 미래가 불확실하면 최적의 점은 가능한 정답들의 요약값 (L1 이면 차원별 조건부 중앙값) 이라 '반쯤 옮긴' 예측이 최적일 수 있다. 반대말 = 분포를 내는 손실 (확률적 · 다중 미래) |
| **운반 신뢰도 κ** | 점 손실 (L1) 의 최적 예측이 '실제 움직임으로 옮긴 토큰' 을 쓰는 비율. 옮긴 토큰이 다음 블록 정답과 잘 맞을수록 크다. 다른 팀 측정 [측정, 미커밋]: 자연 영상 0.21 · 결정적 3D 합성 0.32, 기준 블록 AR 이 실제로 옮기는 계수 0.18 ≈ 자연 영상 데이터 최적 |
| 물체 자리 채점 · 세 세계 판독 | 물체가 있어야 할 칸만으로 낸 점수 · 후보 미래 셋 (계속 움직임 · 마지막 본 자리에 멈춤 · 사라짐) 중 어디에 가까운가 |

## 2. 측정이 method 에 요구하는 것

### 2-1. E1 · E2 (학습 없음, 끝남 — 상세 결과 메모)

**왜.** v1 의 M1 은 "표적에서 떨림을 빼면 손실이 평균보다 운반을 더 보상한다" 에 기댔다. 이것을 학습 전에 데이터로 쟀다 (기각선은 결과 전에 적었다).

**어떻게.** 학습 없는 예측 (복사 · 문맥 평균 복사 · 역사 없는 수축 · 운반 오라클) 의 L1 과 쌍 정확도를 표적 공간 다섯에서 쟀다. 판 = 자연 영상 (SSv2 200) · VOBench 720 묶음.

**결과 [측정].**

|---|---:|---:|
| 문맥 평균 보상 (원래) | 16.8 % | 13.3 % |

| 끝 가림 움직이는 물체 쌍 (전체 토큰) | 복사 | 문맥 평균 복사 | 운반 오라클 |

**해석.**
- **M1 (표적만) 기각** (미리 적은 기각선 25 % 아래). 32 비트 계산도 무효과.
- 짧은 걸음의 평균 보상은 떨림이다 (걸음 1 에서 잡음 평균이 4.8 → −0.4 %). 긴 걸음 몫은 결정적 VOBench 에서도 걸음에 따라 늘어 '물체를 번지게 하는 해' 의 몫이다 [추측].

- **운반 보상은 이동 거리와 무관하게 3.4–3.7 %** 다 (칸 미만 이동 탓 아님). 물체 칸에서만 보면 35 %. 전체 토큰 손실에서 물체 칸 몫이 작아서다.

### 2-2. 진단 (근거표 v2 · STORY v2) 과 합친 요구

- 기준 블록 AR 은 **보이는 물체는 옮긴다** (물체 자리 채점 92.5 vs 복사 68.3, 오라클 99.2) — 이것은 '떨어지지 않음' 으로 지킨다.
- **가려진 움직이는 물체는 자리에 놓지 않는다** (51.4 = 복사, 오라클 95.3). 가려진 정지 물체는 놓는다 (93.1). 기제 = 역사 대신 마지막 관측 수축 [측정, 다른 팀 + E1].
- 그래서 method 가 해야 할 것 (do):
  1. **역사를 쓰게 한다** — 가려진 움직이는 물체의 미래는 앞 블록에서만 온다.
  2. **운반을 보상한다** — 전체 토큰 손실에서 물체를 옮기는 몫이 3.5 % 라 수축 · 평균 해가 이긴다.
  3. 보이는 운반 · 정지 물체 · 자연 영상 손실 · 외부 벤치마크를 떨어뜨리지 않는다.
- 하면 안 되는 것 (don't, 이미 실패):
  - 같은 표적 · 같은 손실로 데이터만 바꾸기 (Ariel 판 · 미세조정 · 3D 합성 전용 학습 — 도메인 밖으로 안 옮겨 감).
  - 마지막 관측 복사 섞기 (gating) · 시간 변화량 항 · 물체 라벨 보조 손실 · 2D 합성 미세조정 (끝 가림 영속을 깎음).
  - Xie & Alanwar 처방 그대로 (가림 마스크만) — 존재는 남지만 "마지막 자리에 얼림" 이 보고됐다. **그래서 기준 팔이다.**

## 3. method — "역사를 요구하는 과제 + 운반을 보상하는 손실"

### 3-0. 이 method 의 자리 — latent 예측의 설계 선택 (사용자 지시 10-22)

- 이 논문은 **latent space 예측**이다. predictor 의 입력 · 출력 · 학습 정답 · 채점은 모두 고정 표적 encoder 의 블록 토큰 (latent) 공간에서 이뤄진다. 픽셀을 복원하지 않는다.
- 세 성분은 모두 **latent 표적 공간에서의 점 손실을 바꾸는 설계 선택**이다:
  - 입력 가림막: 가림막은 입력 영상에 그리지만, 그 결과는 predictor 가 받는 **입력 latent** 에만 들어가고 정답 latent 는 그대로다 — "입력 latent 가 가려져도 정답 latent 를 맞혀라" 는 과제 설계.
  - 운반 가중 예측 손실: latent 칸마다 점 손실의 무게를 바꾼다 (문맥 판 = 입력 latent 의 변화로 정한다).
  - 떨림 억제 입력 · 정답: latent 공간 자체를 고정 선형 사영으로 고른다.
  - ⚠️ 정정 (라운드 2 R1 · I1) — 앞 판의 "표적 공간을 고르는 손잡이는 JEPA 계열 latent 예측만 가진다, 픽셀 예측은 정답 공간이 픽셀로 고정" 은 **틀렸다. 철회.** Cosmos 같은 생성형도 토크나이저 latent 토큰을 예측한다. 맞는 구분은 **재구성용 latent** (토크나이저 — 픽셀로 되돌리게 학습) vs **자기지도 비재구성 latent** (V-JEPA 2 · DINOv2) 다. 우리 측정 (떨림 · κ · 수축) 은 자기지도 latent 하나 (V-JEPA 2 표적 encoder) 에서만 했다. 재구성 latent 에서는 재지 않았다 → "latent 예측 고유" 라고 쓰지 않는다.
- 판정 지표도 전부 **latent 판독**이다: 물체 자리 채점 = 물체 칸의 표적 토큰 L1 로 낸 가능 · 불가능 쌍 정확도, 운반 이득 = 예측 토큰에서 파라미터 없이 읽은 변위, 자연 영상 = 표적 토큰 rollout L1. 픽셀 지표는 쓰지 않는다.

### 3-1. 무엇을 바꾸나 (방법 절 첫 줄 후보)

> 지금까지의 관측 학습 predictor 는 모두 같은 떨리는 블록 표적에, 모든 칸을 같은 무게로 보는 L1 을 걸었고, 학습 영상에서 역사가 필요한 경우가 드물었다. 우리는 구조 · 데이터는 그대로 두고 (1) 입력에만 마지막 관측까지 이어지는 가림막을 그려 역사를 쓰지 않으면 풀리지 않는 칸을 만들고, (2) 그 칸의 손실이 정지 칸에 묻히지 않게 운반 가중 예측 손실을 건다.

| 성분 | 겨누는 고리 (근거표 ①–⑦) | 측정 근거 |
|---|---|---|
| 입력 가림막 (마지막 관측까지) | ④ 학습 분포가 역사를 요구하지 않는다 · ⑤ 마지막 관측 수축 | 자연 영상 역사 값 1–3 % (Ariel 판 · 기준 블록 AR 모두) · 학습 없는 수축이 평균 보상의 75 % |
| 운반 가중 예측 손실 | ③ 학습 신호가 운반을 거의 보상하지 않는다 | 운반 보상 3.5 % (전체 토큰) vs 35 % (물체 칸) · 표적 비국소성 4.3 % ≈ 면적 |
| 떨림 억제 64 입력 · 정답 (E1b 로 확정) | ② **입력 쪽** 떨림 → 평균 · 수축 보상 | E1b: 입력만 씻으면 문맥 평균 보상 VOBench −60 % · 자연 영상 −45 %, 수축 보상 소멸. 정답만 씻으면 오히려 커짐. E1: 떨림 억제 64 에서 수축 보상 소멸 · 운반 보상 1.9 배 (같은 차원 주성분 대조는 무효과) |

- **관측만**이다 (행동 · 라벨 없음, 자연 영상만).
- **블록 AR 구조 · 입출력 · rollout 은 그대로**다 (planning · AC 후속 학습에 그대로 붙는다). 가림 · 가중은 학습에만 있다. 떨림 억제를 넣으면 관측을 인코딩할 때 고정 선형 사영 하나가 붙는다 (rollout 비용 0, planning 에너지도 같은 공간에서 잰다).
- 구현: `paper_lab/method/` (기존 학습 코드를 고치지 않고 손실 · 인코딩 함수만 바꿔 끼운다, CPU 검사 여섯 통과) — 부록.

### 3-3. 실패 시나리오 (미리 적음)

1. **가림이 존재만 올리고 자리는 그대로** (Xie & Alanwar 의 얼림). 그러면 우리 팔 − 가림만 팔의 차이가 운반 가중의 몫이다 → 0 이면 운반 가중도 실패.
2. **운반 가중이 떨림을 키운다.** 정답이 앞 블록 평균과 다른 칸에는 떨림 큰 칸도 들어간다 (자연 영상은 정지 칸도 블록마다 흔들린다). → 가중 지도와 물체 칸의 겹침을 VOBench 에서 잰다. 떨림 억제 입력 · 정답이 이 위험을 줄인다 (E1b 가 지지하면 넣는다).
3. **가중 자체의 효과일 뿐 '운반 칸을 고른' 효과가 아니다.** → 우리 팔이 가림만 팔을 넘으면, 같은 가중 분포를 칸 사이에서 무작위로 섞은 대조 팔 (무작위 가중) 을 넷째 팔로 돌린다. 무작위 가중이 같은 만큼 올리면 "운반 칸을 고른 효과" 라고 쓰지 않는다.
4. **짧은 이어 학습 (2,000 step) 으로는 기준 해에서 못 벗어난다.** → 같은 step · 같은 데이터로 팔끼리만 비교하고, 셋 다 차이가 없으면 "이 예산에서는 차이 없음" 으로 적는다 (학습량을 팔 하나만 늘리지 않는다). 학습 곡선 (500 · 1,000 · 2,000 step) 을 같이 낸다.
5. **보이는 운반 · 자연 영상 손실이 떨어진다.** → '떨어지지 않음' 칸으로 잡는다.
8. **떨림 억제 입력은 출발점에서 분포가 바뀐다.** 기준 블록 AR 은 원래 블록 토큰으로 학습됐다. A1 은 첫 step 부터 사영된 입력 · 정답을 받는다 — 학습 전 검증 (IntPhys 1 60 쪽, 학습 공간) 이 81.7 → 73.3 % 로 낮게 시작했다 [측정]. 2,000 step 안에 이 적응 비용이 A1 을 깎을 수 있다. → A1 < AX 이면 '운반 가중 · 떨림 억제가 나쁘다' 로 바로 쓰지 않고, **떨림 억제 없이 가림막 + 운반 가중만 쓴 A2** (원래 공간, 적응 비용 없음) 를 넷째 팔로 돌려 가른다 (GPU 1 이 AX 뒤 비면 하루 안).
10. **정답 의존 가중의 편향 (다른 팀 열 번째 회신).** A1 의 가중은 정답에 의존해 L1 최적을 분위수 1/(1+λ) 로 옮긴다 [이론] — '늘 바뀐다고 찍는' 해가 이길 수 있다. → 편향 대조 B1–B4 (§4) 와 문맥 판 가중 A1′ 을 넣었다. 문맥 판이 기본 성분이 된다.
9. **운반 가중이 데이터 최적보다 더 옮기게 만든다 (다른 팀 아홉 번째 회신).** 기준 블록 AR 이 '반만 옮기는' 것은 여러 미래 섞기가 아니라 한 갈래 안의 **신뢰도 수축**이다: 자연 영상에서는 실제 움직임으로 옮긴 토큰이 다음 블록 정답과 덜 맞아서, 점 손실의 최적은 옮긴 증거를 κ (자연 0.21) 만큼만 쓰고, 기준 모델 (0.18) 은 그 최적에 있다 [측정, 다른 팀 · 미커밋]. 운반 가중 손실은 이 κ 보다 더 옮기게 만드는 장치라, **운반 이득 · 자리는 오르지만 자연 영상 예측 (L1) 은 나빠질 수 있다.** → 판정의 필요조건으로 "자연 영상 (K400 val) rollout L1 이 A0 보다 나빠지지 않음" 을 넣었다 (§4 갈림 규칙). 나빠지면 그 결과는 "자리를 얻는 대신 점 손실을 잃는 맞바꿈" 으로 쓰고, 원리적 대안 (κ 가 높은 표적 공간, §6) 으로 간다.
7. **가림 형식이 평가와 다르다 (작성자 반박).** 블록 AR 에는 mask token 이 없어서 입력 토큰을 0 으로 가리면 분포 밖 입력이 되고, predictor 가 '0 토큰' 이라는 신호에만 반응할 수 있다. 평가의 끝 가림은 **보이는 가림막** 이다. → 파일럿의 가림은 **입력 가림막** (입력 영상에만 단색 직사각형을 임의 블록부터 창 끝까지 그린 뒤 인코딩, 정답은 가리지 않은 영상) 으로 바꿨다. 0 토큰 판은 구현만 남긴다. 또 평가 판정 자체가 실제 가림막 (VOBench) 위에서 이뤄지므로, A1 > A0 가 나오면 이 위험은 걸러진다.
6. **블록 AR rollout 과 어긋남.** 학습 때 입력은 가리거나 떨림을 빼지만, rollout 의 되먹임은 predictor 자기 은닉이라 (출력 토큰이 아님) 떨림 억제는 문맥 관측에만 걸린다. 평가 때도 같은 변환을 문맥에 건다 (하네스가 run 폴더의 설정을 읽는다).

### 3-4. 블록 AR · planning 과 이어지나

- 구조 · 입출력이 기준 블록 AR 과 같아서 V-JEPA 2-AC 식 행동 토큰을 그대로 붙일 수 있다.
- planning 에너지 (rollout 끝 토큰 vs 목표 이미지 토큰의 L1) 도 떨림을 받는다. 떨림 억제를 넣으면 에너지를 그 공간에서 잰다 — 학습 없이 성공률 비교가 가능하다 (§7, 데이터 · 체크포인트 확보가 전제).

## 7. planning 다리 (I2)

- 이 머신 (vll5) 에는 Push-T · Wall 데이터 (DINO-WM 공개본) 와 Push-T 학습 체크포인트가 없다 [측정: 찾아봄]. Ariel 쪽 하네스 (고정 ViT-H + 블록 AR + 행동 토큰, GT 재생 1.00 · 무작위 0.00) 는 다른 서버에서 검증됐다.
- 안: (1) 그 서버의 Push-T 체크포인트 두 개 (관측 학습 뒤 행동 학습 · 처음부터) 를 받아 **학습 없이** planning 에너지를 원래 공간 vs 떨림 억제 공간으로 바꿔 성공률을 비교 (50 목표, McNemar) — 사용자 · 리더에게 체크포인트 위치 확인 요청. (2) 우리 method 가 파일럿에서 서면, 그 위 AC 후속 학습을 Push-T 데이터 10 / 30 / 100 % 로 (DINO-world Table 4 재현 + 데이터 비율 축, 그쪽이 안 잰 축).
- DINO-world 와의 차별: 그쪽은 '관측 학습 → 행동 학습' 의 이득만 보였다. 우리는 관측 학습 단계의 설계 (과제 · 손실) 가 AC 이득을 바꾸는지를 데이터가 적을 때 본다. 우리 Push-T 0.60 = 0.60 (데이터 충분 · lr 혼입) 과의 차이도 이 축에서 설명된다 [추측].

### 7-1. 학습 없는 planning 에너지 다리 (I7, R5 라운드 2) — 설계만, 아직 안 돌림

**질문.** planning 은 "예측한 latent 와 목표 latent 의 L1" (같은 표적 공간 · 같은 꼴) 을 에너지로 쓴다. 예측이 마지막 관측 쪽으로 수축하면, 그 에너지에서 실제 미래 · 수축 · 문맥 평균 중 무엇이 목표에 가까운가. 그리고 수축한 예측은 실제 미래가 내는 에너지 하강의 몇 % 를 내는가.
**설계 (CPU, 기존 하네스 산출물 — 칸별 오차 지도가 이미 저장돼 있다).**
- 목표 g = 실제 블록 t + k (k = 1 … 8). 후보 상태의 에너지 E(x) = mean |x − g| — 실제 미래 (0) · 복사 (마지막 관측) · 문맥 평균 · 모델 rollout · 정답 자리 오라클.
- **실현 몫 R_k = 1 − E(모델) / E(복사)** — 복사 (움직이지 않는 계획) 에 비해 모델 예측이 실제 미래의 에너지 하강 중 몇 % 를 내나. 오라클의 R_k 를 상한으로 같이 낸다.
- 칸 두 판: 전체 토큰 (planning 이 실제로 쓰는 꼴) · 물체 칸 (자리).
- 판: VOBench 보이는 이동 · 끝 가림 이동 · 보이는 정지 (대조), K400 val (자연), 중력 포물선.
- 모델: 기준 블록 AR · Ariel 판 · 파일럿 팔 · (평가가 끝나면) 상태 감독 넷.

**읽기 (결과 전에 적음).**

| 결과 | 읽기 |
|---|---|
| 전체 토큰 R_k 가 움직이는 물체 판에서도 정지 판과 비슷 (차 < 10 점) | 전체 토큰 에너지는 물체 자리를 거의 못 본다 (배경이 지배) → planning 성공률은 자리 실패를 드러내지 못한다. planning use case 문장은 "물체 칸 에너지를 쓰는 planning" 으로만 쓴다 |
| 물체 칸 R_k 가 움직이는 물체 판에서 30 % 미만 · 정지 판에서 70 % 이상 | 물체 칸 에너지가 움직이는 목표에서 평탄해진다 → 그런 planning 에서는 같은 실패가 성공률로 보일 것이라고 **예측** (검정은 AC 실험이 있을 때) |
| 물체 칸 R_k 가 움직이는 물체 판에서도 70 % 이상 | 수축이 에너지 순위를 망가뜨리지 않는다 → planning 다리 문장을 내린다 |

- 단서: 행동 조건 예측이 아니다 (관측 rollout). planning 성공률이 아니라 에너지 꼴의 다리다. Push-T 등 행동 데이터 · 체크포인트는 이 노드에 없다 (위).
- 비용: CPU 반 시간 (모델당 수 초). 진행자 1 하네스의 오차 지도를 읽기만 한다.

  - 그 밖 = '이 판으로는 안 갈린다' — 축별 결과만 보고한다. 판정 무게는 진단의 두 원인 (떨림 · κ) 이 주, 블록 안 움직임이 부.
- 단서 (같은 무게): DINOv2 ViT-B (약 86 M) vs V-JEPA 2 ViT-H (약 632 M) — image vs video 의 순수 비교가 아니다 (이 노드에 DINOv2 큰 판 가중치 없음, 새 다운로드는 리더에게). 해상도 (224 vs 256) · 패치 (14 vs 16 px) · 차원이 달라 비 (자기 공간 안의 상대량) 로만 맞댄다. 이 실험은 **표적 공간의 성질**만 잰다 — "image encoder 위에서 predictor 를 학습하면 낫다" 는 predictor 학습 (또는 DINO-world 체크포인트 평가) 없이는 주장하지 않는다.
- 비용: 진행자 1 의 κ 패스 안 (GPU 약 1–2 시간 추가 [추측]). 내 GPU 는 따로 잡지 않는다.

| 단서 | Farneback 흐름 오차는 데이터 κ_Δ 를 낮추는 쪽이다 (일관 칸 0.34 > 전체 0.15). 비자명 검사 (자리를 아는 오라클) 는 자연 영상에 없다. 렌더 판은 위약도 물체를 같이 덮어 판정 불가였다 |

### 11-2. M2 — 옮기는 연산을 predictor 구조에 (1 순위 후보로 재설계)

**왜 지금 M2 인가.** 손잡이 셋 (과제 = 가림막 · 손실 = 운반 가중 · 표적 공간 = 떨림 억제) 이 이 예산에서 자리를 못 열었고, 상태 감독도 못 열었다 (§4 · §9-1). #81 이 맞다면 원인은 '손실 최적이라 덜 옮김' 이 아니라 'predictor 가 옮기는 해를 찾거나 표현하지 못함' 이다 [추측]. 그러면 옮기는 연산을 구조로 주는 것이 다음 수다.
**측정이 구조에 주는 제약 (G19 · G21) [측정, 사후].** V-JEPA 2 블록 공간에서 **토큰 격자를 옮기는 것 (칸 단위 · bilinear) 은 내용을 옮기는 것의 좋은 대리가 아니다**: 픽셀을 옮긴 뒤 인코딩한 블록을 토큰 옮기기가 위약보다 조금밖에 더 설명하지 못한다 (κ_Δ 0.09–0.19), 반 칸 이동 비매끄러움 0.72. 그래서 두 꼴을 나란히 둔다.

| 꼴 | 무엇 | 장점 | 약점 |
|---|---|---|---|
| **M2-t 토큰 주소** | predictor 가 칸마다 변위 (또는 변위 장) 를 내고, 문맥 블록 (마지막으로 물체가 보인 블록 포함) 의 토큰을 변위만큼 떨어진 주소에서 읽어 출력 바탕으로 쓴다 (deformable 주소 · 경로 정렬). 잔차는 predictor 가 | 가려진 물체도 '마지막으로 보인 블록' 에서 읽어 올 수 있다 (안 보이는 것). 비용 0 에 가깝다 | 토큰 옮기기가 내용 옮기기와 다르다 (위 측정) → 출력 공간에서 어긋남 |
| **M2-p 픽셀 제안** | 문맥 프레임에서 흐름을 외삽해 마지막 프레임을 픽셀 공간에서 옮기고, 표적 encoder 로 인코딩한 '제안 블록' 을 predictor 입력에 덧붙인다. predictor 는 제안을 고친다 | 표적 공간의 비국소성을 encoder 가 대신 처리한다 (위 측정의 (b) 연산 그대로) | 가려진 물체는 마지막 프레임에 없으니 못 옮긴다 (보이는 것 · 사건만). 블록마다 encoder 한 번 더 |

**선행과 차별 (§8 #6 갱신).** DF³ (2608.02428, 흐름 warp 로 과거 특징 정렬) · F2MF (분할 특징 이동 + 잔차) · LDR (2608.09926, 낮은 차수 운동학 적분 + 잔차) · Flow-JEPA (2608.29029) 는 모두 **특징 공간에서 옮긴다** (M2-t 꼴). 우리 차별 후보 셋: (1) 고정 V-JEPA 2 표적 공간에서는 특징 격자 옮기기가 내용 옮기기의 대리가 못 된다는 측정 (G19 · G21) 과 그에 맞춘 픽셀 제안 (M2-p), (2) 관측만 · 자연 영상 블록 AR, (3) 끝 가림 자리 · 3a 를 도메인 밖에서 판정. (1) 은 아직 사후 측정이라 §11-1 이 서야 기여로 쓴다.

**가장 싼 결정적 시험 — 학습 없는 하한 (지금 CPU, 결과 전에 고정 15:48).**
- 하한 A (M2-t, 완벽한 지각 가정): 이미 계산된 렌더 (2026-10-13, `design_headroom.py`) — 마지막으로 완전히 보인 물체 3 × 3 토큰을, 지운 캔버스 위 **외삽 궤적** 자리에 붙인다: move_cv (마지막 두 '보인' 샘플 등속) · move_ca (2 차 맞춤) · move_or (참 궤적 = 하네스 오라클과 같은 꼴). 문맥의 **라벨 위치** 를 쓴다 → 관측만 판이 아니다. 이 하한이 지면 관측만 판도 진다 (지각이 더 나빠질 뿐이다).
- 채점: 하네스와 같은 표적 · R2 자리 여유 · 먼 칸 자리 여유 (§6 정의), 끝 가림 움직이는 물체 360 쌍. 기준 = 기준 블록 AR (vast70).
- **판정 (결과 전)**:

  | 결과 (move_cv 또는 move_ca − 기준 블록 AR) | 읽기 | 다음 수 |
  |---|---|---|
  | 먼 칸 자리 여유 ≥ +10 % 오라클 거리 · 구간 0 위 **그리고** 이진 쌍 정확도 +5 점 이상 | "궤적만 알면 붙이기만으로 가려진 움직이는 물체의 자리가 열린다" — 구조 (M2-t) 에 여지가 있고, 남는 일은 **관측에서 궤적을 추정** 하는 것 | M2-t 의 관측만 판 하한 (라벨 대신 토큰 판독 추적) → 통과하면 학습 판 설계 (D10 승인 요청) |
  | 먼 칸 0 위지만 10 % 미만, 또는 이진 +5 점 미만 | 외삽 붙이기는 조금만 연다 | M2-t 는 보류. M2-p 를 보이는 운동 · 자연 영상 판에서 따로 (GPU, 공정한 시험 뒤) |
  | 먼 칸 구간이 0 을 품거나 음 | 완벽한 지각의 외삽 붙이기도 기준 AR 을 못 넘는다 → 등속 · 2 차 외삽이 VOBench 궤적에 안 맞거나, 붙인 토큰이 새 자리의 정답 토큰과 다르다 | M2-t 폐기 (이 판). move_or (참 궤적) 와의 차로 '외삽 오차' vs '토큰 붙이기 오차' 를 가른다 |
- 단서: 렌더는 Ariel 판 하네스 시기 (10-13) 에 만든 것이지만 표적은 같은 블록별 LN 표적 encoder 토큰이다 — 두 파일의 복사 오차 지도가 같은지 스크립트가 확인한다. 등속 외삽은 ramp · 가속 · 감속 운동에서 틀린다 (그래서 move_ca 를 같이 본다).
