# 분석 정리 (사용자용 한 장)

**질문**: 관측만으로 학습한 블록 AR predictor 는 어디서, 왜 intuitive physics 를 따르는 미래를 못 내나. 지금까지 무엇이 측정으로 서 있고, 무엇이 아직 모르는 것인가.
**답**: 기준 블록 AR 은 보이는 물체만 일부 옮기고, 가려진 움직이는 물체 · 낙하 · 포물선에서는 예측 없는 기준선과 같다 [측정]. 학습된 모델은 데이터가 보상하는 운반의 약 4–13 % 만 옮긴다 (사전 등록 재현) [측정]. 학습 없는 추적 기준선 (문맥 프레임만으로 물체를 추적해 외삽) 은 가려진 움직이는 물체를 학습된 모델보다 잘 풀지만 (76.1 vs 51.4) 선반 낙하는 5.6 % 다 (우연 50, 학습된 모델 30.6) [측정, #86] → method 가 둘을 다 이길 수 있는 판은 사건 판이다. V-JEPA 2 encoder 를 고를 측정 이유는 아직 없고, 점 손실은 V-JEPA 2 공간에서만 평균 · 수축에 상을 준다 [측정]. 공정한 예산의 입력 가림막 과제는 먼 칸에서 오히려 덜 놓는다 (−0.49 % [−0.79, −0.25]) — 부정 결과다 [측정, 사전 등록].
**다음 할 일**: 사용자 결정: encoder 교체 학습 · 궤적 라벨 위치 · 운반 가지 method 의 공정한 예산.

| 용어 | 뜻 |
|---|---|
| 블록 · 블록 토큰 | 연속 두 프레임 = 블록 하나. 표적 encoder 가 블록마다 16 × 16 칸의 토큰을 낸다 |
| 기준 블록 AR | 관측만으로 70 epoch 학습한 블록 단위 자기회귀 predictor (V-JEPA 2 ViT-H encoder 고정) |
| Ariel 판 | 이전에 학습한 블록 AR predictor (더 짧은 블록으로 학습) |
| latent 예측 · 표적 공간 | 픽셀이 아니라 표적 encoder 의 토큰을 예측한다. 손실과 채점이 모두 이 토큰 공간에서 이뤄진다 |
| 끝 가림 | 마지막 관측에서 물체가 가려져 있는 경우 |
| 복사 · 문맥 평균 | 예측 없는 기준선. 복사 = 마지막 블록을 그대로 미래로. 문맥 평균 = 문맥 블록들의 같은 칸 평균 |
| 정답 자리 오라클 | 마지막으로 다 보인 물체 토큰을 정답 미래 자리로 옮긴 예측. "채점이 성공을 볼 수 있나" 를 검사한다 |
| 전체 토큰 채점 · 물체 자리 채점 | 미래 블록 전체 칸의 L1 / 물체가 있는 3 × 3 칸만의 L1. 가능 · 불가능 미래 중 어디에 가까운지로 쌍 정확도를 낸다 |
| 운반 · 운반 이득 | 물체 토큰을 실제 변위만큼 옮겨 두는 것. 운반 이득 1 = 실제만큼, 0 = 제자리 |
| 자리 여유 | 물체 칸에서 (불가능 미래 오차 − 가능 미래 오차). 연속값이라 작은 이동도 보인다. 오라클 거리의 몫 (%) 으로 읽는다 |
| 먼 칸 | 마지막으로 보인 자리에서 1.5 칸 넘게 떨어진 미래 블록. 제자리에 두는 것만으로는 맞힐 수 없다 |
| 물체 라벨 보조 손실 | 합성 영상의 물체 위치 · 존재 라벨을 예측 토큰 위 작은 head 에 거는 보조 손실 (사용자가 '상태 감독' 으로 부르던 판) |
| 위약 차분 운반 몫 (κ_Δ) | 실제 흐름 방향으로 옮긴 블록의 계수에서 90° 돌린 방향의 계수를 뺀 값. 방향과 무관한 공간 상관을 빼고 남는 운반 몫 |
| 공정한 시험 | 기준 학습과 같은 학습률 · 전역 배치로, seed 둘을 써서 이어 학습한 시험 |
| 추적 기준선 | 학습 없는 손 예측. 문맥 프레임만 보고 물체를 추적해 궤적을 2 차 곡선으로 외삽하고, 마지막으로 보인 물체 토큰을 그 자리에 붙인다 (관측만) |
| 라벨 추적 판 | 추적 기준선과 같되 추적에 라벨 위치를 쓴 판 (완벽한 지각 가정). 상한 확인용 |
| 떨림 | 눈에 안 보이는 화소 잡음 (±1/255) 이 토큰을 바꾸는 크기 ÷ 다른 영상 같은 칸과의 거리 |
| 수축 보상 · 평균 보상 | 손으로 만든 예측 (마지막 관측을 원점 쪽으로 0.5 배 줄임 · 문맥 블록 같은 칸 평균) 이 복사보다 점 손실을 얼마나 줄이나 (%). 클수록 손실이 그 지름길에 상을 준다 |
| 보류 R² | 학습에 안 쓴 절반 영상에서 판독기가 정답 분산을 설명한 몫. 1 = 완벽, 0 = 평균만큼 |

## 1. 판정 도구 검사

- **왜**: 실패를 주장하려면 그 채점이 성공을 볼 수 있어야 한다.
- **어떻게**: 정답 자리 오라클 · 복사 · 문맥 평균을 같은 공간에서 전체 토큰 채점과 물체 자리 채점에 넣었다.
- **결과** [측정]:
  - 전체 토큰 채점은 자리를 못 본다. 끝 가림 이동에서 오라클 53.3 = 복사 53.3 이다 (#20). 선반에서는 오라클도 7 / 72 다 (#23).
  - 물체 자리 채점은 자리를 본다. 오라클이 끝 가림 이동 95.3 · 보이는 이동 99.2 · 선반과 포물선 100 이다 (#57 · #67 · #68).
- **해석**: 이 아래의 실패 주장은 모두 물체 자리 채점, 곧 오라클을 통과한 칸에서만 한다.

## 2. 기준 블록 AR 은 어디서 실패하나

- **왜**: 마지막 관측에 "보이는 것 · 안 보이는 것 · 없는 것" 중 어디서 무너지는지 가른다.
- **어떻게**: 같은 하네스, 같은 공간 기준선 셋으로 쟀다 (#67 · #68 · #69 · #82).
- **결과** [측정]:

| 칸 | 기준 블록 AR | Ariel 판 | 복사 | 문맥 평균 | 오라클 · 상한 | 우연 |
|---|---:|---:|---:|---:|---:|---:|
| 보이는 이동 물체 (자리) | 79.2 | 92.5 | 68.3 | 56.7 | 99.2 | 50 |
| 보이는 이동 물체 (운반 이득) | 0.22 | 0.65 | −0.02 | −0.50 | 상한 0.90 | |
| 가려진 정지 물체 | 88.9 | 93.1 | 63.9 | **100** | 90.3 | 50 |
| **가려진 이동 물체** | **51.4** | 51.4 | 51.1 | 50.8 | 95.3 | 50 |
| 가려진 이동 물체, 먼 칸만 | 41.3 | 41.0 | 39.7 | 40.3 | 94.3 | 50 |
| 선반 낙하 (고른 미래) | 30.6 | 7.6 | 31.2 | 41.0 | 100 | 50 |
| 포물선 (고른 미래) | 11.1 | 25.0 | 0.0 | 16.7 | 100 | 11.1 |
| 자연 영상 L1 (낮을수록 좋음) | 0.561 | 0.563 | 0.720 | 0.571 | | |

- **해석**:
  - 보이는 물체는 일부만 옮긴다. 옮기는 정도는 모델에 따라 다르다 (0.22 vs 0.65). 다만 두 모델의 학습 블록 길이가 달라 (0.5 초 vs 0.17 초) 시간 척도가 섞여 있다.
  - 가려진 정지 물체는 맞힌다. 그러나 학습 없는 문맥 평균이 이미 100 이라 능력이 아니다.
  - 가려진 움직이는 물체 · 낙하 · 포물선은 예측 없는 기준선과 같다. 먼 칸에서는 우연 (50) 아래인데, 이 칸은 불가능 미래가 '안 움직임' 쪽과 닮도록 설계됐기 때문이다.
  - 자연 영상에서 복사 대비 이득의 약 90 % 는 문맥 평균이 이미 낸다.
  - ⚠️ 한계: VOBench 의 움직임은 모두 등속 · 등가속이다. 그래서 끝 가림 판은 마지막에 다 보인 물체 토큰을 외삽 궤적 자리에 옮기기만 해도 풀린다 (라벨 위치 가정, 등속 86.7 · 2 차 95.3 = 오라클, 계획표 §11) [측정]. 이 판은 실패 진단에는 유효하다. 하지만 method 이득을 말할 때는 이 추적 기준선을 같이 내야 하고, 궤적이 결정적이지 않은 판이 따로 필요하다.
- 선행과의 경계: 가려진 물체의 존재 실패와 '마지막 본 자리에 얼림' 은 Xie & Alanwar 2026 의 결과다. 우리 몫은 오라클로 검사한 채점 · 블록 AR · 선반 낙하의 판정이다.

## 2-1. 학습 없는 추적 기준선: 어떤 판이 method 를 가를 수 있나

- **왜**: method 가 이겨도 "물체 추적기를 쓰면 되지 않나" 에 답할 수 있어야 한다. 추적기가 푸는 판과 못 푸는 판을 먼저 가른다.
- **어떻게**: 추적 기준선을 하네스와 같은 표적 · 같은 채점에 넣었다. 판 쓰기 규칙 ("추적 기준선 < 오라클의 50 % 이면 추적기가 못 푸는 판") 과 예측은 결과 전에 고정했다 (계획표 §11-2 · §13).
- **결과** [측정]:

| 판 | 기준 블록 AR | 추적 기준선 | 라벨 추적 판 | 오라클 |
|---|---:|---:|---:|---:|
| 가려진 이동 물체 (360 쌍) | 51.4 | **76.1** | 95.6 | 95.3 |
| 가려진 이동 물체, 먼 칸 (300 쌍) | 41.3 | **69.0** | 94.7 | 94.3 |
| 가려진 정지 물체 (72 쌍) | 88.9 | 63.9 | 65.3 | 90.3 |
| 선반 낙하 (144 묶음, 고른 미래) | 30.6 | 5.6 | **0.0** | 100 |
| 선반 낙하, 먼 칸 | 34.0 | 6.2 | **0.0** | 100 |

  - 추적 기준선의 추적은 라벨 위치에서 중앙값 2.2 화소 · 90 % 10.2 화소 벗어난다 (화면 256). 가려짐 판단은 라벨과 78.5 % 일치한다.
  - 선반에서 두 판 모두 떠 가는 미래를 고른다. 라벨 추적 판은 먼 칸 (복사에 물체가 없는 칸) 에서도 0 % 이고, 떠 가는 미래까지의 오차가 복사보다 작다 (0.541 vs 0.683). 결과 전에 적은 예측과 같다.
  - 2D 합성 사건 장면은 판정 불가다. 오라클 자체가 복사보다 나빠 도구가 서지 않는다 (물체가 토큰 한 칸보다 작다 [추측]).
- **해석**:
  - 가려진 움직이는 물체 판은 학습 없는 추적 기준선이 학습된 모델보다 잘 푼다. 실패 진단에는 유효하지만, method 가 이 판에서 이겨도 추적기를 이겼다고는 말할 수 없다.
  - 선반 낙하 판은 추적 기준선 (5.6 %) 과 학습된 모델 (30.6 %) 이 둘 다 진다. 추적의 실패 이유는 '사건을 모름' 이다. 그래서 **method 가 둘을 다 이길 수 있는 판은 사건 판 (마지막 관측에 없는 것) 이다.**
  - 설계상 긴장 [이론]: 1 순위 method 후보 (운반 가지 = 옮기는 연산을 predictor 구조에) 는 predictor 안의 '추적 + 외삽' 이다. 그러면 가림 판에서는 추적기와 비기고, 선반 판에서는 추적기의 실패를 물려받을 수 있다. 사건을 다루는 성분이 따로 필요하다 (후보: 사건이 있는 학습 영상 + 영상에서 계산한 궤적 라벨) [추측].
- **단서**: 선반 판만으로는 '받침 끝을 외움' 을 못 가른다. 도메인 밖 사건 판 (실물 메시 선반 · 위치 판독 세트의 받침 끝 · 벽) 이 필요하고, 그 판들의 오라클 통과는 아직 안 쟀다. 기준 AR 과 복사가 우연 아래 (31–34 %) 인 데에는 '떠 감이 복사와 닮음' 몫이 섞여 있을 수 있다.

## 3. 역사 대신 마지막 관측 수축

- **왜**: 가려진 움직이는 물체의 미래는 앞 블록들 (역사) 에만 있다.
- **어떻게**: 문맥을 8 블록에서 2 블록으로 자를 때 성능이 얼마나 주는지 (역사 값) 를 쟀다. 그리고 마지막 관측을 바꿔치기해 예측 자리가 어디를 따르는지 봤다 (#58 · #65).
- **결과** [측정, 수축 계수는 다른 팀 · 미커밋]:
  - 학습 없는 문맥 평균에게 역사는 쓸모 있다 (역사 값 0.30–0.49).
  - 학습된 모델은 역사를 거의 안 쓴다 (0.011–0.014).
  - 정지 칸에서는 마지막 관측을 a = 0.54 로 수축한다 (데이터 최적 0.49–0.52).
  - 가까운 걸음의 예측 자리는 마지막 관측을 따르고, 그 움직임도 잇는다.
- **해석** [추측]: 마지막 관측 하나에 묶인 해라서, 마지막 관측에 없는 물체는 옮길 재료가 없다.

## 4. 학습 신호를 바꾼 파일럿 (판정 아님)

- **왜**: 쉬운 처방 (가림 과제 · 운반 가중 · 떨림 억제 사영 · 짧은 문맥) 이 가려진 움직이는 물체를 옮기게 하는지 본다.
- **어떻게**: 기준 블록 AR 에서 팔마다 2,000 step 을 이어 학습했다. 같은 step 기준 (A0) 과 짝지어 비교했다 (#72–#76 · #82).
- **결과** [측정]:
  - 이진 주 지표 (가려진 이동 물체, 360 쌍) 는 모든 팔이 50.6–52.6 이다 (복사 51.1, 오라클 95.3).
  - 입력 가림막을 쓴 세 팔은 가려진 정지 물체만 올렸다 (+9.7 · +11.1 · +9.7). Xie & Alanwar 의 '얼림' 과 같은 꼴이다.
  - 연속 지표 (자리 여유) 로는 가림막 팔이 옳은 쪽으로 +1.0–1.5 % 움직였다. 하지만 **먼 칸에서는 −2.1 % (반대쪽)** 다. 그 작은 이동은 가까운 칸 몫이다.
  - 운반 가중을 다른 세기 · 다른 공간으로 건 팔도 가림막 팔과 쌍 하나 다르지 않았다 (계획표 §4).
- **단서 (같은 무게)**:
  - 예산은 기준 학습 표본의 0.23 % 이고, 최대 학습률은 1/10, seed 는 하나다. 그래서 공정한 시험이 아니다 (#76).
  - 연속 지표 · 먼 칸 지표는 결과를 본 뒤 건 점검이다. 미리 정한 판정은 이진이라 그대로다.
- **해석**: "이 예산에서 이진 지표가 안 움직였다" 까지만 말할 수 있다. "처방이 듣지 않는다" 는 철회했다. 이 판정은 공정한 시험 (§8) 이 한다.

## 5. 물체 라벨 보조 손실 체크포인트

- **왜**: 위치 · 존재 라벨을 손실에 넣으면 (D8 의 (i) 안), 예측 latent 의 자리가 열리는지 본다.
- **어떻게**: 사용자의 기존 체크포인트 넷을 학습 없이 같은 하네스로 쟀다. 핵심 대조는 "같은 2D 합성 데이터 · 같은 step, 보조 손실 있음 vs 없음" 이다 (#83).
- **결과** [측정, #83]:
  - 핵심 대조는 무변화다. 이진 −0.3 [−1.9, +1.7], 자리 여유 +0.04 % 로, 미리 정한 문턱 10 % 의 1/250 이다.
  - 여러 물체 판은 이진이 +1.9 [+0.3, +3.9] 로 간신히 0 밖이다. 그러나 자리 여유 +1.14 % 로 문턱 아래이고, 먼 칸은 −7.7 % 다. 같은 모델이 가려진 정지 물체는 100 으로 올리고 보이는 운반은 떨어뜨렸다. 옮김이 아니라 얼림이 세진 꼴이다.
  - 보조 손실 없이 2D 합성으로만 이어 학습한 판이 오히려 보이는 운반 (0.22 → 0.41) · 포물선 (11.1 → 27.8) · 선반 (30.6 → 45.8, 아직 우연 아래) 을 올렸다. 대신 자연 영상 L1 은 3.6 % 나빠졌다.
- **해석**: "라벨이 읽혀도 예측 latent 의 자리에는 안 놓인다" 는 사용자 기존 관찰이 다시 확인됐다. 단서: seed 하나 · 15 epoch 이고, 평가 (3D 렌더) 는 학습 (2D 합성) 의 도메인 밖이다.

## 6. 운반 몫 κ: 손실 최적까지 옮기나

- **왜**: 다른 팀은 "모델의 옮긴 계수 0.18 ≈ 데이터 최적 0.21" 을 보고했다 (#70). 맞다면 실패는 점 손실 최적의 성질로 설명된다.
- **어떻게**: 같은 회귀를 우리 손으로 다시 했다. 미리 정한 도구 검사는 "복사를 정답 자리에 넣으면 옮긴 계수 ≤ 0.10" 이다 (§3-2a).
- **결과**:
  - 미리 정한 판 셋 (토큰 옮기기 · 렌더 · 2D 합성) 은 모두 도구 검사를 못 넘었다. 복사도 0.11–0.74 를 받아, 회귀가 옮김과 복사를 못 가른다. 그래서 판정 불가다 [측정, §3-2b].
  - 사후 위약 판 (방향을 90° 돌린 대조를 뺌) 은 자연 영상 · 픽셀 판에서만 검사를 통과했다. 데이터가 보상하는 운반 몫은 0.152 [0.128, 0.177] 이다. 학습된 블록 AR 은 모두 0.005–0.011 이다 (기준 0.007). 학습 데이터 · 예산 · 창 설계와 무관하다 [측정, 사후, #81].
  - **사전 등록 재현 (10-22 저녁, 계획표 §11-1)**: 겹치지 않는 자연 영상 300 개에서 다시 쟀다. 데이터 몫은 초당 4 장 0.134 [0.115, 0.153] · 8 장 0.189 [0.164, 0.212] 이다. 자연 영상으로 학습한 모델들 (기준 · Ariel 판 · 파일럿 둘 · 공정한 시험 기준 팔 25 % 시점) 은 0.007–0.010 · 0.017–0.025 다. 최대치가 데이터의 7.5 % · 13 % 로, 미리 정한 문턱 20 % 아래다 [측정, 사후 발견 → 사전 등록 재현].
  - **공정한 시험의 마지막 체크포인트 넷 (10-23 04 시)**: 초당 4 장 0.007–0.008 · 8 장 0.018 로 기준 (0.007 · 0.017) 과 같다. 학습률을 다시 올리고 예산을 기준 step 의 5 % 만큼 더 써도, 가림 과제를 더해도 옮기는 양은 그대로다 [측정, 사전 등록 문장 그대로]. 단서: 이것이 막은 것은 '가림 과제 · 같은 손실로 더 학습' 이다. 표적 공간을 바꾼 손실 (§7-1) 은 공정한 예산에서 아직 안 쟀다.
  - 위약 전 계수 0.19–0.21 은 다른 팀 0.18 과 비슷하다. 그러나 그 몫은 90° 돌린 방향에도 똑같이 나오는 공간 상관이었다.
- **단서 (같은 무게)**:
  - 처음 발견은 사후 판이었다 (재현은 사전 등록). 자연 영상에는 오라클 같은 비자명 검사가 없다.
  - 흐름 추정 오차는 데이터 쪽 값을 낮춘다 (일관 칸만 보면 0.344).
  - "모델 몫이 학습 데이터의 κ 를 따라가나" 는 2D 합성 κ 가 판정 불가라 검정하지 못했다.
- **해석**: "모델은 손실 최적까지 옮긴다 (κ 법칙)" 는 우리 도구로 재현되지 않아 철회했다. 측정은 오히려 "학습된 블록 AR 은 데이터가 보상하는 운반의 1/5 도 옮기지 않는다" 쪽이고, 이것은 사전 등록 판에서 다시 섰다. §3 의 수축과 같은 방향이다 [추측]. 다른 팀 κ (#70 · #78) 는 "다른 팀 수치 · 재현 불가" 로만 쓴다.

## 7. encoder 질문: 왜 image encoder 가 아니라 V-JEPA 2 두 장 블록인가

- **왜**: 사용자 질문이다. 레포에는 image encoder 를 블록 encoder 로 쓴 비교가 없다 (#80).
- **어떻게**: 학습 없이 두 가지를 쟀다 (§1-12 · #79 · §3-2b). 하나는 같은 encoder 에서 연속 두 장 vs 한 장 복제 (V-JEPA 2-AC 꼴) 다. 다른 하나는 DINOv2 와의 떨림 · 칸 미만 매끄러움 · κ 비교다.
- **결과** [측정]:
  - VOBench 에서는 블록 안 움직임 판독이 자리 정보와 갈리지 않는다. 자리만으로 R² 0.986 이라 판정 불가다.
  - 운반 몫은 연속 두 장과 한 장 복제가 같다 (0.152 = 0.152, 사후 · 자연 영상).
  - 떨림은 V-JEPA 2 표적 쪽이 크다 (0.259 vs DINOv2 0.052). 칸 미만 비매끄러움은 비슷하다 (비 0.90). DINOv2 의 κ 는 사후 검사도 못 넘었다.
- **해석**: 이 판으로는 안 갈린다. 떨림만 DINOv2 가 작다. **V-JEPA 2 를 고를 측정 이유는 아직 없다.** 단서: 두 encoder 는 크기 · 해상도 · 패치가 다르다.
- **정정 (리더, 10-22 16:10)**: 앞서 리더가 사용자에게 "같은 64 차원 일반 PCA 는 효과가 없다" 고 답했으나 틀렸다. E1 의 대조는 주성분 256 vs 떨림 억제 64 였다. 같은 256 끼리는 비슷해 차원 축소 몫과 잡음 방향 몫이 안 갈렸고, 그래서 아래 7-1 의 주성분 64 대조를 했다.

### 7-1. 점 손실은 encoder 공간마다 무엇에 상을 주나 (10-22 저녁, 계획표 §12-1, 사전 등록)

- **왜**: 학습된 모델이 옮기지 않고 수축하는 것이 V-JEPA 2 표적 공간의 성질인지 본다. 사용자 질문 "우리도 PCA 를 해야 하나" 에도 답한다.
- **어떻게**: 같은 클립에서 손으로 만든 예측 (복사 · 문맥 평균 · 수축 · 정답 자리로 옮김) 을 V-JEPA 2 블록 공간과 DINOv2 한 장 공간에서 채점했다. 각 공간을 원래 · 주성분 64 · 떨림 억제 64 로 사영해 같이 봤다.
- **결과** [측정]:

| 복사보다 얼마나 이득인가 | V-JEPA 2 블록 | DINOv2 한 장 |
|---|---:|---:|
| 수축 (자연 영상) | **12.6 %** | **−2.9 %** |
| 문맥 평균 (자연 영상) | 16.8 % | 2.7 % |
| 문맥 평균 (보이는 이동) | 13.3 % | −1.8 % |
| 정답 자리로 옮김 (보이는 이동) | 16.4 % | 12.3 % |

  (떨림 값은 7-2 의 표 하나로만 쓴다 — 같은 개념을 다른 잡음 크기 · 다른 클립으로 잰 값을 섞지 않기 위해)

  - 짝지은 차 (자연 200 클립): 평균 보상 V-JEPA 2 − DINOv2 = +14.1 점 [+13.0, +15.2], 수축 보상 차 +15.5 점 [+13.7, +17.4]. 미리 정한 판정 1 ("encoder 에 따라 보상 구조가 다르다") 통과.
  - ⚠️ 정정 (리더, 10-22 20 시): 리더가 사용자에게 "DINOv2 에서는 옮기기가 4 배 더 이득" 이라고 말했으나 틀렸다. 그 지표는 문맥 평균 대비였고, DINOv2 에서는 평균이 복사보다 나빠 부풀려졌다. 복사 대비로는 옮김 이득이 DINOv2 12.3 % < V-JEPA 2 16.4 % 다.
  - PCA: V-JEPA 2 에서 주성분 64 만으로 수축 보상이 12.6 → 4.7 % 로 약 60 % 사라진다. 떨림 억제 64 는 그 위에 −0.7 % 까지 더 없앤다. 차는 5.4 점 [4.8, 5.9] 로 문턱 5 를 구간이 품어 강하게 쓰지 않는다 (DINOv2 도 5.3 점).
- **해석**:
  - **V-JEPA 2 공간에서는 옮기지 않고 평균만 내도 이득의 대부분을 얻는다. DINOv2 공간에서는 평균 · 수축이 손해라서 옮기는 것만이 이득이다** [측정, 손으로 만든 예측]. 학습된 모델의 수축 (§3) 이 이 지름길 때문일 수 있다 [추측].
  - PCA 는 그 지름길을 대부분 막는다. 그러나 떨림 억제 공간에서 학습한 파일럿 팔 (§4) 은 주 지표를 못 올렸다. 보상 구조가 바뀌어도 학습된 해가 따라 바뀐다는 보장은 없다.
- **단서**: 학습된 predictor 비교가 아니다. DINOv2-B (86 M) vs V-JEPA 2-H (632 M) · 해상도 · 패치가 같이 바뀐다. DINOv2 기반 예측 모델 (DINO-Foresight) 도 우리 레포 측정에서 가림에서 같은 꼴로 실패했다 (v11 77.1 vs 복사 76.4).

### 7-2. 2 장 블록 · 문맥 통째 인코딩이 image encoder 에 없는 정보를 담나 (10-22 저녁, #84, 사전 등록)

- **왜**: video encoder 의 이유가 (a) 블록 하나가 순간 움직임을 담는 것, 또는 (b) 문맥 전체를 한 번에 인코딩해 시간을 통합하는 것일 수 있다. V-JEPA 2 떨림의 원인도 가른다.
- **어떻게**: 자연 영상 400 개 (Kinetics-400 검증) 에서 칸 토큰 하나로 그 칸의 순간 움직임 (광학 흐름) 을 선형 판독했다. 칸 자리만으로는 R² 0.000 이라 판으로 쓸 수 있다. 떨림은 한 장 복제 블록에도 쟀다.
- **결과** [측정]:

| 입력 | 순간 움직임 보류 R² | 떨림 (자연 · VOBench) |
|---|---:|---|
| V-JEPA 2 연속 2 장 블록 | 0.030 | 0.259 · 0.760 |
| V-JEPA 2 한 장 복제 블록 | 0.000 | **0.359 · 0.914** |
| DINOv2 한 장 · 두 장 이어 붙임 | 0.000 · 0.001 | 0.052 · 0.380 (한 장) |
| V-JEPA 2 문맥 16 장 통째 | 0.045–0.047 | — |

  - 연속 2 장 − 한 장 복제 = +0.030 [+0.020, +0.040] 으로, 미리 정한 문턱 0.20 에 한참 못 미친다.
  - 문맥 끝 마지막 2 장을 회색 상자로 가린 판에서는 모든 입력이 0 근처다. 정보가 입력에 있는 대조 (가려지기 전 프레임 16 장) 도 못 읽었다.
  - **양성 대조 (21 시, 사전 등록)**: 정답을 계산한 바로 그 두 장의 원 화소 (칸과 이웃, 48 × 48) 를 작은 비선형 판독기로 읽어도 보류 R² 0.072 다. 미리 정한 문턱 0.3 아래라 판정은 **"이 정답 · 판은 도구가 못 된다"** 다.
- **해석**:
  - 순간 움직임 판독 (블록 하나 · 문맥 통째) 은 **어느 쪽의 증거로도 쓰지 않는다.** 학습 없는 측정으로는 "video encoder 가 image encoder 에 없는 움직임을 담나" 에 답이 나오지 않았다. 원인 후보는 4 fps 흐름 정답의 잡음 · 카메라 움직임 · 창보다 큰 움직임이다 [추측].
  - **떨림은 2 장 블록 탓이 아니라 encoder 자체의 성질이다** (한 장 복제가 더 크다). 이 측정은 판독기가 아니라 토큰 거리라 양성 대조 실패와 무관하다. 남은 원인 후보는 학습 방식과 크기 · 해상도다. 그래서 V-JEPA 2 를 한 장씩 넣어도 7-1 의 지름길은 남을 것이다 [추측].
- **다음**: 판독기 탐색은 더 하지 않는다. encoder 질문의 결론은 encoder 교체 학습 (DINOv2 표적 vs V-JEPA 2 표적, 둘 다 처음부터, 사용자 결정) 으로 낸다.

## 8. 지금 도는 공정한 시험과 판정 규칙

- **왜**: 파일럿은 예산이 작아 판정이 아니었다. D8 의 세 안이 모두 "가림 과제가 자리를 여는가" 의 답에 기댄다.
- **어떻게** (사용자 승인, 10-22 15:39 시작, 마감 10-23 06:39):
  - 팔은 입력 가림막 팔 (AX) 과 같은 조건의 기준 팔 (B0) 이고, 각각 seed 둘이라 run 넷이다.
  - 학습 데이터는 자연 영상만이다 (Kinetics-400 train 40,000 편 + Something-Something v2 train 97,416 편, 1 : 1).
  - 학습률 · 전역 배치는 기준 학습과 같다. 길이는 기준 step 의 5 % 다. R2 가 권한 10 % 에는 못 미친다.
  - 체크포인트는 25 · 50 · 75 · 100 % 에서 넷이다. 15 시간 안에 못 끝난 run 은 가장 늦은 체크포인트로 평가한다.
- **판정 (띄우기 전에 고정, 계획표 §6)**:
  - **성공**: 다음을 모두 만족한다. 먼 칸 자리 여유 AX − B0 가 오라클 거리의 10 % 이상이다. 그 구간이 0 위다. seed 둘의 부호가 같다. 이진 구간이 0 을 안 품는다.
  - **얼림만**: 자리 여유는 0 위인데, 먼 칸 구간이 0 을 품는다. 부정 결과로 쓴다.
  - **작은 이동**: 먼 칸이 0 위지만 10 % 미만이다. method 기여로 쓰지 않는다.
  - **무변화**: 모두 0 을 품는다. 부정 결과로 쓴다.
  - **떨어지지 않음 검사**: 가려진 정지 물체 · 거짓 운반 · 자연 영상 L1 · IntPhys 1 · 포물선 · 선반이 B0 아래로 떨어지면 '맞바꿈' 으로 적는다.
- **중간 읽기: 학습 25 % 시점 (판정 아님)** [측정]: 빈 GPU 로 중간 체크포인트를 미리 평가했다. AX − B0 (seed 짝 평균) 은 다음과 같다.
  - 먼 칸 자리 여유: −0.23 % [−0.52, +0.02]. seed 별로 −0.34 · −0.11 로 부호가 같다.
  - 자리 여유: +0.43 % [+0.18, +0.67].
  - 이진: +0.1 [−0.6, +0.8].
  - 규칙의 꼴로는 '얼림만' 이다. 떨어지지 않음 검사는 모두 통과했다.
  - 규칙 한계: 가려진 정지 물체 검사는 72 쌍이라 구간 반폭이 3.5 점이다. 그래서 효과가 0 이어도 "아래끝 ≥ −3" 을 못 넘는다. 결과 전에 결정 기록에 적었고, 규칙은 바꾸지 않는다.
  - 이 시점은 학습률이 최고점에 막 닿은 때라 최종과 다를 수 있다.
- **최종 결과 (10-23 03:30, 네 run 모두 마감 전에 100 % 학습, 주 판정 = 마지막 체크포인트)** [측정]:

| AX − B0 (seed 짝 평균) | 끝 가림 이동 전체 (360 쌍) | **먼 칸 (300 쌍)** |
|---|---|---|
| 이진 | +0.3 [−0.4, +1.1] | −0.5 [−1.4, +0.2] |
| 자리 여유 (오라클 몫) | +0.48 % [+0.21, +0.74] | **−0.49 % [−0.79, −0.25]** |
| seed 별 자리 여유 | +0.39 · +0.57 | −0.45 · −0.53 |

  - 먼 칸 학습 곡선: 25 % −0.23 · 50 % −0.49 · 75 % −0.77 · 100 % −0.49 %. 끝까지 0 위로 가지 않는다.
  - 판정 스크립트의 기계 출력은 '그 밖' 이다. 미리 정한 범주 '얼림만' 은 "먼 칸 구간이 0 을 품음" 인데, 실제로는 먼 칸이 0 **아래** 다. 성공 조건의 반대 방향이라 **부정 결과** 로 적는다. 파일럿 (먼 칸 −2.1 %) 과 같은 방향이다.
  - 떨어지지 않음: 거짓 운반 · 자연 영상 L1 · IntPhys 1 끝 가림은 통과했다. 가려진 정지는 차 0.0 이지만 규칙 한계 (반폭 3.5) 로 '실패' 표시다. 포물선 (20.8 vs 22.9) · 선반 (28.5 vs 28.8) 은 점추정이 B0 아래라 '맞바꿈' 표시인데, 차가 한 묶음 수준이다.
  - 보조: 보이는 움직이는 물체의 운반 이득은 AX 0.31 · 0.29 > B0 0.24 > 기준 0.22 다. 가림 과제는 보이는 운반을 조금 늘린다.
  - B0 자체 (학습률을 다시 올려 이어 학습) 는 기준 AR 보다 조금 나빠졌다 (자리 여유 −2.0 · −2.5 %, 가려진 정지 88.9 → 81.9 · 80.6).
- **해석**: 입력 가림막 과제는 공정한 예산에서도 가려진 움직이는 물체를 옮겨야 할 자리에 놓게 하지 않는다. 마지막 관측 근처 (가까운 칸) 만 조금 오르고 먼 칸은 반대로 간다 — 얼림이 세진 꼴이다 [측정]. 단서: 길이는 기준 step 의 5 % 로, R2 가 권한 10 % 에 못 미친다. 크기는 오라클 거리의 0.5 % 로 작다. 그래서 "가림 과제가 먼 칸을 해친다" 로 키우지 않고 "옮기게 하지 않는다" 까지만 쓴다. 범위는 입력 가림막 과제 · 같은 손실 · 같은 표적 공간 · 이어 학습이다 (근거표 #85).
