# visible vs late · PFT 가 바꾸는 것 · 이식이 안 되는 이유 — 정리 (2026-10-31)

> **질문** — 가림막 없음 (visible) 과 문맥 끝 가림 (late) 은 무엇이 다른가? PFT 는 무엇을 바꾸나? encoder 판독기가 predictor 출력에서 안 읽히는 이유는?
> **답** — **late 에서 무너지는 것은 정보가 아니라 "과거 물체를 다시 나타날 미래 자리로 옮기는 일" 이다.** visible 은 마지막 문맥 블록의 물체를 가까이 옮기기만 하면 되지만, late 는 더 오래된 블록에서 가져와야 하고 릴리즈는 그 길을 안 쓴다. PFT 는 그 길을 켜서 정체를 참 자리에 놓지만, 끝 자리는 학습셋 시간표를 따라 생성기 밖으로 안 옮겨진다. 이식이 안 되는 이유도 같은 데서 온다: 정체가 물체 자리에 몰려 있지 않고 화면에 퍼져 있어서, 물체 자리 성분을 읽는 encoder 판독기가 못 읽는다.
> **다음** — 오늘의 VOBench_v2 블록 판독을 PFT p 에 걸어 "PFT 가 바꾸는 것" 을 같은 판에서 확인한다 · 문맥 끝 부분 가림 학습 vs 운반 모듈로 원인을 가른다.

## 1. visible vs late — 무엇이 다른가

**결론** — 두 조건 모두 문맥 encoder 에는 물체 정체가 있다. 차이는 "미래의 그 자리에 물체 내용이 놓이느냐" 다. visible 은 가까운 미래에서 놓이고 멀어질수록 흐려진다. late 는 처음부터 놓이지 않는다.

| 무엇 | visible | late | 출처 |
|---|---|---|---|
| 문맥 z 의 정체 (모양 / 색) | 93–98 / 74–84 % | 보이는 블록 96–100 / 94–100 %, **가린 블록 8 도 82–89 / 76–86 %** | [①] |
| p 자기 판독 (모양 / 색) | 94 → 76 / 91 → 62 % (블록 9 → 16 으로 떨어짐) | **56–66 / 29–50 %** (처음부터 낮고 평평) | [①] |
| z 판독기 → p (이식) | **82 → 43 / 78 → 28 %** (가까운 미래는 됨) | **22–41 / 7–22 %** (우연 16.7 / 12.5 에 가까움) | [①] |
| 표준 채점 사라짐 (A / B) | 100 / 100 % | **0–8 / 100 %** | [§5] · [TG] |
| p 미래에 물체다운 토큰이 남는 길이 | 4–5 슬롯 (마지막 관측 자리에서 2–3 칸 안) | **0 슬롯** | [§5 5-5] |
| 다시 나타날 자리 query → 과거 물체 자리 (경로 세기) | 균등의 2.8 배 | **0.54 배** (같은 거리의 다른 자리 수준) | [TG R4 E37] |

**해석**
- visible 에서 미래를 만드는 방식은 "마지막 문맥 블록의 물체를 가까운 자리로 조금 옮기기" 다 [측정 기반 해석]. 근거: 미래 자리는 마지막 블록만 조작해도 따라온다 (따름 지수 0.63–0.88) [13], 외삽은 2–3 칸까지만 된다 [§5].
- late 에서는 마지막 문맥 블록의 물체 자리에 가림막이 있다. 옮길 재료가 없다. 물체는 k 샘플 전 · 더 먼 자리에 있었고, 그것을 가져오는 길 (경로 세기) 이 쓰이지 않는다 [측정].
- 가려진 시간 길이는 상관없다 (v11 k = 1–4 평평) [§5]. 갈리는 것은 "마지막 관측에 물체가 보이느냐" 하나다.

**단서**
- [①] visible 은 학습 영상이 late 의 1/3 (겹당 90 vs 270) 이다. visible 의 색 수치는 표본에 깎였을 수 있다 [추측].
- 사라짐 채점 · 경로 세기는 VOBench_v1 · v11 에서 잰 값이다.

## 2. PFT 가 바꾸는 것

**결론** — PFT 는 late 에서 "과거 물체를 다시 나타날 자리로 가져오는 길" 을 켜고, 그 길로 정체를 참 자리에 놓는다. 그래서 학습 분포 안에서는 late 사라짐이 풀린다. 그러나 미래의 끝 자리는 문맥 운동이 아니라 학습셋 시간표를 따르고, 효과는 같은 생성기 계열 밖으로 안 옮겨진다.

| 무엇 | 릴리즈 | PFT | 출처 |
|---|---|---|---|
| late 사라짐 A (VOBench 분포 안) | 0–8 % | **98–100 %** | [TG] |
| 경로 세기 (다시 나타날 자리 → 과거 물체) | 0.54 | **8.0** | [TG R4 E37] |
| 그 길을 막으면 | — | 사라짐 A 는 그대로, 참 자리 정체 이득의 66–82 % 가 사라짐 (판독기를 다시 맞춰도 안 돌아옴) | [TG R4 E38] |
| late 정체: 화면 평균 판독 (모양) | 72.8 / 86.6 % | 70.3 / 84.2 % (그대로) | [TG Q1 E3] |
| late 정체: **참 자리 3×3 판독** (모양) | 55.9 / 70.8 % | **89.8 / 94.8 %** | [TG Q1 E3] |
| 참 자리 존재 대비: 크기 · 자리 따라감 | 기준 · 0.50 | ×2.4 · 0.95 | [TG Q2] |
| 참 자리 물체 차이의 방향 (실제 미래 대비 cos) | 0.26 | **0.86** | [TG R4 E38c] |
| 뒤쪽 미래의 가로 끝 자리 | — | **학습셋 시간표를 따름** (보폭 2 판 12/12 block 이 보폭 3 자리) | [TG Q3 E35] |
| 외형 · 색 · 가림 길이 외우기 | — | 안 외움 | [TG Q3] |
| 생성기 밖 전이 | — | VOBench → v11 계열 89–97 % 만. 합성 → IntPhys 0 칸. v11 PFT → VOBench 0 % | [TG R4 E39] |

**해석**
- PFT 가 바꾼 것은 "정체가 있느냐" 가 아니라 **"정체가 참 자리에 놓이느냐"** 다 [측정]. 화면 평균 판독은 그대로이고 참 자리 판독만 오른다.
- 그 길은 정체를 나르는 데 인과적으로 쓰인다 [측정, 막기]. 다만 사라짐 정답은 그 길을 막아도 그대로라, 점수를 정하는 경로는 따로 있다 [측정].
- "어디" 는 학습셋 시간표를 외웠다 [측정, 사전 등록]. 그래서 끝 자리가 다른 생성기에서는 효과가 안 켜진다.

**단서**
- 이 표는 VOBench_v1 과 서로 다른 판독기에서 온 수치다. 오늘의 VOBench_v2 블록 판독 (①) 으로는 PFT 를 아직 안 쟀다.
- 표준 채점은 물체 칸을 안 바꾸고 나머지 칸만 PFT 로 바꿔도 사라짐 A 가 93 % 다 [TG Q2]. 사라짐 점수만으로는 물체 운반의 증거가 아니다.

## 3. 이식이 안 되는 이유 (encoder 판독기 → p)

**결론** — 방향은 같다. visible 의 먼 미래는 주로 크기 문제고, late 는 꼴 (정체가 놓인 자리) 문제다. late 의 p 는 정체를 다시 나타날 자리에 몰지 않고 화면에 퍼뜨린다. encoder 판독기는 물체 자리에 몰린 성분을 읽으므로 그것을 못 읽는다. 그 원인은 1 · 2 절의 "가져오는 길이 꺼져 있다" 와 같은 것이다.

| 무엇 | 결과 | 출처 |
|---|---|---|
| 정보가 p 에 있나 | late p 자기 판독 모양 56–66 · 색 29–50 % (우연 16.7 · 12.5 보다 높음) | [①] |
| encoder 판독기로 읽히나 | late z → p 22–41 · 7–22 %, h → p 16–29 · 11–20 % (우연 근처) | [①] |
| 방향 | 장면을 뺀 정체 효과의 cos 0.92–1.04 (같다) | [TG Q1] |
| 크기 (visible 먼 미래) | 대비를 2 배로만 키워도 실패의 60–75 % 회복 | [TG Q1] |
| 크기 (late) | 어떤 토큰별 사상 (late 로 맞춘 것 포함) 도 4–15 % 를 못 넘음 | [TG Q1] |
| 자리 윤곽 (late) | h · PFT 는 다시 나타날 자리에 봉우리 (+10 ~ +60 pt). 릴리즈 · 관측 학습 AR 은 봉우리 없음 | [TG Q1 E34] |
| encoder 안에서도 | 보이는 표현으로 배운 판독기를 가려진 encoder 표현에 걸면 9–21 % | [TG] |
| 이식을 맞추면 영속이 풀리나 | p 를 h 공간으로 정렬해도 사라짐 A 3–7 %. 참 자리에 물체 토큰을 넣으면 72 % | [TG Q2] · [②] |

**해석**
- 이식 실패와 late 영속 실패는 같은 뿌리다 [측정 기반 해석]. 둘 다 "다시 나타날 자리에 물체 내용이 놓이지 않는다" 에서 온다.
- PFT 처럼 그 자리에 정체를 놓으면 참 자리 판독이 오른다 (56 → 90) [TG].
- 그래서 판독기 이식을 맞추는 것 (사상 · 정렬) 은 해법이 아니다 [측정]. 필요한 것은 참 자리의 내용이다.
- 가려진 표현이 보이는 표현과 다른 꼴이라는 점은 encoder 안에서도 이미 보인다 (9–21 %) [TG]. 그래서 이식 실패 전부를 predictor 탓으로 쓰지 않는다.

## 4. 아직 모르는 것 · 다음

| 모르는 것 | 가르는 실험 |
|---|---|
| 릴리즈가 왜 오래된 블록에서 가져오는 길을 안 쓰나 (역사 압력 부족 [13: 문맥 2 블록으로 잘라도 이득의 1–3 % 손실] · 내용 없는 미래 query · 가까운 쪽 치우침) [추측] | **문맥 끝 부분 가림 학습** (마지막 1–3 블록에서 움직이는 영역만 가리고 타깃은 원본 미래 — 역사 압력) vs 운반 모듈 (구조) 을 같은 판으로 |
| PFT 가 오늘의 블록 판독판에서 p 정체 · 이식을 얼마나 바꾸나 | VOBench_v2 visible · late 에 PFT p 추출 → ① 과 같은 판독 (GPU 약 30 분) |
| 사라짐 정답을 정하는 경로 (어느 토큰 · 층) | 토큰별 surprise 기여 지도 |
| 끝 자리 사전이 외부 비전이의 원인인가 | 끝 자리를 더 세게 흩뜨린 PFT (학습 표본기 seed 수정 뒤) |

⚠️ **정정 (10-31, 사용자 지적)** — 앞서 제안한 "문맥 끝 블록 통째 dropout" 은 late 를 겨누지 못한다. 블록을 빼면 남은 마지막 블록이 새 마지막 관측이 되고 그 블록은 깨끗하다. 그래서 모델은 "마지막 블록을 더 멀리 옮기기" 만 배우고, late 의 상황 ("마지막 블록의 물체 자리에 가림막이 있어서 더 앞 블록에서 가져와야 함") 은 학습에 안 생긴다. 역사 압력은 마지막 블록들을 **부분적으로** 가려야 생긴다.

**금지 표현 점검** — 이 문서는 "기억 문제다", "predictor 가 X 를 못 만든다", "목적함수 때문이다" 를 쓰지 않는다. 원인 후보는 모두 [추측] 으로 두었다.
