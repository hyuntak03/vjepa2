# ② 공간 지도 주입 — 지도 모듈의 학습 전 상한 시험 (2026-10-30)

> **질문** — 문맥 z 에서 "마지막으로 보인 물체 토큰을, 추정한 운동으로 미래 칸에 옮긴 지도" 를 만들어 릴리즈 p 에 넣으면 late 사라짐이 오르나? 지도의 어느 부분이 병목인가?
> **답** — **물체 찾기 · 내용은 된다. 병목은 미래 자리 (운동 외삽) 다.** 추정 내용을 참 자리에 넣으면 63 % (라벨 판 72 %) 인데, 추정한 운동으로 옮기면 25–30 % 다. 사전 판정은 "중간" 이다.
> **다음** — 지도 모듈의 supervision 을 "미래 자리" 에 준다. 학습셋 끝 자리를 외우지 못하게, 좌표 열만 입력으로 받는 운동 head 를 쓰고 끝 자리가 다른 판으로 평가한다.

## 용어

| 용어 | 뜻 |
|---|---|
| 지도 | 미래 블록 8 개 × 16 × 16 칸. 물체가 있을 칸에만 마지막으로 보인 블록의 물체 토큰 (문맥 z) 을 채운 것 |
| 물체 칸 판독기 | 문맥 z 토큰마다 "물체가 이 칸에 있나" 를 맞히는 선형 판독기 (1280 → 1). 지도 모듈 안에서 라벨 (시뮬레이터 물체 상자) 을 쓰는 유일한 부분 |
| 주입 | 릴리즈 p 를 복사하고 지도의 채운 칸만 덮어쓴 것. cross-attention 모듈의 학습 없는 대역 |
| 라벨 판 | 같은 주입을 시뮬레이터 라벨 (마지막 보임 블록 · 물체 상자 · 궤적) 로 한 것. 이식 조사 E24 와 같은 구성 |
| 사라짐 A | permanence 짝에서 "물체가 있던 문맥 → 빈 미래" 가 불가능인 쪽의 정답률. 릴리즈 late 이동에서 0–8 % |

## 1. 왜 했나
- 사용자 제안 (10-30): 공간 지도 모듈을 만들어 predictor 와 cross-attention 으로 섞는다. 지도 모듈에는 따로 supervision 을 준다.
- 학습 전에 확인할 것: 지도가 문맥 z 만으로 만들어질 수 있나, 어느 부분이 막히나.

## 2. 무엇을 어떻게 했나
- 판: VOBench_v1 late · 이동 · permanence 60 장면 (방향 A = 물체 문맥, B = 빈 문맥) + 모양 위반 60 장면 (A). 채점은 표준 (전체 토큰 L1, matched 짝).
- 지도 만들기 (영상마다 그 영상의 문맥 z 만):
  1. 물체 칸 판독기로 칸마다 물체 점수. 판독기는 장면 단위 2 겹으로, 평가 장면을 뺀 영상으로 학습했다.
  2. 블록 점수 (상위 3 칸 평균) 가 문턱 이상이면 "보임". 문턱은 학습 쪽 블록 라벨로 정했다. 보이는 블록이 없으면 지도를 비운다.
  3. 보이는 블록마다 물체 중심 (칸 단위 실수).
  4. 미래 자리 = 보이는 블록 중심에 직선 (1 차) · 2 차식 최소제곱 · 차수 자동 (사전 규칙).
  5. 마지막으로 보인 블록의 물체 칸 토큰을 미래 자리로 평행 이동.
- 비교: 릴리즈 · 마지막 문맥 복사 · 라벨 판 (마지막 본 자리 · 1 차 · 2 차 = 참 자리) · 추정 내용을 참 자리에 (내용과 자리를 분리).
- 첫 시도 (라벨 없이 문맥 8 블록 중앙값 대비 두드러짐) 는 실패했다. ViT-H 문맥 토큰은 배경도 블록마다 크게 흔들려 물체가 두드러지지 않는다 (최대점이 빈 장면에도 같은 크기) [측정]. → 판독기 판으로 바꿨다.

## 3. 결과 [측정] — permanence 방향 A 정답률 %, 60 장면, [95 % CI]

| 지도 | 사라짐 A | 미래 자리 오차 (칸) | 참 칸 1 칸 안 |
|---|---:|---:|---:|
| 릴리즈 (주입 없음) | 8 [2, 15] | — | — |
| 마지막 문맥 복사 | 57 [43, 70] | — | — |
| 라벨 판, 2 차 외삽 (= 참 자리) | **72** [60, 82] | 0 | 100 % |
| 라벨 판, 1 차 외삽 | 45 [32, 58] | — | — |
| 라벨 판, 마지막 본 자리 | 10 [3, 18] | — | — |
| **추정 내용 → 참 자리** | **63** [52, 75] | 0 | 100 % |
| 추정 내용 → 추정 운동 (1 차 / 2 차 / 차수 자동) | **30 / 25 / 30** | 2.2 / 2.7 / 2.3 | 41 / 37 / 40 % |
| 추정 내용 → 마지막 본 자리 | 8 | 4.1 | 7 % |

- **지도 앞부분은 된다:** 물체 있음 판정은 물체 문맥 100 % · 빈 문맥 0 %. 마지막 보임 블록 98 % 일치. 보이는 블록 중심 오차 0.53 칸.
- **빈 문맥 (방향 B) 은 모든 판에서 100 %:** 지도가 빈 장면에 헛물체를 그리지 않는다.
- **운동별 미래 자리 오차 (12 장면씩, 차수 자동):** 등속 0.5 칸 · 감속 1.7 · 경사 오름 2.0 · 가속 3.3 · 경사 내림 3.6.
- 모양 위반 (A) 도 같은 순서: 라벨 참 자리 82 · 추정 내용 참 자리 78 · 추정 운동 58–65 · 릴리즈 45 · 복사 45.

## 4. 해석
- **병목은 미래 자리다** [측정]. 내용을 참 자리에 넣으면 라벨 판에 거의 닿는다 (63 vs 72). 추정 운동으로 옮기면 25–30 % 로 떨어진다.
- **원인은 오차 증폭이다** [측정 + 이론]. 보이는 블록의 자리 오차는 0.5 칸으로 작지만, 미래 8 블록까지 외삽하면 2–3 칸이 된다. 가속 · 경사처럼 2 차 항이 필요한 운동에서 가장 크다.
- 사전 판정은 "중간" 이다 (추정 운동 최대 30, 문턱 20–60 사이).
- **복사 기준선 (57) 보다 낮다** [측정]. 지금 판의 지도로는 예측 없는 복사를 못 넘는다.

**지도 모듈 supervision 에 주는 함의** [측정 기반 설계안]
- supervision 은 "지금 물체가 어디 있나" 보다 "미래에 어디 있을까" (운동) 에 줘야 한다.
- 위험: VOBench 에서 미래 자리를 학습하면 PFT 처럼 학습셋 끝 자리를 외울 수 있다 [추측, 이식 조사 Q3 의 끝 자리 사전].
  - 막는 법 1: 운동 head 의 입력을 추정 좌표 열로만 제한한다 (장면 내용을 안 봄).
  - 막는 법 2: 끝 자리가 학습셋과 다른 판 (보폭 2 등) 으로 평가한다.

**단서**
- 물체 칸 판독기는 시뮬레이터 라벨을 쓴다 (특권 정보). "관측만으로" 의 판이 아니다.
- 주입은 cross-attention 의 대역이다. 학습된 모듈이 이렇게 동작한다는 뜻은 아니다.
- 60 장면이라 CI 가 ±12 pt 안팎이다. 등속 장면은 참 자리 라벨 판도 50 % 라 이 채점에서 원래 어려운 칸이다.
- VOBench_v1 판이다. VOBench_v2 로 다시 돌리지 않았다.
