# 음의 손실은 왜 필요했나 — 예측 속 가려진 물체의 진단과 처방 (2026-11-10)

> **3줄 요약**
> - **질문** — 가려진 물체가 다시 나오는 장면에서, 예측한 미래 안의 물체는 어떤 상태인가? 그 상태에서 무엇이 모자라서 음의 손실이 필요한가?
> - **답** — **진단 1:** 릴리즈의 예측은 가려진 물체를 놓친다 (물체 있음 판정 33 %). AR 은 들고 간다 (86 %). **진단 2:** AR 이 들고 가는 물체는 흐리다 (분리도가 실제 표현의 0.64 배). **처방:** 가능 미래와의 거리만 줄이는 L1 에는 없는 "불가능 미래와 떨어지라"는 항, 곧 음의 손실. **결과:** 분리도 0.64 → 1.31 배, 실제 영상 사라짐 정답률 36.8 → 71.6 %.
> - **다음** — 같은 분리도 분석을 실제 영상에 한다 (지금은 합성 장면에서만 잼). 부작용 (방향 어긋남, 빈 장면으로 번짐) 을 줄이는 방법을 본다.

## 용어

| 용어 | 뜻 |
|---|---|
| 물체 장면 | 물체가 굴러가다 문맥 끝에서 가림막 뒤로 숨고, 미래에서 다시 나오는 영상 (가능한 영상) |
| 빈 장면 | 같은 장면에서 물체만 뺀 영상 (가능한 영상). 물체 장면과 짝을 이룬다 |
| 블록 | 연속 2 장을 encoder 에 넣어 얻은 위치별 벡터 묶음, 16 × 16 = 256 토큰 × 1,280 차원 |
| 미래 블록 1–8 | 문맥 8 블록 뒤의 8 블록. 물체는 미래 블록 1 (일부는 2) 까지 가려져 있고 블록 3 부터 다시 보인다 |
| 실제 표현 | 실제 미래 영상을 그 모델의 정답용 encoder 에 넣어 얻은 블록 (채점 때 정답과 같은 공간). 릴리즈는 영상 전체를 한 번에, AR 은 블록마다 따로 넣는다 |
| 예측 표현 | 모델이 문맥만 보고 만든 미래 블록 (채점 때 예측과 같다) |
| 물체 판별기 | 실제 표현 한 블록을 보고 "물체 장면 / 빈 장면"을 맞히는 선형 분류기 (로지스틱 회귀) |
| 판별 점수 | 판별기의 출력 값 (로그 오즈). 0 보다 크면 "물체 있음". 실제 표현에서 물체 장면은 약 +7, 빈 장면은 약 −6 |
| 실제 물체 방향 | 실제 표현에서 (물체 장면 − 빈 장면) 차이 벡터를 장면 평균한 방향 (1,280 차원 단위 벡터) |
| 분리도 d′ | 각 장면의 표현을 실제 물체 방향에 투영한 값으로, 물체 장면 무리와 빈 장면 무리의 평균 차를 무리 안 흩어짐으로 나눈 값. 클수록 물체 유무가 또렷하다 |
| 분리도 비 | 예측 표현의 분리도 ÷ 같은 모델 실제 표현의 분리도. 1 이면 실제만큼 또렷하다 |
| 실제 영상 사라짐 · 나타남 정답률 | 실제 영상 영속성 벤치 (짝 95 개씩) 의 짝 정답률. 사라짐 (A) = 물체가 가려진 뒤 없어지는 위반, 나타남 (B) = 없던 물체가 나오는 위반 |
| 릴리즈 / AR | 공개 V-JEPA 2 predictor / 자연 영상으로 처음부터 학습한 블록 단위 자기회귀 predictor (encoder 는 둘 다 같은 공개 encoder, 얼림) |
| + L1 · + 음의 손실 | 위 모델에서 합성 데이터 v4bc4 로 이어 학습한 판: L1 만 / L1 + 사라짐 · 나타남 음의 손실 (p 0.2 판) |
| 음의 손실 | 불가능한 미래 (사라짐 · 나타남) 의 실제 표현과 예측 사이 L1 이 여유값보다 작으면 벌점: max(0, 여유값 − L1(예측, 불가능 미래)) |

## 1. 왜 했나

- 성능으로는 차이가 보였다. 가림 직후 물체가 사라지는 위반을 릴리즈는 거의 못 잡고 (VOBench v3 늦은 가림, 움직이는 물체 사라짐 4 %), AR 은 잡는다 (90 % 안팎). 실제 영상에서는 둘 다 우연 아래다 (사라짐 29.5 / 36.8 %). 음의 손실을 걸면 오른다. [측정]
- 논문에서 "AR 을 출발점으로 고르고, 그 위에 음의 손실을 건다"를 말하려면, 성능 표가 아니라 **예측 표현을 진단해서** 두 결정이 나와야 한다.
- 가설: (1) 릴리즈는 예측한 미래에서 가려진 물체를 놓치고 AR 은 들고 간다. (2) AR 이 들고 가는 물체는 실제보다 흐려서, 물체가 사라진 미래와 잘 갈리지 않는다.

## 2. 무엇을 어떻게 했나

**파이프라인**

```
VOBench v3 늦은 가림 840 장면 × (물체 장면, 빈 장면)
   │  채점과 같은 창: 원본 96 장 중 0, 3, …, 93 → 32 장 = 문맥 8 블록 + 미래 8 블록
   ▼
모델마다 (6 개)  ── 문맥 → 예측 표현 (미래 8 블록)
                └─ 실제 미래 → 실제 표현 (미래 8 블록)
   │  블록마다 256 토큰을 평균 · 최대로 요약 → 블록당 벡터 하나
   ▼
진단 1 · 물체가 남는가 ─ 물체 판별기를 실제 표현으로만 학습 (장면 절반) → 같은 판별기 · 같은 문턱을 예측 표현에 붙인다 (나머지 절반)
진단 2 · 얼마나 또렷한가 ─ 실제 물체 방향 위에서 분리도 d′ 를 예측 · 실제 각각 잰다 → 분리도 비
   ▼
검증 ─ 같은 6 개 모델의 실제 영상 사라짐 · 나타남 정답률과 순서를 비교
```

- 진단 1 은 장면 단위로 둘로 나눠 한 번씩 학습 · 시험하고 평균 냈다 (같은 장면의 물체 · 빈 버전은 같은 쪽). 판별기는 실제 표현 시험에서 99.7–99.9 % 다.
- 진단 2 는 평균 요약 벡터만 쓴다. 학습하는 것이 없다 (방향 하나와 평균 · 분산뿐).
- 가능한 영상만 썼다 (불가능한 영상은 문맥과 미래를 이어 붙인 것이라 표현 분석에 쓰지 않는다).
- 물체가 다시 보이는 미래 블록 3–8 을 평균 냈다.
- **왜 실제 표현 기준인가** — 예측 표현에 직접 판별기를 학습하면, 물체가 아주 흐리게 남아 있어도 그 흐린 신호를 배워 거의 100 % 가 나온다 (4-4). 실제 표현을 자로 쓰면 "예측 속 물체가 실제 물체만큼 보이는가"를 잰다.

| 릴리즈 | 1.06 / 2.61 (0.41 배) | 0.97 / 1.87 (0.52 배) | 0.80 |
| AR | 1.11 / 3.30 (**0.34 배**) | 1.51 / 2.89 (0.52 배) | 0.64 |
| AR + L1 | 2.33 / 3.30 (0.71 배) | 1.93 / 2.89 (0.67 배) | 1.05 |

- 분리도의 실제 값이 계열마다 다른 것 (1.41 / 1.15) 은 실제 표현을 만드는 방식이 달라서다 (영상 전체 vs 블록마다). 그래서 계열 안의 실제 값으로 나눈 비를 쓴다.

### 4-3. 처방의 검증 [측정]

| 모델 | 분리도 비 | 실제 영상 사라짐 A | 실제 영상 나타남 B | 합성 VOBench v3 사라짐 / 나타남 (실물 모양 물체) |
|---|---:|---:|---:|---|
| 릴리즈 | 0.80 | 29.5 % | 81.1 % | 31.4 / 100 |
| 릴리즈 + L1 | 0.81 | 41.1 % | 74.7 % | 52.6 / 100 |
| 릴리즈 + 음의 손실 | 1.21 | 65.3 % | 63.2 % | 93.1 / 100 |
| AR | 0.64 | 36.8 % | 79.5 % | 89.8 / 84.0 |
| AR + L1 | 1.05 | 53.7 % | 78.9 % | 95.2 / 100 |
| AR + 음의 손실 | **1.31** | **71.6 %** | 75.8 % | 98.6 / 99.8 |

- **같은 데이터에서 L1 만으로도 분리도 비가 실제 수준 (1.05) 까지 오른다.** 실제 영상 사라짐은 53.7 % 에서 멈춘다.
- **음의 손실은 분리도 비를 실제보다 높게 (1.31) 올리고, 실제 영상 사라짐은 71.6 % 까지 오른다.**
- 6 개 모델에서 분리도 비 순서와 실제 영상 사라짐 순서는 한 자리 (릴리즈 ↔ AR 원판) 만 다르다. 순위 상관 0.94.
- **같은 처방, 다른 출발점:** 릴리즈 위에 걸면 사라짐 65.3 / 나타남 63.2 % (나타남 −17.9). AR 위에 걸면 71.6 / 75.8 % (나타남 −3.7).
- AR 계열은 합성 벤치 (VOBench v3) 가 L1 판에서 이미 천장 근처라 (95.2 / 100), 처방의 차이는 실제 영상에서 드러난다.

### 4-4. 대조: 예측 표현에 직접 판별기를 학습하면 [측정]

릴리즈 · AR 세 판 모두, predictor 12 개 층의 내부 표현과 예측 표현 어디서든 물체 장면 / 빈 장면을 98–100 % 가른다.
→ 물체 정보 자체는 모든 모델의 예측에 남아 있다. 문제는 그 정보가 실제 물체만큼 크고 또렷하게 그려지느냐다 (4-1 · 4-2).

## 5. 해석

- **진단 1 → 출발점:** 릴리즈는 가려진 물체를 예측한 미래에서 "없는 쪽"으로 그린다. AR 은 "있는 쪽"으로 그린다. 그래서 AR 에서 출발한다. [측정]
- **진단 2 → 모자란 것:** AR 의 물체 신호는 방향은 맞고 세기가 모자란다 (분리도 비 0.64). 정보가 없는 것이 아니라 (직접 판별기 98–100 %) 흐리게 그려진다. [측정]
- **원인 → 처방:** L1 은 가능 미래에 가까워지라는 신호만 준다. 채점이 읽는 "불가능 미래와의 차이"는 그 부산물이다. 음의 손실은 이 차이를 직접 요구한다. [이론] L1 이어 학습도 같은 데이터로 분리도를 실제 수준까지 올리지만, 실제 영상 사라짐은 음의 손실 판에서 18 %p 더 오른다. [측정]
- **왜 실제보다 더 또렷해야 실제 영상에서 듣는가:** 합성 장면에서 잰 여유가 실제 영상으로 넘어가며 줄어들기 때문일 수 있다. [추측] 실제 영상에서 분리도를 재야 확인된다.
- **왜 AR 위에 거는가 (성능 쪽 근거):** 같은 처방에서 나타남 손실이 릴리즈 −17.9 %p, AR −3.7 %p 다. [측정] 이 차이를 표현으로는 아직 설명하지 못한다 (아래 단서 3).

## 6. 단서

1. **진단은 합성 장면 (VOBench v3 늦은 가림) 에서만 했다.** 실제 영상의 예측 표현에서 분리도가 같은 순서인지는 안 쟀다. 실제 영상에는 짝을 이루는 빈 장면이 있어야 같은 분석이 된다.
2. **순위 상관 0.94 는 모델 6 개의 순서다.** 경향을 보여 줄 뿐, 분리도가 정답률을 정한다는 증거는 아니다. 실제 영상 정답률은 짝 95 개라 오차가 ±9–10 %p 다.
3. **빈 장면 쪽 지표는 실제 영상 나타남을 거꾸로 짚는다.** 합성 빈 장면 판정은 릴리즈 + 음의 손실 97.9 % · AR + 음의 손실 43.3 % 인데, 실제 영상 나타남은 63.2 % · 75.8 % 다. 그래서 나타남 쪽 설명에는 이 분석을 쓰지 않는다.
4. **부작용:** 음의 손실은 물체 신호를 키우면서 방향을 흐린다 (cos AR 0.90 → 0.60, 릴리즈 0.86 → 0.70). 실제 물체 방향이 아닌 성분도 같이 커졌다. 빈 장면 예측도 물체 쪽으로 민다 (확실한 "물체 있음" 9 → 35 %).
5. 블록마다 256 토큰을 평균 · 최대로 요약한 벡터다. 물체 영역 토큰만 본 분석이 아니다.
6. 판별기 (진단 1) 는 실제 표현에 맞춘 문턱을 쓴다. 예측 표현이 실제 표현과 전체적으로 어긋나 있으면 그 어긋남이 비율에 드러난다. 그래서 문턱과 무관한 AUC 와, 학습 없는 분리도 (진단 2) 를 같이 적었다.
7. 물체는 미래 블록 1–2 에서 다시 나온다. "오래 가려진" 경우는 시험하지 않는다.
8. "예측 ÷ 실제"로 읽는 값 중 세기의 비 (점수 비, 투영 이득, 벡터 길이 비) 는 CLAUDE.md 의 인용 금지 항목 (헤지 계수 α) 과 같은 계열이라 본문에서 뺐다. 분리도 비는 흩어짐으로 나눈 판별 지표라 α 와 다르다고 보지만, 논문 인용 전에 확인이 필요하다.
9. "L1 에는 불가능 미래와의 차이를 요구하는 항이 없다"는 손실의 정의에서 나오는 [이론] 이다. CLAUDE.md 는 목적함수를 **원인** 으로 거는 것을 경계한다 — 여기서는 원인 주장이 아니라 처방의 근거이고, 처방은 재학습으로 확인했다 (4-3).
