# 가설 · 실험 계획 R2 — 이식 실패 (Q1 · Q2) · PFT 비전이 (Q3) (2026-10-30, 가설 [H])

> **질문** — R1 뒤에 남은 것. Q1: 보이는 먼 미래의 이식 실패에서 "크기" 몫 (약 60 %) 을 뺀 나머지는 방향인가, 정보 감소인가. late 의 "메아리" 는 가려진 꼴인가, predictor 입력 encoder 의 꼴인가. Q2: 이식과 영속이 **모델이 만든 출력**에서도 갈리나. PFT 의 영속 이득은 물체 자리에 있나, 화면 전체에 있나. 정답 궤적 없이 정한 자리로도 되나. Q3: 외부 벤치가 안 오르는 이유는 채점 창 · 화면 공통 이동 · 입력 화소 통계 민감성 · 학습 생성기 · 진행 거리 외우기 중 무엇인가.
> **답 (계획)** — 활성 가설 21 개 (Q1 8 · Q2 5 · Q3 8), 실험 15 개 (E17 · E19–E32, E18 번호는 비움). 새 도구 셋: ① **판별 부분공간 이식** (h 의 판별 방향만 가져오고 축척 · 원점은 p 에 다시 맞춤) 과 그 파라미터 없는 짝 (반쪽 신뢰도로 보정한 클래스 평균 대비 cos). ② **채점 마진 분해 · 영역 교환** (사라짐 판정이 어느 칸에서 정해지나, PFT 이득이 어느 칸에 있나). ③ **PFT 가중치 보간 · 층 묶음 교환** (모델이 만든 중간 출력에서 이식과 영속이 같이 움직이나). Q3 는 이미 있는 자연 실험 (다른 데이터로 학습한 PFT) · 화면 공통 이동 빼기 · 외부 문맥 끝 판 · 입력 교차 2×2 · 진행 거리 추적으로 가른다. 새 predictor 학습은 없다.
> **다음** — [X1] 마진 분해 · 영역 교환 → 주입 격자 → 배율 곡선 → 판별 부분공간 → 메아리 대조 → 위치 판독기 → 보간 · 층 교환 (약 3.5 시간, GPU ≤ 4). [X2] 교차 생성기 · 외부 정렬 판 행렬 → 공통 이동 → sliding 가림 창 → 입력 교차 → 진행 거리 → (남으면) 문맥 끝 위치 스윕 · 대칭 잡음 (약 4 시간, GPU ≤ 4). 다시 학습해야 하는 시험 일곱은 사용자 결정 (§8).

수치 출처 표시: **[측정, R2 재계산]** = 이번에 [H] 가 산출물 (결과 JSON · 행 파일 · per_block) 에서 다시 센 값. **[측정, R 재계산]** = [R] R1 이 다시 센 값. "문서값" = 원 문서에서 옮긴 값.

| 통로 | O_끝 에서 O_참 까지 물체가 지나는 칸 전부 (두 영역 포함) |
| 영역 교환 | 정한 영역 칸만 PFT 출력으로, 나머지는 릴리즈 출력으로 짠 예측 (또는 반대) |
| 신탁 자리 | 정답 label 의 미래 궤적으로 정한 자리. 모델이 모르는 정보라 상한으로만 쓴다 |
| 화면 공통 이동 c | 튜블릿마다 256 칸 평균으로 낸 (PFT 출력 − 릴리즈 출력). 화면 전체가 같이 움직인 몫 |
| 가중치 보간 λ | predictor 가중치 (1 − λ)·릴리즈 + λ·PFT |
| 층 묶음 교환 | predictor 의 앞 · 가운데 · 뒤 블록 묶음 중 하나만 PFT 가중치로 바꾼 것 (또는 하나만 릴리즈로 남긴 것) |
| 문맥 끝 판 | 외부 벤치에서 문맥 끝을 위반 직전에 맞춘 고정 창 하나 (이미 있는 IntPhys 1 · 2 판) |
| 오프셋 δ | IntPhys 2 문맥 끝 판에서 사람 라벨 위반 시작 d 에 더한 장 수 (60 fps). 라벨 판 δ = 0, 라벨 −10 판 δ = −10 |

| 복사 기준선 | 문맥 encoder 마지막 튜블릿 (정규화) 을 미래 모든 튜블릿 예측으로 쓴 채점 |

## 기호

- i 영상, b block, t ∈ {8, …, 15} 미래 걸음, c ∈ {0, …, 255} 칸, d ∈ {1, …, 1280} 채널. LN = 학습 계수 없는 토큰 층 정규화.
- 특징 u_{i,t}(X; O) = LN( mean_{c∈O} LN(X_{i,t,c}) ). O = 화면 전체 (블록 평균판, 주) 또는 O_참 (물체 영역판).
- s(p; h) = mean_{t,c,d} |p − h| (표준 채점, 전체 토큰). 짝은 같은 문맥이라 p 가 같다.
- 우연 = 1/K (모양 6 · 색 8 · realistic 모양 6, VOBench index 에서 셈 [측정, R2 재계산]).

## 2. Q1 — 경쟁 가설 (방향 · 크기 · 정보 · 꼴 · 자리)

**왜 새 도구가 필요한가** [이론] — R1 의 κ 는 "h 이웃 걸음끼리" 를 천장으로 썼는데, h 의 정체 대비가 걸음마다 크게 바뀌어 천장이 p–h 값보다 낮았다. 그래서 방향을 판정하지 못했다. R2 는 (i) 표본을 클래스로 평균해 잡음을 줄이고 반쪽 신뢰도로 천장을 잰다 (파라미터 없음), (ii) 판별 부분공간만 옮겨 보는 판독 (학습, 자유도 작음) 으로 같은 질문을 다시 묻는다. 두 열이 맞을 때만 판정한다.

| id | 진술 | 상태 (R1 뒤) | 참이면 보일 것 | 거짓이면 보일 것 |
|---|---|---|---|---|
| **H1-S 크기 (등방 수축)** | p 의 정체 대비는 h 와 같은 방향인데 평균 토큰에 비해 작다 | **S2 지지** (배율만으로 R 0.63 / 0.60) | D ≥ 0.8 · κ_cls* ≥ 0.7 · ρ_cls ≤ 0.5 · 배율 곡선이 R ≥ 0.9 에서 포화 | D ≤ 0.4 또는 배율 곡선이 R 0.6 에서 멈춤 (나머지는 다른 이유) |
| **H1-D 방향 다름** | p 의 정체 정보가 h 의 판별 방향 밖에 있다 | 미정 (판정 불가였음) | D ≤ 0.4 · κ_cls* ≤ 0.4 | D ≥ 0.8 |

| **H1-F 비선형 꼴** | p 의 정체는 선형 판별로는 안 보이고 비선형 판독기로만 보인다 | 새 | attention p 판독 천장 − 선형 p 천장 ≥ 15 pt | 차 ≤ 5 pt |
| **H1-P 자리** | 정체는 있으나 참 자리가 아닌 곳 (마지막 본 자리 · p 가 둔 자리) 에 놓였다 | 사용자 판독기 실패의 원인은 아님 [이론, 판독기 위치 무시]. 자리 어긋남 자체는 실재 (S2 f 0.56) | 위치 판독기가 O_p · O_끝 에서 읽고 O_참 에서 못 읽음 (차 ≥ 15 pt) | 모든 자리에서 같거나 모두 낮음 |
| **H1-E1 가려진 꼴 메아리** | late p 는 encoder 가 가린 물체에 실은 꼴 (어느 encoder 든) 을 닮는다 | 약한 지지 → 쪼갬 | κ(Δz_7) ≈ κ(Δh_7) > κ(Δh_t), 보임 조건에서는 차이 없음 | 아래 둘 중 하나 |
| **H1-E2 입력 encoder 꼴 메아리** | p 는 가림과 무관하게 입력 (온라인 encoder) 의 꼴을 닮는다 | 새 (1-2 (a)) | late κ(Δz_7) − κ(Δh_7) ≥ 0.02 (CI 하한 > 0) **그리고** 보임 조건 S2 에서도 κ(Δz_끝) > κ(Δh_7) | 보임 조건에서 차이 없음 |
| **H1-E0 메아리 없음** | 차이는 탐색 · 영역 크기의 부산물이다 | 새 | z 바닥 (다른 block 의 Δz_7) 을 빼면 차이가 CI 안 | 바닥을 빼도 차이 유지 |
| H1-A 비등방 수축 | — | **기각** (주성분 지수 0.6–0.9) | — | — |
| H1-C 조건 특유 꼴 | — | **불성립** (late 맞춤 사상도 4–15 %) | — | — |
| H1-0 encoder 와 같은 꼴 | — | **기각, 크기 비로만** (S5 0.84–1.02 vs S2 0.21). 방향 판정은 E17 S5 로 | — | — |

- 가설은 배타가 아니다. **몫을 나눈다**: 크기 = 축척 몫 C, 방향 = 1 − D, 정보 = 1 − I.
- 수축 회귀 계수 (p ≈ a·h + b·μ 꼴) 는 쓰지 않는다 (인용 금지 α 분해와 같은 꼴, R1 §7 결정 대기). 이번 지표 (D · C · I · κ_cls · ρ_cls) 는 회귀 계수가 아니다.

## 5. 실험

### 5-0. 공통 규칙

- split v2 하나. 판독기 · 사상 · LDA 학습은 train block, 평가는 test block. PFT 수치는 test block 만. 릴리즈 파라미터 없는 측정은 모든 block.
- 판독 · 사상 학습은 가능 변이만 (CLAUDE.md §1-4). 채점은 matched pair · A / B 병기 · 복사 기준선 · **전체 토큰 채점이 주**.
- primitive · realistic 따로. realistic 색 · 결합은 쓰지 않는다 (원색 80 %).
- 통계: block bootstrap 2,000 (외부 벤치는 장면 묶음 4,000). 짝 비교는 같은 재표집. 캐시 (bfloat16) 채점은 공식과 짝 판정 92.6 % 일치 → VoE 는 같은 캐시 안의 Δ 로 읽는다. |Δ| < 1 pt 는 해석하지 않는다.
- 학습된 자 (LDA · 위치 판독기) 는 held-out · encoder 대조 · 파라미터 없는 교차검증을 같이 낸다 (CLAUDE.md §12-8).
- 결과 위치 · 스크립트 이름은 부록에만 둔다. 그림 라벨은 영어.

### E17. 판별 부분공간 이식 + 클래스 평균 대비 — Q1 의 중심 [X1] · CPU 약 40 분

**가르는 것**: H1-S · H1-D · H1-I · H1-F, S5 의 방향, late 판 (H1-E 의 크기 무관판).
**표본**: S1 · S2 (test 105 block / objset) · S4 (late 재등장, block 5 겹) · S5 (h 의 가린 튜블릿) · PFT S2 · S4 (test). 특징 u(X; 화면 전체) 가 주, u(X; O_참) 가 보조.
**학습 판정 (LDA)** — 축소 LDA (클래스 내 공분산 + λI, λ 는 train 의 20 % block 으로) 로 판별 부분공간 W_X (K−1 방향) 를 맞춘다.
- a = 그대로 이식: W_h · 클래스 평균 · 공분산 모두 h train → p test.
- b = 부분공간 이식: W_h 고정, K−1 차원 안의 클래스 평균 · 공분산만 p train 으로.
- c = p 천장: 모두 p train. d = h 기준: 모두 h train → h test.
- **D = (b − 우연) / (c − 우연) · C = (b − a) / (c − a) · I = (c − 우연) / (d − 우연)**. 비선형 꼴: (R1 attention p 천장) − c.
**파라미터 없는 판정** — 클래스 평균 m_k^X (test 표본), κ_cls = mean_k cos(m_k^p − m̄^p, m_k^h − m̄^h), 반쪽 신뢰도 r_X (block 반쪽끼리 같은 표현), **κ_cls* = κ_cls / √(r_h r_p)**, ρ_cls = ‖M^p − m̄^p‖ / ‖M^h − m̄^h‖.
**late 판** — W 의 원천을 넷으로 바꿔 late p 에 건다: h_t (참 미래) · z_7 (온라인 가림) · h_7 (EMA 가림) · z_끝 (온라인 마지막 보인). 각각 D_X. 천장 c 는 late 안 block 5 겹.
**대조 · 검증**: 라벨 섞기 (D 의 우연 분포) · h 반쪽끼리 D_hh (≥ 0.9 여야 지표가 쓸 만함) · S5 (W_h(보임) → h(가림)) · 판정이 E4 사다리 (배율 R 0.6) 와 맞는지.
**판정**: §2 판정표. 
**두 결과의 문장**: "h 의 판별 방향만 가져와 축척을 다시 맞추면 p 판독 천장의 D % 에 닿는다 — 이식 실패의 (C) 는 크기, (1 − D) 는 방향, (1 − I) 는 정보 감소다." 어느 값이어도 사용자 질문 (1) 에 수치로 답한다.

### E19. 배율 곡선 [X1] · CPU 약 5 분 ([R] 요청)

**공식**: M_k(p̃) = μ^p + k·γ_t (p̃ − μ^p), k ∈ {0.5, 1, 2, 3, 4, 8} · 영상 자기 평균판 m_i + k·γ_t (p̃ − m_i) · h 에 같은 꼴 μ + k(h − μ).
**낸다**: h 판독기 정확도 · R (S2 · S4 · PFT S2), h 에 건 판의 유지율.
**판정**: 포화 R ≥ 0.9 → 크기가 전부. 포화 R ≈ 0.6 → 나머지는 크기가 아님 (E17 로). h 판이 k ≥ 4 에서 90 % 아래로 떨어지면 포화점은 판독기의 배율 허용 한계로 적는다.
**두 결과의 문장**: "대비를 k* 배 키우면 h 판독기가 R 만큼 되살아나고 그 뒤 평평하다."

### E20. 위치 판독기 [X1] · GPU 1 · 약 40 분 ([R] 요청)

**왜 위치 임베딩 판독기 대신 패치 판독기인가** [이론 + 문서값] — 절대 위치 임베딩을 넣으면 판독기가 화면 자리 사전을 외운다 (v11 k = 0 위치 자 실패, CLAUDE.md §6). 패치 판독기는 읽을 자리를 **밖에서 준다** — 자리 사전을 외울 수 없다.
**구조**: 3×3 칸 토큰 (LN) → attention 풀링 (질의 1, 머리 16, 패치 안 상대 위치 9 개) → 정체 + '없음'.
**학습**: h, 보임 조건 · train block · 가능 변이. 양성 = 참 물체 중심 3×3. 음성 '없음' = 물체에서 3 칸 넘게 떨어진 무작위 3×3 (영상 · 걸음당 2 개).
**자 검증**: held-out h → h (참 자리) ≥ 85 % · 배경 '없음' ≥ 90 % · encoder 대조 (보임 조건 문맥 z 의 마지막 보인 자리) ≥ 80 % · 파라미터 없는 교차 (E2 자리 질량 순서 참 > 끝 이 판독 순서와 같은가).
**적용**: 릴리즈 p · PFT p · 배율 2γ 판 × 자리 셋 (O_참 · O_끝 · O_p) × S2 · S4.
**판정**: H1-P (S2) = O_p ≥ O_참 + 15 pt 이고 O_p ≥ 50 %. late: O_끝 ≥ 50 % · O_참 ≤ 20 % 면 "마지막 본 자리에 묶임"; 셋 다 ≤ 20 % (배율 판 포함) 면 "자리에 놓인 정체가 없다 (퍼짐)" — late 블록 평균 판독 72 % 와 함께 읽는다.
**두 결과의 문장**: "h 로 배운 위치 판독기는 p 의 정체를 참 자리에서 X %, 마지막 본 자리에서 Y %, p 가 둔 자리에서 Z % 읽는다."

### E21. 메아리 대조 [X1] · GPU 1 · 10 분 (추출) + CPU 20 분 ([R] 요청)

**가르는 것**: H1-E1 · H1-E2 · H1-E0.
**추출**: 보임 조건 (visible · early · mid) 이동 모양 · 색 block 의 두 팔 문맥 z (온라인), 280 block × 2 = 560 영상, 8 튜블릿.
**공식** (late 는 R1 의 κ_O 그대로, 영역 규칙 하나 추가):

- (b) encoder 종류: κ_O(Δp_t, Δz_7) vs κ_O(Δp_t, Δh_7) (이미 있음, 1-2 (a)).
- (c) 보임 조건: S2 의 Δp_t 대 {Δz_끝 (온라인, t7, 보임), Δh_7 (EMA, 같은 튜블릿), Δh_t (참 미래)}.

**두 결과의 문장**: "late p 의 정체 대비는 (입력 encoder 의 꼴 / 가려진 꼴 / 어느 것도 아닌 것) 을 닮는다 — 보임 조건 대조에서 같은 순서가 (나온다 / 안 나온다)."

### E22. 채점 마진 분해 [X1] · CPU 약 15 분

**가르는 것**: H2-6 (파라미터 없는 쪽), Q2 "무엇을 고쳐야 A 가 뒤집히나".
**공식**: m = (s(imp) − s(pos)) / s(pos) = Σ_R m_R, m_R = Σ_{t, c∈R_t} Σ_d (|p − h_imp| − |p − h_pos|) / (N · s(pos)). R ∈ {O_참, O_끝 \ O_참, 통로의 나머지, 나머지 칸}. N = 8 · 256 · 1280.
**예측**: 릴리즈 · PFT · 복사 · R1 주입 d1 · d3 · 배율 2γ 판.
**대상**: late 이동 permanence A · B (릴리즈 60 / PFT test 30), 모양 · 색 A (60 / 30), 보임 조건 permanence (대조).
**낸다**: m_R 중앙값 · "O_참 만으로 부호가 정해지는 짝" 비율 · PFT − 릴리즈 마진 변화 Δm 의 영역별 몫.
**판정**: Δm 의 ≥ 60 % 가 통로 → "PFT 이득은 물체 자리에서". 나머지 칸 ≥ 60 % → "화면 전체에서" (운반 해석 약화).
**두 결과의 문장**: "릴리즈가 사라짐 A 를 틀리는 마진 (−1.9 %) 의 X % 는 물체 통로에서, Y % 는 나머지 칸에서 온다. PFT 는 그것을 각각 …만큼 바꿨다."

### E23. 영역 교환 [X1] · CPU (E22 와 같은 작업) ([R] 요청: 크기 몫 vs 자리 몫)

**공식**: p_mix(R) = R 칸은 PFT, 나머지 칸은 릴리즈 (+ 반대 판). R ∈ {O_참, O_참 한 칸 넓힘, 통로, 나머지, 전부}. 두 출력은 같은 캐시 경로 (bfloat16) 에서 왔다.
**대상**: late 이동 permanence A · B (test 30), 모양 · 색 A (test 60), 보임 조건 전체 (부작용).
**판정**: A(통로만 PFT) ≥ 80 이고 A(나머지만 PFT) ≤ 30 → 물체 자리. A(나머지만 PFT) ≥ 70 → 화면 전체. 둘 다 30–70 → 나눠 갖는다.
**두 결과의 문장**: "PFT 출력을 물체 통로에만 넣으면 사라짐 A 가 X %, 나머지 칸에만 넣으면 Y % 다."

### E24. 주입 격자 (신탁 없는 자리) [X1] · CPU 약 30 분 ([R] 요청)

**내용 셋**: (z) 마지막 보인 문맥 튜블릿 z 의 물체 칸 (R1 d2 · d3) · (p1) 릴리즈 p 가 O_p 에 둔 자기 토큰 · (p2) 그 대비를 2γ 배.
**자리 넷**: O_끝 · O_p (릴리즈가 둔 자리 = 존재 대비 최대, 출력만 씀) · **O_등속** (마지막 보인 두 문맥 튜블릿 중심으로 등속 외삽, 문맥 label 만 씀 = 관측 가능) · O_참 (신탁, 상한).
**PFT 되돌림 (test 30)**: (i) PFT 의 O_참 물체 토큰을 O_끝 으로 옮기고 O_참 은 빈 장면 문맥의 PFT 예측으로 채움 · (ii) PFT 물체 영역 대비를 릴리즈 크기로 줄임 (ρ 비) · (iii) 둘 다.
**같이 잴 것 (R1 공백, 사용자 전제)**: late 문맥 encoder 가 가려진 물체의 **속도**를 읽나 — z_6 · z_7 (블록 평균 · O_끝) 에서 문맥 끝 속도 (가로 · 세로, label) 를 ridge, block 5 겹 R². 보임 조건 (E21 추출) 과 비교.
**지표**: 사라짐 A · B, 모양 A, 운동 종류별 (등속 · 가속 · 감속 · 경사 내림 · 경사 오름, 각 12 쌍), E20 위치 판독기 판독.
**판정**: H2-4 = A(z, O_등속) ≥ 복사 − 5 (약 62) 이고 A(z, O_참) 와 10 pt 안. 등속 칸만 되면 "1 차 외삽은 등속에서만". H2-5 = A(p2, O_p) ≥ 50. PFT 되돌림: (i) 로 A ≤ 30 → 자리 몫, (ii) 로 ≤ 30 → 크기 몫, (iii) 에서만 → 둘 다 필요. 속도: R² ≥ 0.8 → "late 에서도 encoder 가 속도를 읽는다" · ≤ 0.3 → 사용자 전제 수정.
**두 결과의 문장**: "문맥의 정체를 정답 없이 등속 외삽 자리에 두면 사라짐 A 가 X % (신탁 자리 Y %, 복사 Z %)."

### E25. 가중치 보간 · 층 묶음 교환 — 모델이 만든 출력에서 이식 vs 영속 [X1] · GPU 2 · 약 1 시간

**왜** — [R] 의 지적대로 E7 의 "읽힘 ≠ 영속" 은 판독기 · 채점의 구성상 성질이다. 사람이 짠 토큰이 아니라 **predictor 자신이 만든** 출력에서 둘이 갈리는지 봐야 Q2 에 답한다. 학습은 없다 (가중치를 섞기만 한다).
**변이 11 판**: λ ∈ {0, 0.25, 0.5, 0.75, 1} · 묶음 셋 (입력 사상 + mask token + 블록 0–3 / 블록 4–7 / 블록 8–11 + 끝 정규화 + 출력 사상) 중 하나만 PFT (셋) · 하나만 릴리즈 (셋).
**판마다 지표** (test block): h 판독기 이식 (S2 t11–15 · late 재등장) · ρ_O · 따라감 f (S2 · late) · late 이동 사라짐 A · B (30) · 모양 · 색 A (60) · VOBench test 전체 정확도 · ε. 전체 p 는 저장하지 않는다.
**판정 (H2-7)**: 분리 판이 있으면 "이식과 영속은 모델 출력에서도 갈린다 → 이식은 영속의 충분조건이 아니다 (구성이 아닌 증거)". 없고 순위 상관 ≥ 0.8 이면 "둘은 같이 온다 — 이 모델 계열에서는 뗄 수 없다". 어느 묶음이 이식 · A · 공통 이동 (E27) 을 각각 움직이나도 같이 적는다.
**두 결과의 문장**: 위 둘 중 하나. 어느 쪽이어도 Q2 의 "이식을 고치면 영속이 풀리나" 에 모델 출력 수준으로 답한다.

### E27. 화면 공통 이동 [X2] · CPU 20 분 + GPU 2 · 45 분 ([R] 요청)

**공식**: c_{i,t} = (1/256) Σ_c (p^PFT − p^rel)_{i,t,c} ∈ ℝ^1280. c̄_D = 세트 D 평균.

**두 결과의 문장**: "PFT 의 화면 공통 이동을 빼면 외부 ε 가 X → Y, VOBench late A 는 Z." ⚠️ 고정 창이라 Garrido 수치와 비교하지 않는다 (CLAUDE.md §1-3).

### E30. IntPhys 1 sliding — 문맥 끝이 가림 안인 창만 [X2] · CPU 30 분 ([R] 요청)

**공식**: 영상별 가림 구간 (OcclusionStats) 으로 창 w 를 나눈다. 문맥 끝 샘플 e_w 가 가림 구간 안이고 그 구간이 미래로 이어지면 "문맥 끝 가림 창". 창 단위 surprise 로 쌍 판정 → 릴리즈 vs PFT, 장면 bootstrap. 창 비율 · Garrido 집계에서 그 창의 가중.
**판정**: 문맥 끝 가림 창에서 G ≥ +10 (CI > 0) 이고 나머지 창 ≈ 0 → H3-W · H3-E ("효과는 있는데 표준 채점이 희석"). 그 창에서도 0 → "IntPhys 1 의 짧은 가림 (이동 0.2 초, skip 2 에서 1–3 장) 에서는 효과가 없다".
**두 결과의 문장**: "IntPhys 1 sliding 창 중 문맥 끝이 가림 안인 창은 X % 이고, 그 창에서 PFT 이득은 Y 다."

### E31. 입력 파이프라인 민감성 [X2] ([R] 요청)

- **(a) 기존 산출물** · CPU 15 분: 재양자화 판 − 원본 판의 영상 surprise 이동 (절대 · 상대), IntPhys 1 (NF 채점) · VOBench (E12 T0 vs 원본). 기준 오차에 대한 회귀 (분모 착시 검사).
- **(b) 입력 교차 2×2** · GPU 1 · 30 분: VOBench test 360 영상 (조건 층화). z ∈ {원본, 재양자화} × h ∈ {원본, 재양자화}, 릴리즈 · PFT. 문맥 쪽 몫 = s(z_T0, h_원) − s(z_원, h_원), 목표 쪽 몫 = s(z_원, h_T0) − s(z_원, h_원), 교호. 출력 민감도 = ‖p(z_T0) − p(z_원)‖₁ / ‖p(z_원) − h‖₁.
- **(c) 대칭 잡음 (남으면)** · CPU 30 분 (프레임) + GPU 4 · 1 시간: 확률적 반올림 시드 4 개. IntPhys 1 (Garrido w32, 하네스) · VOBench test (한 번 통과 경로). 정확도 분포 · (PFT − 릴리즈) 분포 · 뒤집힘 방향 (시드를 모은 부호 검정) · 체계적 surprise 이동.
**판정**: H3-L = (b) 문맥 쪽 몫이 PFT 에서 릴리즈의 3 배 이상 · 출력 민감도 2 배 이상, (c) 뒤집힘 몰림 p < 0.05. H3-L0 = 목표 쪽 몫이 지배 · 절대 이동이 같음. (c) 의 PFT − 릴리즈 분포가 IntPhys 1 보고 하락 (−5.6) 을 포함하면 "하락은 잡음 바닥 안", 분포가 0 아래로 몰리면 "하락은 실제".
**두 결과의 문장**: "눈에 안 보이는 입력 차이에 대한 PFT 의 반응은 (predictor 출력 쪽 / 채점 분모 쪽) 에서 온다."

### E32. 진행 거리 · 방향 끌림 [X2] · GPU 1 · 30 분 (R1 계획 E14 를 다시 설계)

**왜** — 사용자 Q3 의 "진행 방향" 을 직접 잰다. E12 의 역재생 · 보폭은 점수만 봤다.
**공식**: 존재 대비 지도 Δx_t = x(물체 문맥) − x(빈 문맥) (같은 block 두 가능 영상). 참 자리 = Δh_t 에너지 최대 3×3 (label 불필요), 예측 자리 = Δp_t 에너지 최대 3×3. 진행 거리 d̂ = |예측 자리_t15 − 마지막 본 자리|, 참 d 도 같은 방식. 기울기 b (d̂ = a + b·d) · 방향 일치 (부호) · 끌림 비율 = |d̂ − 5.7| < |d̂ − d| 인 영상 비율 (5.7 칸 = VOBench 전형 진행 거리 중앙값, R1 label 에서 셈).
**관문**: VOBench 에서 Δh 자리가 label 과 1 칸 안 ≥ 90 %.
**세트**: VOBench test (대조) · v11 부분 late 이동 · v11 실물 메시 · VOBench 보폭 2 판. 릴리즈 · VOBench PFT.
**판정**: H3-V = v11 · 보폭 2 판에서 PFT b ≤ 0.5 · 끌림 ≥ 70 %. 거짓 = b ≥ 0.8 · 방향 일치 ≥ 90 %.
**두 결과의 문장**: "VOBench PFT 는 다른 세트에서 미래 물체를 (문맥의 운동대로 / VOBench 전형 거리 쪽으로) 옮긴다 (b = …)."

## 8. 사용자 결정이 필요한 것

1. **다시 학습해야 답이 나오는 Q3 시험 (설계만)** — 각 약 35 분, GPU 4 장 (처음 보는 물체 PFT 학습 시각 기준).
   - (a) **late 를 뺀 PFT** (visible · early · mid 만): late 이득이 생기면 운반 능력, 안 생기면 late 배치 외우기. 가장 직접적.
   - (b) **배경을 뺀 PFT** (assets 배경만 학습 → VOBench v11 배경 test · v11): H3-S 장면 외우기 시험. E11 의 겹침 (54 %) 을 푼다.
   - (c) 보폭을 섞은 PFT · (d) 창 위치를 섞은 PFT: E12 의 "약 1/5" 이 데이터 다양성으로 막히나.
   - (e) **시드만 다른 VOBench PFT** (2 개): 갱신 방향 cos 0.92–0.97 의 대조, 그리고 E25 · E27 결과의 시드 의존성.
   - (f) 입력 파이프라인을 섞은 PFT (재양자화 · 다른 축소 커널 증강): H3-L 이 서면 그 처방 시험.
   - (g) 외부 벤치 데이터 PFT 의 학습량 맞추기 (IntPhys 1 late 창 PFT 는 200 step): E26 의 역방향 비교를 공정하게.
2. G0 관문 — 공식 정밀도 (float32 + float16 autocast) 로 다시 뽑을지 (R1 부터 대기).
3. "외부 벤치 비교에 잡음 바닥" 규칙을 CLAUDE.md 에 넣을지 — 넣는다면 E31c 의 대칭 잡음 시드로 정의.
4. VOBench split v2 릴리즈 기준값 정본 75.69 (하네스) · 75.97 (한 번 통과).
5. 수축 회귀 계수 표기 (R1 대기) — 이번 계획은 계수를 안 쓴다.
6. vast AR 토큰 단위 Q1 (R1 대기, GPU 약 1.5 시간) — E17 · E20 도구가 생기면 같은 도구로 R3 에 넣을지.

## 9. 하지 않는 것 · 이미 답이 있어 반복하지 않는 것

- 정렬 사다리 (E4) · 정렬 재채점 (E6) · 문맥 튜블릿 바꿔 넣기 (E8) · 처음 보는 물체 채점 (E10) · 변환 다섯 (E12) 은 다시 하지 않는다.
- 좌우 반전 · 시작 프레임 이동은 PFT 증강에 있어 Q3 시험이 아니다.
- realistic 색 · 결합 수치는 쓰지 않는다.
- "세기를 키우면 된다" 는 v11 에서 기각됐다 (천장 51–65 %). E19 · E24 의 배율 판은 측정 도구다.
- 회귀 계수 · α · 보정 · 헤지 계수 인용 금지. 수축의 원인으로 목적함수를 걸지 않는다.
- 금지 표현: "p 에 정체가 없다" (→ "h 판독기로는 안 읽힌다"), memory · state 프레임, "중력을 안다", "predictor 가 X 를 못 만든다".

## 10. 계획 시점에 모르는 것 · 단서

- E17 의 LDA 는 표본 875 / objset 에 1280 차원이라 축소 강도에 민감할 수 있다. λ 를 train 안에서 고르고, 결과가 λ 두 배 · 반에서 바뀌면 경계로 적는다.
- E20 패치 판독기의 '없음' 클래스는 배경 표본 규칙에 의존한다. h → h '없음' 이 90 % 안 되면 판정을 내지 않는다.
- E25 의 보간 판은 학습된 적 없는 가중치다. 출력이 깨지면 (ε > 1.1) 그 판은 뺀다.
- E27 은 고정 창 c16t32 라 IntPhys 1 Garrido 수치와 비교하지 않는다.
- E28 · E29 의 IntPhys 2 판은 문맥이 화소로 같지 않다. 판 사이 쌍 판정 일치율 (72–80 %) 자체가 창 민감도의 크기다.
- 사라짐 A 의 PFT 칸은 test 30 쌍이다 (0 / 30 의 95 % 상한 약 12 %). +30 pt 미만은 판정하지 않는다.
- IntPhys 1 late 창 PFT 의 학습량 (200 step) 이 작아 1-2 (c) 의 역방향 증거는 약하다.
