# Q1 · Q2 — 이식 실패는 방향인가 크기인가, 맞추면 영속이 풀리나 (2026-10-30, 실험 A [X1], 1 라운드)

> **R2 갱신 (2026-10-30, 정본은 `Q1Q2_REPRESENTATION_R2.md`)** — **질문**: 같다. **답**: 방향은 같다 (장면을 뺀 화면 평균에서 p · h 정체 방향이 잡음 천장까지 일치). 보이는 먼 미래의 크기 몫은 60–75 % 이고 대비 2 배에서 포화한다. 나머지는 꼴이다 — 릴리즈 p 의 먼 미래 · late 정체는 물체 자리 패치에 없고 화면 전체에 퍼져 있다 (위치 판독기 0–10 %). 이식은 영속의 지렛대가 아니다: 보이는 먼 미래 이식은 영속 없이 63–70 % 까지 오르고, late 에서는 둘이 같은 가중치 변화 (블록 0–7) 로 함께 생긴다. 표준 채점의 사라짐 판정은 물체 칸 없이도 뒤집힌다 (93 %). **다음**: vast AR 같은 표 · 사건으로 꺾이는 세트에서 주입.
> 아래 R1 본문의 정정 셋은 줄 옆 "⚠️ 정정 (R2)" 와 R2 문서 §11 에 있다. 아래 R1 요약의 "스칼라 하나" 는 "배율 (2 배 포화)" 로 고쳐 읽고, "가려진 꼴의 메아리" 는 철회한다 (R2 §4: 같은 영역으로 맞추면 참 미래와 구분 안 됨).


> **질문** — encoder 출력으로 배운 판독기가 predictor 출력에서 안 읽힌다. 표현 벡터의 방향이 다른가, 크기가 다른가, 꼴 자체가 다른가 (Q1). 읽히게 맞추면 object permanence 가 풀리나 (Q2).
> **답** — 조건마다 다르다. **보이는 먼 미래에서는 대부분 크기다**: 평균 토큰에서 벗어난 정도를 걸음마다 스칼라 하나 (약 1.8 배) 로 키우면 [⚠️ 정정 (R2) — 칸별 평균 토큰 바꿈 + 걸음별 배율이었다. 배율만으로 같은 회복, 2 배에서 포화 (R2 §1)] 이식 실패의 약 60 % 가 되살아나고, 회전을 더해도 0.1 안팎만 는다. **late (문맥 끝 가림) 에서는 크기도 회전도 아니다**: 어떤 토큰별 사상도 못 되살리고, 예측의 정체 대비는 참 미래보다 **가려진 마지막 문맥 튜블릿의 꼴**을 더 닮았다. **읽히게 만들어도 영속은 안 풀린다**: 판독을 99 % 로 되살린 물체 토큰을 마지막 본 자리에 두면 사라짐 방향 정답은 10 % 그대로이고, 같은 토큰을 참 미래 자리로 옮겨야 72 % 가 된다.
> **다음** — (1) 위치를 쓰는 판독기 (위치 임베딩을 넣은 판독기) 로 "자리" 몫을 다시 잰다 — 지금 판독기는 구조상 자리를 못 본다. (2) PFT 가 크기와 자리를 같이 바꿨으므로, 둘을 떼어 보는 개입 (크기만 키운 p 를 참 자리로 옮기기) 을 R2 에 둔다. (3) 정밀도 관문 (G0) 이 실패해 VoE 는 Δ 만 보고했다 — 공식 정밀도 (float32 + float16 autocast) 로 다시 뽑을지 [L] 결정.

| 릴리즈 · PFT | 공개 predictor · 그것을 VOBench split v2 train + gravity 로 이어 학습한 판 |
| 칸 · 튜블릿 · 걸음 | 칸 = 16×16 공간 토큰 하나 (512 px 프레임에서 32 px). 튜블릿 (걸음) = 연속 2 샘플 |
| 보임 조건 · late | 보임 조건 = visible · early · mid (문맥 끝에서 물체가 보인다). late = 문맥 끝 k 샘플과 미래 앞 k 샘플이 가려짐 (k = 1–3) |
| S1 · S2 · S4 | S1 = 보임 조건 · 이동 · 미래 t8–10 / S2 = 같은 조건 t11–15 (보이는 먼 미래) / S4 = late · 이동 · 다시 보이는 걸음 |
| h 판독기 | h 의 보이는 튜블릿으로 학습한 정체 판독기 (attention 풀링 한 층, 클래스 = 모양/색 결합 + 없음). 사용자가 말한 "encoder embedding 으로 학습한 probe head" |
| p 판독기 | 보임 조건 p 로 학습한 같은 구조 판독기. p 안의 정보 천장 |
| late 안 판독기 | late 의 p 로 학습 · 시험한 모양 판독 (선형, block 5 겹 교차검증) |
| 쌍 차이 Δ | 같은 block 의 두 가능 영상 A · B (같은 장면 · 같은 궤적, 물체만 다름) 의 표현 차이. 모양 · 색 block = **정체 대비**, permanence block = **존재 대비** (물체 − 빈 장면) |
| ρ_O | 물체 영역에서 ‖Δp̃‖ / ‖Δh‖. 판독기가 보는 정체 대비의 상대 크기 |
| κ_O | 물체 영역에서 Δh 의 꼴을 Δp̃ 안에서 찾았을 때의 최대 cos (칸 평행 이동 가로 ±9 · 세로 ±3). 방향이 같은 정도 |
| 따라감 f | Δp̃ 의 정체 대비가 참 이동을 얼마나 따라갔나. 1 = 참 자리, 0 = 마지막으로 보인 자리에 머묾 |
| 정렬 사상 | p̃ 를 h 공간으로 옮기는 함수. 보임 조건 · train block 짝으로만 맞춘다. 사다리 단: 채널별 평균·분산 → 전역 대비 스칼라 (걸음별) → 주성분별 대비 → 직교 회전 (Procrustes) → 일반 선형 (ridge) → 비선형 (작은 MLP) |
| 회복률 R | (사상 뒤 h 판독기 정확도 − 사상 전) ÷ (p 판독기 정확도 − 사상 전) |
| 사라짐 방향 A | permanence late 의 matched 짝 (물체가 있던 문맥 → 빈 미래 가 불가능). 릴리즈 late 이동에서 0–8 % |
| 복사 기준선 | 문맥 encoder 의 마지막 문맥 튜블릿을 미래 모든 걸음 예측으로 쓴 채점 |

## 0. 관문과 판독기 (E1 · E3)

**왜** — 뒤 실험이 쓰는 캐시 (bfloat16) 채점이 공식 채점과 같은지, 새 split 으로 다시 맞춘 판독기가 R1 의 꼴을 재현하는지 먼저 본다.

**어떻게** — 캐시로 표준 채점 (전체 토큰 L1) 을 다시 내 공식 영상별 surprise 와 짝 판정을 맞췄다 (G0 릴리즈, G3 PFT). A · B 두 팔의 궤적이 같은 칸 안인지 label 에서 셌다 (G1). 판독기는 split v2 train block 으로 시드 둘을 학습했다.

- [측정] R1 의 꼴 (보일 때 가까운 미래는 이식됨, 먼 미래 · late 는 안 됨, PFT 뒤 late 이식 0 → 74–85 %) 이 split v2 에서 재현된다.
- [측정] realistic 의 결합 · 색 정확도는 원색 다수 클래스로 부풀려진다 (R1 고정). 그래서 realistic 은 모양 열로만 읽는다.
- ⚠️ [측정] primitive 의 같은 시점 판독기 (걸음 하나만으로 학습, 252 표본 · 49 클래스) 는 같은 걸음의 h 조차 46–61 % 만 읽는다. 학습 부족이라 primitive S3 는 해석하지 않는다.

## 1. Q1 — 쌍 차이 지도 (E2 · 파라미터 없음)

**왜** — 판독기를 끼우지 않고, 같은 장면 · 같은 궤적에서 물체만 다른 두 영상의 차이로 "정체 대비" 만 떼어 낸다. 그 대비가 p 에서 h 보다 작은가 (크기), 다른 방향인가 (방향), 다른 자리에 있나 (자리) 를 따로 잰다.

**어떻게** — block 마다 걸음 t8–t15 에서 Δh 와 Δp̃ 를 만들었다. 물체 영역 (참 자리의 외곽 상자 + 1 칸) 에서 크기 비 ρ_O, 같은 자리 cos (κ_O 고정), 자리를 맞춘 cos (κ_O 이동), 따라감 f, 대비 에너지가 참 자리 · 마지막 본 자리에 있는 몫, 그리고 Δp̃_t 가 가장 닮은 참 걸음 (τ*) 을 냈다. 바닥 = 같은 조건의 다른 물체 block 의 Δh 와의 κ_O. 대조 S5 = encoder 안에서 가린 튜블릿의 Δh 를 가장 가까운 보이는 튜블릿의 Δh 와 비교. 통계는 block bootstrap 2000.

**해석**
- [측정] p 의 정체 대비는 **보일 때도 h 의 1/3 크기**다 (S1 ρ_O 0.33). 그런데도 S1 에서는 h 판독기가 읽힌다 (89–91 %). 먼 미래로 갈수록 크기가 더 줄고 (0.21), 같은 자리 방향 일치가 바닥 쪽으로 내려가며 (0.07 vs 0.04), 대비가 참 이동의 절반쯤에서 뒤처진다 (f 0.56). Δp̃_t 는 4–5 걸음 앞 (문맥 끝 무렵) 의 Δh 를 가장 닮았다.
- ⚠️ 정정 (R2, 지우지 않음) — 아래 문단의 "late 정체 대비는 참 미래보다 가려진 마지막 문맥 튜블릿의 꼴을 더 닮는다" 는 비교 대상마다 다른 탐색 영역 (각자의 물체 영역) 에서 나온 순서다. R2 E21 에서 모든 대상에 같은 영역 (Δp 에너지 최대 3×3) 을 쓰면 참 미래 0.123 · 가린 t7 0.119 · EMA t7 0.115 로 구분되지 않는다 (차 0.003 [−0.002, 0.009]). "가려진 꼴의 메아리" 는 철회한다. 정본은 `Q1Q2_REPRESENTATION_R2.md` §4.
- [측정] late 재등장에서는 같은 자리 방향 일치가 바닥 수준이다 (0.03 vs 0.04). 그리고 정체 대비는 참 미래보다 **가려진 마지막 문맥 튜블릿의 꼴 (Δz_t7)** 을 더 닮았다 (0.095 vs 0.061, CI 겹치지 않음). 가려진 꼴은 encoder 안에서도 보이는 꼴과 거의 직교다 (S5 0.02–0.05, Δz_t7 vs Δh_t 0.05). PFT 는 이 순서를 뒤집는다 (참 미래 0.137 > 가려진 꼴 0.061).
- [측정] 존재 대비는 다르다. 릴리즈 late 에서도 참 미래를 가장 닮는다 (0.188 > 0.134). 크기가 0.18 로 작을 뿐이다.

- ⚠️ [측정] **h 의 정체 대비는 물체 칸에 몰려 있지 않다.** 정체 block 의 Δh 에너지는 유효 칸 약 130 개에 퍼져 있고, 물체 영역 (평균 32 칸, 전체의 12.5 %) 의 몫은 10 % 뿐이다 (존재 대비는 유효 칸 176 개, 물체 영역 16 %). 물체 하나를 바꾸면 encoder 토큰 전부가 조금씩 바뀐다 [추측: 32 장 전체 attention]. 전체 칸 지표 (ρ · κ) 는 이 퍼진 성분이 지배하므로 위 표는 물체 영역판을 주로 쓴다. 물체 영역판도 대비 에너지의 일부만 본다는 한계가 있다.

- [측정] 모양 위반에서도 같은 꼴이다 (d2 57 → d3 82). 다른 물체를 참 자리에 두면 (d4) 32 % 로 내려간다 → 모양 판정에는 정체도 필요하다. 색 위반은 d4 가 원값과 같다.
- [측정] permanence 의 d4 는 B 팔이 빈 장면이라 "참 자리에 아무것도 없음" 이 된다. 계획의 "d4 ≈ d3 이면 '어디에 무언가'" 비교는 permanence 에서 성립하지 않는다 (설계 결함, 기록).
- [이론] 표준 채점은 칸마다의 L1 평균이다. 물체 칸이 참 자리에 있어야 짝 미래와의 거리 차가 생긴다. 판독기가 읽는다고 그 차가 생기지는 않는다. 그래서 "이식" 은 영속 채점의 충분조건이 아니다.

## 6. Q2 — 문맥 토큰 바꿔 넣기: 미래의 정체는 어느 문맥 튜블릿에서 오나 (E8)

**왜** — 문맥 encoder 는 가린 튜블릿에도 물체 모양을 싣는다 (62–66 % 판독, R1). predictor 가 그 채널을 쓰나, 아니면 마지막으로 보인 튜블릿에서만 가져오나 (H2-2).

**어떻게** — 모양 · 색 block 전부 (480) 에서 A 영상의 문맥 z 중 튜블릿 집합 J 만 같은 block B 영상의 것으로 바꿔 릴리즈 predictor 에 넣었다. π_J = 예측이 B 쪽으로 움직인 비율 (미래 전 칸, 그리고 물체 영역). 건전성: J 없음 π = 0, 전부 π = 1 (실측 최대 편차 0.0 / 0.0).

**결과** [측정, 이동 block, 두 objset 합, π (전 칸) / π (물체 영역)]

| 조건 (가림 튜블릿) | 가린 튜블릿 J_가림 | 마지막으로 다 보인 튜블릿 J_끝 | 보인 튜블릿 전부 |
|---|---|---|---|
| visible (가림 없음, J_끝 = t7) | — | 0.34 / 0.53 | 1.00 |
| early (가림 t2–t4) | 0.18 / 0.08 | t7: 0.37 / 0.56 | 0.82 / 0.92 |
| mid (가림 t4–t6) | 0.23 / 0.16 | t7: 0.39 / 0.59 | 0.77 / 0.84 |
| **late k = 2 (t7 만 완전히 가림)** | **t7: 0.26 / 0.38** | t6: 0.10 / 0.11 | 0.74 |
| late k = 1 (t7 반 가림) | 0.28 / 0.42 | t6: 0.10 / 0.10 | 0.72 |
| late k = 3 (t6 반 · t7 가림) | 0.38 / 0.50 | t5: 0.08 / 0.08 | 0.62 |

- late 안 판독기 (train block 의 원래 late p) 로 읽으면, t7 만 바꿔도 B 의 모양으로 읽히는 비율은 거의 안 는다 (primitive 36 → 44 %, realistic 36 → 36 %). 보인 튜블릿 전부를 바꾸면 67 / 53 %.

**해석**
- [측정] **H2-2 (가린 정체 채널을 안 쓴다) 기각.** late 에서 완전히 가려진 마지막 문맥 튜블릿 t7 하나만 바꿔도 예측의 물체 영역이 B 쪽으로 38 % 움직인다 (사전 기각선 0.3 이상). 마지막으로 보인 튜블릿 t6 은 10 % 다.
- [측정] 모든 조건에서 **마지막 문맥 튜블릿이 가장 큰 몫**을 준다 (가림이 없을 때 t7 0.34 / 0.53). late 에서도 그 자리 (t7) 가 가려져 있을 뿐 같은 규칙이다. 기존 "anchor 이식" (미래는 마지막 문맥 블록에서 온다, 10-13) 과 같다.
- [측정 + 추측] E2c 와 합치면: late 예측은 가려진 t7 의 정체를 가져오되 **가려진 꼴 그대로** 가져온다 (Δz_t7 를 가장 닮음). 그 꼴은 보이는 꼴과 거의 직교라 h 판독기가 못 읽는다. late 안 판독기의 블록 평균 판독이 복사 판독과 구분되지 않는 것과도 맞는다. [추측] 그래서 late 의 이식 실패는 "크기" 가 아니라 **"가려진 꼴의 메아리"** 로 보는 것이 가장 간단하다.

## 7. 종합 — 사전 판정표에 넣으면

**Q1** (방향 · 크기 · 자리 · 꼴)

| 시나리오 | 파라미터 없음 (E2 · E2c · E3) | 학습된 사상 (E4) | 판정 |
|---|---|---|---|
| S1 보이는 가까운 미래 | ρ_O 0.33, 자리 맞음 (f 0.98) | 사상 없이도 천장 이상 | 실패 아님 (이미 이식됨) |
| **S2 보이는 먼 미래** | ρ_O 0.21 · 주성분 평평 · 방향 판정 불가 · 자리 뒤처짐 (f 0.56) | 스칼라 / 채널별에서 처음 R ≥ 0.5, 회전 증분 ≤ 0.1 | **크기 (등방 수축), 조건부.** 자리 어긋남은 있으나 이 판독기의 실패 원인은 아님 |
| **S4 late 재등장** | 방향 일치 바닥 수준 · 가려진 t7 꼴을 더 닮음 · late 안 판독 ≈ 복사 | 어느 단도 못 함, late 맞춤도 못 함 | **조건 특유 꼴 = 가려진 꼴의 메아리** (H1-E 지지, 복사 판독 기준은 경계) |
| S5 encoder 보임 → 가림 | 같은 크기 · 거의 직교 | — | encoder 실패는 **방향 (꼴)**. predictor S2 와 다르다 → H1-0 기각. late 는 encoder 의 가린 꼴을 이어받는다 |
| S6 PFT | 크기 ×1.9–2.4 · 자리 따라감 0.95 · 참 미래 꼴을 닮음 | PFT p 는 사상 없이 h 판독기로 77–89 % | PFT 는 크기와 자리를 같이 바꿨다 |

**Q2** (읽히게 하면 영속이 풀리나)

| 가설 | 근거 | 판정 |
|---|---|---|
| H2-0 읽힘 ≠ 영속 | 읽힘 91–99 % 인 d2 의 A 10 % · d3 72 % · 보임 맞춤 사상 A ≤ 7 % | **지지** (test 판 d3 63 % 경계) |
| H2-1 판독이 병목 | 정렬 재채점 A +3–7 pt | **기각** |
| H2-2 가린 정체 채널을 안 씀 | t7 하나 바꾸면 π_O 0.38 | **기각** — 쓴다, 다만 가린 꼴 그대로 |
| H2-3 PFT 이득 = 운반 | 참 자리 몫 ×1.8–3.0 · 따라감 0.95 | **성립** (정체 대비는 2 배 기준 경계) — 단 크기도 같이 바뀜 |

**사용자 질문에 대한 짧은 답**
- (1) **보이는 먼 미래: 크기다** — 같은 방향이되 작다 (대비 1/3–1/5). 스칼라 하나로 이식 실패의 약 60 % 가 되살아난다. 방향 (회전) 몫은 0.1 안팎이다. **late: 크기도 방향도 아닌 다른 꼴이다** — 예측은 가려진 마지막 문맥 튜블릿이 가진 "가려진 꼴" 의 정체를 이어받고, 그 꼴은 보이는 꼴과 거의 직교다. encoder 안의 보임 → 가림 이식 실패 (9–21 %) 도 같은 직교 꼴이다.
- (2) **이식을 맞추는 것만으로는 영속이 안 풀린다.** 판독을 99 % 로 되살린 물체 토큰도 마지막 본 자리에 있으면 사라짐 A 는 10 % 다. 참 미래 자리로 옮겨야 72 % 다. PFT 가 late A 를 100 % 로 만든 것은 크기를 키우고 **자리를 따라가게** 바꾼 것과 함께 일어났다.

**그림** (결과 폴더의 요약 그림, 부록 참조) — (a) 보이는 먼 미래 (S2) 에서 정렬 사다리 단마다 h 판독기 결합 정확도 (test block, 시드 둘 평균). 점선 = 같은 표본의 p 판독기 천장 (색 = objset). (b) primitive 정체 대비의 물체 영역 크기 ρ_O, 걸음별 (릴리즈 보임 조건 이동 · 릴리즈 late 이동 · PFT late 이동). (c) permanence late 이동의 사라짐 방향 A 정답률 — 원값 · 복사 · 주입 d2 (정체를 마지막 본 자리에) · d3 (참 자리에) · d1 (참 미래) 은 모든 block 60 쌍, PFT 는 test block 30 쌍. [측정]

## 8. 단서 (결론과 같은 무게)

- G0 · G3 관문 실패: bfloat16 캐시 채점은 공식 채점과 짝 판정이 92.6 % 만 같다 (근소한 차 쌍). VoE 수치는 같은 캐시 안의 Δ 로만 읽는다. permanence 칸은 공식과 같다.
- late 사라짐 A 의 test 표본은 30 쌍 (objset 합) 이다. 0/30 의 95 % 상한은 약 12 % 다. +30 pt 미만 차이는 판정하지 않았다.
- 판독기에 위치 임베딩이 없다 → "자리" 가설은 이 판독기로 시험할 수 없다. E2 의 자리 어긋남은 따로 실재한다.
- 정렬 사상의 천장 정규화 (κ̂) 는 쓸 수 없었다 (h 자체가 걸음마다 방향이 바뀜). 방향 판정은 학습된 사상 쪽에 기댄다.
- 일반 선형 · 비선형 사상은 h 를 망가뜨려 사다리에서 뺐다. 회전 사상도 primitive 에서 h 를 79 % 로 떨어뜨린다.
- 존재 대비 (permanence) 와 정체 대비 (모양 · 색) 는 꼴이 다르다. 존재 대비는 late 에서도 참 미래를 가장 닮고 크기만 작다. "late = 메아리" 는 정체 대비에 대한 말이다.
- 정렬 · 주입은 측정 도구다. 방법 제안이 아니다. PFT 의 원인은 다루지 않는다 (목적함수 원인 귀속 안 함).
- vast AR 모델은 이번 라운드에서 재지 않았다 (계획 §7-3, 사용자 결정 대기).
- E5 (판독기 attention 진단) 는 하지 않았다. 판독기가 위치를 안 본다는 것이 확인돼 우선순위를 낮췄다.

## 9. 계획과 다른 점 (기록)

- 쌍 차이 지도에 **물체 영역판 지표** (ρ_O · κ_O · 물체 영역 따라감) 를 더했다. 전체 칸 지표가 물체 밖 칸에 지배돼서다.
- τ* 는 물체 영역 L1 대신 쌍 차이 cos 판으로 냈다.
- **E2c (late 메아리 검사)** 를 새로 넣었다. E8 의 결과 (가린 t7 에서 정체를 가져옴) 가 나온 뒤 추가한 사후 분석이다.
- E8 의 "가린 문맥 튜블릿" 은 가려진 샘플이 하나라도 있는 튜블릿이다. 반만 가린 튜블릿이 섞이지 않는 칸은 late k = 2 이고, 결론은 그 칸으로 낸다.
- L6 (공간 사상) 과 E5 는 하지 않았다.
