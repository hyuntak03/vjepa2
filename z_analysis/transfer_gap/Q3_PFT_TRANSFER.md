# Q3 — PFT 가 다른 벤치마크로 안 옮겨지는 이유: 진행 방향 · 분포를 외워서인가 (2026-10-30, 실험 B [X2])

> **R2 갱신 · 정정 (2026-10-30, 지우지 않고 덧붙임)** — 2 라운드 정본은 `Q3_PFT_TRANSFER_R2.md` 다.
> (1) 아래 "그 밖의 이득은 … 약 1/3 줄고" → **약 1/5, CI 넓음** (반올림만 한 판의 유지율이 이미 0.87 [0.73, 1.03] 이라 그 몫을 빼면).
> (2) "IntPhys 1 하락 (−5.6) 은 … 잡음 바닥 크기다" → 결정적 반올림은 대칭 잡음이 아니었다. **대칭 잡음 (확률적 반올림 4 seed) 에서는 PFT − 릴리즈가 +1.1 – +5.0** 으로 바뀌고 잡음에 약한 쪽은 릴리즈 (88.9 → 79–81) 다. 하락이라 부를 근거가 없다 (R2 E31c).
> (3) "같은 생성 꼴의 다른 세트 (v11) 로 옮겨진다" → **VOBench → v11 방향에서만**. v11 로 학습한 PFT 는 VOBench late 사라짐 0 % (자리 3 %) 다 (R2 E26 · E32b).
> (4) "외부 벤치에서 … 출력 변화가 목표와 거의 직교" → 공통 이동은 외부 평균 오차와도 같은 쪽 (cos 0.46–0.74) 이고 약간 돕는다. 외부의 해는 칸마다 다른 나머지 변화에서 온다 (R2 E27).

> **질문** — 릴리즈 predictor 를 VOBench 로 이어 학습 (PFT) 하면 VOBench 에서는 크게 오르는데 IntPhys 1 · GRASP · InfLevel · IntPhys 2 는 안 오른다. VOBench 의 운동 · 가림 배치 · 외형을 외웠기 때문인가?
> **답 (R1)** — **한 축을 외운 것은 아니다.** PFT 의 핵심 효과 (문맥 끝에 가려진 물체가 사라지는 미래를 놀라워함, 릴리즈 0–17 % → 67–100 %) 는 처음 보는 물체 · 같은 생성 꼴의 다른 세트 (v11 · v11 실물 메시) · 학습에 없던 가림 길이 · 속력 · 시간 부호 · 창 배치 · 자리 · 색을 바꿔도 남는다. 그 밖의 이득은 시간 척도 · 시간 부호 · 창 배치를 바꾸면 약 1/3 줄고, 가려진 색 바뀜 이득은 거의 사라진다. 외부 벤치에서는 PFT 가 출력을 크게 바꾸지만 (오차의 32–44 %) 그 변화가 목표와 거의 직교해 오차가 그대로이고 (ε 1.00–1.03), 보고된 IntPhys 1 하락 (−5.6) 은 눈에 안 보이는 입력 반올림만으로 −1.7 로 줄어드는 잡음 바닥 크기다.
> **다음** — (1) 외부 벤치마다 "문맥 끝 가림 + 사라짐" 꼴 칸이 얼마나 있는지 세기 · (2) E16 변화를 물체 칸 / 배경 칸으로 나누기 · (3) 모든 외부 벤치 비교에 잡음 바닥 (같은 모델 재양자화 판) 붙이기 · (4) 다시 학습해야 가를 수 있는 것 (late 를 뺀 PFT · 보폭 · 창 위치를 섞은 PFT) 은 사용자 결정.

R1 의 모든 수치는 이번 산출물 (per_video · per_window · te 배열 · 체크포인트) 에서 다시 셌다. 원 문서값을 옮긴 곳은 "문서값" 이라고 적었다.

## 용어

| 용어 | 뜻 |
|---|---|
| 릴리즈 | 공개 V-JEPA 2 ViT-H predictor (encoder 는 모든 모델이 같다) |
| PFT | 릴리즈 predictor 를 이어 학습한 것. 기본 = VOBench split v2 train + gravity train 30 epoch ("VOBench PFT"). 학습 증강: 좌우 반전 0.5 · 시작 프레임 0/1/2 |
| 처음 보는 물체 PFT | 모양 2 · 메시 2 · 색 2 를 학습에서 통째로 뺀 VOBench PFT (gravity 없음, 30 epoch) |
| 쌍 정확도 | matched 쌍 (문맥 16 장이 화소 단위로 같은 가능 · 불가능 영상) 에서 가능 영상의 surprise 가 더 작으면 정답. 우연 50 % |
| surprise | 영상 하나의 미래 8 튜블릿 평균 L1 = mean \|predictor 출력 − 정규화한 목표 encoder 출력\| (표준 채점, 전체 토큰) |
| late | 문맥 끝 k 샘플 + 미래 앞 k 샘플이 가려진 조건 (VOBench k = 1–3, v11 k = 1–4) |
| 사라짐 A | 짝 (pos_a, imp_ab). permanence 에서 "물체가 있던 장면 → 물체가 사라진 미래" 가 불가능 쪽. 릴리즈의 late 이동 A 는 0 % 근처 |
| 이득 G | 같은 쌍에서 acc(PFT) − acc(릴리즈), %p |
| 유지율 r | 변환한 판의 이득 ÷ 기준 판의 이득 (같은 block). 1 = 이득이 그대로, 0 = 사라짐 |
| ε | 가능 영상 평균 surprise 의 비 = PFT ÷ 릴리즈 (같은 창 · 같은 문맥 길이 · 같은 영상). < 1 이면 PFT 가 예측 오차를 줄였다 |
| 복사 기준선 | 문맥 마지막 튜블릿 (문맥 encoder, 정규화) 을 미래 모든 튜블릿에 복사해 같은 쌍을 채점한 것. 예측 없이 풀리는 정도 |
| 잡음 바닥 | 눈에 안 보이는 입력 차이 (화소 반올림 ≤ 0.5/255) 만으로 뒤집히는 쌍 판정의 비율 |
| block bootstrap | block 을 2,000 번 다시 뽑아 낸 95 % 구간 (CI) |

## 1. 왜 — 가설 (PLAN_R1 §4 그대로)

| 가설 | 참이면 보일 것 |

| H3-T 가림 시점 · 창 배치 외우기 | 창 이동판 · 학습에 없던 가림 길이 (v11 k = 4) 에서 이득이 사라짐 |

## 4. 실험 E11 — 가까운 세트 (v11 · v11 실물 메시) (H3-G vs H3-M · T)

**해석**
- [측정] VOBench PFT 가 배운 "가려진 물체가 사라지는 미래를 놀라워함" 은 다른 가림막 폭 · 속력 · 물체 · 실물 메시 · 학습에 없던 가림 길이로 간다. B 방향 (빈 → 물체) 은 100 그대로라 "늘 물체를 그린다" 는 아니다.
- [단서] 표준 채점은 토큰 평균 L1 이라 물체가 **제자리에** 다시 나타나는지는 못 본다. 이 결과로 "물체를 옮긴다" 를 말할 수 없고 "사라지지 않는 미래를 덜 놀라워함" 까지만 말한다.
- [단서] v11 은 VOBench 원시 물체 판의 배경 하나와 같은 장면 꼴이다 — '가까운' 세트다.

## 5. 실험 E12 — VOBench 변환 (축별 외우기)

**왜** — 이득이 한 축 (샘플당 속력 · 시간 부호 · 가림이 창 경계에 걸리는 배치 · 화면 자리 · 색) 에 묶여 있으면, 그 축만 바꾼 VOBench 에서 이득이 사라져야 한다.

**어떻게** — split v2 test (720 쌍) 를 바꿔 릴리즈 · VOBench PFT · 복사를 채점했다.

| 변환 | 바꾼 것 | 바뀌는 축 |
|---|---|---|
| T1 보폭 2 | 원본에서 2 장 간격, 문맥 끝은 원래와 같은 프레임 | 샘플당 속력 ×2/3 · 가린 샘플 수 ×1.5 |
| T2 역재생 | 프레임 순서를 뒤집고 짝을 다시 맺음 (관문 360 / 360 block 통과) | 운동의 시간 부호 (가속 ↔ 감속), 이른 · 중간 가림 → 미래 가림 |
| T3 잘라 옮기기 ×4 | 448 px 창을 네 자리에서 잘라 256 으로 | 화면 자리 · 크기 ×1.14 |
| T4 색상 +180° | 채도 · 명도를 두고 색상만 반대로 | 외형 (색) |
| T5 창 이동 | 기존 창 이동판 (가림이 문맥 끝에서 끝남) 의 test block | 가림 시점 |

- T3 은 물체 중심이 네 창 모두 안에 있는 210 block 만 썼다 (원시 물체는 화면을 가로질러 대부분 빠졌다 → 사실상 실물 메시 + 정지 원시 판). 상자 기준으로 거르면 70 block 만 남아 버렸다.
- 모든 판의 문맥 무결성 (matched 쌍 문맥 16 장 화소 동일) 은 불일치 0 이다.

⚠️ **정정 — 기준 판 관문이 실패했다.** 사전 등록한 T0 (같은 작성기로 원본을 다시 씀) 은 공식 채점과 쌍 판정 99 % 일치를 요구했다. 실제로는 **90 % (릴리즈) · 94 % (PFT) · 84 % (복사)** 였다. 두 판의 입력 차이는 반올림 ≤ 0.5/255 뿐이다 (로더 입력 최대 차 0.0088, 정규화 단위로 확인). 정확도는 ±1.3 pt 안에서만 움직였다. 그래서 기준을 나눴다: 작성기로 쓴 T3 · T4 는 T0 대비, 원본 프레임을 읽는 T1 · T2 · T5 는 원본 판 (같은 채점 경로) 대비. 이 실패 자체는 §6 의 잡음 바닥 결과다.

  - **외움 판정 0 개.**
  - **T4 (색) = 아님** → H3-A 기각 (E10 과 같은 방향).

- [단서] T1 은 속력과 가린 샘플 수가 같이 바뀐다 (하나만 떼지 못함). T2 는 late 를 빼면 가림 위치도 바꾼다. 표준 채점이라 자리는 못 본다.

## 6. 잡음 바닥 — 눈에 안 보이는 입력 차이로 뒤집히는 쌍 (E12 관문 실패에서 나온 측정)

**왜** — 외부 벤치의 PFT 하락은 180 쌍 중 10 쌍 (IntPhys 1) 같은 작은 차이다. 같은 모델이 의미 없는 입력 차이로 얼마나 흔들리는지 알아야 그 차이를 읽을 수 있다.

**어떻게** — 같은 영상을 (a) 원본 512 px PNG → 로더 축소 (b) 같은 축소 뒤 uint8 로 반올림해 다시 쓴 256 px PNG 로 채점했다. 두 입력의 화소 차는 ≤ 0.5/255 다. 참고로 (c) 같은 원본을 두 채점 경로 (묶음 크기가 다름) 로 돌린 차이도 쟀다.

## 7-b. 실험 E16 — PFT 는 분포 밖에서 출력을 바꾸나 (계획 밖 추가)

**왜** — ε ≈ 1 은 두 경우와 맞다. (가) 갱신이 분포 밖 입력에서 출력을 거의 안 바꾼다. (나) 출력은 크게 바뀌지만 오차를 줄이지 않는 방향이다.

**어떻게** — 같은 encoder · 같은 창 · 같은 가능 영상 (세트당 160 개) 에서 릴리즈 출력과 PFT 출력을 함께 뽑았다. 변화량 d = mean |p_PFT − p_릴리즈| 를 릴리즈 오차 e = mean |p_릴리즈 − h| 로 나눴다. 변화가 오차를 줄이는 방향인지 cos(변화, 목표 − 릴리즈 출력) 로 쟀다. 변화를 "화면 전체 공통 변화" (튜블릿마다 256 칸 평균) 와 나머지로 나눴다.

**결과** [측정]

| 세트 | 종류 | ε | 변화량 / 오차 | cos (변화, 오차 방향) | 공통 변화 / 나머지 | 움직이는 토큰과 상관 |
|---|---|---:|---:|---:|---|---:|
| VOBench test | 분포 안 | 0.815 | 0.55 | **0.57** | 0.146 / 0.288 | 0.08 |
| v11 | 가까움 | 0.955 | 0.47 | 0.32 | 0.148 / 0.226 | 0.01 |
| v11 실물 메시 | 가까움 | 0.954 | 0.47 | 0.32 | 0.147 / 0.223 | 0.01 |
| IntPhys 1 | 외부 | 1.002 | 0.44 | 0.21 | 0.144 / 0.214 | 0.01 |
| GRASP (보폭 5) | 외부 | 1.002 | 0.41 | 0.20 | 0.124 / 0.204 | 0.02 |
| InfLevel continuity (보폭 5) | 외부 | 1.014 | 0.32 | 0.14 | 0.110 / 0.174 | −0.04 |

- **(가) 기각** — PFT 는 외부 벤치에서도 출력을 오차의 32–44 % 만큼 바꾼다.
- **(나) 지지** — 변화가 오차 방향과 맞는 정도가 0.57 (분포 안) → 0.32 (가까움) → 0.14–0.21 (외부) 로 떨어진다. 변화가 오차를 줄이려면 cos 가 변화 크기 비의 절반 (≈ 0.16–0.22) 보다 커야 한다 [이론, 제곱 오차 기준]. 외부는 그 경계에 있어 ε ≈ 1 이다.
- 변화의 약 40 % 는 화면 전체 공통 변화이고 그 크기는 세트와 거의 무관하다 (0.11–0.15). 출력 사영층의 bias 변화는 0.002 로 작다 → bias 가 아니라 망이 만드는 공통 변화다 [측정].
- 변화는 화면에 고르게 퍼져 있고 (상위 5 % 토큰의 몫 8–10 %, 고르면 5 %) 움직이는 토큰과 상관이 없다.

**해석**
- [측정] PFT 는 분포 밖 출력을 "VOBench 목표 쪽으로" 바꾼다. 그 방향은 다른 벤치의 목표와 거의 직교하고, 큰 몫이 물체가 아니라 화면 전체에 걸린다.
- [추측] 표준 채점은 전체 토큰 평균이라, 이 화면 전체 변화가 외부 벤치의 근소한 쌍을 무작위에 가깝게 뒤섞는다 → §6 의 잡음 바닥 크기 흔들림과 맞는다. 쌍 단위로는 아직 확인 안 했다.
- [단서] 세트당 160 영상 · 가능 영상만. cos 는 영상 하나 전체를 펼친 값이라 물체 칸 · 배경 칸을 나누면 다를 수 있다.

**한 문장 (R1)** — VOBench PFT 는 "문맥 끝에 가려진 물체가 사라지는 미래를 놀라워함" 을 외형 · 가림 길이 · 속력 · 시간 부호 · 창 배치와 무관하게 배우고, 그것은 같은 생성 꼴의 다른 세트로 간다. 외부 벤치에서는 PFT 가 출력을 크게 바꾸지만 그 방향이 목표와 거의 직교해 예측 오차가 그대로이고, 그 효과를 재는 칸 (IntPhys 1 이동 + 가림) 도 오르지 않는다. 외부 벤치의 작은 하락은 창 선택 · 쌍 판정 잡음 바닥과 같은 크기다.

**아직 모르는 것**
- 외부 벤치가 **왜** 이 효과를 안 재는가. 후보: (1) 외부 벤치의 위반이 "문맥 끝 가림 + 사라짐" 꼴이 아니다 (IntPhys 1 이동 + 가림은 0.2 초 가림, 위반 시점이 창 경계와 따로 논다) · (2) ~~장면 분포 밖에서는 PFT 갱신이 출력을 거의 안 바꾼다~~ — **E16 으로 기각** (출력은 오차의 32–44 % 만큼 바뀐다). 대신 "바뀌는 방향이 그 벤치의 목표와 직교하고 화면 전체에 걸린다" 가 남는다. 물체 칸 / 배경 칸으로 나눠 확인할 것 (R2 제안).
- 물체가 **제자리에** 다시 나타나는지 (운반) 는 표준 채점으로 못 본다 — Q1 · Q2 의 자리 측정 (X1) 과 묶어야 한다.

**사용자 결정이 필요한 것 (다시 학습)** — late 를 뺀 PFT (가장 직접적) · 보폭을 섞은 PFT (T1 의 1/3 손실이 데이터 다양성으로 막히나) · 창 위치를 섞은 PFT (T5). 각 약 35 분 GPU 4 장 (처음 보는 물체 PFT 학습 시각에서 셈).
