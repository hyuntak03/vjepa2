# 가설 · 실험 계획 R1 — 이식 실패 (Q1 · Q2) · PFT 비전이 (Q3) (2026-10-30, 가설 [H])

> **질문** — Q1: encoder 출력 h 로 배운 판독기가 predictor 출력 p 에서 안 읽힌다. 방향이 달라서인가, 크기가 달라서인가, 아니면 자리 · 꼴이 달라서인가. Q2: 읽히게 만들면 late 의 사라짐 방향 (0 %) 이 풀리나. Q3: PFT 가 다른 벤치로 안 옮겨지는 것은 VOBench 의 운동 · 가림 시점 · 외형을 외워서인가.
> **답 (계획)** — 경쟁 가설 17 개를 세웠다 (Q1 7 · Q2 4 · Q3 5 · 대조 1). 중심 측정은 **쌍 차이 지도**다. 같은 장면 · 같은 궤적에서 물체만 다른 두 가능 영상의 표현 차이를 쓰고, 파라미터 없이 방향 · 크기 · 자리를 따로 잰다. 그 위에서 정렬 사다리로 "어느 단에서 h 판독기가 되살아나나" 를 본다. Q2 는 주입 · 바꿔 넣기로, Q3 는 처음 보는 물체 PFT · 가까운 세트 · VOBench 변환으로 가른다. 새 predictor 학습은 없다.
> **다음** — [X1] 추출 → 관문 → 쌍 차이 지도 ∥ 판독기 → 정렬 사다리 → 주입 · 재채점 (약 4 시간, GPU ≤ 4). [X2] 기존 산출물 → 처음 보는 물체 PFT → v11 전이 → VOBench 변환 (약 3.5 시간, GPU ≤ 4). 다시 학습해야 하는 실험 넷과 수축 계수 표기 문제는 사용자 결정으로 올린다 (§7).

수치는 [R] 의 R1 재계산값 (`results/R1_facts_recount.json`) 이거나 이번에 index · label 에서 센 값이다 (표시함). "문서값" 은 원 문서에서 옮긴 것이다.

## 용어

| 용어 | 뜻 |
|---|---|
| h | 목표 encoder 출력. 32 장을 한 번에 넣고 학습 계수 없는 층 정규화를 건다. 튜블릿 t · 칸 c 마다 1280 차원. 토큰 노름은 √1280 로 고정 |
| p | predictor 의 미래 튜블릿 출력 (t8–t15). h 와 같은 1280 공간을 겨냥하지만 노름이 고정되지 않는다 |
| p̃ | p 의 토큰마다 학습 계수 없는 층 정규화를 건 값. attentive 판독기는 입력에 층 정규화를 먼저 걸기 때문에 **판독기가 실제로 보는 것은 p̃** 다 |
| z | 문맥 encoder (온라인) 출력. 문맥 16 장만 본다 |
| 칸 c | 16×16 공간 토큰 하나. 512 px 프레임에서 32 px |
| 튜블릿 t (걸음) | 연속 2 샘플. 문맥 t0–t7, 미래 t8–t15 |
| h 판독기 | h 의 '보이는' 튜블릿 (t0–t15) 으로 학습한 정체 판독기 (attentive, 질의 1 · 머리 16 · 깊이 1, 결합 정체 + 없음). 사용자가 말한 "encoder embedding 으로 학습한 probe head" |
| p 판독기 | 보임 조건 p 로 학습한 같은 구조의 판독기. p 안의 정보 천장 |
| 같은 시점 판독기 | 걸음 하나 (t8 · t11 · t15) 에서만 학습한 판독기. 자리에 민감하다 |
| late 안 판독기 | late 의 p 로 학습 · 시험한 6 지선다 ridge (블록 평균 · 참 자리 3×3) |
| 보임 조건 | visible · early · mid. 문맥 끝에서 물체가 보인다 |
| late | 문맥 끝 k 샘플과 미래 앞 k 샘플이 가려짐 (k = 1–3). 미래 t9–t10 부터 물체가 다시 보인다 |
| 쌍 차이 지도 Δ | 같은 block 의 두 가능 영상 A · B (같은 장면 · 같은 궤적, 물체만 다름) 의 표현 차이. 칸마다 1280 차원, 256 칸. 배경이 빠지고 정체 대비만 남는다 |
| 영역 | O참 = 그 걸음 참 물체 중심의 3×3 칸 (큰 물체는 외곽 상자 + 1 칸). O끝 = 문맥 안 마지막으로 보인 자리. O숨 = 가려진 동안의 참 경로 (가림막 뒤). Op = Δp 에너지가 가장 큰 칸의 3×3 |
| 정렬 사상 M | p 를 h 공간으로 옮기는 함수. **보임 조건 · train block 의 (p, h) 짝으로만** 맞춘다 |
| 정렬 사다리 | 자유도를 한 단씩 늘린 정렬 사상 (L0–L6) |
| 회복률 R | (정렬 뒤 h 판독기 정확도 − 정렬 전) ÷ (천장 − 정렬 전). 천장 = 같은 시험 표본에서 p 판독기 정확도 |
| 사라짐 방향 A | matched 짝 (pos_a, imp_ab). permanence 에서는 물체 → 빈 장면. 릴리즈 late 이동에서 0 % |
| 복사 기준선 | 문맥 encoder 의 마지막 문맥 튜블릿 (정규화) 을 미래 모든 걸음의 예측으로 쓴 채점. 정체 가독성에도 같은 기준을 둔다 (마지막 문맥 튜블릿으로 학습한 판독기) |
| PFT | 릴리즈 predictor 의 post-FT. 기본 = VOBench split v2 train + gravity train, 30 epoch. 학습 증강에 **좌우 반전 (확률 0.5) 과 시작 프레임 0 · 1 · 2 이동**이 들어 있다 |
| 처음 보는 물체 PFT | 모양 2 (torus · cone) · 메시 2 (basketball · scooter) · 색 2 쌍을 학습에서 뺀 PFT. 채점된 적 없다 |

## 기호

- i 영상, b block, t ∈ {8, …, 15} 미래 걸음, c ∈ {0, …, 255} 칸, d ∈ {1, …, 1280} 채널.
- 지도 X_t ∈ ℝ^{256×1280}. ‖X‖ = 칸 · 채널을 펼친 노름. cos(X, Y) = ⟨X, Y⟩ / (‖X‖‖Y‖).
- T_s X = 지도 X 를 칸 단위로 s = (가로, 세로) 만큼 평행 이동 (빈 칸은 0).
- e_c(Δ) = ‖Δ_c‖² (칸 c 의 대비 에너지).
- μ_{t,c} = train 영상의 h 평균 토큰 (그 걸음 · 그 칸). μ^p_{t,c} = 같은 것의 p̃ 판.

## 1. 왜 — R1 이 고정한 출발점

**R1 에서 확정된 것** [측정, R1 재계산]
- 이식 실패는 late 만의 일이 아니다. 보임 먼 미래 (릴리즈 h 판독기 → p, t8 89 → t11 4 %), 같은 시점 (모양 51 / 70 vs p → p 95 / 98), encoder 안 보임 → 가림 (9–21 %) 에서도 일어난다.
- 정보는 그 표현으로 학습하면 읽힌다. p 판독기 t11–t15 53–82 %, late 안 ridge 72 / 87 %, 문맥 encoder 가림 튜블릿 62–66 %.
- h 판독기를 p 에 걸면 오답이 '없음' 으로 몰린다.
- PFT 뒤 이식이 오른다 (보임 24 → 76 %, late 0 → 51–54 %). 같은 test 에서 late VoE 58.3 / 65.7 → 88.0 / 91.7 이다. 외부 벤치는 안 오른다.

**이미 있는 가까운 답** (문서값, 다시 열지 않음)
- v11 풀링 특징 (토큰 평균, 자리 정보 없음): 같은 조건 짝으로 맞춘 직교 Procrustes (p → 문맥 encoder z) 가 encoder 머리의 모양 판독을 보임 99.8 · late 96.4 % (logistic) 로 되살렸다. 짝을 섞으면 12–14 % 다. 보임 짝으로 맞춘 사상을 late 에 걸면 54.5 (logistic) / 18.4 % (ridge) 만 남는다. encoder 끼리의 사상도 late 에서 같이 무너진다 (RollOutV3 감사 §2).
- v11 VoE 재채점: 보임 조건 짝으로 맞춘 전역 선형 사상이 late 를 61.2 → 64.4 (+3.2) 로만 올렸다. ramp late 칸은 +0.9 (0 포함) 이고, PFT 이득의 약 1/5 이다 (ctxenc_subspace_v2).
- vast phys3d (보이는 표본, 물체 칸): 정체 개념 방향 cos 0.86 → 0.45, 크기 0.2–0.3 배.
- vast 개입 둘: 정답 토큰 판독기 감독 (이식 성공 · late 66–69) · 정체 개념 더하기 (전체 토큰 ±1–2 pt, 이동 사라짐 0 % 그대로).

**이번 계획이 새로 묻는 것**
1. **토큰 단위 · 원래 attentive 판독기**로 방향 · 크기 · 자리의 몫을 나눈다. v11 은 풀링이라 자리를 볼 수 없었다.
2. late 와 보임 먼 미래를 같은 도구로 잰다.
3. PFT 를 자연 대조로 쓴다. 이식이 24 → 76 % 로 오를 때 무엇이 바뀌었나.
4. Q2 에서 **자리**를 개입 변수로 넣는다. "읽힘" 과 "제자리에 있음" 을 따로 켠다.
5. Q3 에서 외우기를 축 (운동 · 시간 척도 · 가림 시점 · 화면 자리 · 외형) 별로 가른다.

## 2. Q1 — 경쟁 가설 (방향 · 크기 · 자리 · 꼴)

**"크기" 의 정의.** 판독기는 토큰마다 정규화하므로 토큰 노름은 의미가 없다. 그래서 크기는 **평균 토큰에서 떨어진 정도 (대비)** 로 잰다. 쌍 차이 지도에서는 평균 토큰이 지워지므로 ‖Δp̃‖ / ‖Δh‖ 가 곧 판독기가 보는 대비의 크기다. [이론]

| id | 진술 | 참이면 보일 것 | 거짓이면 보일 것 |
|---|---|---|---|
| **H1-S 등방 수축 (크기)** | p 의 정체 대비는 h 와 같은 방향인데 작다. 모든 방향이 같이 작아져 물체 토큰이 평균 토큰처럼 보인다 | 자리를 맞춘 cos 가 높고 (κ̂이동 ≥ 0.7) 크기 비 ρ ≤ 0.5. 주성분별 비가 평평하다. 걸음 스칼라 하나 (L2) 로 R ≥ 0.5. 판독기 attention 은 물체를 찾는데 '없음' 으로 답한다 | ρ ≥ 0.7, 또는 L2 가 R < 0.2 |
| **H1-A 비등방 수축** | 큰 분산 방향은 남고 작은 분산 방향 (세부 외형) 만 줄었다. 판독기가 그 방향을 쓴다 | 주성분별 크기 비가 위 10 % 대 아래 50 % 에서 3 배 넘게 다르다. 주성분별 대비 맞춤 (L2b) 은 R ≥ 0.5 인데 L2 는 못 한다 | 주성분별 비가 평평하다 (지수 < 1.5) |
| **H1-R 회전 (방향)** | 대비의 크기는 비슷한데 h 와 다른 방향에 있다 | κ̂이동 ≤ 0.4, ρ ≥ 0.7. 직교 Procrustes (L3) 에서 처음 R ≥ 0.5. 최선 선형 사상의 회전 성분이 단위 행렬에서 멀다 | κ̂이동 ≥ 0.7 이거나 L3 증분 < 0.1 |
| **H1-P 자리 · 번짐** | 정체 대비가 다른 자리 (마지막 본 자리 근처 · 시점 지연) 에 있거나 여러 칸으로 번져, 어느 토큰도 h 의 물체 토큰처럼 보이지 않는다 | 자리를 고정한 cos 가 자리를 맞춘 cos 의 절반 이하다. 또는 유효 칸 수가 h 의 2 배를 넘는다. 토큰별 사상 (L1–L5) 은 R < 0.5 인데 공간 사상 (L6) 이나 파라미터 없는 평행 이동 (L-자리) 이 R ≥ 0.5. 판독기 attention 이 물체 영역에서 균등 (0.035) 수준으로 내려간다 | 자리 고정 cos ≈ 자리 맞춘 cos, 유효 칸 수 비 < 1.3 |
| **H1-C 조건 특유 꼴** | 보임 조건 p 의 부호와 late p 의 부호가 다르다 (비선형 포함). 보임에서 맞춘 어떤 사상도 late 로 안 옮겨진다 | 보임 맞춤 사상은 보임에서 R ≥ 0.5, late 에서 R < 0.2. late 재등장 걸음으로 맞춘 사상은 late 에서 R ≥ 0.5 | 보임 맞춤 사상이 late 에서도 R ≥ 0.5 |
| **H1-E late 메아리** | late 안 판독기가 읽는 정체는 물체 토큰이 아니다. 마지막 문맥 대비가 화면에 퍼진 메아리이고, 가독성은 복사 수준이다 | late Δp 가 참 미래 대비보다 마지막 문맥 대비 (Δh·Δz 의 t끝) 와 더 닮았다 (κ끝 > κ이동). 에너지의 80 % 이상이 O끝 · 나머지에 있다. late 안 판독 정확도가 복사 판독 (마지막 문맥 튜블릿 판독기) 이하다 | κ이동 ≥ κ끝 이고 O참 질량이 균등의 3 배 이상. 또는 late p 판독이 복사 판독보다 5 pt 넘게 높다 |
| **H1-0 대조: encoder 안 실패와 같은 꼴** | encoder 안 보임 → 가림 이식 실패 (9–21 %) 도 같은 기하 (예: 수축) 로 설명된다 | 가린 튜블릿 h 의 쌍 차이 지도 지표가 p 와 같은 판정을 낸다 | 다르다 → "predictor 특유" 를 주장할 수 있다 |

- 가설은 서로 배타가 아니다. **몫을 나눈다.** 사다리 각 단의 회복 증분이 그 몫이다.
- 수축의 원인 (손실 · 목적함수) 은 축으로 두지 않는다. 쓰더라도 discussion 한 문단이다 (CLAUDE.md §12).
- ⚠️ 수축 회귀 p ≈ a·h + b·μ 의 계수는 인용 금지된 α 분해와 꼴이 같다. 이번 계획은 파라미터 없는 대비 비 ρ 만 문서에 쓰고, 회귀 계수는 결과 JSON 에만 둔다 (§7 사용자 결정 2).

### Q1 판정표 (사전 등록, 시나리오마다 따로)

시나리오: **S1** 보임 조건 · 이동 · 가까운 미래 (t8–t10, 이식이 되는 대조) / **S2** 같은 조건 먼 미래 (t11–t15) / **S3** 같은 시점 판독기 / **S4** late · 이동 · 재등장 걸음 / **S5** encoder 보임 → 가림 (대조) / **S6** PFT 뒤 S2 · S4.

| 쌍 차이 지도 (E2, 파라미터 없음) | 정렬 사다리 (E4, 학습된 사상) | 답 |
|---|---|---|
| κ̂이동 ≥ 0.7 · ρ ≤ 0.5 · 주성분 지수 < 1.5 | L1 또는 L2 에서 R ≥ 0.5 | **크기 (등방 수축)** |
| 주성분 지수 ≥ 3 | L2b 에서 처음 R ≥ 0.5 | **특정 방향의 크기** |
| κ̂이동 ≤ 0.4 · ρ ≥ 0.7 | L3 에서 처음 R ≥ 0.5 | **방향 (회전)** |
| κ̂고정 ≤ 0.5·κ̂이동 또는 유효 칸 수 비 ≥ 2 | L-자리 · L6 에서만 R ≥ 0.5 | **자리 · 번짐** |
| — | L4 · L5 에서 처음 | **선형 일반 · 비선형 꼴** |
| late 만: κ끝 > κ이동 · 복사 판독 이상 아님 | 보임 맞춤 전부 R < 0.2, late 맞춤 R ≥ 0.5 | **조건 특유 꼴 / 메아리** |

- **두 열이 어긋나면 판정을 내지 않는다.** 학습된 사상과 파라미터 없는 검사가 다른 답을 내면 그대로 적는다 (CLAUDE.md §12-8).
- 문턱 (0.7 · 0.5 · 0.4 · 3 · 2) 은 데이터를 보기 전에 정한 값이다. 결과가 문턱 근처 (±0.05) 면 "경계" 로 적는다.

## 3. Q2 — 경쟁 가설 (읽히게 하면 영속이 풀리나)

| id | 진술 | 참이면 보일 것 | 거짓이면 보일 것 |
|---|---|---|---|
| **H2-0 읽힘 ≠ 영속** | h 판독기로 읽히게 만들어도 물체가 **참 미래 자리**에 없으면 사라짐 방향 A 는 안 오른다. 영속 채점은 자리를 요구한다 | 정렬 사상 재채점 (E6): late 이동 A 가 +5 pt 이하. 주입 (E7): 정체를 마지막 본 자리에 둔 판 (d2) 은 A 가 복사 수준이고, 참 자리에 둔 판 (d3) 만 오른다 | d2 에서 A 가 복사 + 20 pt 넘게 오른다 |
| **H2-1 판독이 병목** | p 는 물체를 제자리에 두지만 h 판독기와 채점이 못 알아보는 꼴이다. 정렬하면 A 가 오른다 | 정렬 공간 재채점에서 late 이동 A 가 +30 pt 이상 (CI 하한 > +10), B 가 10 pt 넘게 무너지지 않고, 복사 기준선을 넘는다 | A 변화 ≤ +5 pt (v11 사전 예측: late +3.2) |
| **H2-2 가린 정체 채널을 안 쓴다** | predictor 는 문맥 encoder 가 가린 튜블릿에 실은 정체 (62–66 % 판독) 를 쓰지 않는다. 마지막으로 보인 튜블릿에서 가져온다 | 가린 문맥 튜블릿 토큰만 다른 물체 것으로 바꿔 넣으면 p 가 거의 안 움직인다 (π가림 ≤ 0.1). 마지막 보인 튜블릿을 바꾸면 크게 움직인다 (π끝 ≥ 0.5) | π가림 ≥ 0.3 → 그 채널을 쓴다. 실패는 정체가 아니라 자리 쪽이다 |
| **H2-3 PFT 이득 = 운반** | PFT 의 late 이득은 판독 정렬이 아니라 정체 대비를 참 자리로 옮긴 것이다 | PFT p 의 late 대비 에너지가 O참 으로 옮겨가고 (m참 이 릴리즈의 2 배 이상), 최선 이동 s* 가 참 이동의 50 % 넘게 따라간다 | ρ 만 오르고 자리 질량 · s* 는 그대로 |

- vast 반례 둘 (정답 토큰 판독기 감독 · 정체 개념 더하기) 이 이미 H2-0 쪽이다 (문서값). 이번에 새로운 것은 **같은 표본 안에서 "읽힘" 과 "자리" 를 따로 켜는 것** (E7) 과 **어느 문맥 튜블릿에서 정체를 가져오나** (E8) 다.

## 4. Q3 — 경쟁 가설 (PFT 비전이 = 외우기?)

| id | 진술 | 참이면 보일 것 | 거짓이면 보일 것 |
|---|---|---|---|
| **H3-M 운동 · 시간 척도 외우기** | PFT 는 VOBench 의 샘플당 속력 · 운동 꼴 (등속 · 가속 · 경사) 분포에 맞춰졌다 | 보폭 2 (샘플당 속력 ×2/3) 변환에서 PFT 이득 유지율 ≤ 0.5. v11 (다른 속력 · 가림막 폭) late 이동에서 이득 ≈ 0 | 보폭 변환 유지율 ≥ 0.8 |
| **H3-T 가림 시점 · 창 배치 외우기** | 이득은 "가림이 문맥 끝 · 미래 앞에 대칭으로 걸린다" 는 배치에 묶여 있다 | 창 이동판 (가림이 문맥 끝에서 끝남) 과 v11 k = 4 (학습에 없던 가림 길이) 에서 이득이 사라진다 | 창 이동판 유지율 ≥ 0.8 |
| **H3-A 외형 · 장면 외우기** | 이득은 본 물체 · 본 색 · 본 장면에 묶여 있다 | 처음 보는 물체 PFT 의 이득이 안 본 모양 · 색 쌍에서 본 쌍의 절반 이하. 색상 회전 · 잘라 옮기기에서 이득이 사라진다 | 안 본 쌍 이득 ≈ 본 쌍 이득 (비 ≥ 0.8) |
| **H3-G 능력은 옮겨지나 벤치가 안 잰다** | PFT 는 옮겨지는 운반 능력을 배웠다. 외부 벤치 총점이 안 오르는 것은 그 능력을 재는 칸이 작거나 leakage 가 크기 때문이다 | v11 · v11_realistic late 이동 A 가 PFT 로 +20 pt 이상 오른다. IntPhys 1 의 '이동 + 가림' 칸은 오르고 하락은 다른 칸에서 난다 | 가까운 세트 late A 도 안 오른다 |
| **H3-F 분포 밖 일반 예측 저하** | PFT 가 분포 밖 영상의 예측 자체를 나쁘게 만든다 (망각) | 분포 밖 가능 영상의 평균 surprise 가 1.05 배 넘게 오른다 (네 곳 중 셋 이상). 분포 안은 내려간다. 하락이 가림과 무관한 칸에 몰린다 | 분포 밖 비 ≈ 1 (0.98–1.02) |

- 가설은 배타가 아니다. 특히 H3-F 는 다른 넷과 함께 참일 수 있다.
- **좌우 반전과 시작 프레임 이동은 PFT 학습 증강에 이미 있어 시험이 아니다.** 이 둘은 빼고 다른 변환을 쓴다.
- split v2 test 는 운동 · 속도 칸이 train 과 같다. 그래서 "궤적 외우기" 는 split v2 test 점수로 가를 수 없다. 변환 · 가까운 세트로만 가른다.

## 5. 실험

### 5-0. 공통 규칙

- **split 하나로 통일**: VOBench split v2 (장면 설정 묶음 50 / 50). 판독기 학습 · 사상 맞춤은 train block, 평가는 test block. PFT 는 train block 으로 학습됐으므로 PFT 수치는 test block 만 쓴다. 릴리즈의 파라미터 없는 측정 (E2 · E8) 은 모든 block 을 쓴다.
- 판독기 · 사상 학습에는 가능 변이만 쓴다 (CLAUDE.md §1-4). 채점은 matched pair, A / B 방향 병기, 복사 기준선 Δ.
- primitive · realistic 을 따로 낸다. realistic 의 색 · 결합 정확도는 다수 클래스 함정 (원색 80 %) 때문에 쓰지 않는다. realistic 은 모양만 쓴다.
- 통계: block 단위 bootstrap 2,000 회. 짝 비교는 같은 재표집으로 한다. 한 가족 (예: 사다리 7 단) 안에서 Holm 보정. 캐시 재채점은 정밀도 잡음이 있다 (v11 에서 쌍 1.5 % 뒤집힘, 문서값). 그래서 |Δ| < 1 pt 는 해석하지 않는다.
- 학습된 자 (판독기 · 사상) 마다 세 가지를 같이 낸다: held-out 정확도 · encoder 대조 · 파라미터 없는 교차검증 (E2).
- 그림 라벨은 영어. 결과는 이 폴더의 `results/` 아래에 둔다 (부록).

### E2. 쌍 차이 지도 — Q1 의 파라미터 없는 판정 [X1] — GPU 1 장 (메모리 용) · 약 45 분

**가르는 것**: H1-S · H1-A · H1-R · H1-P · H1-E · H1-0, 그리고 E8b (H2-3).

**어떻게**: 모양 · 색 위반 block (정체 대비) 과 permanence block (존재 대비 = 물체 − 빈) 마다, 걸음 t 마다:
- Δh_t = h_A,t − h_B,t, Δp_t = p̃_A,t − p̃_B,t (모두 256 × 1280).
- 대조군 (S5): 같은 block 의 가린 튜블릿 h 로 Δh^가림 을 만들고 p̃ 자리에 넣는다.
- 기준 지도: 마지막으로 보인 문맥 튜블릿 t끝 의 Δh_t끝 · Δz_t끝.

| 지표 | 공식 | 무엇을 보나 |
|---|---|---|
| 크기 비 ρ | ‖Δp_t‖ / ‖Δh_t‖ (전 칸). 물체 영역판 ρ_O 도 낸다 | 판독기가 보는 대비의 크기 |
| 자리 맞춘 방향 κ이동 | max_{s∈S} cos(Δp_t, T_s Δh_t). S = 가로 ±9 · 세로 ±3 칸. s* = 최선 이동 | 자리를 빼고 본 방향 |
| 자리 고정 방향 κ고정 | cos(Δp_t, Δh_t) | 방향 + 자리 |
| 모은 부호 방향 κ모음 | cos(Σ_{c∈Op} Δp_t,c , Σ_{c∈O참} Δh_t,c) | 칸 하나로 모은 정체 부호의 방향 |
| 메아리 κ끝 | max_s cos(Δp_t, T_s Δh_t끝) (Δz_t끝 판도) | 마지막 문맥 대비와 닮음 |
| 번짐 | 유효 칸 수 N(Δ) = (Σ_c e_c)² / Σ_c e_c². 비 N(Δp) / N(Δh) | 대비가 몇 칸에 퍼졌나 |
| 자리 질량 | m_X = Σ_{c∈O_X} e_c / Σ_c e_c, X ∈ {참, 끝, 숨, 나머지}. 균등 기준 9/256 = 0.035 | 대비가 어디 있나 |
| 주성분별 크기 | h 토큰 주성분 u_j (train) 에서 r_j = E[(u_jᵀΔp)²] / E[(u_jᵀΔh)²]. 지수 = 중앙값 r (분산 위 10 %) ÷ 중앙값 r (아래 50 %) | 등방 수축 vs 특정 방향 수축 |
| 시점 어긋남 τ* | p̃_t 와 L1 이 가장 작은 h_t′ 의 t′ (물체 영역) | p 가 어느 시점의 h 를 닮았나 |
| 정규화 | κ̂ = (κ − κ바닥) / (κ천장 − κ바닥). κ천장 = κ이동(Δh_t, Δh_t+1) (같은 block · 한 걸음 차 참). κ바닥 = κ이동(Δp_b, Δh_b′) (같은 조건 · 다른 물체 쌍의 block b′, 같은 탐색 폭) | 탐색이 cos 를 부풀리는 몫을 뺀다 |

**출력**: 시나리오 S1–S6 × objset × 운동 (정지 / 이동) × 걸음별 표. 모델 = 릴리즈 (모든 block) · 릴리즈 + PFT (test block).
**판정**: §2 판정표의 왼쪽 열. E8b (H2-3): PFT 에서 late 의 m참 이 릴리즈의 2 배 이상이고 s* 가 참 이동의 50 % 넘게 따라가면 "PFT 이득 = 운반".
**두 결과의 문장**: 등방 수축이면 "p 의 정체 대비는 h 와 같은 방향인데 ρ 배로 작다". 회전이면 "같은 크기인데 κ̂ 만큼 다른 방향이다". 자리면 "대비는 맞는데 마지막 본 자리에 N 칸으로 퍼져 있다". 어느 쪽이어도 문장이 선다.

### E3. 판독기 다시 맞춤 (split v2) [X1] — GPU 2 장 · 약 40 분 (E2 와 동시)

h 판독기 · p 판독기 · 같은 시점 판독기 (t8 · t11 · t15) 를 split v2 train 으로 objset × 시드 2 개 학습한다. 설정은 R1 판독기와 같다 (35 epoch).
late 안 ridge (출력 블록 평균 · 참 자리) 와 **복사 판독** (late 영상 마지막 문맥 튜블릿 LN(z) 위 같은 ridge) 도 낸다.
**관문**: h → h ≥ 85 %, h → p t8 ≥ 75 %, h → p t15 ≤ 40 %. R1 의 꼴이 재현돼야 E4 로 간다. 수준이 다르면 split 차이로 적는다.
**자 검증**: held-out (test block) · encoder 대조 (h → h) · 파라미터 없는 교차검증 (E2).

### E4. 정렬 사다리 — Q1 의 학습된 판정 [X1] — GPU 2 장 · 약 1.5 시간

**맞춤 데이터**: split v2 train block · 보임 조건 · t8–t15 중 참에서 물체가 보이는 걸음 · 모든 칸의 (p̃, h) 짝. objset 당 252 영상 × 8 걸음 × 256 칸 ≈ 52 만 토큰 (가린 걸음을 빼면 조금 적다). 맞춤은 "전 걸음 공유" 와 "걸음별" 두 판으로 한다.

| 단 | 사상 x̂ = M(p) | 자유도 | 가리키는 가설 |
|---|---|---|---|
| L0 | p 그대로 | 0 | 기준 |
| L1 채널별 평균 · 분산 | x̂_d = m^h_{t,d} + (s^h_{t,d} / s^p_{t,d})(p̃_d − m^p_{t,d}) | 걸음 · 채널마다 2 | 크기 (채널별) |
| L2 전역 대비 | x̂ = μ_{t,c} + γ_t (p̃ − μ^p_{t,c}), γ_t = RMS(h − μ) / RMS(p̃ − μ^p) | 걸음마다 1 | H1-S |
| L2b 주성분별 대비 | x̂ = μ + U diag(σ^h_j / σ^p_j) Uᵀ (p̃ − μ^p), U = h 주성분 | 1280 | H1-A |
| L3 직교 Procrustes | R = argmin_{RᵀR=I} ‖(H − μ) − γ(P̃ − μ^p)R‖, x̂ = μ + γ(p̃ − μ^p)R | 회전 하나 | H1-R |
| L4 ridge 선형 | x̂ = μ + (p̃ − μ^p)W, λ 는 train 의 20 % block 으로 고른다 | 1280² | 선형 일반 |
| L5 토큰별 작은 MLP | x̂ = L4 + f(p̃), f = 1280 → 2560 → 1280 GELU, L1 손실, 3 epoch | 약 650 만 | 비선형 |
| L-자리 | p̃ 지도를 E2 의 s* 만큼 평행 이동 (빈 칸 = μ) | 0 | H1-P (자리) |
| L6 공간 사상 (남으면) | 걸음 하나의 256 토큰 전체를 받는 2 층 transformer (폭 512) | 약 600 만 | H1-P (번짐) |

**대조**: (a) 섞은 짝 L4 (같은 조건 · 같은 걸음의 다른 block 영상과 짝지어 맞춤 — v11 에서 12–14 % 로 떨어졌던 대조). (b) 사상을 h 에 걸었을 때 h 판독기가 85 % 넘게 유지되나 (사상이 h 를 망치지 않는지). (c) L4 의 극분해 W = U·P: 회전 성분 평균 cos = tr(U)/1280, 크기 성분 P 의 고유값 중앙값 · 10 / 90 %.
**late 판 (H1-C)**: late train block 의 재등장 걸음 짝으로 L3 · L4 를 따로 맞춰 late test 에 건다.
**평가**: 고정 h 판독기 (E3) 의 정확도를 x̂ 에서 잰다. S1 · S2 (걸음별) · S3 (같은 시점 판독기) · S4 (late 재등장 · late 가림) · 정지 대조. 결합 (primitive) · 모양 · '없음' 비율 · 회복률 R. late 의 천장은 late 안 판독기를 쓰고, 판독기 종류가 달라 R 대신 절대값을 함께 적는다.
**판정**: §2 판정표의 오른쪽 열. 한 단의 증분 ≥ 0.2 R 이면 그 단을 "몫이 있다" 로 적는다.
**두 결과의 문장**: L2 가 되살리면 "h 판독기 실패의 대부분은 대비가 작아서다 — 방향은 h 와 같다". L3 에서야 되살리면 "방향이 다르다". 아무 단도 못 하면 "보임에서 맞춘 어떤 사상도 late 의 꼴을 h 로 못 옮긴다".

### E5. 판독기 attention 진단 [X1] — GPU 1 장 · 약 20 분 (남으면)

h 판독기 질의 attention (머리 16 개) 을 h · p · x̂(L2 · L3 · L4) 에서 잰다. 물체 영역 질량 (O참 · Op · O끝) 과 정규화 엔트로피 H / ln 256 을 본다.
**판정**: H1-P 면 p 에서 물체 영역 질량이 균등 (0.035) 근처로 내려가고 엔트로피가 오른다. H1-S 면 질량은 h 의 0.7 배 넘게 남는데 '없음' 으로 답한다.

### E6. 정렬 공간 VoE 재채점 — Q2 (a)(b) [X1] — GPU 1 장 · 약 20 분 (E4 산출물 재사용)

**공식**: s_M(i) = mean_{t,c,d} |M(p)_{i,t,c,d} − h_{i,t,c,d}| (t8–t15 전 칸, 표준 채점과 같다). 짝 (pos, imp) 은 같은 문맥이라 같은 p 를 쓴다. s_M(imp) > s_M(pos) 면 정답.
**낸다**: late (전체 · 이동 · 위반별) × A / B. 보임 조건의 부작용. 복사 기준선 (공식 복사 배열, 같은 h 공간) 대비 Δ. 사상 L0 · L2 · L3 · L4 · L5 (+ L6).
**사전 예측**: v11 에서 같은 계열 사상이 late +3.2, ramp late +0.9 (0 포함) 였다. 그래서 VOBench late 도 Δ ≤ +5, 이동 A ≤ 10 % 를 예상한다.
**판정**: H2-1 = 이동 A 가 +30 pt 이상 (CI 하한 > +10) 이고 B 가 10 pt 넘게 무너지지 않으며 복사를 넘는다. H2-0 = 모든 사상에서 이동 A Δ ≤ +5.
**같이 내는 판독**: 같은 사상에서 h 판독기의 late 판독 (E4). "판독은 오르는데 A 는 그대로" 면 H2-0 의 직접 증거다.
**주의**: L2 는 v11 에서 기각된 "균등 증폭" (천장 51–65 %) 과 같은 계열이다. 방법 제안이 아니라 그 재현으로만 읽는다.

### E7. 주입 — Q2 (d) 읽힘과 자리를 따로 켠다 [X1] — GPU 1 장 · 약 25 분

late 영상의 p 에서 물체 영역만 바꾼다. 나머지 칸은 원래 p 그대로다.

| 판 | 물체 영역에 넣는 것 | 넣는 자리 | 정체 | 자리 |
|---|---|---|---|---|
| d0 | 없음 (원래 p) | — | ✗ | ✗ |
| d1 상한 | 참 미래 h_A,t (정답) | O참 (걸음마다) | ✓ | ✓ (정답 사용 — 상한으로만) |
| d2 읽힘만 | 마지막 보인 문맥 튜블릿의 LN(z) 물체 칸 (문맥만 씀) | O끝 (모든 걸음) | ✓ | ✗ |
| d3 읽힘 + 운반 | d2 와 같은 칸 | O참 으로 옮김 | ✓ | ✓ |
| d4 자리만 | 같은 block B 물체의 같은 칸 (다른 정체) | O참 | ✗ (다른 물체) | ✓ |

- 영역 크기는 물체 외곽 상자 + 1 칸 (realistic 큰 물체 대응).
- d2 · d3 은 문맥 encoder 출력만 쓴다. 32 장 h 는 미래 프레임을 보고 만들어져 누수가 있으므로 쓰지 않는다.
- **같이 잰다**: d2 · d3 에서 h 판독기 판독이 80 % 넘게 되살아나는지 확인한다 ("이식 회복" 이 구성상 참인지).
**판정 (H2-0)**: d2 의 이동 A ≤ 복사 + 5 pt 이고 d3 의 이동 A ≥ 70 % 면 **"읽힘만으로는 안 되고 자리가 필요하다"**. d2 도 복사 + 20 pt 넘게 오르면 H2-0 기각.
**d4 로 더 가르는 것**: permanence 의 A 가 d4 ≈ d3 이면 사라짐 판정은 "무엇이" 가 아니라 "어디에 무언가" 로 풀린다. 모양 · 색 위반의 A 는 d4 에서 낮아야 한다 (정체가 필요).
**두 결과의 문장**: "h 판독기로 읽히는 정체를 마지막 본 자리에 두면 사라짐 A 는 X %, 참 자리로 옮기면 Y %". 어느 값이어도 Q2 에 답한다.

### E8. 문맥 토큰 바꿔 넣기 — Q2 (c) 인과 [X1, 시간이 모자라면 X2] — GPU 1 장 · 약 45 분

late 모양 · 색 block (objset 당 60 개, 모든 block) 에서 A 영상의 문맥 encoder 출력 중 튜블릿 집합 J 의 토큰을 같은 block B 영상 (같은 궤적 · 다른 물체) 의 것으로 바꿔 predictor 에 넣는다.
- J ∈ {∅, 가린 문맥 튜블릿, 마지막 보인 튜블릿, 보인 튜블릿 전부, 전부}. permanence block 에서는 B = 빈 장면이라 "지우기" 가 된다.
- **공식**: π_J = ⟨vec(p_J − p_A), vec(p_B − p_A)⟩ / ‖vec(p_B − p_A)‖² (미래 전 칸, p̃). 물체 영역판도 낸다. late 안 ridge (원래 late p 의 train block 으로 학습) 가 p_J 를 B 의 모양으로 읽는 비율도 낸다.
- **건전성**: π_∅ = 0, π_전부 = 1 (±1e-3). 안 맞으면 멈춘다.
- **판정**: H2-2 = π가림 ≤ 0.1 이고 π끝 ≥ 0.5. 기각 = π가림 ≥ 0.3.
- 보임 조건 block 에서도 같은 것을 한다 (마지막 튜블릿 바꾸기) — 대조.
- **두 결과의 문장**: "predictor 미래의 정체는 문맥 encoder 가 가린 튜블릿에 실은 정체를 따라간다 / 따라가지 않는다 (π = …)".

### E9. Q3 — 기존 산출물 분석 [X2] — CPU · 약 50 분

1. **전이 행렬**: 행 = PFT 데이터 {없음, v11, IntPhys 1, IntPhys 2 쌍, VOBench (+gravity), VOBench 처음 보는 물체}, 열 = {VOBench split v2 test (late · 전체), v11 split test, IntPhys 1, GRASP, InfLevel continuity, IntPhys 2}. 산출물에서 채우고 빈 칸 목록을 낸다. 15 분 안에 채울 수 있는 칸은 E11 에서 채운다.
2. **분포 밖 예측 오차 (H3-F)**: 벤치마다 가능 영상의 평균 surprise 를 같은 창에서 비교한다. ε = s̄_PFT / s̄_릴리즈. 분포 안 (VOBench test) 대조를 같이 낸다.
3. **IntPhys 1 칸 분해 (H3-G)**: 릴리즈 → PFT 에서 뒤집힌 쌍을 성질 (O1–O3) × 운동 × 가림 칸으로 센다. 180 쌍 중 10 쌍 (5.6 pt) 하락이 어디서 났나. 칸마다 n 이 작아 판정은 "어느 칸에 몰렸나" 까지만 한다.
4. **갱신 기하**: 층 · 행렬마다 ‖ΔW‖ / ‖W‖. PFT 끼리 갱신의 cos (같은 데이터 기준: VOBench 판 · VOBench+gravity 판 · 처음 보는 물체 판; 다른 데이터: v11 · IntPhys 1 · IntPhys 2 쌍).
**판정**: H3-F = ε ≥ 1.05 가 분포 밖 네 곳 중 셋 이상, 분포 안 ε < 0.95. 갱신: 다른 데이터 cos ≤ 0.2 × 같은 데이터 cos 면 "데이터별 갱신" (외우기와 맞지만 단독 증거는 아니다).

### E10. 처음 보는 물체 PFT 채점 (H3-A) [X2] — GPU 2 장 · 약 20 분

- 관문: 이 split 의 test 프레임이 원본 VOBench 프레임과 같은지 표본 해시로 확인한다. 같으면 릴리즈 · 복사 결과를 원본 채점에서 재사용한다.
- 채점: 처음 보는 물체 PFT 를 그 test (844 쌍) 에. 빠진 범주별 (본 것 56 · 색 180 · 모양 204 · 메시 272 · 둘 다 132 쌍) 과 late 로 나눈다.
- 이득 G = PFT − 릴리즈 (같은 쌍). 참고로 새 PFT 의 split v2 test 이득도 적는다 (다른 시험 세트라 맥락으로만).
- ⚠️ 이 test 의 422 block 중 207 개가 split v2 train 에 있다. 그래서 새 PFT 를 이 test 에 걸지 않는다 (누수).
**판정**: H3-A = 안 본 범주 이득 ≤ 0.5 × 본 범주 이득 (본 것이 56 쌍뿐이라 "색만 안 봄" 을 기준으로도 본다). 거짓 = 비 ≥ 0.8.

### E11. 가까운 세트 전이 (H3-G vs H3-M · T) [X2] — GPU 4 장 · 약 1.2 시간

- v11 split test 의 부분집합 (CPU 로 색인 생성): vanish 위반 × {moving_occlusion (경사) · moving_occlusion_flat · static_occlusion · moving_visible · moving_visible_flat}, k = 0–4. 조건당 test 448 영상. v11 은 VOBench primitive 의 'v11' 배경과 같은 장면 꼴이다. 가림막 폭 · 속력 · 물체 (pyramid 포함) 가 다르다. **k = 4 는 PFT 학습에 없던 가림 길이다** (H3-T 보조).
- v11_realistic (vanish 720 쌍) 전부.
- 모델: 릴리즈 · 릴리즈 + PFT · vast AR · vast AR + PFT. 복사 기준선. 릴리즈 · 복사의 기존 결과가 같은 영상이면 재사용한다.
**판정**: late 이동 사라짐 A 가 PFT 로 +20 pt 이상 (CI 하한 > 0) 이고 보임 칸이 −5 pt 안이면 H3-G 지지. +5 pt 이하면 H3-M · T · A 쪽 (어느 것인지는 E10 · E12 가 가른다).
**두 결과의 문장**: "VOBench 로 배운 운반이 같은 생성 꼴의 다른 세트 (v11) late 에서 A X → Y" — 어느 값이어도 Q3 의 핵심 문장이다.

### E12. VOBench 변환 시험 (축별 외우기) [X2] — 프레임 준비 CPU 40 분 (E9 · E11 과 동시) + GPU 4 장 · 약 1.5 시간

split v2 test 1,440 영상을 바꿔 릴리즈 · PFT · (T1 · T5 는) 복사를 채점한다.

| 변환 | 방법 | 바뀌는 축 | 주의 |
|---|---|---|---|
| T0 항등 | 우리 프레임 작성기로 원본을 그대로 다시 씀 | — | **작성기 관문**: 공식 per_video surprise 와 상대 1e-3 안, 쌍 판정 99 % 일치 |
| T1 보폭 2 | 원본 30 fps 에서 2 장 간격, 문맥 끝을 원래와 같은 raw 45 에 맞춤 (raw 15–77) | 샘플당 속력 ×2/3 · 문맥 시간 ×2/3 · 가린 샘플 수 ×1.5 | 보폭 4 는 원본 96 장 안에 안 들어가 못 한다 |
| T2 시간 역재생 (관문 통과 시) | 프레임 f → 95 − f (링크). 짝을 다시 맺는다: (역 pos_a, 역 imp_ba) · (역 pos_b, 역 imp_ab) | 운동의 시간 부호 (가속 ↔ 감속) | **관문**: imp_ab 의 뒤 48 장이 pos_b 와 픽셀 단위로 같아야 짝 문맥이 같다. 다르면 뺀다 |
| T3 잘라 옮기기 | 448 px 창을 (0,0) · (64,0) · (0,64) · (64,64) 에서 잘라 256 으로 | 화면 자리 · 크기 (×1.14) | 물체가 창 밖으로 나가는 block 은 네 창 모두에서 뺀다 |
| T4 색상 회전 | HSV 색상 +180° | 외형 (색) 분포 | 색 위반 쌍의 색 차 (≥ 60°) 는 유지된다 |

- 좌우 반전 · 시작 프레임 이동은 PFT 증강에 있어 하지 않는다.
- **공식**: 이득 G(T) = acc_PFT(T) − acc_릴리즈(T) (late 전체 · late 이동 A · 전체). 유지율 r_T = G(T) / G(T0).
- **유효 조건**: 릴리즈 자신의 전체 정확도 변화가 ±10 pt 안이고, 복사가 크게 뛰지 않는다 (누수 점검). 넘으면 그 변환은 "과제 자체가 바뀜" 으로 적고 해석하지 않는다.
**판정**: r_T ≤ 0.5 (CI 상한 < 0.8) 면 그 축을 외웠다. r_T ≥ 0.8 (CI 하한 > 0.5) 면 그 축은 아니다. T1 → H3-M, T5 → H3-T, T3 · T4 → H3-A.

### E13. (선택) PFT epoch 곡선 [X2] — GPU 4 장 · 약 1.5 시간

PFT e5 · e10 · e15 · e20 · e25 · e30 을 VOBench test late 와 IntPhys 1 (공식 창 둘) 에 건다. 분포 안 이득과 분포 밖 하락이 같이 생기나 (간섭), 늦게 생기나 (후반 외우기).

### E14. (R2) 분포 밖 끌림

v11 vanish late 이동 block 의 쌍 차이 지도 (물체 − 빈) 로 PFT 가 물체를 얼마나 옮기나 (s*) 를 잰다. 그 거리가 v11 의 참 이동이 아니라 VOBench 의 전형 이동 (중앙값 5.7 칸) 에 가까우면 "VOBench 운동 쪽으로 끌린다" (H3-M).

## 7. 사용자 결정이 필요한 것

1. **다시 학습해야 답이 나오는 Q3 실험 (설계만)** — 각 약 1 시간, GPU 4 장 (처음 보는 물체 PFT 는 30 epoch 학습에 약 35 분 걸렸다, 학습 기록 시각에서 셈).
   - (a) **late 를 뺀 PFT**: visible · early · mid 만 학습 → late 시험. late 이득이 생기면 "운반 능력", 안 생기면 "late 배치 외우기". Q3 를 가장 직접 가른다.
   - (b) 운동을 반 나눈 PFT: flat_vel · flat_acc · ramp_down 학습 → flat_dec · ramp_up · flat_static 시험.
   - (c) 가림 길이를 나눈 PFT: k1–2 학습 → k3 시험.
   - (d) 보폭을 섞은 PFT (보폭 2–3): E12-T1 에서 이득이 사라지면, 데이터 다양성으로 막히는지.
2. **수축 계수 표기** — p ≈ a·h + b·μ 의 회귀 계수는 인용 금지된 α 분해와 꼴이 같다. 기본값은 "JSON 에만 두고 문서에는 파라미터 없는 대비 비 ρ 만" 이다. 써도 되나.
3. **vast AR 토큰 단위 Q1** (AR 굴림 토큰 추출 + 블록 공간 h 판독기 재학습, GPU 약 1.5 시간) 을 R2 에 넣을지.
4. E8 (Q2 인과) 을 [X2] 여유분으로 돌려도 되나 (역할 경계).
5. vast 문서 7 개 가져오기 — 이 조사 범위 밖이다.

## 8. 하지 않는 것 · 이미 답이 있어 반복하지 않는 것

- 정렬 사상 · 주입은 **측정 도구**다. "frozen 위에서 닫힌다" (09-06 폐기) 나 방법 제안으로 쓰지 않는다.
- 수축의 원인으로 목적함수를 걸지 않는다 (discussion 한 문단).
- 좌우 반전 · 시작 프레임 이동은 PFT 증강에 있어 Q3 시험이 아니다.
- realistic 의 색 · 결합 수치는 쓰지 않는다 (원색 80 %).
- "세기를 키우면 된다" 는 v11 에서 기각됐다 (천장 51–65 %). E6 의 L2 는 재현으로만 읽는다.
- vast 의 개념 벡터 빼기 · 더하기 막대는 선형 판독기라 수학적으로 정해진 결과다. 같은 꼴의 측정을 증거로 쓰지 않는다. 이번 개입 (E7) 은 판독기가 아니라 VoE 채점으로 읽는다.
- 금지 표현: "p 에 정체가 없다" (→ "h 판독기로는 안 읽힌다"), "기억 · state", "중력을 안다", "목적함수 때문이다", α · 보정 · 헤지 계수 인용.

## 9. 계획 시점에 모르는 것

- VOBench late 에서 encoder 가 가려진 물체의 **속도**를 읽는가 — R1 미측정. 이번 계획은 정체 중심이라 넣지 않았다. 쌍 차이 지도는 정체 · 존재 대비만 만든다 (VOBench 짝은 속도가 같다).
- vast AR ep70 의 late 안 판독 — 미측정 (§7-3).
- 캐시 (bfloat16) 와 공식 채점 (float32 + float16 autocast) 의 차이가 VOBench 에서 얼마나 되는지 — E1-G0 이 잰다.
