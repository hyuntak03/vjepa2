# z_analysis — 예측이 만든 물체 표현 분석 (2026-10-25 ~)

> **질문** — 블록 AR · 릴리즈 predictor 가 예측한 미래에서 물체는 왜 사라지나, 예측의 물체 표현은 encoder 표현과 어떻게 다른가.
> **지금까지 답** — 물체를 그릴 줄은 알지만 먼 미래일수록 그 칸의 물체 성분이 encoder 방향에서 벗어나고 작아진다. 예측 길이와 무관하고 얼마나 먼 미래인지에 달렸다.
> **다음** — encoder · predictor 층마다 개념 벡터 (모양 · 색 · 정체 · 방향 · 속력 · 위치) 를 따로 구해 비교한다.

## 용어

| 용어 | 뜻 |
|---|---|
| 블록 | 연속한 2 장 (4 fps 라 0.5 초). 블록 토큰 = 블록 하나를 목표 encoder 에 넣고 학습 계수 없는 LN 을 건 칸별 벡터, shape (256, 1280) |
| 물체 칸 | 그 블록 두 장의 물체 상자 안에 중심이 든 칸 |
| teacher forcing 예측 | 정답 블록 0..b 를 보고 낸 블록 b+1 예측 (한 걸음) |
| 굴린 예측 | 문맥 8 블록에서 시작해 자기 상태를 되먹이며 낸 블록 8..15 예측 (걸음 1..8) |
| 개념 벡터 | 클래스 평균 − 클래스 평균들의 평균 (시나리오 평균을 먼저 뺌), shape (1, D). 클래스 K 개면 (K, D) |
| 재현도 | 데이터를 클립 단위로 반씩 나눠 따로 구한 개념 벡터끼리의 일치 |

## 단서

- ⚠️ (2026-10-26 저녁) 화면 전체 평균 개념 벡터 · 판독은 **물체 토큰의 정체가 아니라 화면 전체 (물체에서 3 칸 이상 먼 토큰) 에 퍼진 정체 신호**를 잰다 (concept_vector_regions.json: 화면 평균 개념 vs 먼 구역 개념 cos 0.99 / 0.98, vs 물체 칸 개념 0.31 / 0.47). 이 신호도 안정적이고 장면을 넘어 일반적이지만 (재현도 0.92 / 0.69), 물체 칸의 정체 개념과는 다른 방향이다. decoder 가 물체를 그리는 문제는 물체 칸 개념으로 봐야 한다.
- ⚠️ 정정의 정정 (2026-10-26) — 한때 "같은 클립에서 구한 encoder vs 예측 개념 cos 는 공통 잡음으로 부풀어 있다 (AR 색 0.77–0.89 → 엇갈린 반쪽 0.51–0.57)" 고 적었다. **틀렸다.** 엇갈린 반쪽 cos 는 반쪽 잡음으로 깎인 값이라 비교 대상이 아니었다. 잡음을 내적으로 걷어 낸 보정 cos 는 같은 클립 cos 와 거의 같다 (AR 모양 0.73–0.85 vs 0.72–0.84, AR 색 0.82–0.92 vs 0.77–0.88). 라벨을 섞은 영 기준에서 같은 클립 cos 가 0.54–0.74 인 것은 사실이지만 (두 공간의 잡음 성분끼리 방향이 비슷하다), 전체 표본 개념 벡터에서 잡음 몫이 작아 값을 거의 움직이지 않는다. 앞판 cos 그림의 결론은 그대로다. 정본 `docs/IDENTITY_CONCEPT_VECTORS_2026-10-26.md`.
- 모양 클래스는 고르지 않다 (train torus 35 %, val sphere 26 %; container 에는 cube · pyramid 가 없다). 모양 정확도의 기준은 1/6 = 17 % 가 아니라 최빈 클래스 약 26 % (val) 로 읽을 것. 장면 종류만으로 모양 37 % (train).
- ⚠️ 정정 (2026-10-26) — "정답 개념 벡터를 빼면 선형 probe 가 우연으로 떨어지고, 목표 개념 벡터를 더하면 77–95 % 로 바뀐다" (빼기 · 조작 결과, 막대 그림) 는 **선형 probe 라면 무엇을 읽든 거의 자동으로 나온다.** 클래스 y 의 평균 출력은 W·(클래스 y 평균) + b 인데, 개념 벡터 = 클래스 y 평균 − 클래스 평균들의 평균 을 빼면 모든 클래스의 평균 출력이 같아진다 (→ 우연). 목표 개념을 더하면 목표 클래스의 평균 출력이 된다. 같은 공간 · 같은 분포에서 개념 벡터와 probe 를 구했기 때문이다. 개념 벡터가 정체를 나르는 방향이라는 증거로 쓰지 말 것 — 계산 일관성 확인일 뿐이다.
- 개념 벡터 (블록 전체 평균) 방향 위 흔들림은 대부분 정체가 아니다: encoder 에서 모양 개념 부분공간 (5 차원) 위 분산 중 모양이 설명하는 몫 16 %, 색 (7 차원) 4 %. 반쪽 재현 cos 는 모양 0.86–0.92, 색 0.57–0.67. encoder–예측 개념 cos 는 같은 클립에서 구해 공통 잡음이 섞이므로 색 cos (0.85–0.89) 는 과대일 수 있다 (재현도 보정 > 1).
- 데이터는 3D 합성 (phys3d_single_v1, 물체 1 개 · 고정 카메라) 이다. 두 모델 모두 이 데이터로 학습한 적이 없다.
