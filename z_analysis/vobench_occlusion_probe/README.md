# VOBench 가림 판독 — 완전히 가린 블록에서 물체 정보가 읽히나 (2026-10-29, 같은 날 속도 · 가속도 추가)

> **질문** — 물체가 완전히 가려진 블록에서, 문맥 encoder · predictor 예측 · 실제 미래의 encoder 표현에 물체 있음 · 모양 · 색 · 속도 · 가속도가 읽히나. predictor 만 덜 읽히나.
> **답** — 물체 있음은 네 표현 모두 가려도 94–98 % 로 읽힌다. 모양 · 색은 가리면 세 표현 모두 같은 만큼 떨어진다 (모양 49–54 %, 색 13–17 %, 우연 수준 17 / 12.5 %). predictor 만의 손실은 이 비교에서 보이지 않는다. 다만 판독기 학습 표본이 90 개라 "이 표본으로는 못 읽는다" 까지만 말할 수 있다. **속도는 가려도 세 표현 모두 R² 0.99 로 읽히고, 물체가 없는 같은 장면에서는 0 이하라 물체 정보다.** 가속도는 가린 블록에서 물체 없는 장면으로도 똑같이 읽혀 물체 정보라고 말할 수 없다 (장면 단서).
> **다음** — late 에서 가림판이 걷힌 뒤의 미래 블록 (2–8) 을 같은 방식으로 읽어, 예측이 물체 정체를 되살리는지 본다. 채점이 무너지는 곳은 거기다.

## 용어

| 용어 | 뜻 |
|---|---|
| 블록 | 모델 입력의 연속 2 장 (원본 30 fps 에서 3 장 간격으로 뽑은 장, 블록 하나 = 0.2 초). 영상 하나 = 문맥 8 블록 + 미래 8 블록 |
| 블록 토큰 | 블록 하나의 칸별 벡터, shape (256, 1280) |
| 문맥 encoder 표현 | 릴리즈 V-JEPA 2 ViT-H 의 문맥 encoder 에 문맥 16 장을 넣고 학습 계수 없는 LN 을 건 것 |
| predictor 예측 | 릴리즈 predictor 가 문맥 encoder 표현에서 낸 미래 블록 토큰 (출력 투영 뒤 1280 차원, 채점 공간) |
| 실제 미래 표현 | target encoder 에 32 장 전부를 넣고 LN 을 건 것의 미래 블록 (채점의 정답) |
| 보이는 블록 · 가린 블록 | 그 블록 두 장 모두 물체가 보임 · 두 장 모두 가림판 뒤 (VOBench 의 장별 가림 기록). 한 장만 가린 블록은 쓰지 않는다 |
| 판독기 | 블록 토큰 (256, 1280) → attention pooling (질의 1 개) → (1, 1280) → 선형 분류 |
| 물체 있음 (obj) | 같은 장면 · 같은 가림판에서 물체가 있는 영상과 없는 영상을 가르는 2 지선다 |
| 속도 · 가속도 | 그 블록 중심에서 물체 화면 위치 (u, v) 의 1 · 2 차 시간 미분, px/s · px/s² (256 px 화면). VOBench 의 장별 위치 기록 (가려진 장도 실제 위치가 있다) 에 블록 중심 ±6 장 2 차 곡선을 맞춘다. 판독기는 출력 2 개 회귀, 점수는 R² (u · v 합침, 0 = 평균만 맞힘) |
| 가속 3 지선다 | 평지 등속 · 가속 · 감속 영상만 놓고 "그대로 / 빨라짐 / 느려짐" 을 고른다. 세 운동은 그 순간 속도가 같아 (≈ 61 px/s) 가속도만 다르다 |
| 빈 장면 대조 | 같은 장면 · 같은 가림판에서 물체만 없는 영상에 같은 판독기를 건 값. 라벨은 같은 묶음의 물체 영상 것. 여기서도 읽히면 판독기는 물체가 아니라 장면을 읽은 것이다 |

## 1. 왜 했나

앞선 분석에서 "predictor 가 가림에서 모양 · 색을 잃는다" 처럼 보이는 결과가 나왔다. 그런데 비교 조건이 맞지 않았다 — 판독기 학습 표본 수, 블록 위치, 영상 구성이 표현마다 달랐다. 조건을 전부 맞춰 다시 잰다.

가설: predictor 예측은 encoder 표현보다 가린 블록에서 물체 정보를 더 잃는다.

## 2. 무엇을 어떻게 했나

- **같은 영상 · 같은 위치**: late k2·k3 는 문맥 마지막 블록과 미래 첫 블록이 함께 완전히 가려진다. 그래서 문맥 encoder 는 문맥 마지막 블록, predictor 예측 · 실제 미래 표현은 미래 첫 블록을 읽는다. 가린 블록 = late k2·k3 영상, 보이는 블록 = 같은 위치에서 물체가 보이는 early · mid k2·3 영상. 네 패널이 같은 영상을 쓴다
- **k = 1 제외**: 블록 하나가 2 장이라 두 장 모두 가려진 블록만 완전히 가린 것이다. k = 1 은 mid · late 에서 가린 두 장이 블록 경계에 걸쳐 그런 블록이 없어서 통째로 뺐다
- **판독기를 따로**: 보이는 블록용 · 가린 블록용 판독기를 따로 학습하고, 각자 자기 범주에서만 시험한다 (정보 존재). (c) 만 예외로, 문맥 encoder 로 학습한 판독기를 predictor 예측에 그대로 건다 (정렬)
- **표본 수**: 모든 패널 · 범주에서 학습 표본 수를 같게 — 물체 있음 36, 모양 90, 색 90. 가린 미래 블록이 late k2·k3 의 120 개 (물체 있음 48 개) 뿐이라 이것이 최대다
- **위치 짝**: 가린 블록 하나마다 같은 위치의 보이는 블록 하나를 짝지어 학습 · 시험한다
- **학습**: 600 걸음 고정 (묶음 16). 영상 묶음 (VOBench block) 단위 5-fold, 씨앗 3 개 (fold 배정 · 표본 뽑기 · 초기화가 바뀐다)
- **대조**: 학습 라벨을 섞은 판독기 (우연 수준이 나와야 한다) · 학습 집합의 다수 클래스를 늘 고르는 기준선
- 가능 변이만 쓴다 (불가능 변이는 라벨과 렌더가 어긋난다)

## 3. 결과 [측정]

시험 정확도 % (95 % CI = 영상 묶음 단위 부트스트랩). 씨앗당 시험 표본 120 개 (물체 있음 48 개).

| 패널 | 보이는 블록: 물체 있음 / 모양 / 색 | 가린 블록: 물체 있음 / 모양 / 색 |
|---|---|---|
| (a) 문맥 encoder, 문맥 마지막 블록 | 95 / 90 / 68 | 95 / 54 / 16 |
| (b) predictor 예측, 미래 첫 블록 | 99 / 95 / 83 | 94 / 49 / 17 |
| (c) (a) 판독기를 (b) 에 | 87 / 69 / 51 | 89 / 28 / 10 |
| (d) 실제 미래 표현, 미래 첫 블록 | 99 / 93 / 60 | 98 / 49 / 12.5 |
| 우연 수준 | 50 / 16.7 / 12.5 | 50 / 16.7 / 12.5 |

가린 블록의 95 % CI: 모양 (a) 44–62 · (b) 39–58 · (d) 41–57 / 색 (a) 11–21 · (b) 12–23 · (d) 8–18.

대조 — 라벨 섞기: 물체 있음 46–54, 모양 8–18, 색 11–16 (전부 우연 수준). 다수 클래스 기준선: 물체 있음 48–50, 모양 8–14, 색 4–10. 판독기 학습 정확도는 전부 100 %.

보충 — 문맥 encoder 를 위치 3–8 의 가린 블록 전부에서 (같은 학습 표본 90 개): 보임 91 / 75 / 50, 가림 87 / 50 / 17. 앞선 실행에서 학습 표본을 약 520 개로 늘리면 가림 100 / 81 / 66 이었다 (설정이 조금 다름, 씨앗 1 개).

## 4. 해석

1. **물체가 있다는 것은 가려도 남는다** [측정]. 네 표현 모두 94–98 %. 가림판 뒤 화면은 두 영상이 거의 같으니, 이 정보는 다른 장면에서 가져온 것이다 (화면 단서가 조금 섞였을 가능성은 아래 단서).
2. **모양 · 색은 가리면 세 표현 모두 같은 만큼 떨어진다** [측정]. 가린 블록에서 모양은 (a) 54 · (b) 49 · (d) 49, 색은 16 · 17 · 12.5 로 CI 가 겹친다. 실제 미래 표현 (d) 도 그 블록에서 같다.
   → **"predictor 가 가림에서 모양 · 색을 날린다" 는 이 비교로 지지되지 않는다.** 가려진 블록의 encoder 표현 자체가 그렇다.
3. **predictor 예측은 문맥 encoder 공간과 일부만 맞는다** [측정]. 문맥 encoder 판독기를 예측에 걸면 보이는 블록에서 87 / 69 / 51 — 예측 자신으로 학습한 판독기 (99 / 95 / 83) 보다 낮다.
4. **표본 수가 결론의 범위를 정한다** [측정 + 이론]. 같은 문맥 encoder 도 학습 표본 90 개면 가린 블록 색이 17 %, 약 520 개면 66 % 다. 그러니 가린 블록에서 우연 수준은 "90 개로는 못 읽는다" 이지 "정보가 없다" 가 아니다. 가린 미래 블록은 120 개뿐이라 predictor 예측 · 실제 미래 표현은 더 늘릴 수 없다.

아직 모르는 것: 가림판이 걷힌 뒤 (late 의 미래 블록 2–8) 예측이 물체 정체를 되살리는지. 채점이 무너지는 곳은 거기다 [추측].

## 4-b. 속도 · 가속도 [측정]

**왜** — 모양 · 색 같은 정체 말고, 움직임 상태 (속도 · 가속도) 도 가린 블록에 남는지 본다. predictor 가 미래를 굴리려면 이것이 필요하다.

**어떻게** — 위와 같은 설계 (같은 영상 · 블록 위치 하나 · 위치 짝 · 보임 / 가림 판독기 따로 · 씨앗 3 × 5-fold · 600 걸음). 바뀐 것:
- 모양 · 색 라벨이 필요 없어 realistic 물체 영상도 쓴다 → 가린 미래 블록 120 → 240 개. 학습 표본 속도 · 가속도 180, 가속 3 지선다 90
- 대조를 하나 더 — 빈 장면 대조 (용어 참고)
- 운동 라벨 점검: 정지 0, 등속 61 px/s · 가속도 0, 가속 / 감속 ±29 px/s², 경사는 대각선. 같은 운동이면 영상끼리 값이 거의 같아 (6 무리) **속도 · 가속도 R² 는 사실상 운동 구분이다.** 가속 3 지선다가 순수 가속도 시험이다

**결과** — 점수 % (속도 · 가속도 = R², 3 지선다 = 정확도). 괄호 = 빈 장면 대조.

| 패널 | 보이는 블록: 속도 / 가속도 / 3 지선다 | 가린 블록: 속도 / 가속도 / 3 지선다 |
|---|---|---|
| (a) 문맥 encoder, 문맥 마지막 블록 | 99.7 (−10) / 99.7 (54) / 100 (50) | 99.0 (−1) / 99.9 (**99**) / 100 (**97**) |
| (b) predictor 예측, 미래 첫 블록 | 99.6 (−15) / 99.7 (43) / 100 (43) | 99.2 (−11) / 99.3 (**99**) / 100 (**100**) |
| (c) (a) 판독기를 (b) 에 | 51 / 88 / 85 | 16 / 78 / 97 |
| (d) 실제 미래 표현, 미래 첫 블록 | 99.7 (−27) / 99.7 (53) / 100 (35) | 98.5 (−14) / 97.7 (**96**) / 100 (**97**) |
| 우연 수준 | 0 / 0 / 33 | 0 / 0 / 33 |

라벨 섞기 대조: 속도 R² −19 ~ −64, 가속도 −44 ~ −73, 3 지선다 24–41 % (우연 수준). (c) 가린 블록 속도의 95 % CI 는 −16 ~ 35.
빈 장면 시험 표본은 작다 (씨앗당 속도 · 가속도 48 / 24 개, 3 지선다 24 / 12 개).

**해석**
1. **속도는 가려도 남고, 그것은 물체 정보다** [측정]. 세 표현 모두 가린 블록에서 R² 0.985–0.992. 물체 없는 같은 장면에서는 0 이하다. 가린 블록 화면에는 물체가 없으니, 속도는 다른 장면에서 시간 attention 으로 옮겨 온 것 (encoder) 이거나 문맥에서 예측한 것 (predictor) 이다.
2. **predictor 예측의 속도는 문맥 encoder 와 다른 방식으로 담긴다** [측정]. 문맥 encoder 판독기를 예측에 걸면 보이는 블록 R² 0.51, 가린 블록 0.16 (CI 가 0 을 포함). 예측 자신으로 학습하면 0.99 다. 정보는 있고 배치가 다르다.
3. **가린 블록의 가속도는 물체 정보라고 말할 수 없다** [측정]. 물체가 없는 같은 장면에서도 R² 0.96–0.99, 3 지선다 97–100 % 로 똑같이 읽힌다. 보이는 블록에서는 빈 장면 값이 35–54 로 떨어지니 그쪽 판독은 물체에서 온다.
   장면이 가속도를 드러내는 이유 [추측]: VOBench 는 묶음마다 가림판 자리를 그 궤적의 가림 구간에 맞춰 놓고, 경사 운동에는 경사면이 있다. 같은 순간 속도에서 가속 · 감속 영상은 물체가 지나는 자리가 달라 가림판 자리도 다르다.

**이 데이터로 못 하는 주장**: 가린 블록에서 "predictor 가 가속도를 안다". 장면 단서를 끊으려면 가림판 자리가 운동과 무관한 영상이 필요하다.

## 4-c. late k2 블록별 — 문맥 1–16 장 · 예측 17–32 장 (2026-10-29) [측정]

![late k2 블록별](figures/late_k2_ctx_fut.png)

**어떻게** — 시험 영상 = late k2 (15 · 16 장과 17 · 18 장이 가림판 뒤). 판독기는 블록마다 따로, 전 조건 영상 (모양 · 색 600, 속도 1,200) 으로 영상 묶음 단위 5-fold × 씨앗 3.
(a) 문맥 encoder 의 문맥 블록 b 로 학습 · 시험 / (b) predictor 미래 블록 b 로 학습 · 시험 / (c) 문맥 encoder 블록 8 개를 모아 학습한 판독기 하나를 predictor 미래 블록에 그대로.
위 4–4-b 절과 달리 학습 표본 수를 표현끼리 맞추지 않았다 (블록마다 학습 영상 450–1,000).

| | (a) 문맥 encoder | (b) predictor | (c) 문맥 encoder → predictor |
|---|---|---|---|
| 모양 정확도 | 보이는 블록 97–100, **가린 마지막 블록 76** | 68–85 (가린 첫 블록 71) | 16–28 (우연 수준 17) |
| 색 정확도 | 77–95, **가린 마지막 블록 50** | 21–45 (가린 첫 블록 21) | 17–32 (우연 수준 12.5) |
| 속도 R² | 99.5–99.9 (가린 블록 99.5) | 99.1–99.5 (가린 블록 99.4) | 19 → 8 → −10 → … → −113 (멀어질수록 나빠짐) |

비교 — visible 영상에서 (c) 는 모양 99 → 65, 색 99 → 61, 속도 R² 91 → −66 으로 미래 블록이 멀어질수록 떨어진다.

**해석**
1. 문맥 encoder 는 가린 마지막 블록에서도 모양 · 색이 남지만 줄어든다 (76 / 50). 속도는 그대로 (99.5) [측정].
2. predictor 예측은 속도를 미래 전 구간에서 담는다 (R² 0.99). 모양은 68–85, 색은 21–45 로 문맥 encoder 보다 낮다 [측정].
3. 문맥 encoder 판독기는 predictor 예측에 거의 통하지 않는다. late k2 에서 모양 · 색은 우연 수준, 속도는 첫 블록 R² 0.19 에서 멀어질수록 음수로 간다. visible 에서도 첫 블록 근처만 통한다 (모양 99 · 속도 91) [측정]. 예측은 정보를 담되 encoder 와 다른 자리에 놓고, 그 차이가 미래로 갈수록 커진다.

## 4-d. predictor 예측에 색이 정말 없나 — 판독기에 최대 기회를 준 판 (2026-10-29) [측정]

**왜** — 4-c 의 predictor 색 21–45 % 가 판독기 학습 부족 (블록마다 따로, 전 조건으로 학습) 탓일 수 있다.

**어떻게** — 영상당 블록 8 개를 모두 학습 표본으로 써서 판독기 하나를 학습한다 (입력 = 블록 하나 (256, 1280), 블록 위치 섞음, 영상 180 × 8 = 1,440 표본, 2,000 걸음).
학습 · 시험 모두 한 무리 안에서: late (k1·2·3) / early+mid (같은 수 180 영상, 대조). 블록별 정확도와 영상 단위 정확도 (8 블록 판정의 log-확률 합) 를 낸다.
같은 절차를 실제 미래 표현 (target encoder) 에도. 씨앗 3 × 영상 묶음 단위 5-fold. 라벨 섞기 대조 (영상 단위로 섞음).

| | late: 블록 1–8 | late: 영상 단위 | early+mid: 영상 단위 |
|---|---|---|---|
| predictor 색 | 27–31 (평평) | **30** | 93 |
| 실제 미래 색 | 56 (가린 블록 1) → 90–97 | 98 | 96 |
| predictor 모양 | 69–76 | 75 | 97 |
| 실제 미래 모양 | 71 (가린 블록 1) → 94–99 | 99 | 99 |

라벨 섞기: 11–18 % (우연 수준 색 12.5 · 모양 17).

**해석**
1. **late 에서 predictor 예측의 색은 판독기에 최대 기회를 줘도 30 % 다** [측정]. 우연 수준 (12.5) 보다는 높아 흔적은 있지만, 같은 절차로 early+mid 예측은 93 %, late 의 실제 미래는 98 % 다. 판독기 · 표본 탓이 아니다.
2. **가림판이 걷힌 뒤에도 돌아오지 않는다** [측정]. 실제 미래는 블록 2 부터 90 % 이상으로 회복하는데, 예측은 블록 1–8 내내 27–31 % 로 평평하다.
3. 모양은 75 % 로 색보다 덜 잃는다 [측정].

## 5. 단서

- 가린 블록은 전부 late 영상, 보이는 블록은 전부 early · mid 영상이다. 같은 위치에서 비교하려면 피할 수 없다 — "가림" 과 "문맥 끝이 가려짐" 이 함께 바뀐다
- 씨앗당 시험 120 개 (물체 있음 48 개): 영상 하나가 0.8 점 (2.1 점)
- 물체 있음의 가린 블록 값에 화면 단서 (그림자 · 가림판 가장자리) 가 섞였는지는 이 실험이 가르지 않는다
- 토큰 캐시는 bf16 (probing 관례). 채점 (fp32 + fp16 autocast) 과 수치가 조금 다를 수 있다
- 속도 · 가속도 라벨은 운동 6 종의 무리라 R² 0.99 는 "운동 종류와 방향을 안다" 이지 "속도 크기를 미세하게 안다" 가 아니다
